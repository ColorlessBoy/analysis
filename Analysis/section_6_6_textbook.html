— 引言 —

本章一直致力于研究实数序列 \((a_n)_{n=m}^\infty\) 及其极限。有些序列收敛到单一的极限， 而另一些则有多个极限点。例如，序列 \[ 1.1,\ 0.1,\ 1.01,\ 0.01,\ 1.001,\ 0.001,\ 1.0001,\ \ldots \] 有两个极限点 \(0\) 和 \(1\)（它们恰好也是下极限和上极限）， 但该序列实际上不收敛（因为上极限和下极限不相等）。 然而，虽然这个序列不收敛，它似乎包含收敛的"成分"； 它看起来是两个收敛子序列的混合，即 \[ 1.1,\ 1.01,\ 1.001,\ \ldots \] 和 \[ 0.1,\ 0.01,\ 0.001,\ \ldots \] 为了使这一概念精确化，我们需要子序列的概念。

6.6.1：子序列

6.6.1（子序列）。 设 \((a_n)_{n=0}^\infty\) 和 \((b_n)_{n=0}^\infty\) 是实数序列。 称 \((b_n)_{n=0}^\infty\) 是 \((a_n)_{n=0}^\infty\) 的， 如果存在一个严格递增的函数 \(f: \mathbb{N} \to \mathbb{N}\) （即对所有 \(n \in \mathbb{N}\) 有 \(f(n+1) > f(n)\)），使得 \[ b_n = a_{f(n)} \quad \text{对所有 } n \in \mathbb{N}. \] 更一般地，称 \((b_n)_{n=m'}^\infty\) 是 \((a_n)_{n=m}^\infty\) 的子序列， 如果存在严格递增函数 \(f: \{n \in \mathbb{N} : n \geq m'\} \to \{n \in \mathbb{N} : n \geq m\}\)， 使得对所有 \(n \geq m'\) 有 \(b_n = a_{f(n)}\)。
补充说明：Lean 中的定义
/-- Definition 6.6.1: b is a subsequence of a -/ abbrev Sequence.subseq (a b: ℕ → ℝ) : Prop := ∃ f : ℕ → ℕ, StrictMono f ∧ ∀ n, b n = a (f n)

Lean 中用 StrictMono f（即 \(f(n+1) > f(n)\) 对所有 \(n\)）来编码"严格递增"。 注意教材中的子序列关系是定义在 ℕ → ℝ 上的谓词， 而非在 Sequence 类型上，这简化了与教材的对应。

6.6.2–6.6.3

6.6.2。 设 \((a_n)_{n=0}^\infty\) 是一个序列，则 \((a_{2n})_{n=0}^\infty\) 是它的子序列， 因为函数 \(f: \mathbb{N} \to \mathbb{N}\) 定义为 \(f(n) := 2n\) 是严格递增的。 注意我们不要求 \(f\) 是满射，虽然它必然是单射（为什么？）。 更非正式地说，序列 \[ a_0,\ a_2,\ a_4,\ a_6,\ \ldots \] 是 \[ a_0,\ a_1,\ a_2,\ a_3,\ a_4,\ \ldots \] 的子序列。
6.6.3。 前面提到的两个序列 \[ 1.1,\ 1.01,\ 1.001,\ \ldots \] 和 \[ 0.1,\ 0.01,\ 0.001,\ \ldots \] 都是 \[ 1.1,\ 0.1,\ 1.01,\ 0.01,\ 1.001,\ 0.001,\ 1.0001,\ \ldots \] 的子序列。

6.6.4：自反性与传递性

6.6.4。 设 \((a_n)_{n=0}^\infty\)、\((b_n)_{n=0}^\infty\)、\((c_n)_{n=0}^\infty\) 是实数序列。则
  • \((a_n)_{n=0}^\infty\) 是自身的子序列（自反性）；
  • 若 \((b_n)_{n=0}^\infty\) 是 \((a_n)_{n=0}^\infty\) 的子序列，且 \((c_n)_{n=0}^\infty\) 是 \((b_n)_{n=0}^\infty\) 的子序列，则 \((c_n)_{n=0}^\infty\) 是 \((a_n)_{n=0}^\infty\) 的子序列（传递性）。
"是子序列"这一关系不是对称的。

/-- Lemma 6.6.4 / Exercise 6.6.1: reflexivity -/ theorem Sequence.subseq_self (a:ℕ → ℝ) : Sequence.subseq a a := by refine ⟨id, strictMono_id, λ n ↦ rfl⟩ /-- Lemma 6.6.4 / Exercise 6.6.1: transitivity -/ theorem Sequence.subseq_trans {a b c:ℕ → ℝ} (hab: Sequence.subseq a b) (hbc: Sequence.subseq b c) : Sequence.subseq a c := by rcases hab with ⟨f, hf, hab'⟩ rcases hbc with ⟨g, hg, hbc'⟩ refine ⟨f ∘ g, hf.comp hg, λ n ↦ ?_⟩ calc c n = b (g n) := hbc' n _ = a (f (g n)) := hab' (g n)

自反性用恒等函数 id，传递性用复合函数 f ∘ g， 严格递增函数的复合仍严格递增（StrictMono.comp）。

6.6.5：子序列与极限

6.6.5（子序列与极限的关系）。 设 \((a_n)_{n=0}^\infty\) 是实数序列，\(L\) 是实数。则以下两个命题逻辑等价：
  • (a) 序列 \((a_n)_{n=0}^\infty\) 收敛到 \(L\)。
  • (b) \((a_n)_{n=0}^\infty\) 的每个子序列都收敛到 \(L\)。
证明.
见习题 6.6.4。（注意两个方向中有一个的证明非常短。）
∎
补充说明：Lean 中的对应定理
/-- Proposition 6.6.5 / Exercise 6.6.4 -/ theorem Sequence.convergent_iff_subseq (a:ℕ → ℝ) (L:ℝ) : (a:Sequence).TendsTo L ↔ ∀ b:ℕ → ℝ, Sequence.subseq a b → (b:Sequence).TendsTo L

(b) ⟹ (a) 的方向很短：序列是自身的子序列（引理 6.6.4），故直接代入即可。 (a) ⟹ (b) 的方向需要利用严格递增函数 \(f\) 满足 \(f(n) \geq n\)， 因此当 \(n\) 足够大时 \(f(n)\) 也足够大，使 \(a_{f(n)}\) 接近 \(L\)。

6.6.6：子序列与极限点

6.6.6（子序列与极限点的关系）。 设 \((a_n)_{n=0}^\infty\) 是实数序列，\(L\) 是实数。则以下两个命题逻辑等价：
  • (a) \(L\) 是 \((a_n)_{n=0}^\infty\) 的极限点。
  • (b) 存在 \((a_n)_{n=0}^\infty\) 的一个子序列收敛到 \(L\)。
证明.
见习题 6.6.5。（提示：为证明 (a) 蕴含 (b)，对每个自然数 \(j\)，定义 \(n_j := \min\{n > n_{j-1} : |a_n - L| \leq 1/j\}\)，约定 \(n_0 := 0\)，并解释为何集合 \(\{n > n_{j-1} : |a_n - L| \leq 1/j\}\) 非空。然后考虑序列 \(a_{n_j}\)。）
∎
补充说明：Lean 中的对应定理
/-- Proposition 6.6.6 / Exercise 6.6.5 -/ theorem Sequence.limit_point_iff_subseq (a:ℕ → ℝ) (L:ℝ) : (a:Sequence).LimitPoint L ↔ ∃ b:ℕ → ℝ, Sequence.subseq a b ∧ (b:Sequence).TendsTo L

(a) ⟹ (b) 的 Lean 证明使用 Classical.choose 递归构造下标函数 \(f\)： 对每个 \(k\)，在 \(\{n > f(k) : |a_n - L| \leq 1/(k+2)\}\) 中选取一个元素作为 \(f(k+1)\)。 由此构造的 \(b_n := a_{f(n)}\) 满足 \(|b_n - L| \leq 1/(n+1) \to 0\)，故收敛到 \(L\)。

6.6.7：极限与极限点的对比

注 6.6.7。 上述两个命题给出了极限与极限点概念的鲜明对比。当序列有极限 \(L\) 时， 所有子序列也都收敛到 \(L\)。但当序列以 \(L\) 为极限点时， 只有某些子序列收敛到 \(L\)。

6.6.8：Bolzano–Weierstrass 定理

我们现在可以证明实分析中的一个重要定理，它归功于 Bernard Bolzano（1781–1848）和 Karl Weierstrass（1815–1897）： 每个有界序列都有收敛子序列。

6.6.8（Bolzano–Weierstrass 定理）。 设 \((a_n)_{n=0}^\infty\) 是有界序列 （即存在实数 \(M > 0\) 使得对所有 \(n \in \mathbb{N}\) 有 \(|a_n| \leq M\)）。 则 \((a_n)_{n=0}^\infty\) 至少有一个收敛子序列。
证明.

令 \(L\) 为序列 \((a_n)_{n=0}^\infty\) 的上极限。由于对所有自然数 \(n\) 有 \(-M \leq a_n \leq M\)， 由比较原理（引理 6.4.13）得 \(-M \leq L \leq M\)。特别地，\(L\) 是实数（不是 \(+\infty\) 或 \(-\infty\)）。 由命题 6.4.12(e)，\(L\) 是 \((a_n)_{n=0}^\infty\) 的极限点。 再由命题 6.6.6，存在 \((a_n)_{n=0}^\infty\) 的一个子序列收敛（事实上，收敛到 \(L\)）。

∎

注意，我们同样可以使用下极限代替上极限来完成上述论证。

补充说明：Lean 中的形式化
/-- Theorem 6.6.8 (Bolzano-Weierstrass theorem) -/ theorem Sequence.convergent_of_subseq_of_bounded {a:ℕ→ ℝ} (ha: (a:Sequence).IsBounded) : ∃ b:ℕ → ℝ, Sequence.subseq a b ∧ (b:Sequence).Convergent

Lean 证明忠实地遵循教材思路：先由有界性得出上极限有限（finite_limsup_liminf_of_bounded）， 再由命题 6.4.12(e) 得上极限是极限点（limit_point_of_limsup）， 最后由命题 6.6.6 将极限点转化为收敛子序列（limit_point_iff_subseq）。

6.6.9：紧致性

注 6.6.9。 Bolzano–Weierstrass 定理说明：如果一个序列有界，那么它最终"别无选择"只能在某些地方收敛； 它"没有空间"散开并阻止自己获得极限点。对无界序列这不成立；例如序列 \(1, 2, 3, \ldots\) 没有任何收敛子序列（为什么？）。用拓扑的语言来说，这意味着区间 \(\{x \in \mathbb{R} : -M \leq x \leq M\}\) 是 ， 而无界集合如实数轴 \(\mathbb{R}\) 不是紧致的。紧致集与非紧致集的区分在后续章节中非常重要—— 其重要性类似于有限集与无限集的区分。

个人感悟：Bolzano–Weierstrass 定理的深远意义

Bolzano–Weierstrass 定理是实分析中最基本的"存在性定理"之一：它不告诉你极限是什么， 只告诉你极限存在。这种"非构造性"的存在性证明，正是上极限/下极限框架的力量所在—— 上极限天然是极限点，而有界性保证了它是有限实数，于是收敛子序列自动存在。

命题 6.6.6 的深刻之处在于：它把"极限点"这个用 \(\varepsilon\)-\(N\) 语言定义的、 看似静态的概念，与"存在收敛子序列"这个动态的、构造性的概念等价起来。 在 Lean 形式化中，这个等价定理的 (a) ⟹ (b) 方向需要用选择公理 （Classical.choose）递归地构造子序列的下标—— 这体现了"从存在性到构造性"的转换在形式上需要非平凡的工作。

注 6.6.9 中提到的"紧致性"将在后续章节（特别是关于连续性和度量空间的部分）发挥核心作用。 Bolzano–Weierstrass 定理正是实数轴上闭区间紧致性的序列刻画。
