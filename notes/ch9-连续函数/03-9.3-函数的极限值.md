# 03 · 9.3 函数的极限值：把"极限"从序列搬到函数

> 陶哲轩《实分析》9.3 完整叙事 + 原文 + Lean 形式化对照
> One Big Idea：**极限不再只属于序列——函数在一点附近也可以"逼近"某个值，而"附近"第一次有了 ε-δ 的形状。**

---

## 第一幕 · 动机：为什么要"函数极限"？

### 开场：你已经有序列极限了

第 6 章你学会了序列收敛：aₙ → L 当 n → ∞。第 7 章你学会了级数和。从"序列"到"函数"，道路看起来不太长——函数 f 的"极限"，不就该是"lim_{x→x₀} f(x)"吗？

但"写了记号"不等于"有了定义"。要回答"lim f(x) = L"是什么意思，必须先把"x 接近 x₀"这个动作数学化——而这正是 9.1 的 ε 粘着点开始做的事。**9.3 的全部内容，就是把第 6 章的序列极限重新写成"函数在一点收敛"的新亲戚，同时让 ε 和 δ 第一次同台。**

### 反派登场：函数比序列"顽固"

序列的极限只需要回答"n 很大以后"；函数极限要回答"x 靠近 x₀ 的所有路径"。于是出现了三个坎：

1. **单点陷阱**：f(x₀) 本身可能没定义（比如 f(x) = (x²−1)/(x−1) 在 1 处）。极限必须允许 x₀ 不在 f 的定义域里——它只关心"邻近"。
2. **方向陷阱**：从左边逼近和从右边逼近，结果可以不同（9.5 正是为它单独开节）。
3. **空集陷阱**：若 x₀ 不是 E 的驻点（9.1！），则"接近 x₀"无意义，极限无从谈起。

## 第二幕 · 揭示：ε-Closeness → Convergesto → 极限律

### 第 1 级：CloseFn（ε-closeness, Definition 9.3.1）

先定义"f 是 ε-接近 L"（在整条 X 上）：
```
ε.CloseFn X f L := ∀ x∈X, |f x − L| ≤ ε
```
这是"全场目标"："整条函数都被装进以 L 为中心半径 ε 的带子里"。

### 第 2 级：CloseNear（局部 ε-接近, Definition 9.3.3）

问题：“接近 L”不需要管远处——只要**某个小邻域内**成立：
```
ε.CloseNear X f L x₀ := ∃ δ>0, ∀ x∈X, |x−x₀|<δ → |f x − L| ≤ ε
```
x₀ 是 E 的驻点（因此存在“靠近”E 的点可参照）。δ 把"多近"量化；有了它，函数极限的第一个 ε-δ 雏形出现了。

### 第 3 级：Convergesto（Definition 9.3.6 / 9.3.9）

最后一级，是真正的极限：

```
Convergesto X f L x₀ := ∀ ε > 0, ε.CloseNear X f L x₀
```

逐字读：**"不管你把 ε 调得多小，我都能找一个 δ，使 X 里所有距 x₀ 小于 δ 的点，其函数值距 L 小于 ε。"**——换句话说，L 是所有"邻近值"共同逼近的目标。

Lean 的关键等价（Definition 3 的核心枢纽，`Section_9_3.lean:104-149`）：

```lean
theorem Convergesto.iff (X f L x₀) :
    Convergesto X f L x₀ ↔
    ∀ ε > 0, ∃ δ > 0, ∀ x ∈ X, |x − x₀| < δ → |f x − L| ≤ ε
```

以及它的"序列版"（Proposition 9.3.9，`:149`）：
```
Convergesto E f L x₀ ⟺ 任何 E 内收敛到 x₀ 的序列 (aₙ)，都有 f(aₙ) → L
```
**这就是序列思想的迁移：函数极限与序列极限等价。** 以后想证明函数极限，可以先"翻译"成序列，用第 6 章的武器库。

### 重要的细节：x₀ 成不成为自变量？

在 Tao 的定义里，x₀ 是 E 的驻点（9.1）。在 Lean 的实现里（`Convergesto.iff`），你看到 `x₀ ∈ E` 或 `AdherentPt x₀ E` 的条件——**x₀ 不一定属于 E**（极限不要求 f 定义于 x₀），但必须在 E 的“邻域”里才有意义。这正好让你以后无需全班重置定义，就可检查 f(x₀) 是否定义。

### 第四幕 极限律：Proposition 9.3.14

省掉无关紧要的铺垫，最终弹药库（`Section_9_3.lean:213-268`）：

```
Convergesto.add     —— lim(f+g) = lim f + lim g
Convergesto.sub     —— lim(f−g) = lim f − lim g
Convergesto.mul     —— lim(f·g) = lim f · lim g
Convergesto.div     —— (M≠0) lim(f/g) = lim f / lim g
Convergesto.max/min —— 同理
Convergesto.smul    —— lim(c·f) = c·lim f
Convergesto.comp    —— 复合
Convergesto.uniq    —— 极限唯一（若 x₀ 是驻点）
```

Laws 的参数全是 `ℝ → ℝ` 且不带连续性假设——**这些律在"不连续"时依然成立**，只要极限不出现。这正是 9.2 搬运工要服务的对象：极限与函数算术互相渗透。

### 反直觉的边角：Example 9.3.19-20（分母零点边角）

```lean
-- 如 g(x₀) = 0 时，f/g 在 x₀ 无定义；
-- 用 Convergesto.div 需要 hM ≠ 0，或"缩小定义域"把零点排除。
```

**极限律不是免费的**——它只在分母极限非零时通过。这个小心思，正是后面 9.4 定理证明里反复出现的"分母非零"条件的来源。

## 第三幕 · 愿景：进军连续

9.3 之后，你拥有了：

- "函数在某点收敛"的完整定义（ε → δ 双子）
- 一个**顺手定理**：极限的代数（Proposition 9.3.14）
- 一个**等价翻译**：函数极限 ⟺ 全部序列版本（9.3.9）
- 一个**新边界**：唯一性，方向性（因 x₀ 驻点而存在）

第 9.4 是它的直接继承人：**连续 = 极限存在于取值**。所有 9.3 的武器，将原样交给 9.4。

**OK，让我们看看极限怎么变成连续。**

## 原文（PDF 提取）

**Definition 9.3.1 (ε-closeness)**: Let X be a subset of R, and f : X →R a function, L a real number and ε > 0. We say that f is ε-close to L iff f (x) is ε-close to L for every x ∈X.

**Definition 9.3.3 (Local ε-closeness)**: ... f is ε-close to L near x0 iff there exists a δ > 0 such that f becomes ε-close to L when restricted to the set {x ∈X : |x −x0| < δ}.

**Definition 9.3.6 (Convergence of functions at a point)**: Let E ⊆ X, x0 an adherent point of E, and L a real number. We say that f converges to L at x0 in E iff f restricted to E is ε-close to L near x0 for every ε > 0. If f does not converge to any L at x0, we say that f diverges at x0, and leave lim undeﬁned.

**Proposition 9.3.9**: ... equivalent: (a) f converges to L at x0 in E; (b) for every sequence (an) in E converging to x0, the sequence (f (an)) converges to L.

**Proposition 9.3.14 (Limit laws for functions)**: ... subject to denominators being nonzero, the limit of combination equals combination of limits.

**Example 9.3.20**: f (x) := (x2 −1)/(x −1) on R{1}. Then f (1) is undeﬁned, yet 1 is an adherent point of R{1} and lim_{x→1} f (x) = 2. — 这正是"x0 不需在定义域"的活例。

**Example 9.3.21**: The Dirichlet function f (x) := 1 if x ∈Q else 0 has no limit at 0 — 用有理与无理两个序列 1/n 与 √2/n 的矛盾证明。这是"函数极限未必存在"的经典反例。

在 Lean 中 `Convergesto`（凸形）几乎等价于 Mathlib 的 `Filter.Tendsto f (nhdsWithin x₀ E) (nhds L)`；`Section_9_3.lean` 用自洽定义对手把它包装成更接近书本的动词。
