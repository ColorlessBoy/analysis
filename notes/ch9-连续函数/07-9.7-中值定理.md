# 07 · 9.7 中值定理：连续函数的图像是一整条线段

> 陶哲轩《实分析》9.7 完整叙事 + 原文 + Lean 形式化对照
> One Big Idea：**连续函数把闭区间映成闭区间——每一层中间值都被某个输入真正取到。**

---

## 第一幕 · 动机：为什么这个定理值得一个名字？

### 开场：一个你一生都在用的直觉

"如果 f(0) < 0 而 f(1) > 0，那么必有一个 x ∈ (0,1) 使 f(x) = 0。"

你在中学就用它：判断方程 f(x) = 0 在 (a,b) 内有解。当时你"看"出来——函数从负到正，怎会不碰零？这个直觉如此自然，以至于你不会想到：**在严格的实数公理（第 4-5 章）下，这句话需要证明，而且证明不平凡。**

为什么"显然"会失败？因为"从负到正"只告诉了你**两个点的值**，没有告诉你**中间任何一点的行为**——除非连续性介入。连续性的承诺正好是："只要你靠近 x，f 的值就靠近 f(x)"——用它，才能把"负"和"正"之间的缝隙一点一点填满。

### 反派登场：不连续就把缝隙露出来

g(x) = x 若 x < 0.5；x+1 若 x ≥ 0.5。在 0.5 处跳了 1 个单位。它穿过 0 吗？当然——但在 x = 0.5 附近，**数轴 (0.5, 0.5+0.1) 这段里没有任何函数值**：值域活生生挖掉一条缝。连续函数绝不挖缝，这就是中值定理的全部内容——**它断言连续性的直接后果是"图像无洞"。**

### 动机总结

这一节要证明的东西，学名叫做：

> **Theorem 9.7.1（中值定理，IVT）**：f 在 [a,b] 上连续，则对 f(a) 与 f(b) 之间的一切值 y，都存在 c ∈ [a,b] 使 f(c) = y。

注意它有两个变体，Lean 全都有：

- 经典版：y 介于 f(a) 与 f(b) 之间（`intermediate_value`，`Section_9_7.lean:89`）
- **像版**：f 的像是一个区间，`continuous_image_Icc' : f '' Icc a b = Icc (sInf f'') (sSup f'')`（`:179`）——**图像没有洞**，这是更强的"区间版本"

## 第二幕 · 揭示：sup 的第三次分红

### 证明思想（书上经典证法）

1. 不妨设 f(a) ≤ y ≤ f(b)（另一端对称）
2. 造集合 E := { x ∈ [a,b] : f(x) ≤ y }——**E 非空**（a ∈ E）、**有上界**（b 是上界）
3. 由第 5 章：sSup E 存在。令 c := sSup E
4. 证明三件事：
   - f(c) ≤ y：若 f(c) > y，用 9.4 的连续性抓到一个 δ，使 (c−δ, c+δ) 内 f > y，与 c 是 E 的上界矛盾
   - f(c) ≥ y：取序列逼近 c，9.4 极限 + 上界性质
   - ⟹ f(c) = y

**注意第 3 步**：**第 5 章的 sSup 又一次出马**（第一次是 9.6 的最大原理）。9.7 是"sup 理论"的第二次征收——而且这次更彻底：`continuous_image_Icc`（`:179`）里直接写着 `sInf (f '' Icc) ≤ y ∧ y ≤ sSup (f '' Icc)`——"有界中值"形态的 IVT。

### 两个重磅推论

1. **不动点定理**（`:191`）：`f 把 [0,1] 映进 [0,1]，f 连续 ⟹ ∃ x ∈ [0,1], f(x) = x`——把 g(x) := f(x) − x 在中值定理下用一遍就出来了。**"任何连续映射把一个区间映回自身必有不动点"**——这是拓扑学 Brouwer 不动点定理的一维微缩版，也是经济学均衡理论的亲爹。

2. **单调反函数**（9.8 的主角，`MonotoneOn.exist_inverse`）：严格单调 + 连续 ⟹ 反函数存在且连续。这个中值定理+"连续性"的联合成果是第 10 章 exp/log/arcsin 一切反函数的基础。

### Lean 的机器证明能走多远？

`intermediate_value` 在 Lean 的 mathlib 里是现成的（`IntermediateValue` 家族）。仓库的 `:89` 定理自己用 `ContinuousOn` 陈述并一行一行证过；`:146` 的 `continuous_image_Icc` 直通 `sInf (f '' Icc) ≤ y ∧ y ≤ sSup (f '' Icc)`——**书上的"图像 = 区间"在 Lean 里被原样兑现**。

## 第三幕 · 愿景：中值定理的三种性格

中值定理在数学里同时是三件东西：

1. **存在性工具**：方程 f(x) = 0 的解存在（不构造出来，只保证存在）
2. **连通性宣言**：连续映射把"连着的"（区间）映成"连着的"（区间）——拓扑连通性的祖先
3. **反函数的地基**：9.8 的 `exist_inverse` 完全建立其上

它也是第一道"分析必须严格证明的几何直觉"。**数学教育里最重要的时刻之一，就是有人第一次告诉你：那根红线真的存在，且它的存在需要证明。**

下一节，我们把连续和单调放在一起，看反函数是怎么从"递增 + 满射"长出来的。

## 原文（PDF 提取）

**Theorem 9.7.1 (Intermediate value theorem)**: Let a < b and f : [a,b] →R be continuous. Then for every real number y between f (a) and f (b), there exists c ∈[a,b] such that f (c) = y.

**Corollary 9.7.4 (Images of continuous functions)**: Let a < b and f continuous on [a,b]. Then f ([a,b]) is a closed interval.

**Exercise 9.7.1**（在 Lean 中是 `continuous_image_Icc`）：证明 f([a,b]) = [inf, sup]——即 9.7.4 的具体形状。

**Exercise 9.7.4**：若 f 把 [0,1] 映进 [0,1] 且连续，证明存在 x 满足 f(x) = x（不动点）。

—— 陶哲轩在书中的历史注（选段）：中值定理的严格形式来自 Bolzano（1817）与 Cauchy，中间隔了几十年才被教科书接受（另一面：几何直觉可以支撑结论，支撑不了证明）。
