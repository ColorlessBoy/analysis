# 05 · 9.5 左右极限：方向感，从单侧逼近开始

> 陶哲轩《实分析》9.5 完整叙事 + 原文 + Lean 形式化对照
> One Big Idea：**极限不只有"从两边来"，还有"从左边来"和"从右边来"——方向感是极限的隐藏参数。**

---

## 第一幕 · 动机：为什么需要"左右"？

### 开场：一个熟悉又陌生的符号

你早就见过符号 lim_{x→0⁺} 和 lim_{x→0⁻}。它们在微积分书里随手就来。但请问：**"x → 0⁺"是什么数学对象？** 是"x 趋向 0，但保持为正"。这要求极限的定义域不是整个 X，而是 X ∩ (0, ∞)——**单侧极限，就是用"更小的定义域"重新跑一遍 9.3 的定义。**

而单侧极限不是装饰品。看符号函数：

```
sgn(x) =  1  x > 0
          0  x = 0
         −1  x < 0
```

lim_{x→0⁺} sgn = 1，lim_{x→0⁻} sgn = −1——**两侧都存在，却不相等**。于是 lim_{x→0} sgn 不存在。方向性，是"极限存在"的必要条件：**从两侧看都一样，才算真极限。**

### 反派登场：不连续的两副面孔

单侧极限存在的价值，是可以对"不连续"做**分类学**。看两个不连续函数：

- **跳跃**：sgn 在 0 处左右极限都是有限数，但不相等——"啪"地跳一下
- **可去**：f(x) = 1 若 x=0，否则 0——左右极限都等于 0，但 f(0)=1——把 f(0) 改成 0 就连续了，"洞"可以补

同一个"不连续"，在单侧极限下长出两种性格：**跳变（jump）与可去（removable）**。9.5 的 Lean 里甚至直接给了两个谓词（`Section_9_5.lean:162,205`）：`HasJumpDiscontinuity` 和 `HasRemovableDiscontinuity`。

**动机总结**：9.5 不只是"把 9.3 换个方向重写一遍"——它是"连续"的诊断工具：哪里断了、怎么断的、能不能补，全都由单侧极限回答。

## 第二幕 · 揭示：单侧极限定义与"连续 ⟺ 左右相等"

### 定义（Definition 9.5.1）

单侧极限 = 把定义域切到一侧，其余不动：

```
RightLimitExists X f x₀ := ∃ L, (nhdsWithin x₀ (X ∩ .Ioi x₀)).Tendsto f (nhds L)
LeftLimitExists  X f x₀ := ∃ L, (nhdsWithin x₀ (X ∩ .Iio x₀)).Tendsto f (nhds L)
```

Lean 直接用了 Mathlib 的 `nhdsWithin`（邻域限制在子集内）——比重新发明 ε-δ 更清晰：**"从右边来"就是"所有邻域都先和 (x₀, ∞) 相交再谈"。**

书中给右极限的值"垃圾值 0"（junk value）处理定义域问题（9.5.1 的 Lean 注释专门说了这一点）；Lean 的 `right_limit.eq`（`:32`）则保证：极限若存在，唯一。

### 核心定理：连续 ⟺ 左右极限都等于函数值（Proposition 9.5.3）

```
theorem ContinuousAt.iff_eq_left_right_limit {X} {f} {x₀} (h : x₀ ∈ X) :
    ContinuousWithinAt X f x₀ ↔
      RightLimitExists X f x₀ ∧ LeftLimitExists X f x₀
        ∧ (∀ L, RightLimitAt ... = L ∧ LeftLimitAt ... = L → L = f x₀)
```

（`Section_9_5.lean:115`；此处给出的是思想骨架，精确签名以文件为准。）

**这条定理是"连续"的分诊台**：要检查 f 在 x₀ 是否连续，只需分别检查左、右两侧——这是所有"分段函数连续"习题的通用解法。

### 分类学落地：跳跃 vs 可去

Lean 两个谓词把不连续分成两类：

- `HasJumpDiscontinuity`（`:162`）：左右极限存在但不相等——函数"跳"了
- `HasRemovableDiscontinuity`（`:205`）：左右极限相等但不等于 f(x₀)——函数"开洞"了，改一点就能补

用它们检查 sgn 与"0 处为 1"的函数：前者跳，后者可去。**不连续不再是一团浆糊，而是两种可分辨的病理。**

## 第三幕 · 愿景：给"连续"装上方向

9.5 之后你多了一件武器：**单侧检查**。它在后面反复出现：

- **9.7 中值定理**：证明里常分左右逼近端点
- **第 10 章（预告）**：导数本质上是"双侧极限存在"——单侧导数先行
- **第 11 章（预告）**：Riemann 积分对端点不需要双侧连续

而最重要的哲学收获是：**"连续"不是形容词，是可拆开验证的合同**——左、右各签一次，中间值兜底。不连续的分类（跳/可去）让你能说出"它为什么断"，这是分析从"有没有"走向"怎么断"的一步。

## 原文（PDF 提取）

**Definition 9.5.1**: We define the right limit f (x0+) and the left limit f (x0−) as the limits of f restricted to (x0, ∞) and (−∞, x0) respectively, when they exist. (In Lean: `RightLimitExists` / `LeftLimitExists` via `nhdsWithin`.)

**Proposition 9.5.3**: Let X ⊆ R, f : X →R, x0 ∈X. Then f is continuous at x0 iff f (x0+) = f (x0) = f (x0−) in the sense that the two one-sided limits exist and equal f (x0). — 连续 ⟺ 左右极限（含值）三者重合。

**关于"垃圾值"**：书（与 Lean）在单侧极限不存在时给值 0，避免"未定义"的复杂化——这是分析中常见的"junk value"技巧，Lean 注释里明确说明。
