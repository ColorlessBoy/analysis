## 这一章讲了一个什么故事

从第 4 章建数到第 8 章处理无穷，你终于有了一个完整的实轴。现在的问题很朴素：**什么样的一根线，才配叫"不断"？**

第 9 章的定义不靠画图。它先造出"从 A 点靠近 X"的精确语言（9.1 的 ε 邻域与驻点），再把"函数在某点的值 = 极限值"写成一条可以机器验证的公式（9.3-9.4 的 Convergesto / Continuous），然后在这条定义上盖起三座高楼：

- **9.6 最大原理**：闭有界上的连续函数一定有最大值和最小值——用第 5 章攒下的 sSup 兑现；
- **9.7 中值定理**：连续函数把闭区间映成闭区间，穿过每一个中间值；
- **9.9 均匀连续**：把"每个点各要一个 δ"升级成"全场统一一个 δ"——这是后来 Riemann 积分的地基。

**一句话讲完这一章**：连续不是"画得不断"，而是"极限值和函数值永远守约"；而这一条约定，能让你证明画图时代只能"看出"却"说不出"的一切。

## 十节的叙事（三幕剧结构）

| 节 | One Big Idea | 反派 → 揭示 → 愿景 |
|----|--------------|---------------------|
| 9.1 子集 | **"靠近"是可以量化的**：ε 距离 | 直觉的"到了没到" → ε 邻点 → 闭包、闭集、Heine-Borel |

| 9.4 连续函数 | **连续 = 极限等于取值** | "画得顺"的含糊 → ContinuousWithinAt → 全是连续（多项式/指数） |
| 9.5 左右极限 | **从左侧和从右侧接近是两回事** | 全局邻域的粗糙 → 单侧邻域 → 跳跃与可去间断的分类学 |

## 全章的角色谱系（第 9 章的英雄们）

```
AdherentPt     9.1 —— 点的"附着"：任一 ε 都找得到集合里的近邻
closure        9.1 —— 所有附着点打包成壳
Convergesto    9.3 —— 函数在某点收敛到某个值的精确定义
Continuous     9.4 —— 收敛到自身函数值：Convergesto (f x₀)
LUB / sSup     9.6 —— 有界集合的"顶"
IsMaxOn        9.6 —— 把"顶"真正取到一个点上
MonotoneOn     9.8 —— 单调序（及 Anti 反序）
UniformContinuous 9.9 —— δ 之全局化
```

你在这章把四个日常词汇——**接近、连续、极值、单调**——全部重新定义成"带 ε、带 δ、带 ∀x、可以上机验证"的句子。这是从"看图说话"到"ε-δ 证明"的转折点：几何直觉在之后只是脚手架，结论本身由一句话的拆解撑着。

## 理论的构建过程（十步台阶）

```
第 1 阶（9.1 子集）
   ε 邻点：AdherentPt x X := ∀ ε>0, ∃ y∈X, |x−y| ≤ ε
   ⇒ closure X := { x | AdherentPt x X }
   ⇒ IsClosed，极限点，孤立点；Heine-Borel：闭有界 ⟸ 紧致
   依赖：第 5 章实数与 ε 语言

第 2 阶（9.2 函数代数）
   逐点运算：f+g、f−g、f⋅g、f/g、max、min、scalar
   结论：函数空间对代数运算封闭
   依赖：实数域本身的算术

第 3 阶（9.3 函数的极限）
   CloseNear ε X f L x₀ := ∃δ>0, ∀x∈X, |x−x₀|<δ → |f x−L|<ε
   Convergesto := ∀ε>0, ε 处满足 CloseNear
   极限律：add / sub / mul / div / max / min / sq / lin / quad
   唯一性：极限若存在则唯一（Convergesto.uniq）

第 4 阶（9.4 连续）
   ContinuousWithinAt X f x₀ := Convergesto (f x₀)
   "连续 ⟺ 极限 = 值"（tfae 一揽子等价）
   后续：多项式、指数、绝对值、复合、商的连续性——代数封闭

第 5 阶（9.5 左右极限）
   单侧：Right / LeftLimitExists（对 Ioi x₀ 或 Iio x₀）
   分类：跳跃（HasJump）与平滑可去（HasRemovable）
   定理：连续 ⟺ 左右极限存在且相等 ⟹ 等于 f x₀

第 6 阶（9.6 最大原理）
   BddAboveOn / BddBelowOn / BddOn
   紧致区间上的连续 ⟹ BddOn
   Prop 9.6.7 IsMaxOn：连续在 [a,b] 上取到最大值与最小值点
   （关键：BddOn.of_continuous_on_compact 是整个证明的铰链）

第 7 阶（9.7 中值定理）
   连续于 [a,b]：图像是闭区间，即对每个中间值 y 有 x 达它
   intermediate_value；连续 → 不动点（fixed point 定理）

第 8 阶（9.8 单调）
   单调保序（MonotoneOn / StrictMonoOn 及反序 Antitone）
   强导出：严格单调 + 连续 ⟹ 反函数连续（exist_inverse）
   反直觉：单调但处处不连续的函数（f_9_8_5）

第 9 阶（9.9 均匀连续）
   均匀：∀ε ∃δ ∀x₀——δ 不依赖 x₀
   与序列等价：UniformContinuousOn ⟺ 保持 Cauchy 序列
   （Heine-Cantor）闭有界 ⇒ 均匀连续（定理 9.9.16）

第 10 阶（9.10 无穷极限）
   用 EReal ⊤/⊥ 把"无界"表述成 sup = ⊤
   TendstoAtTop：极限到 +∞（atTop ⊓ principal X）
```

## 与全书的接线

- **第 5 章**：sSup/sInf 在 9.6-9.7 的实质兑现——`sSup f '' Icc` 是 9.7 的精确表述

- **第 10 章（预告）**：左右极限是导数与微分几何的准备；单调反函数是 exp/log 构造的起点
- **第 11 章**：均匀连续是 Riemann 可积性的关键条件
