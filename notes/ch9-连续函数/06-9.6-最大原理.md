# 06 · 9.6 最大原理：闭有界与连续相遇，极值必然出现

> 陶哲轩《实分析》9.6 完整叙事 + 原文 + Lean 形式化对照
> One Big Idea：**连续函数在闭有界区间上不仅"有界"，还"取得到"最大最小值——Heine-Borel 的第一笔回报。**

---

## 第一幕 · 动机：为什么"有界"和"取到"是两回事？

### 开场：一个"显然"到让你从没怀疑过的命题

f(x) = x² 在 [0,1] 上有最大值 1。f(x) = sin x 在 [0, 2π] 上有最大值 1。谁怀疑过？

但"显然"的代价是：你不知道**为什么**。请试着证明"连续函数在闭区间上有最大值"——你马上撞上一堵墙：**"最大值"是一个点，函数有无数个点，你要怎么保证'这一个点'存在？**

### 反派登场：反例教会我们的边界

三个反例告诉你"闭有界 + 连续"三个条件缺一不可：

| 反例 | 缺什么 | 结果 |
|------|--------|------|
| f(x) = x 在 ℝ 上 | 闭（无界区间） | 连续但无界，更无最大值 |
| f(x) = 1/x 在 (0,1) 上 | 闭（开区间） | 连续但无界（x→0⁺ 时爆炸） |
| f(x) = 1 若 x=0，0 若 x≠0，在 [0,1] 上 | 连续 | 有界但没有最大值点？（有：0 是最大值点？不——f(0)=1 是最大值，没问题） |

第三个要换：f(x) = x 若 x < 1，0.5 若 x = 1，在 [0,1] 上**不连续**，sup = 1 但 1 永远取不到——**sup 存在（5.5！）却不能被任何点到达**。

**看到没有：第 5 章的 sSup 只说"存在上确界"，没说"上确界被某个点取到"。** 最大原理干的正是这一步：把"sup"升级成"argmax"。这就是"有界 ≠ 取到"的精确写照。

### 动机总结

9.6 的第一目标（Lemma 9.6.3）很朴素：**闭有界 + 连续 ⟹ 有界**。但第二目标（Proposition 9.6.7）才是主角：**不仅 sup 存在，而且存在 x_max 真正达到它**。前者是"总账不爆"，后者是"点真的存在"——后者靠的正是 9.1 的 Heine-Borel：从取 sup 的序列里抓出收敛子列。

## 第二幕 · 揭示：从"有界"到"取到"

### 第一步：三个有界概念（Definition 9.6.1）

```
BddAboveOn f X := ∃ M, ∀ x∈X, f x ≤ M
BddBelowOn f X := ∃ M, ∀ x∈X, −M ≤ f x      （注意：用 −M 表示下界）
BddOn      f X := ∃ M, ∀ x∈X, |f x| ≤ M      （双向）
```

`BddOn.iff`（Lean `:30`）：有界 ⟺ 既有上界又有下界。直译：**夹得住。**

### 第二步：Lemma 9.6.3 —— 闭有界 + 连续 ⟹ 有界

证明骨架（Lean `BddOn.of_continuous_on_compact` `:143`）：

1. 假设 f 无界：对每个 n，存在 xₙ ∈ [a,b] 使 |f(xₙ)| ≥ n
2. 序列 (xₙ) 全在闭有界集里 ⟹ **Heine-Borel**（9.1.24）抓出收敛子列 x_{nⱼ} → L ∈ [a,b]
3. 连续 ⟹ f(x_{nⱼ}) → f(L)（收敛）
4. 收敛序列必有界（第 6 章）——但 |f(x_{nⱼ})| ≥ nⱼ → ∞，矛盾

**这就是 Heine-Borel 的首次分红**：没有它，无从"抓子列"；没有子列，无从"连续引向 f(L)"。反证法 + 紧致性，是这一节的灵魂。

### 第三步：Proposition 9.6.7 最大原理 —— 从 sup 到 argmax

证明骨架（Lean `IsMaxOn.of_continuous_on_compact` `:187`）：

1. 由 Lemma 9.6.3，f 有界，sup S := sSup(f''[a,b]) 存在（第 5 章）
2. 用 sup 的性质：对每个 n，存在 xₙ ∈ [a,b] 使 S − 1/n < f(xₙ) ≤ S
3. 再用 Heine-Borel 抓收敛子列 x_{nⱼ} → x_max
4. 连续 ⟹ f(x_{nⱼ}) → f(x_max)；夹逼 ⟹ f(x_max) = S

**f 在 x_max 处真的取到了 sup。** 数轴上的"天花板"（sup）终于有了"站上去的那个人"（argmax）。这正是 5.5 的 sSup 与 9.1 的 Heine-Borel 在本书中第一次联手。

### Lean 的构造：IsMaxOn / IsMinOn

```lean
theorem IsMaxOn.of_continuous_on_compact {a b : ℝ} (h : a < b) {f : ℝ → ℝ}
    (hf : ContinuousOn f (.Icc a b)) : ∃ x₀ ∈ .Icc a b, IsMaxOn f (.Icc a b) x₀
```

`IsMaxOn f X x₀` 的意思是"在 X 上，x₀ 是 f 的最大值点"。最小值同理（`:237`）。**一个定理，两种兑现：最大、最小。**

## 第三幕 · 愿景：最大原理的地位

9.6 是 9.1 武器库的第一次实战，也是后面所有"存在性"的模板：

- **9.7 中值定理**：证明里 `sSup (f '' Icc a b)` 正是这里练熟的手感
- **第 10 章（预告）**：Rolle 定理 → 均值定理，本质是"闭区间上的极值点"
- **第 11 章（预告）**：Riemann 积分的上下和，sup/inf 贯穿始终

它教会你的不是"最大值存在"这个结论，而是**一个证明套路**：sup 存在（第 5 章）→ 逼近序列（sup 的定义）→ 抓子列（Heine-Borel）→ 连续（9.4）→ 极限等于值。这个套路，会跟着你走完整个分析。

## 原文（PDF 提取）

**Definition 9.6.1**: We say that f is bounded from above iff there exists a real number M such that f (x) ≤M for all x ∈X; bounded from below iff ∃M such that f (x) ≥−M; bounded iff ∃M such that |f (x)| ≤M for all x ∈X.

**Lemma 9.6.3**: Let a < b and f continuous on [a, b]. Then f is bounded.

**Proposition 9.6.7 (Maximum principle)**: Let a < b and f continuous on [a, b]. Then f attains its maximum at some point xmax ∈[a, b] and also attains its minimum at some point xmin ∈[a, b].

—— Remark 9.6.8: Strictly speaking, "maximum principle" is a misnomer, since the principle also concerns the minimum. Perhaps a more precise name would have been "extremum principle". — 陶哲轩自己吐槽命名。

—— Remark 9.6.4: 证明的两点提醒：(1) 展示了 Heine-Borel 的用处；(2) 这是间接证明——它不告诉你 bound 是多少，只证明"无界"会导致矛盾。
