# 10 · 9.10 无穷极限：把"无穷"变成极限定义里的一员

> 陶哲轩《实分析》9.10 完整叙事 + 原文 + Lean 形式化对照
> One Big Idea：**"趋向无穷"不是极限的例外，而是极限定义通过扩展实数（EReal）得到的正式公民。**

---

## 第一幕 · 动机：为什么需要"极限在无穷处"？

### 开场：一个你已经会做、却无法言说的事

第 6 章你学过序列极限：aₙ → L 当 n → ∞。那里 ∞ 只是"n 无限增大"的隐晦说法。现在轮到函数：

```
lim_{x → ∞} f(x) = L 是什么意思？
```

直觉：x 变得任意大时，f(x) 接近 L。但"任意大"不是实数——你不能写 |∞ − x| < δ。9.10 做的事就是**把这句直觉正式化**：要么引入扩展实数 EReal（把 ±∞ 当成合法端点），要么把"x → ∞"改写成"x > M 的 ε 条件"。

### 反派登场：∞ 不是数，却想当端点

第 5 章你见过 `ExtendedReal.sup`：非空无上界集合的 sup = ⊤（`Section_5_5.lean:765`），空集 sup = ⊥。扩展实数早就把 ∞ 当成"端点"用了——**但那时 ∞ 只是 sup 的值，还不是极限的靶子。** 9.10 要把"以 ∞ 为目标"和"以实数为目标"放进同一个极限语言里。

### 动机总结

这一节是第 9 章的"收尾工作"，但它有两件实际大事：

1. **把"无界"翻译成极限语言**：`¬ BddAbove X ⟺ sSup X = ⊤`（Lean `:18-21`）——"无界"从此可以写成一条方程
2. **定义"趋向无穷的函数极限"**：`lim_{x→∞} f(x) = L` 用"对任意 ε，存在 M，x > M ⟹ |f(x) − L| < ε"定义（Lean `:40`）

## 第二幕 · 揭示：两个定义，一套语法

### 第一步：无穷作为"驻点"（Definition 9.10.1）

把 ∞ 看成"无限粘着点"：X 无上界，意思是"无论 M 多大，X 里都有点大于 M"——即 ∞ 永远"擦着 X 的表面"。Lean 直接用无界表述：

```lean
theorem BddAbove.unbounded_iff (X : Set ℝ) : ¬ BddAbove X ↔ ∀ M, ∃ x ∈ X, x > M
theorem BddAbove.unbounded_iff' : ¬ BddAbove X ↔ sSup ((fun x ↦ (x:EReal)) '' X) = ⊤
```

**第二行是最漂亮的**：把 X 嵌入 EReal 再取 sup——无界就是"sup 是 +∞"。第 5 章的 ExtendedReal 在这里回收了：**∞ 作为 sup 的公民身份，今天转为极限的公民身份。**

### 第二步：x → ∞ 的极限（Definition 9.10.13 / 9.10.18）

```
Filter.Tendsto.AtTop.iff (f : ℝ → ℝ) (L : ℝ) :
  Tendsto f (.atTop ⊓ .principal X) (nhds L)
    ↔ ∀ ε > 0, ∃ M, ∀ x ∈ X ∩ .Ici M, |f x − L| < ε
```

（`Section_9_10.lean:40`）读法：**"f 在 X 上趋向 +∞ 收敛到 L，当且仅当：任意 ε，存在门槛 M，超过 M 的每个 X 中 x 都满足 |f(x) − L| < ε。"**

注意 `.atTop ⊓ .principal X`——"趋向 ∞"是滤子语言里的"向右去"：`atTop`（大到任意大）与"限于 X"（principal）相交。**这不是新定义，是旧滤子语法的组合**——这正是"无穷极限"毫不特殊的原因。

### 第三步：两边都行——lim 为 ∞

函数极限的靶子也可以是 ∞ 本身（如 lim_{x→0} 1/x² = +∞）。Lean 用 EReal 统一：`limsup`/`liminf` 在 `Section_6_4` 早已出现（`Sequence.limsup : EReal`），9.10 只是把同一套 EReal 语法用在函数的 x 变量上。

## 第三幕 · 愿景：收尾的回报

9.10 给整章补上最后一块：

1. **语法统一**：极限的靶子（实数或 ∞）与极限的变量（x 或 n）现在共用一套 ε/滤子语言
2. **第 11 章的前置**：瑕积分（improper integrals）需要"极限在 ∞"——`lim_{x→∞} f` 是它的语法基础
3. **无界的正式面孔**：`¬ BddAbove ⟺ sSup = ⊤` 让"无界"变成可以代入方程的量

至此，第 9 章完成闭环：

```
9.1 子集（ε 邻域）→ 9.3 函数极限 → 9.4 连续
→ 9.6 最大原理 → 9.7 中值定理 → 9.9 均匀连续 → 9.10 无穷极限
```

**你从"函数是什么"一路走到"函数在无穷处如何表现"——第 10 章，导数，将站在这一切之上。**

**Definition 9.10.1**: We say that +∞ is an adherent point of X iff X is unbounded above... (Lean：`¬ BddAbove X`，配合 `sSup = ⊤`。)

**Definition 9.10.13 / 9.10.18（极限在无穷）**: 我们称 lim_{x→∞} f (x) = L，当且仅当对任意 ε > 0 存在 M 使对所有 x > M 有 |f (x) −L| < ε。（Lean：`Filter.Tendsto.AtTop.iff`。）
