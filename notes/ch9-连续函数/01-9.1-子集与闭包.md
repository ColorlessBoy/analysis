# 01 · 9.1 子集：在"内部"和"外部"之间，有一条精确的线

> One Big Idea：**想讨论"极限和连续"，你得先能回答"一个点离集合有多近"。**

---

## 第一幕 · 动机：为什么分析需要"靠近"这个概念的公民身份

### 开场：一个你从没问过的问题

连续函数的研究目标，通俗说法是"函数不断线"。但"不断"在你心里其实是画面：笔尖不离纸。

现在请对自己提出一个极其幼稚的问题：**"哪个子集的点算'在函数上面'？"** 比如函数 f(x) = x² 画在纸上，点 (2.01, 4.0401) 在不在函数上？当然在——它就是 f(2.01)。那点 (2, 4) 呢？也在。

但真正的问题在别处。告诉你 x₀ 是函数定义域里"附近"的点——**"附近"是几毫米？**在纸上，一毫米就是近；在数学里，"近"必须有个定义。没有这个定义，后面的"极限 = 函数值"就是一句永远证不完的话——因为把 ε 调小一点，"近"的要求又变了。

### 反派登场：点的"身份"

再看另一个细小的谜团。考虑开区间 (0,1) 和它的端点 1：

- 1 不在 (0,1) 里——它是开区间，两端点被排除
- 但 1 是"接触"这个区间的：随便你用多小的距离量，在 (0,1) 里总能找到离 1 比任何给定距离更近的点

于是矛盾出现了：**1 既"不在"集合内部，又"贴着"集合的边缘。** 这个暧昧的存在，需要精确的语言来命名。不然"闭包的闭包"这类运算无法开展，而"连续函数在端点取得极值"也根本没有承载它的盒子。

### 动机总结

第 9 章之所以先用 9.1 介绍子集结构，是因为之后的每一步——左极限、右极限、最大原理——都需要回答：

- "点 x 有没有资格谈论 f 在 x 处的极限？"（答案是：x 必须是定义域的**粘着点**）
- "一个集合有没有'边缘'？"（闭包）
- "哪些集合配得上'紧致'这个强性质？"（Heine–Borel 定理）

**没有 9.1，后面的所有定理都是空中楼阁。** 本节的全部内容，可以浓缩为一个词：**ε-adherent**（ε 粘着）。其余一切，都是它的推论。

## 第二幕 · 揭示：ε 粘着与闭包的阶梯

### 第一步：ε-粘着（Definition 9.1.5）

陶哲轩先把"接近程度"参数化。给定 ε > 0，说点 x 是集合 X 的 **ε-粘着点**：

> **定义**：x ∈ ℝ，X ⊆ ℝ，ε > 0。x 是 X 的 ε-粘着点，当且仅当存在 y ∈ X 使 |x − y| ≤ ε。

也就是"集合里有没有一个点，离 x 不超过 ε"。参数 ε 是你的测量精度：ε 越严苛，x 越难粘着。

Lean 中（`Section_9_1.lean:64`）：

```lean
abbrev Real.adherent' (ε:ℝ) (x:ℝ) (X: Set ℝ) := ∃ y ∈ X, |x - y| ≤ ε
abbrev AdherentPt (x:ℝ) (X:Set ℝ) := ∀ ε > (0:ℝ), ε.adherent' x X
```

读法：**"对任一 ε > 0，都能在 X 里抓到离 x 不超 ε 的一个点。"** 注意这里的 ∀ ε 是"无论你把尺子调得多精细，我都能找到更近的点"。这就是"x 无论如何都擦着集合表面"的精确叙述。

### 第二步：闭包（Definition 9.1.10）

把 ε 放逐到任意大小，得到**闭包**：

> **定义（闭包）**：X 的闭包 X̄ = {x ∈ ℝ : x 是 X 的驻点}

在 Lean：`closure X = { x | AdherentPt x X }`（`:118`）。

三个立刻出现的结论（Lemma 9.1.11-9.1.14）：

- **包容**：X ⊆ X̄ ── 自己的点当然擦着自己
- **闭包的闭包还是闭包**：X̄̄ = X̄
- **极限刻画**（Lemma 9.1.14，Lean `limit_of_AdherentPt`）：x 是 X 的驻点 **⟺** 存在一条 X 内的序列收敛到 x。**这是"粘附"和"序列极限"的握手：9.1 是通向 9.4 的序列桥。**

### 第三步：闭集（Definition 9.1.15）

```
X 是闭的  ⟺  X̄ = X  ⟺  每个驻点都真的属于 X
```

Lean（`:429`）：`IsClosed X ↔ closure X = X`。

闭区间是闭的，开区间不是——端点只有闭区间才敢"收留"。**Closure 是"把边界补回集合"的动作，闭集是不需要补的集合**。反过来补完的集合恰是闭包。

### 第四步：极限点 vs 孤立点（Definition 9.1.18-19）

这里第一次出现"剪断"的操作：

- **极限点**：x 是 X \ {x} 的驻点（把 x 自己挖掉，还剩一堆点逼近它）
- **孤立点**：x ∈ X，且离 X \ {x} 有正距离（把 x 挖掉后，没人再挨得着它）

`LimitPt.iff_limit`（Lean `:576`）：x 是极限点 ⟺ 存在序列全在 X \ {x} 里收敛到 x——**极限点的本质是"可以去而复返"**；孤立点的本质是"孤零零一格"。

### 第五步：Heine–Borel（Theorem 9.1.24）

结尾是第 9 章的第一颗高压阀：

> **定理 9.1.24（线版 Heine–Borel）**：X ⊆ ℝ 是**闭且闭**的，当且仅当：任何取值于 X 的序列，都有子列收敛到 X 里的某个点。

翻译成人话：**闭有界集合从不' 逃'**——无论序列怎么在 X 里乱跑，总能抓出一个收敛的子序列且不走漏边界。反之，一旦集合不闭或不bound，就会有人能逃出去。

Lean 对应（`:906`）：

```lean
theorem Heine_Borel (X : Set ℝ) : IsClosed X ∧ IsBounded X ↔ 任何(子)收敛序列不动 X
```

这个定理是全章最贵的"积分材料"：9.6 的最大原理、9.7 的中值定理、9.9 的均匀连续，**全部**在这颗树上。陶哲轩在 9.6 开头明说："It is here that we shall begin exploiting the full power of the Heine–Borel theorem."

## 第三幕 · 愿景：为 9.3/9.4 铺路

### 本节盖好什么

1. **"靠近"有了法律**：ε-adherent、AdherentPt、closure
2. **"边界"有了定义**：闭集（不需要补的集合）
3. **"可以无限滞留"有了定理**：Heine–Borel——序列逃不出闭有界集
4. **极限的资格**：x₀ 必须是 E 的驻点，函数才能谈 x → x₀ 的极限（这就是 9.3 的定义前提！）

### 反直觉一刻：Q 稠密却不开

闭包引理（Lemma 9.1.13）给出一组难以置信的组合：

```
clos(ℤ) = ℤ       -- 整数"补不上"，原地不动
clos(ℚ) = ℝ       -- 有理数密密麻麻，闭包是整条线！
```

- ℚ **不闭**：因为 ℚ 的驻点是所有实数，而 ℚ ≠ ℝ。
- ℤ 的闭包是 ℤ：整数的驻点还是整数，所以**闭**。

**闭集 ≠ 风墙粗**。ℤ 稀疏但闭，ℚ 稠密但不闭。 密不封闭、闭不密——闭包是这套差别的最小精确叙述。

> Lean：`closure_of_Q : closure ((fun q:ℚ ↦ q) '' .univ) = Set.univ`（`:388`）——一行证明 https:// 3.2的密度定理('\sqrt2 取网)。

## 原文（PDF 提取，公式为 ASCII 转写）

**Definition 9.1.5 (ε-adherent points)**: micro...
Let X be a subset of R, let ε > 0, and let x ∈R. We say that x is ε-adherent to X iff there exists a y ∈X which is ε-close to x (i.e., |x −y| ≤ε). [Remark 9.1.6: The terminology"ε-adherent" is not standard in the literature. However, we shall shortly use it to define the notion of an adherent point, which is standard.]

**Definition 9.1.8 (Adherent points)**: Let X ⊆ ℝ, and x ∈ ℝ. x is an adherent point of X iff it is ε-adherent to X for every ε > 0.

**Definition 9.1.10 (Closure)**: The closure X of X is the set of all the adherent points of X.

**Definition 9.1.15**: E ⊆ ℝ is closed iff E = Ē, i.e. E contains all of its adherent points.

**Lemma 9.1.14**: x is an adherent point of X iff there exists a sequence (an)∞ n=0, consisting entirely of elements in X, which converges to x.

**Theorem 9.1.24 (Heine–Borel theorem for the line)**: X ⊆ ℝ is closed and bounded ⟺ every sequence taking values in X has a subsequence converging to a point L in X.

—— Tes. selected bullet: "In the language of metric space topology, it asserts that every subset of the real line which is closed and bounded is also compact; see Sect.1.5. A more general version of this theorem, due to Eduard Heine(1821–1881) and Emile Borel(1871–1956), can be found in Theorem 1.5.7."

—— Remark 9.1.25 (on why Heine–Borel matters): "This theorem shall play a key role in subsequent sections of this chapter."
