# 08 · 9.8 单调函数：单调是"半个连续"，却是反函数的地基

> 陶哲轩《实分析》9.8 完整叙事 + 原文 + Lean 形式化对照
> One Big Idea：**单调函数不需要连续也能有极限、有反函数——连续只是"锦上添花"，单调才是"命根子"。**

---

## 第一幕 · 动机：为什么把"单调"单独开一节？

### 开场：一个你以为必须连续才能成立的定理

问你：f(x) = x³ 有没有反函数？有：x^(1/3)。f 连续吗？连续。所以你可能以为"反函数存在"需要连续性。

现在问：f 如果**不连续**呢？比如取整函数 f(x) = ⌊x⌋——单调不减，处处跳跃。它有"反函数"吗？严格说没有（2.5 的像不存在唯一的原像？不对——⌊x⌋ = 2 有无限多个 x）。但换个视角：**单调不减函数的"值域"和"定义域"之间，存在一种几乎完整的对应——只要你不要求"满"和"一一"，单调性本身就能把"逆"造出来。** 这一节反复在玩这件事。

### 反派登场：单调的三种人格

定义上，单调（monotone）有四种变体，Lean 全都有对应的 iff 判定定理（`Section_9_8.lean:21-38`）：

```
MonotoneOn   f X ↔ ∀ x y ∈ X, y > x → f y ≥ f x     -- 不减
StrictMonoOn f X ↔ ∀ x y ∈ X, y > x → f y > f x     -- 严格增
AntitoneOn   f X ↔ ... f y ≤ f x                     -- 不增
StrictAntiOn f X ↔ ... f y < f x                     -- 严格减
```

四种都只是"比较的方向 + 严格与否"的组合。但它们的性质天差地别：**严格单调 ⟹ 单射**（一一对应），而"不减"则允许平台。反函数需要的正是单射性——所以严格单调才是反函数的必要条件，连续根本不是。

### 本节的反直觉王牌

看这个函数（Lean `f_9_8_5`，`:670` 起）：

```
f(x) = 0                 若 x < 0
       1/q                若 x = p/q 为最简分数（q>0，p≠0）
       1                   若 x 是无理数
```

等等——这函数**在每个有理点都不连续**（`ContinuousAt.of_f_9_8_5'` `:750`），但它**严格单调递增**（`StrictMonoOn.of_f_9_8_5` `:670`）！这是陶哲轩 Exercise 9.8.5 的怪物：处处稠密的不连续点 + 严格的单调性并存。

**单调函数可以在稠密集合上处处不连续。** 连续性不是单调性的结果，也不是它的前提——它们是两个互相正交的性质。这就是本节存在的理由：**把"单调"从"连续"的阴影里解放出来，单独发一张身份证。**

## 第二幕 · 揭示：单调 ⟹ 极限存在（单侧）

### 单调函数的"半连续"

教科书上这条（Proposition 9.8.1 附近）可能是整个第 9 章最被低估的定理：

> **f 单调 ⟹ 在每一点都有左极限和右极限**（在扩展实数意义下）。

直觉：单调函数"只往一个方向走"，所以在每一点两侧都有明确的极限——左边是"从下方逼近的墙"，右边是"从上方逼近的墙"。不需要连续，**单调本身就是"极限存在"的保证**。

Lean 里对应的不是"极限存在"而是它最强的事实——`MonotoneOn.exist_inverse`（`:152`）：

```
定理：f 在 [a,b] 上严格单调且连续
      ⟹ ∃ g : [f a, f b] → [a,b]，g 是 f 的反函数（且 g 连续）
```

**严格单调 + 连续 ⟹ 反函数连续。** 这是 9.8 的总定理，也是第 10 章构造 exp、log、arcsin 的弹药：先证明严格单调（好证），再证明连续（中值定理帮），反函数随之自动存在且连续（本节）。

### 用单调性证明"不连续点不多"

另一个重要事实（Froda 定理）：**单调函数的不连续点至多可数**。直觉：每次跳跃都"吃掉"一个非空的区间——(f(x⁻), f(x⁺))，而不同的跳跃区间互不相交，数轴上互不相交的非空区间只能有可数多个。**单调函数的"混乱"是稀疏的。**

Lean 里 `no_monotone_intermediate_value`（`:469`）等四条定理（`:439-520`）唱的是另一出戏：**严格单调函数不满足中值定理**——它可能从一个值跳到另一个值而从不穿过中间值。反过来说：**中值定理（9.7）与单调性（9.8）是两个独立的性格**，连续函数可能既不单调又满足中值定理，单调函数可能满足也不连续。

## 第三幕 · 愿景：单调性带来的世界

9.8 之后你多了一件装备：

1. **反函数制造机**：严格单调 + 连续 ⟹ 反函数连续（`exist_inverse`）——第 10 章 exp/log 全家都靠它
2. **跳跃计数**：单调函数不连续点至多可数（Froda）——"跳"是稀罕物
3. **平台与跳跃的分类**：`IsMaxOn.of_monotone_on_compact`（`:350`）——单调函数在闭区间上极值出现在端点

还有一层更深的哲学：**9.7 和 9.8 是互补的**——中值定理说"连续 ⟹ 填满"，单调说"严格 ⟹ 不重叠"。两者一起，才给了"连续严格单调 ⟹ 同胚（保序同构）"这个第 10 章反复使用的金刚钻。

## 原文（PDF 提取）

**Definition 9.8.1 (Monotone functions)**: Let X ⊆ R and f : X →R. We say f is monotone increasing iff f (x) ≤f (y) whenever x < y; strictly monotone increasing iff f (x) < f (y); and analogously for decreasing. (Lean：`MonotoneOn` / `StrictMonoOn` / `AntitoneOn` / `StrictAntiOn`。)

**Proposition 9.8.3**: Let X ⊆ R, f : X →R monotone increasing. Then f (x+) and f (x−) exist (possibly extended reals). 单调函数的单侧极限存在。

**Theorem 9.8.6 / Exercise 9.8.4（Lean `MonotoneOn.exist_inverse`）**: Let a < b and f : [a, b] →R be continuous and strictly monotone. Then f is a bijection onto its image, and the inverse f −1 is also continuous. — 反函数连续定理。

**反例 f_9_8_5（Lean 的 `f_9_8_5` 与 `ContinuousAt.of_f_9_8_5'`）**: 一个单调（甚至严格单调）却在有理点处处不连续的函数——教科书与 Lean 用同一具"怪物"证明单调 ≠ 连续。
