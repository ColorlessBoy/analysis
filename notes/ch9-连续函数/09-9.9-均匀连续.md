# 09 · 9.9 均匀连续：把 δ 从"点"中解放出来

> 陶哲轩《实分析》9.9 完整叙事 + 原文 + Lean 形式化对照
> One Big Idea：**连续说"每个点都能找到自己的 δ"；均匀连续说"一个 δ 服务全场"——后者才是积分需要的那一个。**

---

## 第一幕 · 动机：为什么"连续"还不够？

### 开场：连续性的"小气"

把 9.4 的 ε-δ 定义重新摆出来：

```
连续在 x₀： ∀ ε > 0, ∃ δ > 0, ∀ x ∈ X, |x−x₀| < δ → |f x − f x₀| < ε
```

注意量词顺序：**∃ δ 在 ∀ x 之前**——但 δ 可以**依赖 x₀**。这个"依赖"不是写出来的，是藏着的：不同的 x₀ 允许不同的 δ。连续只承诺"每个点附近有办法"，不承诺"同一个办法全场通用"。

于是问题来了：**什么时候需要"同一个 δ"？** 答案是：当你不能逐点检查的时候——正是积分！Riemann 积分把函数切成小段，如果每段的误差"各自为政"，总和就无法控制。**积分需要的不是"处处连续"，是"处处连续且共用一把尺"——均匀连续。**

### 反派登场：1/x 的背叛

看 f(x) = 1/x 在 (0, 2) 上（Lean `not_uniform_continuous_one_div_Ioo` `:170`）。它在每个点都连续——但没有一个 δ 能服务全场。为什么？因为越靠近 0，函数的斜率越大：在 x = 0.001 处，|1/x − 1/0.001| 在 |x − 0.001| = 0.0005 时就已超过 500。**固定 ε = 1，无论你选多小的 δ，都总能在更靠近 0 的地方找到一对点，距离 < δ 但函数值差 ≥ 1。**

用序列的语言（Proposition 9.9.8）：1/n 和 1/(n+1) 都趋于 0，两者**等价**（距离趋于 0）；但 f(1/n) = n 和 f(1/(n+1)) = n+1 的距离趋于 1，**不等价**。均匀连续的函数必须"等价序列映到等价序列"——1/x 做不到。

### 动机总结

9.9 的存在理由是**为第 11 章的 Riemann 积分铺路**：积分证明需要"ε 全局可控"。而它的核心定理（Heine–Cantor，定理 9.9.16）说：**连续 + 闭有界 ⟹ 均匀连续**——你不需要检查所有连续函数，只要域是闭有界的（第 9.6 章），连续自动升级。

## 第二幕 · 揭示：定义、序列等价、Heine–Cantor

### 定义（Definition 9.9.2）

```
UniformContinuousOn f X :=
  ∀ ε > 0, ∃ δ > 0, ∀ x y ∈ X, |x − y| < δ → |f x − f y| < ε
```

**δ 在 ∀ x y 之前**——同一个 δ 服务所有点对 (x, y)。`UniformContinuousOn.iff`（`Section_9_9.lean:161`）就是这条。

注意没有 x₀ 了——均匀连续甚至不需要"点"的概念，它只谈"任意两个点之间"。

### 序列等价（Proposition 9.9.8 / Lemma 9.9.7）

Lean 给出的两个等价刻画（`:336`、`:660`）：

1. **保持等价**：`UniformContinuousOn.iff_preserves_equiv` —— f 把"等价序列"映成"等价序列"
2. **保持 Cauchy**：`UniformContinuousOn.ofCauchy` —— f 把 Cauchy 序列映成 Cauchy 序列

**这是"均匀连续"的最优识别法**：一个函数均匀连续，当且仅当它不把"纠缠在一起的点"拆散。1/x 在 (0,2) 上把 1/n 与 1/(n+1) 这对"纠缠点"硬生生掰开成距离 1——所以不均匀。

### Heine–Cantor 定理（Theorem 9.9.16，Lean `UniformContinuousOn.of_continuousOn` `:886`）

> **闭有界 + 连续 ⟹ 均匀连续**

证明思想：反证。假设存在 ε₀ 使每个 δ 都失效——则对每个 n 存在 xₙ, yₙ 距离 < 1/n 但 |f xₙ − f yₙ| ≥ ε₀。**Heine-Borel（9.1.24）**从 (xₙ) 抓出收敛子列 x_{nⱼ} → x；y_{nⱼ} 也收敛到同一 x（距离 < 1/nⱼ → 0）。连续性（9.4）⟹ f(x_{nⱼ}) → f(x) 且 f(y_{nⱼ}) → f(x)，两者距离趋于 0——与 ≥ ε₀ 矛盾。

**又一次 Heine-Borel 的分红**（第三次：9.6 第一次、9.7 第二次）。闭有界是"抓子列"的资格证，连续是"极限等于值"的保证，均匀性是它们的免费结论。

## 第三幕 · 愿景：为什么积分爱它

1. **积分的入场券**：第 11 章 Riemann 积分需要函数在"分割"上的表现可控——`UniformContinuousOn` 直接提供"全局 δ"，积分证明因此从"逐点打游击"升级为"一次性的 ε-δ 总攻"。
2. **紧致性的报酬**：Heine–Cantor 是"闭有界 ⟹ 好性质"家族里最响的一声——它把"连续"这个局部性质**免费升级**成全局性质，只要域紧。
3. **反例的反面教材**：1/x 在 (0,2) 不均匀、在 [ε, 2] 均匀（闭区间救场）——**开区间是"局部好全局坏"的温床**，闭区间是"局部好全局好"的乐园。

下一节是第 9 章的收尾：把极限的定义域延伸到"无穷"——9.10 无穷极限。

## 原文（PDF 提取）

**Definition 9.9.2 (Uniform continuity)**: Let X ⊆ R and f : X →R. We say f is uniformly continuous iff for every ε > 0 there exists a δ > 0 such that |f (x) −f (y)| < ε for all x, y ∈X with |x −y| < δ.

**Proposition 9.9.8**: Let X ⊆ R and f : X →R. Then f is uniformly continuous iff it maps equivalent sequences to equivalent sequences. — 序列等价刻画。

**Theorem 9.9.16 (Heine–Cantor 定理，书上以 Exercise 形式给)**: A continuous function on a closed bounded interval is uniformly continuous.

**Example 9.9.10**: f (x) = 1/x is continuous but not uniformly continuous on (0, 2) — 因为等价序列 1/n 与 1/(n+1) 被映到不等价序列 n 与 n+1。

在 Lean 中：`UniformContinuousOn.iff_preserves_equiv`（`:336`）与 `UniformContinuousOn.of_continuousOn`（`:886`）分别是 9.9.8 与 9.9.16 的机器版。
