## 第一幕 · 一个合理的希望，和一次徒劳的尝试

### 希望：凭什么实数就不行？

8.1 结束时，你手上有一叠证据：偶数等于自然数，整数等于自然数，连密密麻麻的有理数都等于自然数。每一次你的直觉说"这个显然更大"，一一对应都证明它是错的。经过这么多次教训，一个念头已经变得几乎无法抗拒：

> 也许，所有的无穷都是同一个无穷。也许，实数也是可数的。

这个念头不是妄想，它有一条看起来站得住的推理链。实数是第 5 章里那个精心构造的对象——它来自有理数的极限：柯西序列、等价类、取极限。而有理数可数，是 8.1 刚刚用表格和蛇形路线证明过的事。那么，**从数得完的有理数出发，取极限得到的实数，理应也是数得完的**。可数 → 取极限 → 还可数。这条链子在 8.1 的经验里顺畅得像真的一样。

陶哲轩在 8.3 的开头替你说出了这个推测，说得非常公道：有理数可数，实数只是有理数的极限，所以"实数也可数"看起来完全合理。他甚至没有嘲笑这个推测——因为嘲笑它，等于嘲笑 1873 年之前的整个数学界。当时所有人都是这么想的。

### 尝试：你自己动手排一排

在给出答案之前，先做一件数学家真正会做的事：动手试。

假设你要把实数排成一个序列。有理数能排，靠的是把分数 (a, b) 排成一张无限表格，然后沿对角线走蛇形路线。你自然想对实数做同样的事。把每个实数写成十进制展开：

```
0. 1 2 3 4 5 6 …
0. 5 7 8 1 9 2 …
0. 2 1 4 3 7 5 …
⋮
```

第一行排一个实数，第二行排一个，第三行排一个……你马上撞上两个麻烦。

第一个麻烦，表格不够用。有理数的表格里，每一行是一个分母，行数可数，所以蛇形路线能走完。但实数的表格里，"每一行"本身是无限长的一串数字——你排多少行都填不满这串数字的无限。想用表格排实数，等于先把"实数可数"当成了前提。这是循环。

第二个麻烦，同一个实数有两种写法。0.999… 和 1.000… 是同一个数，表格会重复。

你试了一会儿，承认没找到排法。但是——**"没找到"不是"不存在"**。在 8.1 里你见过多少次"没找到"最终变成"找到了"？整数的手风琴、有理数的蛇形，哪一次不是"你以为排不了"然后被一个巧思解决？所以此刻你的状态是：**没有反例，也没有证明，只有一条看起来顺理成章的推理链，和一次失败的尝试。**

这正是数学里最危险、也最激动人心的时刻。

## 第二幕 · 揭示：换一个问题，然后取反

### 康托尔的换位

1873 年，康托尔（1845–1918）做了一件让整个数学界震惊的事：他证明实数不可数。

他的天才不在于找到了什么精妙的排法——而在于**他换了一个问题**。他不问"怎么把实数排成序列"，他问：

> **假设我已经有一个排好的序列——你能证明它一定有漏网之鱼吗？**

这个换位改变了整个博弈的规则。排法是你找的，你找到什么，他都能当场从你的序列里**构造**一个不在序列里的实数。你换一个排法，他再构造一个。你永远赢不了——不是因为你排得不够好，而是因为**构造法本身保证了任何序列都排不完**。

于是结论不再是"你排得不好"，而是"根本排不完"。一次验证一个序列？不——他的构造法一次验证所有可能的序列。

这个构造法，就是数学史上被引用最多的论证：**对角线论证（diagonal argument）**。让我们分两步看它：先用十进制这种看得见摸得着的形式，再上陶哲轩书里的抽象版本。

### 对角线（十进制版）：漏网之鱼是怎么造出来的

假设你已经把实数排成了一个序列 a₀, a₁, a₂, …。把它们的十进制展开写成一列：

```
a₀ = 0. 3 1 4 1 5 9 …   ← 第 0 行
a₁ = 0. 1 4 1 5 9 2 …   ← 第 1 行
a₂ = 0. 2 7 1 8 2 8 …   ← 第 2 行
a₃ = 0. 4 4 2 8 5 9 …   ← 第 3 行
⋮
```

现在构造一个新数 b。规则只有一条：**b 的第 n 位，取 aₙ 的第 n 位（对角线上的那位）的反面。**如果对角线那位是 3，b 就取 4；如果是 7，b 就取 1；诸如此类——只要保证"取到的数字不等于原来那个"，并且避开 0 和 9 的歧义即可。

按上面的表，b 长这样：

```
b = 0. 4 5 3 6 …
    ↑ ↑ ↑ ↑
    每一位都跟对角线不同
```

现在问那个致命的问题：**b 排在第几行？**

不在第 0 行——b 的第 0 位 ≠ a₀ 的第 0 位，两个数第一位就不同。
不在第 1 行——b 的第 1 位 ≠ a₁ 的第 1 位。
不在第 n 行——b 的第 n 位 ≠ aₙ 的第 n 位。

**b 不在任何一行。**但序列号称包含所有实数。矛盾。

把这段推理的结构拆开看，它干净得让人发冷：

1. 假设存在一个包含所有实数的序列（即可数性成立）
2. 从这个假设出发，构造一个数 b，它和序列里每一个数都不同
3. 于是序列没有包含所有实数——与假设矛盾
4. 所以假设是假的

注意第 2 步的性质：它是**机械的**。b 的每一位怎么取，规则写死了，没有任何"感觉"介入。这就是为什么这个论证能活到今天，能写进 Lean——**它每一步都可以被机器检查。**

### 抽象版：康托尔定理（书里的版本）

陶哲轩的书没有走十进制路线，他直接证明了一个更强的定理。更强，是因为它把"取反"这个动作从"数字"抽象成了"集合"。

先引入工具。集合 X 的**幂集** 2^X，是"X 的所有子集组成的集合"。例如 2^{1,2} = {∅, {1}, {2}, {1,2}}。一个 n 元集合有 2ⁿ 个子集，所以记作 2^X（为什么是 2，见习题 8.3.1）。

**定理（康托尔定理）：对任意集合 X——无论有限还是无限——X 与 2^X 不等势。**

**证明。**反证。假设 X 与 2^X 等势，那么存在一个双射 f : X → 2^X。翻译成人话：**每个元素 x ∈ X，都被配给了一个子集 f(x) ⊆ X。**

现在构造一个特殊的子集：

> **A := { x ∈ X : x ∉ f(x) }**

这个定义值得放慢速度读，它是整个数学史上最著名的一行字。对每一个 x，问它一个问题："**你属于你自己被配给的那个集合吗？**"回答"不属于"的 x，全部收进 A。

A 是 X 的子集（定义就是"X 中满足某条件的元素"），所以 A ∈ 2^X。f 是双射，因此存在唯一的 x₀ ∈ X 使得 **f(x₀) = A**。

现在，对 x₀ 问同一个问题：

- **若 x₀ ∈ A**：由 A 的定义，x₀ ∈ A 意味着 x₀ ∉ f(x₀)。但 f(x₀) = A，所以 x₀ ∉ A。自相矛盾。
- **若 x₀ ∉ A**：由 A 的定义，x₀ ∉ A 意味着 x₀ ∈ f(x₀)（因为 A 只收"∉ f(x) 的 x"，x₀ 不在 A 里，说明 x₀ 满足"∈ f(x₀)"）。但 f(x₀) = A，所以 x₀ ∈ A。自相矛盾。

两种可能，两条死路。假设是假的。□

**为什么这也叫"对角线"？**把 f 想成一张表：行是元素 x，列是子集 f(x)，表格内容回答"x ∈ f(x)？"。A 收集的，恰恰是**对角线上回答"否"的那些 x**——和十进制版本里"取每一位的反面"是同一个动作。十进制翻"数字"，这里翻"属于关系"。翻过来之后构造的对象（b，或 A），天然和每一行都不同。

**同一个动作，两个化身。**这就是对角线论证的完整形态：沿着对角线，把每个答案翻过来，翻出来的东西，谁也配不上。

### 阴影：罗素悖论

陶哲轩在 Remark 8.3.2 里提醒读者：把康托尔定理的证明，和第 3 章的罗素悖论放在一起看。

罗素悖论问的是："**所有不包含自己的集合**组成的集合 R，它包含自己吗？"——无论答是或否，都矛盾。1902 年，就是这个看起来像文字游戏的问题，让弗雷格二十年的大部头当场崩塌。

现在再看 A := {x : x ∉ f(x)}。它和 R := {x : x ∉ x} 长得几乎一模一样——只差一个 f。区别在于：罗素的 R 直接质问"集合能否包含自己"（自指裸奔），而康托尔的 A 把这个问题**折叠进了配给**：f 是双射，所以 A 必须等于某个 f(x₀)，于是 x₀ 的归属问题像罗素悖论一样自指——但这一次，矛盾没有被浪费，它被用来证明"这样的 f 不存在"。

陶哲轩的总结精确得像是给这个问题盖棺定论：**"X 与 2^X 之间的双射，会危险地接近'集合包含自己'这个概念。"**同一个自指动作，罗素用它摧毁了一个体系，康托尔用它建造了无穷的阶梯。自指本身不危险——**没有规则约束的自指才危险**。公理化（第 3 章的集合公理）就是约束；康托尔定理证明的，正是约束之下的自指可以变成什么样的利器。

## 第三幕 · 愿景：无穷的阶梯

### 后果一：2^ℕ 不可数

康托尔定理一出手，第一个推论立刻兑现。假设 2^ℕ 可数，即与 ℕ 等势——但康托尔定理说 2^ℕ 与 ℕ 不等势。矛盾。所以 **2^ℕ 不可数**（推论 8.3.3）。证明里还有一个细小的巧妙：排除"2^ℕ 是有限的"这个可能性时，用的是单点子集 {{n} : n ∈ ℕ}——它和 ℕ 等势，所以 2^ℕ 里装着一个可数无限，不可能是有限集。

### 后果二：实数不可数

然后是那个世纪性的结论：**实数不可数**。因为 ℝ 与 2^ℕ 等势（陶哲轩随后证明这一点；在 Lean 里就是 `Uncountable.real` 一行）。

把这两个后果连起来，8.3 的世界观冲击就完整了：

- **ℕ（自然数）**：可数——最小的无穷
- **2^ℕ ≅ ℝ（实数）**：不可数——严格更大
- **2^ℝ**：再按一次康托尔定理——比实数更大
- **2^(2^ℝ)**：更大
- **无穷大是一个没有顶的阶梯，每一级都严格大于上一级。**

你在 8.1 学到的配对，在这里变成了武器：想证明"这个无穷比那个大"，假设它们能配对，然后用对角线制造一个配不上的对象。**一条对角线，爬不完无穷的阶梯。**希尔伯特后来为这个理论辩护说："没有人能把我们赶出康托尔的天堂。"——你现在知道这座天堂长什么样了：一座没有顶的阶梯。

### 收尾：Schröder-Bernstein，比较的完备化

陶哲轩在这一节的结尾，开始铺垫一个让这座阶梯"规整"的定理。

你自然会问：两个集合，既存在 X 到 Y 的单射（X 不比 Y 大），又存在 Y 到 X 的单射（Y 不比 X 大）——那它们是不是就真的等势？这就是**Schröder-Bernstein 定理**：是的。两个方向都不超，就真的配得平。

这个定理的分量在于：它把"势的比较"从一堆零散的技巧，提升成了一个**完备的序关系**——任何两个集合，在这把尺子上要么小于、要么大于、要么相等。无穷大的阶梯从此有了严格的扶手。（Lean 里 `Schroder_Bernstein` 的完整证明是这一节最难啃的一块，但它值得啃：这是全书第一次让"势"变成一门严格的理论，而不是一组聪明例子。）

### 回到 1873 年

把整个论证从头再走一遍。你会发现它没有一个步骤依赖"感觉"：

| 步骤 | 内容 | 性质 |
|------|------|------|
| 1 | 假设实数可数（或 X 与 2^X 等势） | 反证假设 |
| 2 | 构造 A（或 b），与每一行不同 | 机械构造 |
| 3 | A ∈ 2^X（或 b 是实数） | 定义保证 |
| 4 | 双射保证 A = f(x₀) | 双射定义 |
| 5 | 两种归属都矛盾 | 排除法 |
| 6 | 假设为假 | 反证结束 |

这就是 1873 年那个震惊的全部秘密：它不神秘。**它每一步都可以被检查，所以它不会塌。**你可以不喜欢它的结论（"实数数不完"确实不舒服），但你挑不出它任何一个步骤的毛病——这就是"被验证过的震惊"和"谣言"的区别。

我第一次在 Lean 里看到 `Uncountable.real` 的时候，愣了一会儿：这个震惊了整个数学界的结果，在机器里是十几行代码。但愣完之后是安心——它没有被简化，它本来就干净。**对角线论证能写进 Lean，不是因为漂亮，是因为严格；漂亮只是严格的副产品。**这也是整个第 8 章教给我们的最后一课：直觉可以被背叛，只要推理经得起检查，世界就是稳的。

## 原文（PDF 提取，公式为 ASCII 转写）

> We have just shown that a lot of inﬁnite sets are countable - even such sets as the rationals, for which it is not obvious how to arrange as a sequence. After such examples, one may begin to hope that other inﬁnite sets, such as the real numbers, are also countable - after all, the real numbers are nothing more than (formal) limits of the rationals, and we’ve already shown the rationals are countable, so it seems plausible that the reals are also countable. It was thus a great shock when Georg Cantor (1845–1918) showed in 1873 that certain sets—including the real numbers R are in fact uncountable—no matter how hard you try, you cannot arrange the real numbers R as a sequence a0, a1, a2, . . .. (Of course, the real numbers R can contain many inﬁnite sequences, e.g., the sequence 0, 1, 2, 3, 4, . . .. However, what Cantor proved is that no such sequence can ever exhaust the real numbers; no matter what sequence of real numbers you choose, there will always be some real numbers that are not covered by that sequence.) Recall from Remark 3.4.11 that if X is a set, then the power set of X, denoted 2X := {A : A ⊆ X}, is the set of all subsets of X. Thus for instance 2{1,2} = {∅, {1}, {2}, {1, 2}}. The reason for the notation 2X is given in Exercise 8.3.1.

> **Theorem 8.3.1 (Cantor’s theorem)** Let X be an arbitrary set (ﬁnite or inﬁnite). Then the sets X and 2X cannot have equal cardinality.

> *Proof* Suppose for sake of contradiction that the sets X and 2X had equal cardinality. Then there exists a bijection f : X → 2X between X and the power set of X. Now consider the set A := {x ∈ X : x ∉ f (x)}. Note that this set is well-deﬁned since f (x) is an element of 2X and is hence a subset of X. Clearly A is a subset of X, hence is an element of 2X. Since f is a bijection, there must therefore exist x ∈ X such that f (x) = A. There are now two cases, depending on whether x ∈ A or x ∉ A. If x ∈ A, then by deﬁnition of A we have x ∉ f (x), hence x ∉ A, a contradiction. But if x ∉ A, then x ∉ f (x), hence by deﬁnition of A we have x ∈ A, a contradiction. Thus in either case we have a contradiction. □

> **Remark 8.3.2** The reader should compare the proof of Cantor’s theorem with the statement of Russell’s paradox (Sect.3.2). The point is that a bijection between X and 2X would come dangerously close to the concept of a set X "containing itself".

> **Corollary 8.3.3** 2N is uncountable. Proof By Theorem 8.3.1, 2N cannot have equal cardinality with N, hence is either uncountable or ﬁnite. However, 2N contains as a subset the set of singletons {{n} : n ∈ N}, which is clearly bijective to N and hence countably inﬁnite. Thus 2N cannot be ﬁnite (by Proposition 3.6.14) and is hence uncountable. □
