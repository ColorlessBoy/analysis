## 叙事

### 一、一个看起来很合理的希望

在 8.1 里，我们证明了自然数、整数、有理数全部可数——"可数"的意思很具体：**能排成一个序列 a₀, a₁, a₂, …，一个不漏。**

到 8.3 的时候，我们已经积累了一个不寻常的经验：很多东西比你想象的"小"。偶数不比自然数少，整数不比自然数多，连密密麻麻的有理数都能数完。每次你的直觉说"这个集合显然更大"，一一对应都证明它是错的。

于是，一个念头变得几乎不可避免：

> **实数是不是也可数？**

这不是胡思乱想。它有一个看起来站得住脚的理由：实数是什么？——实数是有理数的极限（第 5 章我们就是这样构造实数的）。而有理数可数。既然"数得完的有理数"能生成实数，"数得完"这个性质似乎应该传下去。

这个推理链：可数 → 取极限 → 还可数。在 8.1 的经验里，它像真的。

### 二、先试试：你自己会怎么排实数？

在给出答案之前，值得先做一件数学家做的事：**先动手试**。假如要你把实数排成一个序列，你会怎么办？

有理数能排，靠的是把分数 (a, b) 排成一张表格，然后沿对角线走。你自然想对实数做同样的事：实数的十进制展开是一串数字，比如

- 0.12345678…
- 0.57819283…
- 0.21437581…
- …

把它们的每一位排成一张表，第一行第一位数、第一行第二位数……你立刻发现两件麻烦事：

第一，**表格不够大**。有理数的表格只有可数多行（每一行是一个分母），而实数的十进制展开"每一行"本身是无限长的一串——你想排多少行都行，但"可数多行"这个前提，正是你要证明的东西。用表格排实数，等于先假设了结论。

第二，**同一个实数有两种写法**。0.999… = 1.000…，表格会重复。

你试了一会儿，发现这条路走不通。但请注意：你只是"没找到排法"——这不能证明"排法不存在"。你的尝试失败了，不等于实数的可数性被否定了。**在 8.1 里我们见过太多"没找到"最后变成"找到了"的案例。**

### 三、康托尔换了一个问题

1873 年，康托尔证明实数不可数。他的做法之所以是天才，是因为他**换了问题**：

> 不是问"怎么把实数排成一个序列"，
> 而是假设"我已经排好了一个序列"，然后证明**这个序列一定有漏网的实数**。

这个换位是整个证明的钥匙。排法是你找的——无论你找到什么排法，康托尔都有一个办法，从你的序列里**当场构造一个不在序列里的实数**。一次验证一个序列不够有力？那就一次验证所有可能的序列：随便你给什么序列，构造法都造得出漏网者。于是结论不是"你排得不好"，而是"根本排不完"。

这个构造法，就是**对角线论证**。让我们看它怎么工作——先用十进制这种具体的形式看一遍，再上陶哲轩书里的抽象版本。

### 四、对角线论证（十进制版本）

假设你已经把实数排成了一个序列 a₀, a₁, a₂, …。把它们的十进制展开写成一列：

```
a₀ = 0. 3 1 4 1 5 9 …   ← 第 0 行的第 0、1、2、3…位
a₁ = 0. 1 4 1 5 9 2 …   ← 第 1 行
a₂ = 0. 2 7 1 8 2 8 …   ← 第 2 行
a₃ = 0. 4 4 2 8 5 9 …   ← 第 3 行
⋮
```

现在构造一个新数 b。**它的第 n 位，取第 n 行第 n 位的"反面"**——如果 aₙ 的第 n 位是 3，b 的第 n 位就取 4；如果 aₙ 的第 n 位是 7，b 的第 n 位就取 1，诸如此类（只要保证取到的数字不等于原来那个，且避开 0 和 9 的歧义）。

按上面的表，b 长这样：

```
b = 0. 4 5 3 6 …
    ↑ ↑ ↑ ↑
    跟对角线每一位不同
```

现在检查：**b 在第几行？**

不在第 0 行——因为 b 的第 0 位 ≠ a₀ 的第 0 位，两个数在第一位就不同。
不在第 1 行——因为 b 的第 1 位 ≠ a₁ 的第 1 位。
不在第 n 行——因为 b 的第 n 位 ≠ aₙ 的第 n 位。

**b 不在任何一行。**但序列 a₀, a₁, a₂, … 号称包含所有实数。矛盾。

所以：任何实数序列都有漏网之鱼。**实数不可数。**

注意这个论证的逻辑结构，它干净得让人发冷：

1. 假设存在一个包含所有实数的序列（可数性）
2. 从这个假设出发，构造一个数，它和序列里每一个数都不同
3. 于是序列没有包含所有实数——与假设矛盾
4. 所以假设是假的

整个证明没有一处依赖"直觉"或"显然"——每一步都是机械的、可检查的。这也是为什么它能活到今天，能写进 Lean。

### 五、陶哲轩书里的版本：幂集与抽象对角线

陶哲轩的书没有走十进制路线，他直接证明了一个更强的定理——**康托尔定理**。它把对角线从"数字串"抽象成"集合"，威力大得多。

先引入工具：集合 X 的**幂集** 2^X 是"X 的所有子集组成的集合"。例如 2^{1,2} = {∅, {1}, {2}, {1,2}}——一个 n 元集合有 2ⁿ 个子集，所以记作 2^X（习题 8.3.1）。

**定理（康托尔定理）：对任意集合 X（有限或无限），X 与 2^X 不等势。**

**证明。**反证：假设等势，则存在双射 f : X → 2^X。也就是说，**每个元素 x ∈ X 被配给一个子集 f(x) ⊆ X。**

现在构造一个特殊子集：

> **A := { x ∈ X : x ∉ f(x) }**

这个定义要慢慢读：对每个 x，问它一个问题——"你属于你自己被配给的那个集合吗？"把回答"不属于"的 x 收集起来，就是 A。

A ⊆ X，所以 A ∈ 2^X。f 是双射，故存在唯一的 x₀ ∈ X 使得 f(x₀) = A。现在对 x₀ 问同一个问题：

- **若 x₀ ∈ A**：由 A 的定义，x₀ ∈ A 意味着 x₀ ∉ f(x₀)。但 f(x₀) = A，所以 x₀ ∉ A。自相矛盾。
- **若 x₀ ∉ A**：由 A 的定义，x₀ ∉ A 意味着 x₀ ∉ f(x₀) 不成立，即 x₀ ∈ f(x₀)。但 f(x₀) = A，所以 x₀ ∈ A。自相矛盾。

两种可能都通向矛盾。假设"等势"是假的。□

**为什么这叫"对角线"？**把 f 想成一张表：行是元素 x，列是子集 f(x)，表中的格子回答"x ∈ f(x)"。A 恰恰收集了**对角线上回答"否"的那些 x**——和十进制版本里"取每一位的反面"是同一个动作：沿着对角线，把每个位置的答案翻过来。十进制版本翻"数字"，这里翻"属于关系"。翻过来之后构造的对象（b，或 A），天然和每一行都不同。

### 六、罗素悖论的阴影

陶哲轩在 Remark 8.3.2 里提醒读者：把康托尔定理的证明，和第 3 章的罗素悖论放在一起看。

罗素悖论问的是：**"所有不包含自己的集合"组成的集合 R，它包含自己吗？**——无论答是或否，都矛盾。

康托尔定理的证明里，A := {x : x ∉ f(x)} 这个集合，长得和 R := {x : x ∉ x} 几乎一样。区别在于：罗素的 R 直接质问"集合能否包含自己"，而康托尔的 A 把这个问题**折叠进了 f 的配给**里——f 是双射，所以 A 必须等于某个 f(x₀)，于是 x₀ 的归属问题像罗素悖论一样自指，但这次，矛盾被用来证明"这样的 f 不存在"。

陶哲轩说得精确：**"X 与 2^X 之间的双射，会危险地接近'集合包含自己'这个概念。"**罗素悖论是"自指导致崩塌"，康托尔定理是"把自指变成武器"。同一个动作，一个摧毁了弗雷格二十年的工作，一个证明了无穷大有无止境的等级。

### 七、后果：无穷大的阶梯

康托尔定理一出手，推论立刻兑现：

1. **2^ℕ 不可数**（推论 8.3.3）：假设可数，即与 ℕ 等势——但康托尔定理说 2^ℕ 与 ℕ 不等势。矛盾。
2. **实数不可数**：因为 ℝ 与 2^ℕ 等势（陶哲轩随后证明；Lean 里是 `Uncountable.real`）。

于是世界观冲击完整了：

- ℕ（自然数）：可数——最小的无穷
- 2^ℕ ≅ ℝ（实数）：不可数——严格更大
- 2^ℝ：再按一次康托尔定理——比实数更大
- 2^(2^ℝ)：更大……
- **无穷大是一个没有顶的阶梯，每一级都严格大于上一级。**

8.1 教你的"配对"在这里变成了武器：想证明"这个无穷比那个大"，假设它们能配对，然后用对角线制造一个配不上的对象。一条对角线，爬不完无穷的阶梯。

最后，陶哲轩在这一节结尾开始铺垫一个收尾定理——**Schröder-Bernstein**：如果 X 到 Y 存在单射（X 不比 Y 大），且 Y 到 X 存在单射（Y 不比 X 大），那么 X 与 Y 等势。它回答了一个自然的问题：**两个方向都不超、是不是就真的相等？**答案是是——它让"无穷大的比较"成为完备的序关系。（Lean 里 `Schroder_Bernstein` 的完整证明在这一节是最难啃的一块，但它值得啃：这是全书第一次把"势的比较"从直觉提升为严格的序理论。）

### 八、回到 1873 年

把整个论证再走一遍，你会发现它没有任何一步依赖"感觉"：

| 步骤 | 内容 | 性质 |
|------|------|------|
| 1 | 假设实数可数 | 反证假设 |
| 2 | 构造 A（或 b）与每一行不同 | 机械构造 |
| 3 | A 必须属于 2^X（或 b 必须是实数） | 定义保证 |
| 4 | 双射保证 A = f(x₀) | 双射定义 |
| 5 | 两种归属都矛盾 | 排除法 |
| 6 | 假设为假 | 反证结束 |

每一步都是可以逐行检查的。这就是它和 8.1 里那些"反直觉却成立"的证明共享的品质：**直觉可以被背叛，只要推理经得起检查，世界就是稳的。**1873 年的震惊，靠的不是康托尔的声望，是这条推理链本身。

我第一次在 Lean 里看到 `Uncountable.real` 时，愣了一下——这个震惊了整个数学界的结果，在机器里是十几行代码。但那不是因为它被简化了，而是因为它**本来就干净**。对角线论证能写进 Lean，不是因为漂亮，是因为严格——漂亮只是严格的副产品。

## 原文（PDF 提取，公式为 ASCII 转写）

> We have just shown that a lot of inﬁnite sets are countable - even such sets as the rationals, for which it is not obvious how to arrange as a sequence. After such examples, one may begin to hope that other inﬁnite sets, such as the real numbers, are also countable - after all, the real numbers are nothing more than (formal) limits of the rationals, and we’ve already shown the rationals are countable, so it seems plausible that the reals are also countable. It was thus a great shock when Georg Cantor (1845–1918) showed in 1873 that certain sets—including the real numbers R are in fact uncountable—no matter how hard you try, you cannot arrange the real numbers R as a sequence a0, a1, a2, . . .. (Of course, the real numbers R can contain many inﬁnite sequences, e.g., the sequence 0, 1, 2, 3, 4, . . .. However, what Cantor proved is that no such sequence can ever exhaust the real numbers; no matter what sequence of real numbers you choose, there will always be some real numbers that are not covered by that sequence.) Recall from Remark 3.4.11 that if X is a set, then the power set of X, denoted 2X := {A : A ⊆ X}, is the set of all subsets of X. Thus for instance 2{1,2} = {∅, {1}, {2}, {1, 2}}. The reason for the notation 2X is given in Exercise 8.3.1.

> **Theorem 8.3.1 (Cantor’s theorem)** Let X be an arbitrary set (ﬁnite or inﬁnite). Then the sets X and 2X cannot have equal cardinality.

> *Proof* Suppose for sake of contradiction that the sets X and 2X had equal cardinality. Then there exists a bijection f : X → 2X between X and the power set of X. Now consider the set A := {x ∈ X : x ∉ f (x)}. Note that this set is well-deﬁned since f (x) is an element of 2X and is hence a subset of X. Clearly A is a subset of X, hence is an element of 2X. Since f is a bijection, there must therefore exist x ∈ X such that f (x) = A. There are now two cases, depending on whether x ∈ A or x ∉ A. If x ∈ A, then by deﬁnition of A we have x ∉ f (x), hence x ∉ A, a contradiction. But if x ∉ A, then x ∉ f (x), hence by deﬁnition of A we have x ∈ A, a contradiction. Thus in either case we have a contradiction. □

> **Remark 8.3.2** The reader should compare the proof of Cantor’s theorem with the statement of Russell’s paradox (Sect.3.2). The point is that a bijection between X and 2X would come dangerously close to the concept of a set X "containing itself".

> **Corollary 8.3.3** 2N is uncountable. Proof By Theorem 8.3.1, 2N cannot have equal cardinality with N, hence is either uncountable or ﬁnite. However, 2N contains as a subset the set of singletons {{n} : n ∈ N}, which is clearly bijective to N and hence countably inﬁnite. Thus 2N cannot be ﬁnite (by Proposition 3.6.14) and is hence uncountable. □
