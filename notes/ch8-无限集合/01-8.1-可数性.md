# 01 · 8.1 可数性：在无穷的世界里，数量感会撒谎

> 陶哲轩《实分析》8.1 完整叙事 + 原文 + Lean 形式化对照
> One Big Idea：**在无穷的世界里，你的数量感会撒谎，但配对永远不会。**

---

## 第一幕 · 反派登场：你的数量感

### 开场：一件你从没想过的事

你从来不用数数，就知道自己的十根手指和别人的十根手指一样多——不，你连"数"都不用。你把两根拇指碰在一起，两根食指碰在一起，一直碰下去，没有剩下任何一根。你说："一样多。"

注意这个动作：**你没有数，你配了对。**

这个动作太原始、太自然，以至于你从没把它当回事。但它其实是数学里最深的一个念头——甚至可以说，这一章的全部故事，都藏在这个动作里。

因为，如果"一样多"的定义是"能配对"，那么有一个你从未想过的问题会立刻浮出水面：**数数本身，是什么？**

数数，不过是把"一、二、三、四……"这些自然数和手指一个一个配对。十根手指 = 配对到 10。所以"数数"是"配对"的一个特例——配对到自然数的特例。**配对是更基本的东西。**

这个观察在一开始毫无用处。在有限的世界里，"配对"和"数数"说的完全是一回事：三个苹果和三个梨能配对，和四个梨不能。你的数量感在有限世界里绝对可靠，你信任它，有充分的理由。

但这一章的主题是：**当世界变成无限，你的数量感会开始撒谎。而配对不会。**

### 第一击：自然数和偶数

让我们看第一场冲突。考虑自然数 ℕ = {0, 1, 2, 3, 4, …}，和偶数 {0, 2, 4, 6, …}。

你的数量感说得非常明确：偶数只是自然数的一半，自然数是偶数的两倍。这个判断在有限世界里永远不会错——1 到 10 里只有五个偶数。

然后按配对来。定义一个规则 f：f(n) = 2n。它把每个自然数配给一个偶数：

```
0 → 0
1 → 2
2 → 4
3 → 6
4 → 8
⋮
```

检查这个配对的资格。它漏掉任何一个偶数吗？没有——任何偶数 2k 都被 f(k) 配到了。它有任何一个偶数被配了两次吗？没有——不同的自然数配给不同的偶数。

一个不多，一个不少，全部对上。**自然数和偶数一样多。**

你的数量感第一次被当众反驳。它很不服气："自然数明明有两倍那么多！"但请注意，此刻它拿不出任何论据——它只能重复"明明"。而配对拿出了完整的清单：漏掉任何一个偶数，请你指出来；重复配了任何一个，请你指出来。你指不出来。

在数学里，"我感觉不对"和"我指不出来"，从来不是同一等级的证据。

### 反派的名片

让我们把这场冲突的本质看清楚。你的数量感不是坏东西——它在有限世界里忠心耿耿服务了你好几千年。它的失效也不是偶然：**数量感是为"有限"进化出来的**。当你面对有限的东西，数一数，完了。而当世界变成无限，这个工具的工作原理就崩了——"一半""两倍""更多"这些词，在无限世界里没有一个有定义。

而配对是唯一的幸存者。它不依赖"数得完"，它只依赖"对得上"。**这就是这一章的赌注：在无穷的世界里，直觉全部失效，定义重新接管。**接下来的全部篇幅，就是这场接管的执行过程。

## 第二幕 · 揭示：裁判登场

### 裁判的定义：EqualCard

现在，让裁判正式登场。陶哲轩在 8.1 的开头给出定义：

> **定义（等势）**：两个集合 X 和 Y 等势（equal cardinality），当且仅当存在一个双射 f : X → Y。

在 Lean 里，这个定义长这样（本仓库 `analysis/Section_8_1.lean` 第 28 行）：

```lean
abbrev EqualCard (X Y : Type) : Prop := ∃ f : X → Y, Function.Bijective f
```

逐字读它：**"存在一个从 X 到 Y 的函数 f，而且 f 是双射。"** 双射的意思是：X 里每个元素恰好配给 Y 里一个元素，Y 里每个元素恰好被配到一个——谁也不多，谁也不少。这正是你开场那个"碰手指"的动作，被写成了机器能检查的语句。

这个定义值得你多看两眼，因为它做了两件了不起的事。

第一，**它没有使用"数字"**。没有"数一数"，没有"一样多是多少"——只有配对。所以它可以在无限的世界里运行。

第二，**它是有限世界的严格推广**。三个苹果和三个梨能配对，所以等势；三个苹果和四个梨不能，所以不等势。你的数量感在有限世界判断对的事情，这个定义原封不动地确认。**它没有推翻你的直觉，它只是接管了你的直觉的地盘，并用一种能延伸到无限的方式重新表述。**

从这一刻起，"一样多"不再是一种感觉，是一个可以检查的命题。

### 工具：良序原理

裁判有了，还需要一件工具。

考虑一个场景：自然数的某个无限子集 X——比如所有质数，或者所有平方数。你想把 X 也排成一个序列 a₀, a₁, a₂, …。怎么排？从最小的开始。

这里用到一个命题：**自然数的任何非空子集都有最小元素。**这就是良序原理。它在 8.1 的开头出现，看起来像一句废话——但请想想它的力量：不管 X 是什么奇怪的子集，你总能"从最小开始"。

于是排法就有了：a₀ 取 X 的最小元素，a₁ 取 X 去掉 a₀ 后剩下的最小元素，a₂ 再取一次……每一步，良序原理都担保"下一个最小元素存在"。这样一个接一个，X 被完整地排成了一个序列——**自然数的任何无限子集，都和自然数一样多**（命题 8.1.5）。

注意陶哲轩在这里留下的东西：他把证明写成了带问号的草图——"这个集合是无限的（?）""可以证明 aₙ 是递增的（?）"。问号处，是习题 8.1.3 留给你的。他信你填得上。**这是教材和读者的第一次交接：他给结构，你给严谨。**

### 第二击：整数也可数

工具在手，开始攻城。整数 ℤ = {…, −2, −1, 0, 1, 2, …}，可数吗？

你的数量感说：整数在自然数"两边"都有，该是自然数的两倍。

按配对来。排法：

```
0 → 0
1 → 1
2 → −1
3 → 2
4 → −2
5 → 3
6 → −3
⋮
```

正着走一个，负着走一个，像拉手风琴。每一个整数都被配到，没有漏网，没有重复。**整数和自然数一样多。**

到了这一步，你的数量感已经不再抗议了——它开始困惑。偶数 = 自然数，整数 = 自然数，那到底什么才是"更多"？

### 揭示时刻：有理数也可数

现在，高潮。**有理数 ℚ，可数吗？**

这一次，连你的理智都站在直觉那边。有理数密密麻麻地铺满整条数轴：任何两个有理数之间，永远还有一个有理数。你随手一画，就画得出无限多个。它怎么可能是"数得完"的？它和自然数之间的缝隙，肉眼可见地大。

陶哲轩在下一节（8.3）回忆起此刻的心情时写道：有理数"多得让人不知道该怎么排成序列"。这不是夸张——你试试就会知道。排整数的手风琴技巧对有理数完全失效：0, 1, −1, 2, −2… 走到哪里都漏掉无穷多个分数。

然后康托尔给出那个排法。它值得你用慢动作看一遍，因为它是这一章的第一个揭示时刻。

把所有**正**有理数想象成一张无限大的表格：第 a 行第 b 列放 a/b。

```
1/1  1/2  1/3  1/4  1/5  …
2/1  2/2  2/3  2/4  …
3/1  3/2  3/3  …
4/1  4/2  …
⋮
```

每一个正有理数，都恰好出现在这张表格的某个位置——这是表格的构造保证的，不需要证明。

现在，沿着**对角线**走，像蛇一样：

```
1/1 → 1/2 → 2/1 → 1/3 → 2/2 → 3/1 → 1/4 → 2/3 → 3/2 → 4/1 → …
```

每一条对角线都是有限长的（第 k 条对角线有 k 个数），所以蛇形路线有明确的开头，走起来不会迷路。一路走，一路跳过重复的（2/2 等于 1/1，跳过）——最后，**每一个正有理数都被恰好走到一次**。

正有理数可数。加上零和负有理数，用整数的手风琴技巧一拼——**有理数可数。**

这就是揭示的瞬间。你的数量感彻底哑口无言：它说不出口"有理数更多"了，因为**"多"这个字，在这条蛇走完之后，没有落脚的地方**。

## 第三幕 · 愿景：密集不是多

### 余韵：两个概念的分家

离开 8.1 之前，让我们把这场冲突的遗产清点一下。

你以前把两件事混为一谈：**"数轴上有多少"** 和 **"排不排得完"**。8.1 告诉你，它们是两个完全不同的性质，分别属于两个不同的概念：

- **密集**：任意两个数之间还有数——这是**序**的性质（排列的性质）
- **可数**：能排成一个序列——这是**势**的性质（配对的性质）

有理数密集，但可数。密集在序的世界里，可数在势的世界里，**它们互不相干**。你的数量感之所以被骗，是因为它把序的性质误当成了势的证据——它看到"密"，就推断"多"，而在无限世界里，这个推断没有依据。

这可能是 8.1 教给你的最重要的一件事，比任何定理都重要：**当你的直觉和定义冲突时，不是直觉错了，是直觉用错了地方。**你的直觉在有限世界里进化了几十万年，它诚实可靠，只是范围有限。数学做的不是抛弃直觉，而是**划定直觉的管辖范围**——在管辖范围内，直觉是向导；在范围外，定义是法官。

### And one more thing：那张表格会回来

还记得有理数可数用的那张表格吗？沿对角线走蛇形路线，数得完。

在 8.3，你会看到同一张表格的**反转用法**：还是沿对角线，但这一次不是走，是**取反**——把对角线上的每一个数字翻过来，构造一个"不在任何一行里"的新数。走是数得完，取反是数不完。同一张表格，一正一反，一个是康托尔的 1873 年之前的直觉，一个是 1873 年的震惊。

到那时你会明白，8.1 的蛇形路线不只是"排有理数的小技巧"——**它是 8.3 那个世纪级论证的排练。**

### 8.1 Countability

We will refer to the element n given by the well-ordering principle as the minimum of X, and write it as min(X). Thus for instance the minimum of the set {2, 4, 6, 8, . . .} is 2. This minimum is clearly the same as the inﬁmum of X, as deﬁned in Deﬁnition 5.5.10 (why?).

**Proposition 8.1.5** Let X be an inﬁnite subset of the natural numbers N. Then there exists a unique bijection f : N → X which is increasing, in the sense that f (n + 1) > f (n) for all n ∈ N. In particular, X has equal cardinality with N and is hence countable.

*Proof* We will give an incomplete sketch of the proof, with some gaps marked by a question mark (?); these gaps will be ﬁlled in Exercise 8.1.3. We now deﬁne a sequence a0, a1, a2, . . . of natural numbers recursively by the formula an := min{x ∈ X : x ̸= am for all m < n}. Intuitively speaking, a0 is the smallest element of X; a1 is the second smallest element of X, i.e., the smallest element of X once a0 is removed; a2 is the third smallest element of X; and so forth. Observe that in order to deﬁne an, one only needs to know the values of am for all m < n, so this deﬁnition is recursive. Also, since X is inﬁnite, the set {x ∈ X : x ̸= am for all m < n} is inﬁnite(?), hence non-empty. Thus by the well-ordering principle, the minimum, min{x ∈ X : x ̸= am for all m < n} is always well-deﬁned. One can show(?) that an is an increasing sequence, i.e., a0 < a1 < a2 < . . . and in particular that an is never equal to am for any m < n (why?). …

（本节剩余原文：整数的可数性、有理数可数性的表格论证、命题 8.1.7 等。核心结构是：把 (a, b) 对按 a + b 的和逐层排开，每层有限，层层接龙——有理数因此可数。）

### 英雄的定义（第 28 行，全文第一主角）

```lean
abbrev EqualCard (X Y : Type) : Prop := ∃ f : X → Y, Function.Bijective f
```

"X 和 Y 等势" = "存在一个双射 f : X → Y"。就是开场那个碰手指的动作，机器版。

### 其余核心声明

| 声明 | 对应书中的概念 |
|------|---------------|
| `CountablyInfinite X` | 可数无限：与 ℕ 等势 |
| `AtMostCountable X` | 至多可数：可数无限或有限 |
