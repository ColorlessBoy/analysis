# 社媒聆听调研：「自学数学分析」人群痛点（产品方向验证）

- 日期：2026-08-08
- 方法：social-listening skill（OSINT 采集纪律，Fact/Inference/Assumption 标注）
- 决策支持：为「带机器验证答案的数学学习产品」（陶哲轩《实分析》Lean 形式化仓库 + 全量习题解答）验证需求与定位
- 调研者假设（待验证）：① 做习题费时间 ② 怕做错/以为做对 ③ 不想当"苦行僧" ④ 主要替代 = 题解书/网课

## 采集覆盖度声明（诚实声明）

| 平台 | 状态 | 方法 |
|------|------|------|
| Bilibili | ✅ 强 | 官方搜索 API + 视频评论区 API（cookie 方案），5 组关键词，100 条视频元数据 + 5 个视频评论区 |
| 知乎 | ✅ 强（意外发现） | 360 搜索索引的知乎问答原文（知乎直连需登录，此轮未直采） |
| Douyin | ⚠️ 弱 | 360 搜索索引（账号名、主页摘要），无法采集视频评论区 |
| Weibo | ❌ 无 | 微博 API 432 封禁；百度安全验证；Bing/Sogou 无视 site: 操作符 |

结论：本轮证据主要来自 Bilibili + 知乎，X/YouTube/微博需换网络或走 API 后再补。以下所有结论仅基于 B站 + 知乎语料，强度分级已按来源多样性校正。

### 2. 「是不是得专门搜答案」——习题答案获取难，答案形态低质（强度：中-高）

- **Fact** [Bilibili] 视频《两个多月终于裴礼文刷完了》3 万播放，评论（43 赞）：
  > "这答案后面有吗，不记得了 / 是不是得专门搜答案 / 还没准备刷呢" — 静候待伊人，2024 前后
  （裴礼文 = 国内数分习题集标杆）
- **Fact** [360文库] 《数分证明题大全及答案》— 当前中文互联网答案供给形态 = 文库/PDF 打包，无质量校验
- **Fact** [结构证据] 陶哲轩《实分析》习题结构 = "作者会省略证明，而作为习题由学习者证明"（见发现 6），
  **整本书无官方答案** — 你的仓库恰好补这个结构性空缺
- **Inference**：知乎建议"看着答案做"是社区对"证明题无思路"的通行解法 → 答案本身是刚需，
  但现有答案（文库 PDF、流传的扫描件）没有可信度背书，无法回答"我抄完是对的吗"

## 反虚假信号检查

- 幸存者偏差：社媒上发声的自学者多为"坚持下来/极端挫折"者；"自学人群很大"是 Inference 不是 Fact
- 情绪 ≠ 需求："这也要证"是情绪，付费意愿要看行为（抖音账号无商业行为信号）
- 单条爆款：mindclicer 评论是单点证据，结论全部挂"待访谈验证"
