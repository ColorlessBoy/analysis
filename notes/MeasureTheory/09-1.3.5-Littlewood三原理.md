# 09 · 1.3.5 Littlewood 三原理：可测的东西和你想象的差不多一样好

## 1 这一幕要解决什么

把前四节的收获摆上桌：1.3.1 给简单函数（有限层）算了积分，1.3.2 用简单函数的逐点极限抓出了可测函数，1.3.3 用下积分给无符号函数定了 ∫f，1.3.4 用 ∫|f| < ∞ 的牌照把符号函数也收编了。工具齐了，但 1.3.3 开头那个动画悖论还悬在读者心上：取 fₙ = n·1_{(0,1/n)}——一根越变越尖的钉子，每根钉子的面积 ∫fₙ = n·(1/n) = 1，可逐点极限是零函数，于是 lim ∫fₙ = 1 而 ∫(lim fₙ) = 0。**逐点收敛这么自然的收敛方式，连"积分换序"都保证不了，这个理论是不是和经典分析脱节了？**

Littlewood 的回答是一句著名的安慰（书 p.60 原文引为 "Littlewood's three principles"，出自 J. E. Littlewood 1944 年的讲义 *Lectures on the Theory of Functions*，流传版本措辞各异）：三个原理，**可测集差不多是有限个区间的和；绝对可积函数差不多连续；逐点收敛的序列差不多一致收敛**。这句话的意思是：Lebesgue 理论里那些"病态"对象（千疮百孔的集合、处处不连续的函数、只逐点收敛的序列）并不比经典对象更糟糕——它们只是在"差不多"的意义上仍然善良。注意书原话把三原理定性为 "informal heuristics"：它们不是定理，是直觉；本节全部内容就是给这三个"差不多"各找一个精确的、可以写进定理书的版本，并回答同一个问题：**"差不多"三个字到底该量化为多少？**答案是：一个可以任意小的 ε——"删掉一个测度 ≤ ε 的小集合，剩下的一切就都正常了"。

全节的武器库其实只有四件：§1.2 的正则性（外正则性 `Lebesgue_outer_measure.eq` `Section_1_2_1.lean:5732` 与 ε 版 `exists_open_superset_measure_le` :6009、内正则性 `inner_measure.eq_iff` `Section_1_2_2.lean:6476`）、§1.2 的集合单调收敛（向下单调收敛，习题 1.2.11(ii)）、1.3.4 的 Markov/Chebyshev 不等式、以及几何级数预算 Σ ε/2^{n+1} = ε。下面逐个原理走。

## 2 原理一：可测集几乎开——"集合的差不多"已经兑现

原理一的精确版本在 §1.2 就已经全部立起来了，本节只是引用。外正则性（引理 1.2.12）：对每个可测集 E 和 ε > 0，存在开集 U ⊇ E 使 m(U) ≤ m(E) + ε——**测度有限的集合差一点就是开集**；内正则性（习题 1.2.15）：从内部用闭集/紧集逼近；习题 1.2.7 与 1.2.16 合起来说：可测集（有限测度）几乎是一个初等集——有限个箱子的并。所以书 p.60 说原理一的 "various manifestations" 已经给过（"Various manifestations of the first principle were given in Exercise 1.2.7 and Exercise 1.2.16"），本节不再重复证明，只在一处重新使用它：定理 1.3.20(ii) 的证明里，把指示函数 1_E 逼近成阶梯函数的那一步，用的就是"E 几乎初等"。**集合的差不多是函数的差不多的原料**——这是原理一在本节的真正角色。

## 3 原理二（一）：逼近链——定理 1.3.20，L¹ 里三种稠密子集

原理二说"函数差不多连续"。先给出最朴素的版本——不是把 f 换成连续函数，而是在 L¹ 距离里找连续函数，这是"差不多"最弱的、也最容易的形态。

**定理 1.3.20（L¹ 函数的逼近，书 p.60）**：设 f ∈ L¹(ℝᵈ)，ε > 0，则分别存在
(i) 绝对可积**简单**函数 g，(ii) **阶梯**函数 g，(iii) **连续且紧支撑**的函数 g，使得 ‖f − g‖_{L¹} ≤ ε（记号 ‖h‖_{L¹} = ∫|h| 是 1.3.4 的 L¹ 范数，先想成"h 的平均大小"即可）。阶梯函数指有限个箱子（Box：轴平行闭区间盒，1.1 节初等测度的机器）的指示函数的有限线性组合（书 p.60；Lean `RealStepFunction` :391 = 有限个 `Box` 的指示函数带实系数求和，`ComplexStepFunction` :388 同款复版）。

三条结论共享同一个证明骨架（书 p.60–61）：**从无符号到带符号的降级**。(i) 当 f 无符号时，下积分的定义本身就是答案：∫f 是所有 g ≤ f 的简单函数积分构成的集合的上确界（sSup：比集合里每个数都大的最小数，max 的推广——max 要求最大值被取到，sSup 只要求能被逼近，1.3.3 定义 1.3.13），所以存在简单 g ≤ f 且 ∫g ≥ ∫f − ε，即 ∫(f − g) ≤ ε（Lean `unsigned_approx_from_sup` :19 把这个"从 sSup 里提取 ε 逼近"的步骤形式化了：关键是用 L − ε < L 反证 sSup 的性质，:44–49）；f 实值就拆正负部各逼近到 ε/2，复值再拆实部虚部各 ε/4。(ii) 由 (i) 和三角不等式约化到 f = 1_E（m(E) < ∞）：集合几乎初等（习题 1.2.16），指示函数几乎阶梯（Lean `elementary_indicator_is_step` :397 直接宣告"初等集的指示函数是阶梯函数"）。**关键一步**：原理一在这里被函数化——"E 几乎初等"在秤上读出 m(E Δ E′) ≤ ε 之后，‖1_E − 1_{E′}‖_{L¹} = m(E Δ E′) ≤ ε 是免费赠送的。(iii) 由 (ii) 再约化到 f = 1_E 为单个箱子：把箱子 E 装进一个略大的箱子 F ⊃ cl(E)（m(F) ≤ m(E) + ε），构造 g(x) = max(1 − R·dist(x, E), 0)（R 足够大）：g 在 E 上恒 1、在 Fᶜ 上恒 0、过渡带线性下降，连续且紧支撑（书 p.61 的显式构造；Lean 侧对应 `RealStepFunction.approx_by_continuous_compact_aux` :1236 与 `CompactlySupported` :999）。误差就是过渡带的面积，≤ m(F \ E) ≤ ε。

把数字走一遍。f(x) = x 于 [0,1]（外部零延拓），用 dyadic 阶梯逼近：gₙ 在第 i 个格子 [i/2ⁿ, (i+1)/2ⁿ) 上取左端点值 i/2ⁿ。每格误差 ∫_{i/2ⁿ}^{(i+1)/2ⁿ} (x − i/2ⁿ) dx = (1/2)·(2⁻ⁿ)² = 2⁻²ⁿ⁻¹；共 2ⁿ 格，所以 ‖f − gₙ‖_{L¹} = 2ⁿ·2⁻²ⁿ⁻¹ = **1/2^{n+1}**。代入：n = 3 时误差 1/16 = 0.0625；想做到 ε = 0.001，n = 9 就够——1/2¹⁰ = 1/1024 ≈ 0.000977 < 0.001（n = 10 更宽裕：1/2¹¹ = 1/2048 ≈ 0.000488）。误差随 n 几何衰减，因为每格的宽度 2⁻ⁿ 与格数 2ⁿ 精确抵消一次，剩一个 2⁻ⁿ⁻¹。(ii) 的 Lean 版本 `RealAbsolutelyIntegrable.approx_by_step` :911 的证明正是这个思路的机器化：先用 (i) 把 f 逼近到 ε/2，再把简单函数逼近到 ε/2（`RealSimpleFunction.approx_by_step_aux` :707），三角不等式合并两条 ε/2（:920–922）。

**这意味着什么**：L¹ 里"好函数"（简单、阶梯、连续紧支撑）分别稠密。这不是分析小技巧，它是原理二的全部底气：**积分理论只在乎 L¹ 距离，而在 L¹ 距离里连续函数处处可达**。Lusin 定理（§5）就是在这个基础上把"接近"从积分意义升级成逐点意义。

## 4 原理三：逐点收敛几乎一致——Egorov 定理 1.3.26

原理三要回应动画悖论最扎心的部分：逐点收敛连一致收敛的边都摸不着。先数一数收敛模式（书 p.61–62）：逐点、逐点几乎处处、一致，再加上第四种——**局部一致**（定义 1.3.21）：对每个有界集 E，在 E 上一致收敛。Lean 的 `UniformlyConvergesTo` :1488（∀ε>0, ∃N, ∀n ≥ N, ∀x, dist(fₙ x)(g x) ≤ ε）与 `UniformlyConvergesToOn` :1490（限制在有界集 S 上）照抄定义；`LocallyUniformlyConvergesTo` :1493 = 对所有有界 K 一致收敛于 K——注意这是"有界集"版本，书 Remark 1.3.22 说在 ℝᵈ 上它与"每个点有开邻域一致收敛"的版本等价（Heine-Borel），在非局部紧空间两者会分家。书给了三个尺度对比的例子（p.62）：x/n 在 ℝ 上局部一致但不一致收敛；Taylor 部分和 Σ_{n≤N} xⁿ/n! 同样（局部一致收敛到 eˣ）；而 fₙ(x) = (1/(nx))·1_{x>0}（fₙ(0) = 0）只逐点收敛到 0，连局部一致都不是——任何以 0 为**右侧聚点**的有界集 E（例如含一串 x_k ↓ 0），对固定的 n，sup_{x∈E} fₙ(x) ≥ sup_k 1/(nx_k) = ∞，无法一致收敛。（注意不含 0 右侧聚点的有界集——比如 {0} ∪ {1}——不构成障碍，sup = 1/n → 0 反而一致收敛；障碍来自 x_k ↓ 0 的堆积。）

Egorov 定理说：没关系，逐点收敛差的那一口气，用"删掉一个小集合"就能补上。

**定理 1.3.26（Egorov，书 p.62）**：设 fₙ : ℝᵈ → ℂ 可测、逐点几乎处处收敛到 f（几乎处处，a.e.：除一个零测集外；零测集 = 外测度为 0 的集合，1.2.2 的 `IsNull`），ε > 0。则存在可测集 A，m(A) ≤ ε，使得 fₙ 在 ℝᵈ \ A 上**局部一致**收敛到 f。Lean 两个版本：有限测度版 `egorov_on_finite_set` :2004（A 可测、m(A) < ⊤（⊤ = 扩展实数 [0,∞] 的顶元素，即 ∞ 的机器名字，1.3.3 笔记的记号）时，∃E ⊆ A、m(E) ≤ ε、fₙ 在 A \ E 上**一致**收敛——这对应书 Remark 1.3.27 末尾的观察：若所有 fₙ、f 都支撑在一个有限测度集上，"逃逸"不可能发生，一致收敛可以完全恢复）与全空间局部一致版 `PointwiseAeConvergesTo.locallyUniformlyConverges_outside_small` :2207。

证明骨架（书 p.63）分三步，第一步是全部的关键。**关键一步：把"每个点最终收敛"翻译成"坏点集的测度趋于 0"**。书的记号：对固定的 m，令 E_{N,m} := {x : ∃n ≥ N, |fₙ(x) − f(x)| > 1/m}——"从第 N 项以后仍然差超过 1/m"的坏点。逐点收敛保证 ∩_N E_{N,m} 是空的（a.e.）；E_{N,m} 随 N 递减、都可测。于是**向下单调收敛**（习题 1.2.11(ii)）给出 m(E_{N,m} ∩ B(0,R)) → 0。这里"截断到球"不是装饰：向下单调收敛要求测度有限，而递减列本身可以测度恒 ∞——反例 E_N = (N, ∞)：递减、交集空，但 m(E_N) = ∞ 不趋于 0。Lean 用的坏点集与书的略有不同（两个集合并不相等，但证明只要求"递减且交集零测"）：`egorov_bad_set_measurable` :1965 定义的是 ∪_j {x : 1/(m+1) ≤ ‖f_{n+j}(x) − g(x)‖}——**闭**阈值（≥）且指标平移一格（1/(m+1) 而非 1/m），因为可测性走的是闭集原像判据（阈值集 {‖z‖ ≥ 1/(m+1)} 是闭集，`ComplexMeasurable.preimage_closed` :1958）；`egorov_bad_inter_null` :1982 把"极限处失败的点"（即 ∩_N ∪_j …）证成零测集。第二步是预算分配：对每个 m 取 N_m 使 m(E_{N_m,m} ∩ B(0,m)) ≤ ε/2^{m+1}，A := ∪_m (E_{N_m,m} ∩ B(0,m))，次可加性给 m(A) ≤ Σ_m ε/2^{m+1} = ε（几何级数，Lean `egorov_tsum_geometric` :1905 专门把这条预算机器化了：Σ ε/2^{m+1} = ε·(1/2 + 1/4 + …) = ε）。第三步是收网：x ∉ A、|x| ≤ m₀ 时，对 n ≥ N_{m₀} 有 |fₙ(x) − f(x)| ≤ 1/m₀——在球 B(0,m₀) \ A 上一致。补一句收尾账：真正的失败点一个都不会漏在 A 外——若 x 在尺度 m 失败（无穷多个 n 使 |fₙ(x) − f(x)| > 1/m），取 m₀ ≥ max(|x|, m)，则 x ∈ E_{N_{m₀},m₀} ∩ B(0,m₀) ⊆ A（失败在更粗的尺度 1/m > 1/m₀ 意味着在更细的尺度 1/m₀ 也失败）。A 同时是"失败点集"与"预算补齐"。

Lean 的实现里有一个工程选择：球被换成了**箱链** `egorov_A N := [−N,N]ᵈ`（`egorov_box` :2155、`egorov_A` :2159、可测 :2162、有限测度 :2166），因为 Box 在 1.1 节就带好了体积与可测性机器。局部一致版的装配用两条私有引理：`egorov_bounded_subset_box` :2172（**每个有界集 K 都落进某个 A_N**——取闭球 B(0,R) ⊇ K，再取 N > R，坐标分量被 ‖x‖ ≤ N 压住）与 `egorov_bounded_image` :2189（子空间里的有界集投影回全空间仍有界）；于是"在 Eᶜ 上局部一致"只需在每块 A_N \ E_N 上检查（:2256–2267）。有限测度版在每块 A_N 上花 ε/2^{N+1} 预算，拼接后总账仍是 ε——这是全节反复出现的预算技巧。（`egorov_A_interior` :3148 与 `egorov_A_cover` :3171 两条"嵌套/覆盖"引理不在 Egorov 这边用，它们是 Lusin 的 `lusin_assembly` :3193 的装配工具，见 §5。）

先看一个 Egorov 的数字例子。fₙ(x) = xⁿ 于 [0,1]：逐点收敛到 g（x < 1 处 0，x = 1 处 1），差在单点——去掉 E = (1−δ, 1]，m(E) = δ，则在 [0,1−δ] 上 sup |xⁿ − 0| = (1−δ)ⁿ → 0，一致收敛。取 δ = 0.1，则一致收敛的误差到 0.01 需要 (0.9)ⁿ < 0.01，即 n·ln 0.9 < ln 0.01，n > 4.605/0.1054 ≈ 43.7，n = 44 就够（0.9⁴⁴ = e^{44·(−0.1054)} ≈ e^{−4.636} ≈ 0.0097 < 0.01）。**这意味着什么**：逐点收敛的"坏点"全部被集中进一个任意小测度的集合——坏点可以任意靠近边界（这里堆在 x = 1），但总质量可以压到 ε。这就是"差不多一致收敛"的精确含义：集合的测度可控，集合的位置不可控。

然后是原理三的两个反例，它们精确刻画了 Egorov 的两个"不能"。

**反例 1：一致收敛不能全空间恢复（Remark 1.3.27，Lean `egorov_not_uniform_counterexample` :2306）**。fₙ = 1_{[n,n+1]} 于 ℝ——一个"逃向水平无穷"的鼓包（书原文 moving bump example），每块面积 m([n,n+1]) = 1。逐点处处收敛到 0（每个 x 最终被甩在后面）。但对任何 m(E) ≤ 1/2 的 E：若 [n,n+1] ⊆ E，则 1 = m([n,n+1]) ≤ m(E) ≤ 1/2，矛盾——所以对**每个** n 都有 x ∈ [n,n+1] \ E 使 |fₙ(x) − 0| = 1 > 1/2。fₙ 在任何小测度集合的补集上都不一致收敛。**注意局部一致成立**：每个球 B(0,R) 只与有限个鼓包相交，把相交的那些从 E 里报销掉就行——这就是为什么 Egorov 在全空间只能承诺局部一致，也解释了书 Remark 1.3.27 的正面版本（支撑在固定有限测度集上 ⟹ 一致收敛，Lean `egorov_on_finite_set` :2004 与它的封装 `PointwiseAeConvergesTo.uniformlyConverges_outside_small` :2524）。

**反例 2：例外集不能取零测（Lean `egorov_exceptional_not_null_counterexample` :2375）**。fₙ = 1_{[1/(n+2), 1/(n+1)]}——区间在 0 处堆积的列。每段测度 1/(n+1) − 1/(n+2) = 1/((n+1)(n+2))：n = 0 时 1/2，n = 1 时 1/6，n = 2 时 1/12，望远镜求和 Σ 1/((n+1)(n+2)) = 1；各段只交于端点，所以除端点外每个 x ∈ (0,1] 恰好落在一段里（1/(n+2) ≤ x ≤ 1/(n+1) 在端点 x = 1/(k+1) 处同时有两个解，可数个端点不影响讨论，且相邻两段在端点处的值都是 1，fₙ(x) 的定义不受影响），fₙ(x) 逐点收敛到 0 处处成立（x = 0 也成立，0 不在任何段里）。但对任何零测集 E：每段都有正测度，E 装不下任何一整段，于是每段都有点漏在 Eᶜ——且所有段都在闭球 B(0,1) 内。取 K = B(0,1) ∩ Eᶜ（有界！），对每个 N 都存在 n ≥ N 和 x ∈ K 使 |fₙ(x) − 0| = 1：连**局部**一致收敛都失败。结论：Egorov 的 ε 可以任意小，但**不能是 0**——"任意小"与"为零"是两道不同的门槛，这和书 p.62 的 fₙ = 1/(nx)·1_{x>0} 是同一个现象的两种装束。

## 5 原理二（二）：Lusin 定理 1.3.28——删掉小集合后函数本身连续

定理 1.3.20 的"差不多连续"是积分意义上的：存在连续 g 使 ‖f − g‖_{L¹} 很小。Lusin 定理把话说得更满：**不用换函数，把定义域删掉一小块，f 自己就是连续的**。

**定理 1.3.28（Lusin，书 p.64）**：设 f : ℝᵈ → ℂ 绝对可积，ε > 0。则存在可测集 E，m(E) ≤ ε，使得 f 在补集 ℝᵈ \ E 上连续（限制映射 x ↦ f(x)，子空间意义）。Lean：`ComplexAbsolutelyIntegrable.approx_by_continuous_outside_small` :3198 与 `ComplexMeasurable.approx_by_continuous_outside_small` :3180（更强的形态：存在连续 g 在 Eᶜ 上与 f 逐点相等——注意这里 g 其实就是 f 本身，:3196 的 `rfl` 出卖了这一点）、实值版 `RealMeasurable.continuous_outside_small` :3211、闭集形式 `closed_lusin` :3290（∃F 闭，m(Fᶜ) ≤ ε，f 在 F 上连续——把例外集从"可测"升级到"闭"，与原理一的内正则性呼应）。

书上的证明骨架（p.64）是三条引理的接力。第一步：定理 1.3.20(iii) 给连续紧支撑的 fₙ，‖f − fₙ‖_{L¹} ≤ ε/4ⁿ。第二步：**Markov 不等式（引理 1.3.15）把"积分接近"翻译成"逐点接近（除小集合）"**——这是整个证明的关键一步。m({x : |f(x) − fₙ(x)| ≥ 1/2^{n−1}}) ≤ 2^{n−1}·‖f − fₙ‖_{L¹} ≤ 2^{n−1}·ε/4ⁿ = ε/2^{n+1}（Lean 的 `ComplexAbsolutelyIntegrable.chebyshev` :3746 正是这条不等式的机器版：m({|f| ≥ η}) ≤ η⁻¹·∫|f|，逐点 η·1_E ≤ |f| 后积分得证）。第三步：E := ∪ₙ Eₙ，次可加性给 m(E) ≤ Σ ε/2^{n+1} = ε/2 ≤ ε；而 x ∉ E 时对所有 n 都有 |f(x) − fₙ(x)| ≤ 1/2^{n−1} → 0，fₙ → f 在 Eᶜ 上一致收敛；连续函数的一致极限连续（Lean `uniform_converges_continuousOn` :2596）。预算表代入 ε = 1：E₁ 测度 ≤ 1/4、E₂ ≤ 1/8、E₃ ≤ 1/16，总和 1/2；一致收敛的误差 1/2^{n−1} = 1, 1/2, 1/4, … 压到任意小。

Lean 的实现走了另一条路（两条路都成立，值得对照）：不经过 Markov，而把"每个函数都是简单函数的逐点极限"（可测性的定义，1.3.2）直接用起来——`box_lusin` :2852 先处理有界可测集 A：简单逼近列 sₘ → f 的每个 sₘ 用 `simple_continuousOn_outside_small` :2606 单独修理——每个非零系数的原子 A_i 内取紧核 K_i（内正则性 `LebesgueMeasurable.finite_TFAE` 提供，:2629–2631），sₘ 取零值的空隙 Z = A \ ∪A_i 整块并进来，C := Z ∪ ⋃K_i 是闭集（紧集 ∪ 闭集），预算 ε₀ = δ/(2(n+1)) 分给每片原子，总数 n·ε₀ < δ，于是 m(A \ C) ≤ δ 且 sₘ 在 C 上连续；然后 `lusin_assembly` :3090 用箱链 egorov_A 把各箱的结论粘起来（预算 Σ ε/2^{N+1} = ε），`egorov_A_interior`/`egorov_A_cover` 保证拼接处拓扑干净。闭集形式 `closed_lusin` :3290 再额外用一次**外正则性** `enlarge_open` :3260（E ⊆ O 开，m(O) ≤ m(E) + δ）：把每块例外集胀成开集（多花 ε/2^{N+2}），并集 E = ∪O_N 是开集，F := Eᶜ 闭且 m(Fᶜ) = m(E) ≤ ε。两条路线的共同骨架是同一句话：**全空间切成有界片，每片花 ε/2^{N+1} 的预算，几何级数保证总账 ≤ ε**——这与 Egorov 的证明结构完全同构，不是巧合：Lusin 的装配环节本来就借用了 Egorov 式的箱链拼接。

书在定理后立刻给出告诫（p.64），这是本节最容易被误读的一句话：**Lusin 不声称 f 在 Eᶜ 上"整体连续"**（作为 ℝᵈ → ℂ 的函数在 Eᶜ 的每个点连续，而只是限制映射连续）。标准例子：f = 1_ℚ（有理数的指示函数）处处不连续——任何开区间里同时有有理数和无理数，函数值在 0、1 间跳变；但删掉 E = ℚ（零测！）之后，ℝ \ ℚ 上 f ≡ 0，限制映射是常数函数，当然连续。所以"Lusin 断言 f|_Eᶜ 连续"的"连续"是子空间拓扑里的相对概念；要得到整空间上连续、且与 f 在小集合外一致的真函数 g，还需要 Tietze 延拓定理（书 Remark 1.3.30）。Lean 的 docstring 专门讨论了这一点（:3206–3210）：`RealMeasurable.continuous_outside_small` :3211 的形式（ContinuousOn f Eᶜ）与 :3180 的形式（g 在 Eᶜ 连续且 g = f off E）在这个意义上完全一致，因为后者里的 g 在 Eᶜ 上就是 f。**这意味着什么**：Lusin 说的是"可测函数在子空间的意义下差不多连续"——它给了原理二最强的精确形态，同时诚实交代了它的边界（整体连续需要延拓，无限值需要先修，见下）。

两个修边角的习题。**习题 1.3.23**（书 p.64）：Lusin 的绝对可积假设可以放宽到局部绝对可积，再放宽到可测且几乎处处有限。Lean：`LocallyComplexAbsolutelyIntegrable.approx_by_continuous_outside_small` :3233（局部绝对可积版，`LocallyComplexAbsolutelyIntegrable` :3229 = 每个有界集上绝对可积）、`ComplexMeasurable.approx_by_continuous_outside_small` :3180（可测版）、`UnsignedMeasurable.approx_by_continuous_outside_small` :3663（无符号 + 几乎处处有限版）。书 Remark 1.3.29 说明为什么"几乎处处有限"不能省：无符号函数若在正测度集上取 +∞，Lusin 的结论直接矛盾——∞ 不是连续函数的值；修法是把这个无穷集并入例外集。**习题 1.3.24**（书 p.64–65）：f 可测 ⟺ f 是连续函数的逐点几乎处处极限；Lean `ComplexMeasurable.iff_pointwiseae_of_continuous` :3581 双向 iff。这给 1.3.2 的"可测 = 简单函数逐点极限"换了一批演员：把简单函数换成连续函数，结论照旧——Lusin 在极限意义下给出了可测性的又一个刻画。

## 6 换序问题收官：有界收敛定理与"一致有界"条款

现在回到开头的动画悖论。尖峰列 fₙ = n·1_{(0,1/n)} 的逐点极限是 0，∫fₙ = 1 却不动——lim ∫fₙ = 1 ≠ 0 = ∫lim fₙ。1.3.3 用单调收敛定理（MCT）裁决了它：尖峰列不单调，MCT 不适用。但读者有权追问：**不单调的时候，换序到底什么时候合法？**本节的三原理给了两条补路。Egorov 是一条：删掉小集合后一致收敛，一致收敛下换序当然合法。但注意：尖峰列在 [0,1] 上逐点处处收敛，Egorov 的例外集 A 可以很小，积分却照样跑掉——把账算清楚就知道"面积去了哪里"有一个精确答案：Egorov 保证 fₙ 在 [0,1]\A 上一致收敛到 0，于是 ∫_{[0,1]\A} fₙ ≤ m([0,1]\A)·sup_{[0,1]\A} fₙ ≤ 1·sup → 0；而 ∫fₙ = 1，所以 ∫_A fₙ = 1 − ∫_{[0,1]\A} fₙ → 1——那 1 个单位的面积**精确地住进了例外集 A**。m(A) ≤ ε 可以任意小，但尖峰高度 n 无界，n·m(A) 不收敛，面积就在这个"测度小、高度无界"的集合里安家：尖峰是**逃向垂直无穷**，鼓包 1_{[n,n+1]} 是**逃向水平无穷**，一竖一横，同一个账本。Egorov 管的是收敛模式（它把这个账本翻出来了），但只有有界性条款能收走账本——"一致有界"直接禁止了"小集合 × 无界高度"这种把戏。另一条是**有界收敛定理（BCT）**：一致有界 + 有限测度 ⟹ 换序合法。BCT 在 Tao 书中没有编号（§1.4.6 的 Remark 里提到 S&S 用"the slightly simpler bounded convergence theorem"作为 DCT 的垫脚石；S&S 把它作为命名定理；本仓库**未形式化**，以下标"待证"）。

**BCT（待证，书 §1.4.6 Remark 提及）**：设 fₙ : E → ℂ 可测、|fₙ| ≤ M 一致有界、逐点收敛到 f，E 有限测度，则 ∫fₙ → ∫f。

工作例：**fₙ(x) = xⁿ 于 [0,1]**。检查三条假设：|fₙ| ≤ 1 一致有界 ✓；逐点收敛到 g（x < 1 处 0，x = 1 处 1）✓；m([0,1]) = 1 有限 ✓。换序合法！算账：∫₀¹ xⁿ dx = 1/(n+1)，n = 1 时 1/2，n = 10 时 1/11 ≈ 0.0909，n = 100 时 1/101 ≈ 0.00990，趋于 0；而 ∫g = 0——单点 x = 1 测度为零，不影响积分（1.3.3 的"点不算钱"）。**lim ∫fₙ = 0 = ∫(lim fₙ)，换序成功。**这与 §4 的 Egorov 例子是同一族函数的两面：Egorov 说收敛在 [0,1−δ] 上一致，BCT 说积分直接换序——前者逐点视角，后者积分视角。

对照反例：尖峰列 fₙ = n·1_{(0,1/n)} 在 [0,1] 上，∫fₙ = n·(1/n) = 1 对每个 n（高 n、底 1/n 的矩形面积），逐点极限 0（x > 0 时取 n > 1/x 即 fₙ(x) = 0；x = 0 亦然），于是 lim ∫fₙ = 1 ≠ 0 = ∫0。BCT 的哪条假设被违反了？**|fₙ| ≤ M 失败**：sup fₙ = n 无界。"一致有界"不是装饰——它是尖峰列和 xⁿ 列之间唯一实质的差别（两者都在 [0,1] 上逐点收敛、测度都有限），而正是这个差别决定换序的生死。Egorov 修不了尖峰列（收敛模式没问题，每点都收敛），有界性条款才能修——这正是为什么 1.3.3 的裁决要分两路：单调序列交给 MCT，有界/被支配序列交给 BCT/DCT（DCT 定理 1.4.48 同样属 §1.4 抽象测度，1.3.4 笔记已备好零件）。

## 7 Littlewood 式的第四条：几乎有界（习题 1.3.25）

书在习题 1.3.25 前注明：下面两条 "not, strictly speaking, instances of any of Littlewood's three principles, but are in a similar spirit"（书 p.65）——同样的"差不多"句式，但不是三原理的正式成员。

**(i) 绝对可积函数几乎有界支撑**（习题 1.3.25(a)）：f 绝对可积，ε > 0 ⟹ ∃R，∫_{ℝᵈ \ B(0,R)} |f| ≤ ε。Lean `ComplexAbsolutelyIntegrable.almost_bounded_support` :4186：∃R, ‖f·1_{B(0,R)ᶜ}‖_{L¹} ≤ ε。骨架：先从下积分 sSup 提取无符号逼近 g ≤ |f| 使 ∫(|f| − g) ≤ ε/2（`unsigned_approx_from_sup_134` :4149，与 §3 的 :19 同一招）；g 是有限个测度有限原子上的常数之和，取 R 盖住所有原子（`real_simple_tail_integral_small` :3942——逐项把原子的尾巴清零）；球外 |f| = g 的球外部分 + 差值，积分 ≤ ε/2 + ε/2 = ε（:4324 的合并）。**关键一步**：∫|f| < ∞ 是"f 在无穷远处衰减"的积分语言——质量守恒意味着质量不可以在无穷远处聚集。

**(ii) 可测函数几乎有界**（习题 1.3.25(b)）：f 可测且几乎处处有限，ε > 0 ⟹ ∃E 可测、m(E) ≤ ε、f 在 Eᶜ 上局部有界（每个球内换一个界）。Lean 版 `ComplexAbsolutelyIntegrable.almost_bounded` :4350 更强：要求绝对可积，结论直接是 f 在 Eᶜ 上**整体有界**（`BoundedOn` :4348 = f(Eᶜ) 有界）。骨架：M := max(1, 2I/ε + 1)（I := ∫|f|；max 与 1 取大纯粹是保证 M ≥ 1 好拿正性，对不等式本身不是必需的——2I/ε + 1 ≥ 1 恒成立），E := {x : M ≤ |f(x)|}；Chebyshev（:3746）给出 m(E) ≤ M⁻¹·I ≤ ε/2 ≤ ε——不等式 M⁻¹·I ≤ ε/2 的成立是 M 的定义换了个姿势：M ≥ 2I/ε + 1 ⟹ M⁻¹·I ≤ ε/2（Lean :4365–4383 用 inv_le_inv₀ 走完）；而 Eᶜ 上 |f| < M 是 E 的定义直接翻译（:4402–4410）。**数字例子走一遍**：f(x) = 1/√|x| · 1_{[−1,1]}（f(0) 随便赋值，取 f(0) = 0 即可——a.e. 语境下单点无关紧要，且 |f(0)| = 0 < 9 不影响 E 的界定）。I = ∫|f| = 2∫₀¹ x^{−1/2} dx = 2·[2√x]₀¹ = 4。取 ε = 1：M = max(1, 2·4/1 + 1) = 9。E = {9 ≤ 1/√|x|} ⟺ √|x| ≤ 1/9 ⟺ |x| ≤ 1/81，于是 m(E) = 2/81 ≈ 0.0247 ≤ 1 = ε ✓；Eᶜ 上 |f(x)| = 1/√|x| ≤ 9 ✓——f 无界（x → 0 时发散），但它的"无界部位"只占一条长 2/81 的小区间。**这意味着什么**：可测函数"差不多有界"——在欧氏空间里，绝对可积函数的值域暴走只能发生在一个任意小测度的集合上。书版 (ii) 只要可测 + 几乎处处有限（路线：每个球 B(0,R) 内，水平集 {|f| > n} ∩ B(0,R) 的测度随 n 下降到 0——又是向下单调收敛，再按 ε/2^{R+1} 分预算并起来）；Lean 只验了绝对可积版，书版标"待证"。

## 8 反直觉清单 / FAQ

- **三原理是定理吗？** 不是。书 p.60 原文 "informal heuristics"。"差不多"的精确翻译是：对任意 ε > 0，存在测度 ≤ ε 的例外集，在补集上性质成立。ε 可以任意小，但每一条的证明都要为 ε 付账（几何级数预算）；例外集的位置不可控。
- **"可测集几乎开"与书的措辞"几乎有限个区间的和"是什么关系？** Littlewood 原话（1944 讲义）是"nearly open"；Tao 在书 p.60 写成 (i) "nearly a finite sum of intervals"。两者都指向 §1.2 的同一批机器：外正则性（引理 1.2.12，`Section_1_2_1.lean:5732`）、内正则性（:6476）、初等逼近（习题 1.2.16）。Tao 的措辞更接近他在 §1.3.5 的用途：给定理 1.3.20(ii)（阶梯逼近）当原料。
- **Egorov 的例外集能取零测吗？** 不能。区间列 1_{[1/(n+2), 1/(n+1)]}（Lean :2375）在 0 处堆积：每段正测度（1/((n+1)(n+2))，望远镜和 = 1），零测集装不下任何一段，于是任何零测补集上连局部一致收敛都没有。书 p.62 的 fₙ = 1/(nx)·1_{x>0} 同构。"任意小"与"为零"是两道门槛。
- **Egorov 为什么只能给局部一致？** 逃逸鼓包 fₙ = 1_{[n,n+1]}（Lean :2306）：每块面积 1，逐点收敛到 0，但任何 m(E) ≤ 1/2 的集合都盖不住所有鼓包（否则 1 ≤ m(E) ≤ 1/2 矛盾），Eᶜ 上永远有某块鼓包在跳。局部一致版本（:2207）用球/箱截断化解：每个有界集只碰到有限多块。若所有函数支撑在固定有限测度集上，一致版本完整恢复（`egorov_on_finite_set` :2004）。
- **Lusin 说"f 几乎连续"，那 1_ℚ 为什么是它的例子而不是反例？** 因为"连续在 Eᶜ 上"是子空间意义：1_ℚ 删掉 ℚ（零测）后在 ℝ\ℚ 上 ≡ 0，限制映射连续；但 1_ℚ 作为 ℝ → ℝ 的函数处处不连续。要整空间连续且 off E 与 f 相等的 g，需要 Tietze（书 Remark 1.3.30）——Lusin 自己不给延拓。
- **BCT 在仓库里吗？** 不在。BCT 在 Tao 书中未编号（§1.4.6 Remark），仓库未形式化，本文 §6 的 BCT 工作例是数学推理不是机器验证。仓库为原理三机器化的是 Egorov 两个版本（:2004/:2207）及其反例（:2306/:2375）；DCT（定理 1.4.48）同属 §1.4，1.3.4 笔记只备了零件。
- **Egorov 和 BCT 管的是同一件事吗？** 不是。Egorov 管**收敛模式**（逐点 → 删小集合后一致）；BCT 管**积分换序**。尖峰列在 [0,1] 上逐点处处收敛（Egorov 完全适用，例外集可以很小），但 ∫fₙ = 1 照样不收敛到 ∫0——面积去了哪里与收敛快慢无关；只有"一致有界"条款（BCT/DCT）能抓回这笔账。
- **为什么 Lean 的 Egorov/Lusin 用箱链 egorov_A 而不是球？** 工程选择。Box 在 1.1 节自带体积与可测性机器；Egorov 的局部一致装配用 `egorov_bounded_subset_box` :2172（每个有界集落进某个 A_N）一步到位；Lusin 的装配用 `egorov_A_interior` :3148（A_N ⊆ int A_{N+1}，坐标距离 1/2 的开球即可）与 `egorov_A_cover` :3171（‖x‖ < N）保证拼接处拓扑干净；球同样可行，但箱子的坐标结构让这些引理更短。数学内容与书完全一致。
- **Lusin 证明里 Markov 不等式为什么不可替代？** 定理 1.3.20(iii) 只给 ‖f − g‖_{L¹} ≤ ε——积分近，逐点可能差很远（差一个正测度集合上的大值）。Markov 把"积分近"翻译成"逐点近、除小集合"（m({|f−g| ≥ λ}) ≤ λ⁻¹ε），这是从 L¹ 逼近升级到逐点逼近的唯一桥梁。Lean 的 :3180 路线绕开 Markov 是因为它从"可测 = 简单函数逐点极限"直接出发，但每片原子仍然要用内正则性取紧核——两条路都必须在某处付出"点态控制"的代价。
