# 06 · 1.3.2 可测函数：给"能积的函数"发执照

> Tao《An Introduction to Measure Theory》§1.3.2 讲稿式笔记 + Lean 形式化对照
> 一句话纲领：**1.3.1 把"只有有限种值"的函数积完了，f(x) = x 还横在门口——把横切公式 Σᵧ y·m(f⁻¹{y}) 硬推广到不可数多个层是非法操作（1.2.1 的教训：不可数求和根本不存在）。唯一的出路是承认简单函数只有有限层，把一般函数定义为"简单函数列的逐点极限"——这就是 Tao 的可测函数定义（定义 1.3.8）。随后引理 1.3.9（TFAE）把"可被简单函数逼近"翻译成"每条水平线切下去，层底都可测"（水平集条件），乃至"开集逆像可测"（其他教材的定义，在 Lean 里只是 TFAE 的一个成员）。可测函数类是积分理论的"执照持有者"：它对逐点极限封闭（a.e. 极限定理）——这正是 Riemann 积分缺失的封闭性；Riemann 可积函数全部被收编（习题 1.3.9）。**
> 形式化：`analysis/MeasureTheory/Section_1_3_2.lean`（6686 行，本节核心）；定义 1.3.8、引理 1.3.9、习题 1.3.3–1.3.9、注记 1.3.10 全部机验。

## 1 这一幕要解决什么

上一节结束时我们手里有一台完整的机器：对**只有有限种值**的函数（简单函数），积分 ∫f = Σᵢ cᵢ·m(Eᵢ) 良定、线性、单调，Dirichlet 函数 1_ℚ 被这台机器算出了 0。但 1.3.1 的最后一幕留下了死局：f(x) = x 在 [0,1] 上。简单函数的值域至多 2ᵏ 个值（k 个指示函数的组合）；x 的值域是 [0,1] 本身，不可数。上一节的横切公式对它连"写出来"都做不到——于是这一节要回答的问题只有一个：**怎么把"有限层"放宽到"任意函数"？**

先让读者亲手试最朴素的路：把横切公式 Σᵧ y·m(f⁻¹{y}) 从有限和硬扩展成"对所有 y 求和"。拿 f(x) = x 在 [0,1] 上代入：每一层 y 的层底是单点 {y}，m({y}) = 0，而层有**不可数**多个。写"Σ_{y∈[0,1]} y·0"是越界：**对不可数族根本没有求和这个操作**。这不是新病——1.2.1 节已经见过同一位病人（`Section_1_2_1.lean:3497` 的反例：把单位立方体拆成不可数多个单点，每个单点测度 0；对不可数族，可数可加性连"应用"都谈不上——它只管可数并——若有人硬要把"每个单点测度 0"推广成"总和 0"，立刻撞上立方体测度 1：不可数族不配谈求和）。即便借用最宽泛的"有限部分和的上确界"读法：每项 y·0 = 0，上确界只得 0，而真正的面积 ∫₀¹ x dx = x²/2 |₀¹ = 1/2 − 0 = 1/2。两种读法下公式都死。

失败诊断完毕。方向没错（横切是对的），错在"层"的数目。修补思路也只有一条：**把有限层理论的成果当作台阶，用简单函数去逼近一般函数，再取极限**。这就是"逼近"一词第一次出场：它把问题从"函数"转移到"函数列"——什么样的列算合法逼近？最小要求是逐点收敛：gₙ(x) → f(x) 对每个 x 成立，积分则接力给下一节的极限（lim ∫gₙ）。于是本节的核心问题落定：**什么样的函数才配被简单函数逼近？** 答案就是可测函数。

## 2 定义被逼出来：可测函数 = 可被简单函数逼近

**定义（Tao 定义 1.3.8，非负可测函数）**。f : ℝᵈ → [0,∞] 称为非负可测（unsigned measurable），如果 f ≥ 0，且存在非负简单函数列 gₙ 逐点收敛到 f（`PointwiseConvergesTo`，`Section_1_3_2.lean:18`：∀ x，gₙ(x) 在拓扑意义下趋于 f(x)）。Lean 里的定义一字不差：`UnsignedMeasurable`（`Section_1_3_2.lean:21`）= `Unsigned f ∧ ∃ g, (∀ n, UnsignedSimpleFunction (g n)) ∧ PointwiseConvergesTo g f`。

注意这个定义把"可测"的实质压进了上一节的简单函数：简单函数 = 有限个**可测集**指示函数的加权和（`UnsignedSimpleFunction`，`Section_1_3_1.lean:33`）。所以"f 可测"说的其实是：f 可以被"层底都是可测集"的有限层函数一层层搭出来。定义没引入任何新原料——它只是把 1.3.1 的机器对准了更大的函数类。

定义立即自检。简单函数本身可测吗？当然——取常数列 gₙ ≡ f，逐点收敛是平凡的（`UnsignedSimpleFunction.unsignedMeasurable`，`Section_1_3_2.lean:1730`，习题 1.3.3(ii)）。连续函数可测吗？**不能直接看出来**——"连续"是拓扑词汇，"被简单函数逼近"是测度词汇，两者之间没有免费通道。这需要一条真正的定理：引理 1.3.9 的 TFAE。

**引理 1.3.9（可测性的等价刻画，`UnsignedMeasurable.TFAE`，`Section_1_3_2.lean:1686`）**。设 f ≥ 0（值域是 1.3.1 节的扩展实数 [0,∞]，⊤ 记其中的正无穷），下列 11 条等价：

(i) f 可测（定义 1.3.8）；
(ii) f 是简单函数列的逐点极限（处处）；
(iii) f 是简单函数列的**几乎处处**极限（`PointwiseAeConvergesTo`，:27——例外集零测）；
(iv) 存在简单函数列 gₙ，每个 gₙ 有界、支撑集有限测度（`FiniteMeasureSupport`，:25），gₙ(x) 对每个 x 单调不减，且 f(x) = supₙ gₙ(x)——**单调上确界近似**；
(v) ∀ t，水平集 {x : f(x) > t} 可测；
(vi) ∀ t，{x : f(x) ≥ t} 可测；
(vii) ∀ t，{x : f(x) < t} 可测；
(viii) ∀ t，{x : f(x) ≤ t} 可测；
(ix) 每个有界区间的逆像可测：∀ I，f⁻¹(Real.toEReal '' I.toSet) 可测；
(x) 每个开集 U ⊆ [0,∞] 的逆像 f⁻¹(U) 可测；
(xi) 每个闭集 K 的逆像 f⁻¹(K) 可测。

证明骨架（机器里的蕴含图，文件注释与 `tfae_have` 列表原样）：(i)⟺(ii) 就是定义；(ii)⟹(iii) 平凡（逐点 ⟹ 几乎处处）；(iv)⟹(ii) 因为单调序列收敛到自己的上确界；(iii)⟹(v) 是**主要技术活**——limsup 表示；(v)↔(vi)↔(vii)↔(viii) 靠阈值微调（`v_imp_vi` :448、`vi_imp_v` :525、`vii_imp_vi` :590、`viii_imp_v` :598 等）；(v)⟹(ix) 因为区间 = 半直线的交（`v_to_viii_imp_ix` :606）；(ix)⟹(x) 因为开集 = 可数个开区间之并（还要处理 ⊤，`ix_imp_x` :772、`open_inter_reals_eq_countable_union` :712）；(x)⟺(xi) 取补集（`x_iff_xi` :838）；(x)⟹(vii) 因为 {x : f(x) < t} = f⁻¹((−∞, t))，而 (−∞, t)（记 Iio t）在 EReal 序拓扑里是开集（`x_imp_vii` :851）。最难的方向是 (v)+(vi)⟹(iv)：**分层近似**，机器为此单独造了 `approx_fn`——下一节专门讲它。

**关键一步是 (iii)⟹(v) 的 limsup 表示**（`limsupSet` :198、`iii_imp_v` :219）：在收敛点上，{x : f(x) > t} 与集合

⋃ₘ ⋂ₙ ⋃_{k≥n} {x : gₖ(x) > t + 1/(m+1)}

完全一致（"f = lim gₙ = limsup gₙ"的量化版本，阈值加了 1/(m+1) 的余量来吸收"收敛到"而不是"等于"）。精确地说，机器证的是 {x : f(x) > t} ∩ Nᶜ = E ∩ Nᶜ，N = 收敛失败的点集（`aeLimit` 证明里的 :1900–:1901）——**在收敛点上两者逐点相等**；整个空间上看，两者只差零测集 N。而 limsup 集由可数并、可数交拼成，每块 {gₖ > t'} 是简单函数的水平集——可测（`levelset_gt_LebesgueMeasurable` :126）。于是 {f > t} 可测。**这意味着什么**：逐点收敛把"极限函数的水平集"化成了"逼近函数的水平集的 limsup 运算"——可测集对可数并/可数交封闭（1.2.2 的财产），这一路全是现成的。

现在检验连续函数。先交代定义域纪律：unsigned 版只受理 f ≥ 0（值域 [0,∞]），所以下面先验非负情形，负值域的函数留给 §4 的实值版（习题 1.3.8(i)）与正负部分解。f(x) = x 在 [0, ∞) 上：{x : x > t} = (t, ∞) 是开区间，可测，条件 (v) 成立 ⟹ x 可测（ℝ 上的 x 会取负值，由实值版处理）。f(x) = x²：{x² > 2} = (−∞, −√2) ∪ (√2, +∞)，开集。sin x 的非负情形：{sin x > 1/2} = ⋃ₖ (π/6 + 2πk, 5π/6 + 2πk)——可数多个开区间之并；在 [0, 2π] 上这一块是 (π/6, 5π/6)，长度 5π/6 − π/6 = 2π/3 ≈ 2.094。一般连续函数走 (xi)：连续 ⟹ 闭集逆像闭 ⟹ (xi) 成立 ⟹ TFAE 给出可测性——这就是 `Continuous.UnsignedMeasurable`（:1720，习题 1.3.3(i)）的完整证明（`IsClosed.preimage hf hK` 一行拿连续，再 `.measurable` 拿闭集可测）。连续与可测之间的门，是**闭集**这扇——拓扑与测度在这里第一次握手。

## 3 分层近似：横切直觉的机器形态

回到引理 1.3.9 里最难的方向 (v)⟹(iv)。假设所有水平集 {f ≥ t} 可测，怎么造出单调不减、有界、有限支撑的简单函数列 gₙ 以 f 为上确界？机器里的答案 `approx_fn`（`Section_1_3_2.lean:870`）：

gₙ(x) = ⌊min(f(x), n)·2ⁿ⌋₊ / 2ⁿ　当 ‖x‖ ≤ n；否则 0。

（两个记号先交代：⌊r⌋₊ 是非负向下取整 max(⌊r⌋, 0)——对 r ≥ 0 就是普通 ⌊r⌋，下面所有手算都落在非负情形；‖x‖ 是欧氏范数，"‖x‖ ≤ n" 把支撑收进半径 n 的球。）

读作三个动作的合成：**截高**（min(f(x), n)——超过 n 的部分压平，n 以后趋于 ∞ 所以不丢信息）；**量化**（⌊·2ⁿ⌋/2ⁿ——把值四舍五入到二进制小数的 2⁻ⁿ 网格，只保留 k/2ⁿ 型值）；**截支撑**（‖x‖ > n 时置 0——n 以后球半径趋于 ∞，也不丢信息）。每个 gₙ 只取 ≤ n·2ⁿ + 1 个值（`approx_fn_values` :882），天然是简单函数候选。

走一遍真实数字。f(x) = x，x = 1/3（这里 f 非负、‖x‖ ≤ n 恒真，截高只在 n 小时出力）：n = 1 得 ⌊(1/3)·2⌋/2 = ⌊2/3⌋/2 = 0/2 = 0；n = 2 得 ⌊(1/3)·4⌋/4 = ⌊4/3⌋/4 = 1/4；n = 3 得 ⌊8/3⌋/8 = 2/8 = 1/4；n = 4 得 ⌊16/3⌋/16 = 5/16 = 0.3125；n = 5 得 ⌊32/3⌋/32 = 10/32 = 5/16；n = 6 得 ⌊64/3⌋/64 = 21/64 = 0.328125。数列 0, 1/4, 1/4, 5/16, 5/16, 21/64, … 单调不减，上确界正是 1/3——这是一条定理而不是巧合：对一切 r ≥ 0，r = supₙ ⌊r·2ⁿ⌋/2ⁿ（`floor_approx_iSup_eq` :935，机器用 EReal 的上确界证明；原因就是二进制小数舍入：⌊r·2ⁿ⌋/2ⁿ ≤ r < (⌊r·2ⁿ⌋+1)/2ⁿ，两端误差 ≤ 1/2ⁿ 一致地趋于 0）。误差验算：n = 4 时 |1/3 − 5/16| = |16/48 − 15/48| = 1/48 ≈ 0.0208 ≤ 1/16 = 0.0625；n = 5 时 1/48 ≤ 1/32 = 0.03125。✓

再走一遍截高的动作。f(x) = x 在 [0, ∞) 上（unsigned 版只处理非负，负半轴由实值版处理），x = 7.3，n = 8：min(7.3, 8) = 7.3 没被截，⌊7.3·256⌋/256 = ⌊1868.8⌋/256 = 1868/256 = 7.296875，误差 7.3 − 7.296875 = 0.003125 ≤ 1/256 = 0.00390625 ✓。而 x = 7.3，n = 2：‖x‖ = 7.3 > 2，g₂(x) = 0——支撑被收进半径为 n 的球。**注意**：f 无界（f(10⁶) = 10⁶）但可测性不要求任何有界性——截高让每个 gₙ 有界（≤ n），球截让每个 gₙ 的支撑测度有限（球是有限测度集），单调 sup 把信息完整收回。这就是条件 (iv) 三件套（有界、有限支撑、单调）的设计意图。

最后是"横切"的兑现：在球内，gₙ 的每一层水平集是

{x : ‖x‖ ≤ n} ∩ {x : gₙ(x) = k/2ⁿ} = {x : ‖x‖ ≤ n} ∩ {x : f(x) ≥ k/2ⁿ} ∩ {x : f(x) < (k+1)/2ⁿ}

（k = n·2ⁿ 时右端换成 {f ≥ n}；**注意球的交在两边都要出现**——球外 gₙ = 0，等式只在球内有意义。机器里这条等式在 :1144–:1150，封装在 `approx_fn_levelset_LebesgueMeasurable` :1029 里，它从条件 (vi) 推出每个水平集可测）。一条水平线 y = k/2ⁿ 切下去，层底由两条半直线水平集的交拼成——与 1.3.1 的"层底 m(f⁻¹({y}))"哲学完全一致，只是现在"层"的厚度是 2⁻ⁿ，n → ∞ 时厚度 → 0。于是 (v)+(vi) ⟹ (iv) 闭环（`v_to_xi_imp_iv` :1317）。

**这意味着什么**：可测函数 = 可以被"分层切片机"切成有限层再取极限的函数。分层近似不是引理的边角料——它是下一节 1.3.3 单调收敛定理（MCT）的引擎：supₙ gₙ = f 与单调性正是 MCT 的全部输入，lim ∫gₙ 就是 ∫f 的定义方式。

## 4 核心定理库：可测类的封闭性

有了 TFAE 和分层近似，本节的主菜是一连串"可测性在什么运算下保持"的定理——可测函数类是一个**对各种极限、算术、复合封闭的俱乐部**。逐条走。

**连续 ⟹ 可测**（习题 1.3.3(i) `Continuous.UnsignedMeasurable` :1720；实/复版习题 1.3.8(i) `Continuous.RealMeasurable` :5170、`Continuous.ComplexMeasurable` :5179）。骨架：连续 ⟹ 闭集逆像闭 ⟹ TFAE 条件 (xi) ⟹ 可测。§2 已验 x、x²、sin x。**这意味着什么**：拓扑的全部家当（连续函数、闭集）免费进入测度世界——而反过来差之千里（§5：1_ℚ 可测不连续），可测类是连续类的严格放大。注意 unsigned 版需要非负假设，实/复版不需要。

**简单 ⟹ 可测**（习题 1.3.3(ii) :1730，常数列）；逆命题也真：可测 + 值域有限 ⟹ 简单（习题 1.3.5，`UnsignedSimpleFunction.iff` :2669）——"简单"与"可测 + 有限值"是同一概念的两副面孔。

**sup / inf / limsup / liminf**（习题 1.3.3(iii)，:1753 / :1779 / :1805 / :1818）。骨架：{supₙ fₙ > t} = ⋃ₙ {fₙ > t}——**可数**并，可测集对可数并封闭（1.2.2 的财产）。对比 1.2.1 的教训：不可数并会让一切崩掉（:3497），可数并恰好够用——这是"可数"一词在整个测度论里的第三次出场，次次是同一个配方。inf 用 {infₙ fₙ ≥ t} = ⋂ₙ {fₙ ≥ t}；limsup/liminf = sup∘inf 嵌套。立即的例子：设 qₙ 枚举 ℚ，f(x) = Σₙ n·1_{qₙ}(x)——每个有理点 qₘ 只被第 m 项击中，所以 f(qₘ) = m（有限！），无理点为 0；f 在任何区间上无界（有理数稠密），但 f = sup_k (Σ_{n≤k} n·1_{qₙ}) 是简单函数的上确界（单点集 {qₙ} 可数 ⟹ 可测），由 sup 定理 f 可测。**可测函数可以处处无界**——可测性不管"大小"，只管"分层是否干净"。

**a.e. 相等传递**（习题 1.3.3(iv) `UnsignedMeasurable.aeEqual` :1831；实版习题 1.3.8(iii) `RealMeasurable.aeEqual` :5193）。f 可测、f = g 几乎处处 ⟹ g 可测。骨架：例外集 N 零测，{g > t} 与 {f > t} 只差 N 的子集——零测集可测（`IsNull.measurable`）。**这意味着什么**：可测性是"几乎处处性质"——与积分对零测集失明（1.3.1 的 `integral_eq_integral_of_aeEqual`）同源：理论从一开始就在"商掉零测集"的意义上工作。

**a.e. 极限定理**（习题 1.3.3(v) `UnsignedMeasurable.aeLimit` :1890；实/复版习题 1.3.8(iv) `RealMeasurable.aeLimit` :5334、`ComplexMeasurable.aeLimit` :5382）——**本节的正主**。陈述：gₙ 皆可测，gₙ → f 几乎处处 ⟹ f 可测（unsigned 版还显式要求 f ≥ 0——`Unsigned f` 是机器 :1890 的假设，非负是 unsigned 理论的地基，不能省）。骨架与 TFAE 的 (iii)⟹(v) 同构：对每个 t，在收敛点上 {f > t} 与 limsup 集 ⋃ₘ ⋂ₙ ⋃_{k≥n} {gₖ > t + 1/(m+1)} 一致（差零测集）；现在每块 {gₖ > t'} 由归纳假设（gₖ 可测 ⟹ TFAE 条件 (v)）可测，limsup 集由可数并/交拼出，仍可测。**关键一步**就是这条 limsup 表示——"收敛"被翻译成可数集合运算，这是整个证明的心脏。**这意味着什么**：这就是修复 Riemann 缺陷的定理。Riemann 可积类对逐点极限不封闭——标准反例（可在纸面上完整验证，仓库未另立机验项）：设 q₁, q₂, … 枚举 [0,1] 中的有理数，fₙ = 1_{q₁,…,qₙ}。每个 fₙ 只在 n 个点处不连续，故 Riemann 可积，且积分为 0（把 n 个点分别包进总长任意小的区间，达布上下和都趋于 0）；但逐点极限 limₙ fₙ = 1_ℚ，处处不连续，上下达布和恒为 1 与 0，Riemann 积分不存在。可测类恰好相反：**极限操作不产生新病人**。Dirichlet 1_ℚ 作为简单函数列的极限（常数列即可）在这里被"追认"为可测；下一节的单调收敛、控制收敛（1.3.3–1.3.5）全部站在这个封闭性上——收敛定理不是别的，就是"极限与积分换序"的合法化，而换序的第一步"极限仍可测"已经在此交付。诚实注明一处机器与书的差别：实/复版机器多了一条假设"极限函数 f 有界"（∃ M，∀ x，|f x| ≤ M）——书上的标准陈述（Rudin 等教材的"逐点极限定理"，编号见 §7 对照表）不需要它；机器版本把 {f ∈ (a,b)} 编码成内层收缩区间 Ioo(a + 1/(m+1), b − 1/(m+1)) 的 limsup 集，这个编码要值域有界才闭合。unsigned 版（值域 [0,∞] 自带 ⊤）没有这个限制。需要时先截断再用单调收敛拼回即可，不碍事，但要清楚这是机器的一个真实加强。

**复合连续**（习题 1.3.3(vi) `UnsignedMeasurable.comp_cts` :2072；实/复版习题 1.3.8(v) `RealMeasurable.comp_cts` :5413、`ComplexMeasurable.comp_cts` :5430）。f 可测、φ 连续 ⟹ φ∘f 可测。骨架：开集 U 的逆像 (φ∘f)⁻¹(U) = f⁻¹(φ⁻¹(U))，φ⁻¹(U) 开，f⁻¹ 把开集送进可测集——TFAE 条件 (x) 一行。推论：|f|、f²、f/(1+f²) 皆可测。注意方向：内层 f 可测、外层 φ 连续——成立；但把外层换成"可测函数"就不行：§5 反例 2 里 φ = 1_{f(F)} 可测（层底 f(F) 零测 ⟹ 可测）、f 可测，而 (φ∘f)⁻¹{1} = f⁻¹(f(F))——它在可测集 A'（余可数）上与 F' 重合（机器 :4250），若它可测则 F 可测，矛盾——**可测函数复合可测函数不必可测**（这是注记 1.3.10 的函数语言读法，机器直接机验的是逆像版本）。

**加减乘**（习题 1.3.3(vii) `UnsignedMeasurable.add` :2153；习题 1.3.8(vi) `RealMeasurable.add` :5448、`sub` :5469、`mul` :5577 与复版）。骨架（机器）：**定义直通**——f = lim fₙ、g = lim gₙ 逐点，则 f + g = lim (fₙ + gₙ)，而简单函数之和仍是简单函数（1.3.1 的拼接 `add`，`Section_1_3_1.lean:64`），收敛的加法律（`Tendsto.add`）收尾。**这意味着什么**：这是逼近定义的第一个红利——加法封闭性一行证完；以逆像为定义的教材要绕道乘积空间（(x,y) ↦ x+y 连续 + 乘积可测性），Tao 的定义让收敛与算术自动交换。

**有界情形升级为一致逼近**（习题 1.3.4，`UnsignedMeasurable.bounded_iff` :2611，配套 `UniformConvergesTo` :2200）。有界可测 ⟺ 存在有界简单函数列一致收敛到 f。骨架：⟹ 方向用 **floor 构造**（机器的 "floor-level characterization"，习题 1.3.4 的引擎）——值域落在 [0,M] 的 f 直接取 gₙ(x) = ⌊f(x)·2ⁿ⌋/2ⁿ：这里不需要 §3 的截高截支撑（有界性让"层"自动有限：k 只须取到 M·2ⁿ），舍入误差 ⌊r·2ⁿ⌋/2ⁿ ≤ r < (⌊r·2ⁿ⌋+1)/2ⁿ 与 x 无关，所以 2⁻ⁿ 就是一致收敛的见证（注意 §3 的 `approx_fn` 带球截断、只逐点收敛——一致版必须去掉球截断）；⟸ 方向：一致收敛 ⟹ 逐点收敛 ⟹ 可测，一致极限保号有界（ε = 1 即可）。**这意味着什么**：对"有界"函数，逐点逼近免费升级为一致逼近——这正是 1.3.4 节控制收敛（DCT）的预演，那里的"一致收敛 ⟹ 极限与积分换序"将直接消费这条定理。

**图像可测**（习题 1.3.6，`UnsignedMeasurable.measurable_graph` :2850）。f 可测 ⟹ 图像下方的区域 {(x, t) : 0 ≤ t ≤ f(x)} ⊆ ℝᵈ⁺¹ 可测。骨架：区域 = ⋃ 层切片之并，每片是 {f ≥ t} 型集合在乘积空间里的提升——Fubini 定理（1.3.5/1.4）的引子。

**实/复定义与第二条 TFAE**（定义 1.3.11 `ComplexMeasurable` :4320、`RealMeasurable` :4322；`RealMeasurable.iff` :4324——实可测 ⟺ 复化后复可测；`ComplexMeasurable.iff` :4347——复可测 ⟺ 实部虚部皆实可测；习题 1.3.7 `RealMeasurable.TFAE` :4738：实可测 ⟺ 正部负部皆 unsigned 可测 ⟺ 开集逆像可测；复版 `ComplexMeasurable.TFAE` :5002）。骨架（实版）：水平集 {f < t} 用正负部拼——{f⁺ < t} ∩ {f⁻ = 0} ∪ {f⁺ = 0} ∩ {f⁻ > −t}（`real_lt_iff_pos_neg` :4406、`preimage_Iio_of_pos_neg` :4444），每块由 unsigned 可测性给出。**这意味着什么**：实值可测 = 正部负部分别可测，与 1.3.1 的正负部分解（`RealSimpleFunction.pos`/`.neg`）同构——可测性与积分共用同一台"拆正负"的机器。

**Riemann 可积 ⟹ 可测**（习题 1.3.9，`RealMeasurable.riemann_integrable` :6562）。f 在 I 上 Riemann 可积 ⟹ f 延拓到 I 外为 0 后实可测。骨架：`riemann_step_seqs`（:6183）给出上下阶梯函数列 uₙ ≥ f ≥ lₙ（达布和的两翼），且宽度 wₙ = uₙ − lₙ 的积分被控制成**几何衰减** ∫wₙ ≤ 4/2ⁿ⁺¹（机器 :6355 的假设；Riemann 可积性保证可取分割让上下达布差任意小，做成几何衰减）；由 Borel–Cantelli 型论证——{wₙ 不趋于 0} = ⋃ₘ {wₙ 无穷多次 > 1/(m+1)}，而 Σₙ m{wₙ > ε} ≤ Σₙ (m+1)·∫wₙ < ∞——得 wₙ → 0 几乎处处（`step_diff_ae_null` :6353）；阶梯函数 = 分片常数函数，可测（`pcf_lift_RealMeasurable` :6342）；于是 uₙ → f·1_I 几乎处处；最后调 a.e. 极限定理（:5334）收尾。**这意味着什么**：双重的。第一，Lebesgue 理论**收编** Riemann 理论——1.1 节攒下的全部 Riemann 可积函数自动获得可测执照；反过来不成立（Dirichlet 可测而 Riemann 不可积，1.1.3 已验），收编是严格扩大的。第二，注意证明路线本身：Riemann 可积性被翻译成"阶梯函数 a.e. 收敛"，然后全节攒的定理（阶梯可测 + a.e. 极限封闭）被一次性消费——这是 a.e. 极限定理的第一个真实用户。

## 5 反例与边界情形

**反例一：指示函数把不可测集焊进函数世界。** 设 V ⊆ [0,1] 是 Vitali 集（`VitaliSet`，`Section_1_2_3.lean:66`；`VitaliSet.nonmeasurable` :145）。f = 1_V 的水平集 {f > 1/2} = V 不可测，由 TFAE 条件 (v) 的反方向，f **不可测**。对比 Dirichlet 1_ℚ：{1_ℚ > 1/2} = ℚ 可数 ⟹ 零测 ⟹ 可测，且 1_ℚ 本身就是 k = 2 的简单函数，两条路都通。同样的指示函数语法，一个可测一个不可测——差别全在层底集合。1.2.3 的债在这里兑现：**不可测函数的存在性 ⟺ 不可测集的存在性**，Vitali 集以指示函数为签证进入了函数理论。这也是 1_V 不能进积分理论的判决书：给 1_V 定义积分会与测度的一切性质冲突。

**反例二：可测函数的逆像只对 Borel 集保证（注记 1.3.10，`Section_1_3_2.lean:4219`，机器实现为例题 :4224）。** 前面所有逆像定理（TFAE 条件 (x)(xi)、复合连续）都只断言"开集/闭集的逆像可测"。能不能升级成"**一切**可测集的逆像可测"？不能。先交代术语：Borel 集 = 从开集出发经可数并、可数交与补集运算生成的集合（1.4 节正式定义；这里只需要"开/闭集都是 Borel 的"这一层）。构造：f = binaryToTernary（:3818）——**单调**、把 [0,1] 映进 Cantor 集的函数（`BinaryToTernaryProperties` 里是 `monotone_on` 与 `image_in_cantor`，:3049 起；它在二进有理点上有跳跃，**不是连续的**——例：g(1/2) = 2·(1/3) = 2/3（二进 0.1000… 只有首位为 1），而 x → 1/2⁻ 时数字序列是 0,1,1,1,…，左极限 = Σ_{j≥2} 2·(1/3)ʲ = 2·(1/3)²/(1−1/3) = 1/3 ≠ 2/3。但单调函数自动可测：水平集是区间/凸集，`f_lifted_measurable` :4123 正是走这条 sublevel 路线机验的，:3952、:4043）。f 在非二进有理数集 A 上单射（A ⊆ [0,1] 余可数，F ⊆ A，`exists_nonmeasurable_with_cantor_image` :4151）；取 F ⊆ [0,1] Vitali 不可测。令 E = f(F)：E ⊆ Cantor 集，而 Cantor 集零测（`CantorSet.null`，`Section_1_2_2.lean:1526`），所以 E 零测 ⟹ 可测。但 f⁻¹(E) = F（单射性）不可测。于是：**可测函数 + 可测集（甚至是零测集），逆像照样不可测**。**这意味着什么**：可测函数的"逆像保证"到 Borel 集（开/闭集，以及它们的可数运算）为止，到不了任意 Lebesgue 可测集——这是"Lebesgue 可测集比 Borel 集多"在函数层面的第一次现身，也是为什么 1.4 节会以 Borel σ-代数重新表述"可测函数"（f⁻¹(Borel 集) 可测）——那不是换定义，是把保证条款写精确。顺带把反例翻译成函数语言（§4.6 已用）：φ = 1_{f(F)} 可测（层底 f(F) 零测 ⟹ 可测）、f 可测，但 (φ∘f)⁻¹{1} = f⁻¹(f(F)) 不可测（它把余可数集 A' 上的 F' 整个吞进逆像）——可测函数复合可测函数不必可测。而反例一的 f = 1_V 连 TFAE 条件 (v) 都不满足（{1_V > 1/2} = V 不可测）——"逆像可测"从开集到半直线再到一般可测集是一条线，Vitali 在这条线的最弱处就断了。

**边界情形一：无界不是障碍。** f(x) = x 在整个 ℝ 上无界（f(10⁶) = 10⁶），照样可测（§3 的分层近似同时截高截支撑）；Σₙ n·1_{qₙ} 处处无界也可测（§4 sup 定理）。可测性不约束"多大"，只约束"分层干不干净"。

**边界情形二：零测集上随便改。** f 可测，把 f 在任意零测集上改成任意值（甚至改成 ⊤），可测性不变（a.e. 相等传递，:1831）。"可测"从出生起就是"模零测集"的概念——与积分（∫ 看不见零测集）、几乎处处（例外集零测）三件套完全同构。

## 6 FAQ 与反直觉清单

1. **为什么 Tao 用"简单函数的逐点极限"定义可测函数，别的书用"逆像可测"？** 方向问题：Tao 的整条叙事线是"逼近"（1.3.1 的横切 → 本节的分层近似 → 1.3.3 的收敛定理），定义跟着叙事走；逆像条件是引理 1.3.9 的结论。Folland/Rudin/S&S 在抽象测度空间（(X, M, μ)）工作，那里没有拓扑、没有"逼近"的现成语言，σ-代数是第一公民，"f⁻¹(开集) 可测"是唯一自然的定义，逼近变成定理。两套语言在 TFAE 处汇合。
2. **"逆像可测 ⟺ 可测函数"在 Lean 里叫什么名字？** 没有独立名字——它是 `UnsignedMeasurable.TFAE`（:1686）里的条件 (x)/(xi)（实数版在 `RealMeasurable.TFAE` :4738 的条件 3/4）。这本身是设计选择：机器跟随 Tao，把逆像条件实现为定理成员而非定义。
3. **可测性是不是拓扑概念？** 不是。1_ℚ 可测但处处不连续；连续类 ⊊ 可测类，且可测类对逐点极限封闭而连续类不封闭——"可测"是比"连续"更宽的纪律，宽的部分恰好是 Riemann 需要而缺失的部分。
4. **为什么说 a.e. 极限定理"修复 Riemann 的缺陷"？** Riemann 可积函数列的点态极限可以不可积（§4.5 的 1_{q₁,…,qₙ} → 1_ℚ 例子）；可测函数列的 a.e. 极限恒可测（:1890/:5334）。可积性不是极限封闭的，可测性是——收敛定理（1.3.3–1.3.5）的一切"极限与积分换序"都从这道闸门进入。
5. **实值 a.e. 极限定理为什么机器要求"极限函数有界"？** 机器用 limsup 集 + 内层收缩区间 Ioo(a + 1/(m+1), b − 1/(m+1)) 编码 {f ∈ (a,b)}，这个编码要求值域落在某个有界区间内。unsigned 版（值域 [0,∞] 含 ⊤）无此限制；书上的标准陈述也不需要。这是机器形式化的一个真实加强（为绕开 ±∞ 的实数编码），实用时先截断再拼即可。
6. **为什么说"可测 = 可被横切"？** 分层近似 gₙ 的层底就是 {f ≥ k/2ⁿ} ∩ {f < (k+1)/2ⁿ}（:1144）——1.3.1 的"层底 m(f⁻¹({y}))"的 2⁻ⁿ 加厚版；可测函数就是每条水平线切下去、层底都可测、且能容忍层厚趋于 0 的函数。
7. **分层近似的误差为什么恰是 1/2ⁿ？** 因为 ⌊r·2ⁿ⌋/2ⁿ ≤ r < (⌊r·2ⁿ⌋+1)/2ⁿ——十进制实数换成二进制小数后只保留前 n 位，舍入误差 < 2⁻ⁿ。§3 的 1/48 ≤ 1/32 与 0.003125 ≤ 0.00390625 都是这条不等式的手算实例。
8. **连续 ⟹ 可测为什么"免费"？** 因为闭集逆像闭是拓扑里现成的（连续的定义级结论），而闭集可测是 1.2.2 现成的——两行拼起来就是定理（:1720）。反方向（可测 ⟹ 连续）差得远：1_ℚ 即可测又不连续。
9. **MCT（单调收敛定理）到底在 1.3.2 还是 1.3.3？** 在 1.3.3：Tao 的 §1.3.3 才是"Lebesgue 积分 + 单调收敛"，仓库对应 `Section_1_3_3.lean`（开头就是定义 1.3.12 的上下 Lebesgue 积分）。本节（1.3.2）只造好引擎——sup 形分层近似（条件 (iv)）+ 极限封闭；"极限与积分换序"的定理本体在下一节。05 笔记 FAQ 6 说"解药在 1.3.2……MCT 的工作"指的就是这套引擎，编号归属以本节为准。
10. **Borel 集是什么？** 从开集出发，经可数并、可数交、补集运算反复生成的集合（最小 σ-代数，1.4 节正式定义）。本节的保证条款是"f⁻¹(开/闭集) 可测"，由 TFAE 与可数运算自动升级到"f⁻¹(Borel 集) 可测"；但到不了任意 Lebesgue 可测集（§5 反例二）。

**为什么这差异重要**：构造次序决定读者先信什么。Tao 让读者先信"可测 = 能逼近"——于是逐点极限封闭性对 unsigned 情形几乎是免费的，加法的封闭性一行证完（§4），逼近与收敛的直觉贯穿全节；Folland/Rudin 让读者先信"可测 = 逆像干净"——在抽象测度空间里这是唯一能写的定义，且"复合连续""Borel 逆像"等性质从定义直出，但"逐点极限仍可测"与"加法封闭"要各付一次论证。两套直觉（逼近 vs σ-代数）在 TFAE 处等价，但**它们指向不同的后续**：逼近直觉通往收敛定理（1.3.3–1.3.5），逆像直觉通往抽象测度论与 σ-代数（1.4）。本仓库跟随 Tao，Lean 里逆像条件只是 TFAE 的成员——这正是"哪种定义"的立场声明。
