# 01 · 1.1.1 初等测度：先把"盒子"的体积发出去，剩下的一切才有地方站

> Tao《An Introduction to Measure Theory》§1.1.1 完整笔记 + Lean 形式化对照
> One Big Idea：**测度不是先给"随便什么集合"一个数，而是先给最简单的几何对象（区间 → 盒子 → 有限并）一个数，再一步步放宽资格。**
> 形式化：`analysis/MeasureTheory/Section_1_1_1.lean`（区间/盒子/初等集/初等测度），`analysis/MeasureTheory/Section_1_1_2.lean`（Jordan 测度，即初等测度的第一次外延）

---

## 这一幕要解决什么（动机）

凡是学过黎曼积分的人，其实一直在偷偷使用测度：∫f 的定义需要"小区间宽度 × 高度求和"，那个"宽度"就是区间长度。但仔细一想，这个说法并不无辜——**长度这杆秤是从哪里来的？** 凭什么是 [0,1] 长 1、(0,1) 也长 1，而 (0,1) 明明比 [0,1] 少两个点？更麻烦的是：如果积分对象是个形状怪异的有界集合（比如 {0} ∪ {1/2, 1/3, 1/4, …}），它连"一个区间"都不是，你要怎么量它？

本节要打败的三个"敌人"：

1. **同一块地，两种拼法**：一个初等集（有限个盒子的并）可以有很多种盒子表示。万一一种拼法算出 3、另一种算出 4，整个"测度"概念就是自相矛盾的。**必须先证明：体积与分解无关，测度才有资格被定义。**（引理 1.1.2，Lean 用"格点计数 + 极限"证明）
2. **边界是条泥鳅**：(0,1)、[0,1)、(0,1]、[0,1] 四个集合两两只差一个端点，但如果你搞不定"端点不贡献体积"，后面开闭在哪测不出任何有意义的差别——这一节用 `max(b−a, 0)` 和"端点处计数差至多 2 但除以 N 后消失"把这条泥鳅钉死。
3. **无限并的诱惑**：有限并太好用了，可一旦允许可数无限并，怪物就混进来。先立一个记号：**可数（countable）＝能与 ℕ 一一对应，即能排成 a₀, a₁, a₂, … 一列；可数并 = ⋃ₙ Aₙ**。"ℚ∩[0,1] 这种怪物"就是可数并——它不是有限个盒子的并（整条 ℚ 甚至无界，连被量的资格都没有；有界版 ℚ∩[0,1] 的恐怖在反例 4），测度的天真定义会崩溃。本节刻意把"初等"限定在有限并，把门槛留给 1.1.2（Jordan 测度）和后面的 Lebesgue 测度去迈。

历史上这条路正是 Peano（1887）与 Jordan（1881/1892）的"容度"（content）思想；后来 Lebesgue 只是把拼图换成可数并。**本节做好一件事：在有限博弈下，把"测度"这个概念建立到无懈可击。**

## 精确定义

### 定义 1.1.1（区间 / BoundedInterval）

区间的四种形态被封装为一个归纳类型 `BoundedInterval`（`analysis/MeasureTheory/Section_1_1_1.lean:14`）：

```
Ioo a b   Icc a b   Ioc a b   Ico a b      (a b : ℝ)
```

- **为什么这样封装**：后续需要"一个对象"能直接抽出端点（`I.a` / `I.b`，`:468` / `:475`），并能作为 Finset 的元素做集合运算（`DecidableEq` 实例 `:45`）。
- **反直觉点：junk 区间**。Lean 跟随"给不走值时补垃圾值"的惯例，**允许 b < a 的"倒置区间"**：`Ioo 2 1` 存在，只是它的集合是空集。空区间的"官方代表"是 `Ioo 0 0`（`EmptyCollection` 实例 `:35`，定理 `coe_empty :40` 保证它作为集合就是 ∅）。
- 每个区间都有界（`Bornology.IsBounded.of_boundedInterval :61`）：这是"初等"的骨架——无界集合这节根本不给批发测度。

### 区间长度与盒子体积

```
|I|ₗ := max (I.b − I.a) 0        （BoundedInterval.length，:504）
Box d := { side : Fin d → BoundedInterval }    （:514）
|B|ᵥ := ∏ i, |B.side i|ₗ           （Box.volume，:558）
B.toSet := { x | ∀ i, x i ∈ (B.side i : Set ℝ) }  （:519）
```

- 长度取 `max` 的原因看反例 1：直接写 b−a 会给空集发负数。取 max 后自动有 `length_nonneg`（`:507`）。
- 记号：`|I|ₗ`（下标 ₗ = length）和 `|B|ᵥ`（下标 ᵥ = volume）是宏（`:510`、`:561`），避免和普通绝对值打架。
- d 维盒子 = d 个有界区间的笛卡尔积。1 维区间可看作 `Box 1`（`toBox :532`），体积一致（`Box.volume_of_interval :609`）。空盒体积 0（`volume_eq_zero_of_empty :564`）；**单点盒 `Icc x x`（d > 0）体积 0**（`volume_singleton :587`）。

### 初等集与初等测度

```
IsElementary E  := ∃ S : Finset (Box d), E = ⋃ B ∈ S, ↑B        （:670）
hE.measure      := ∑ B ∈ hE.partition.choose, |B|ᵥ              （IsElementary.measure，:1679）
```

- 初等集 = **有限**个盒子的并。空集是初等集（`IsElementary.empty :754`），盒子本身是初等集（`IsElementary.box :673`）。
- **初等测度只对初等集有意义**：`hE.measure` 的输入不只是集合 E，还携带"E 是初等集"的证明 `hE`。想对非初等集直接定义测度？Lean 在类型上就不让你写出来——这是"配享有测度之资格"的机器语：**先证明资格，再谈数值**。
- 这里用到一个类型论事实（第一次出现，展开讲）：Lean 把**命题也当类型**，命题的"元素"就是它的证明。所以 `hE : IsElementary E` 是一段真实存在的"证明数据"，和数字、集合一样可以作为函数参数传递——`IsElementary.measure` 的类型本质是"对每个集合 E，交来一份'E 是初等集'的证明，才还你一个实数"。给非初等集要测度？类型上写不出来。这就是"先证明资格，再谈数值"的字面实现：不是靠纪律，是靠类型。这种"证明即数据、可作参数"的对应叫 **Curry-Howard 对应**，本笔记后面还会反复遇到。
- 定义中的 `partition.choose` 是"任意取一个分成不相交盒子的分解"（存在性正是引理 1.1.2(i)）。随后必须证明两件事：这个 choice 不依赖（`measure_irrelevant :1836`）、且与手写的任何分解按体积总和一致（`measure_eq :1683`）。

## 例子与反例（全部带算术）

### 例子 1：(1,2) ∪ [3,6] 的初等测度 = 4（Lean 机验）

- |(1,2)| = max(2−1, 0) = max(1,0) = **1**
- |[3,6]| = max(6−3, 0) = max(3,0) = **3**
- 两个区间不相交，可加性（见定理 T5）给出 m = 1 + 3 = **4**。

Lean 把这道题直接写成可执行 `example`（`Section_1_1_1.lean:1701`）：构造 `hE : IsElementary E` 并证明 `hE.measure = 4`。它先设盒集合 `T = {Ioo 1 2, Icc 3 6}`，验证 `E = ⋃B∈T B.toSet`，再用 partition 的不交性 + `sum_pair` 机算 1+3。

### 例子 2：二维盒子的体积与"怎么切不变"

取 ℝ² 中盒子 `(0,1] × [2,4]`：两边长分别是 max(1−0,0) = **1**、max(4−2,0) = **2**，体积 = 1×2 = **2**。

现在换个例子：把单位半开方块 (0,1]² 切成 2×2 共 4 个格子（注意切的是 (0,1]²，不是上面那个 (0,1]×[2,4]）。格子 (i,j)（i,j ∈ {0,1}）= (i/2, (i+1)/2] × (j/2, (j+1)/2]，每个格子每边长 max((i+1)/2 − i/2, 0) = max(1/2,0) = **1/2**，体积 (1/2)² = **1/4**。四个格子两两不交、并起来正好拼回 (0,1]²，所以从 4 个小盒算（4 × 1/4 = **1**）和整盒直接算（每边 1，体积 1·1 = **1**）得到同一个数。这朴素的两句话，就是引理 1.1.2 要证明的全部。

更一般地，`Box.cube d t = (0,t]^d` 的体积是 t^d（`volume_cube :2315`）。取 t = 1/3、d = 2：(1/3)² = **1/9**——单位立方体恰好被 9 = 3² 个这样的"小立方体"铺满，9 × 1/9 = 1。这个"N^d 个 1/N 立方体铺满单位立方体"的算术，是唯一性定理（T6）里 c/N^d 的来源。

### 例子 3：格点近似——N 有限时并不相等，N→∞ 相等

这是"测度良定义"的机理示范。取 I = [0,2]，考察第 N 级格点 {n/N : n ∈ ℤ}。N=10 时：

- 在闭区间 [0,2] 里：n 从 0 到 20 共 **21** 个点，计数/N = 21/10 = **2.1**
- 在开区间 (0,2) 里：n 从 1 到 19 共 **19** 个点，计数/N = 19/10 = **1.9**
- 而 |[0,2]| = |(0,2)| = max(2−0,0) = **2**

两个近似值一高一低夹住 2，差值 = 2/N = **0.2**，随 N→∞ 归零。Lean 里这就是 `BoundedInterval.length_eq`（`:1493`）：lim_N (1/N)·#(I ∩ ℤ/N) = |I|ₗ；开闭之差"至多 2 个端点"由 `lattice_count_diff_bound`（`:1390`）精确量化——正是反例 2 被驯服的机器版本。

**为什么"数格点除以 N"会收敛到长度？**让每个格点 n/N 认领"它右边的那一格"——半开小区间 (n/N, (n+1)/N]，长恰 1/N。这些格两两不交（半开 = 右端归后一格）且铺满整条实轴，所以"格点数/N"恰好等于"被认领小格的总长"。而 I 里格点认领的小格，除至多两个贴着端点的"边界格"外，其余全部整个躺在 I 里：贴左端点 a 的那个可能从 a 左边开始（漏掉 [a,·) 一小段），贴右端点 b 的那个可能伸出 b 之外（多算一小段），每个边界格至多造成 1/N 的误差。于是 |计数/N − |I|ₗ| ≤ 2/N——N=10 时正是上面两个 0.1。这就是 `lattice_count_diff_bound`（`:1390`）"开闭计数差至多 2"的几何含义：端点开闭只影响边界格，边界格最多两个。N→∞ 时 2/N → 0，计数/N 被夹逼到 |I|ₗ。

### 反例 1：退化区间 Ioo 2 1（junk 区间）

`Ioo 2 1` 作为集合是 (2,1) = ∅，但若长度定义为 b−a = 1−2 = **−1**，一个空集合就得到负体积——荒谬。长度取 `max(b−a, 0)` 后为 max(−1,0) = **0**，才符合"空集测 0"。**junk 端点（b < a）→ 空集 → 长度 0** 是这一条约束的自然连锁。

### 反例 2：边界差一个端点，测度不动

[0,1]、(0,1)、[0,1)、(0,1] 四个版本都测度 **1**；单点 {0} = `Icc 0 0` 作为盒子测度 **0**。于是：

> **端点不贡献体积**：m((0,1)) = m([0,1)) = m((0,1]) = m([0,1]) = 1，但 (0,1) ≠ [0,1]。

如果初等测度对端点极敏感，积分理论根本无从落笔。这里的实质是：边界之差只出现在"是否包含端点"这一层，而这一差在引理 1.1.2 的极限论证中是 2/N → 0。1.1.2 节"Jordan 可测 ⇔ 内外测度相等"（`JordanMeasurable.equiv`，`Section_1_1_2.lean:261`）要处理的正是这层边界的多与少。

### 反例 3：D = {0} ∪ {1/n : n ≥ 1}——不是初等集，但 Jordan 测度量它 = 0

除 0 外每个点都是孤立点（**0 不是孤立点**——它是唯一极限点，0 的任何邻域都含某个 1/n），集合有可数无限个连通分块（每个点一块）。初等集是**有限**个盒子的并，每个盒子是连通区间块——有限个盒子最多贡献有限个连通支，而 D 有无穷多支，所以 **D 不是初等集**：本节框架里 m(D) 根本没有定义（Lean 里连类型都无法表达）。这不是缺陷，是阶梯。

但注意：**Jordan 测度量得了 D，答案是 0**（Jordan 内外测度 = 用初等集上下逼近的 sup/inf，定义见下一幕）。内测度：任何初等 A ⊆ D 的盒子都只能是单点或空（D 只有可数个点，不含任何非退化区间），所以 m(A) = 0，sup 给 **0**。外测度：对任意 ε > 0，取 N 使 1/N < ε/2，用一个盒 [0, 1/N] 吞掉尾段 {0} ∪ {1/n : n ≥ N}，再给 1, 1/2, …, 1/(N−1) 各套一个半径 ε/(8(N−1)) 的小盒，总长 1/N + 2(N−1)·ε/(8(N−1)) < ε/2 + ε/4 < ε。于是外测度 = 0。内外相等 ⟹ **D 是 Jordan 可测的，m(D) = 0**（此处为手推论证，Lean 未形式化；机器形式化的"测 0"概念见 `JordanMeasurable.null`/`null_iff`，`Section_1_1_2.lean:4149`/`:4152`）。

这是"初等 → Jordan"是真扩展的第一例：D 是 Jordan 比初等多量到的集合。真正"Jordan 量不了"的障碍是**稠密性**而非孤立的无穷——见反例 4 的 ℚ∩[0,1]：可数个点聚在一点附近，能被一个盒"批发"掉（D）；可数个点稠密地撒遍整个区间，则任何有限覆盖都混进无理数（ℚ∩[0,1]）。**"可数无限个点"不自动是障碍，"铺满不留缝"才是。**

## 核心定理与证明骨架

### T1. 有界 + 序连通 ⇔ 是区间（`BoundedInterval.ordConnected_iff :317`）

*陈述*：X ⊆ ℝ 有界且序连通（`OrdConnected`：任意 x,y ∈ X 整段 [x,y] ⊆ X）当且仅当 X = 某个 `BoundedInterval`。
*直觉*：序连通排除了"挖洞"（如 (0,1)∪(2,3)），有界排除了无限延伸；剩下的只有"一段"或空。
*证明骨架*：空集 → `Ioo 0 0`。非空时取 a = sInf X，b = sSup X。按"端点是否属于 X"分四支：a,b ∈ X → `Icc`；a∈X 且 b∉X → `Ico`；…… 每个方向用 `csInf_le / le_csSup`（端点夹住成员），反方向用序连通性把 [w,z] ⊆ X 填入（`mem_of_mem_Icc_ordConnected :311`）。
*关键一步*：开端点用 `exists_lt_of_lt_csSup / exists_lt_of_csInf_lt`（`:367`/`:379`）抓"离 sup 任意近但仍 < sup 的点"，从而避开端点——这就是"泥鳅（端点）被溜走"的正式动作。
*Lean 位置*：`analysis/MeasureTheory/Section_1_1_1.lean:317-420`。推论：区间交还是区间（`BoundedInterval.inter :422`），这是初等集交封闭（T4）的支柱。

### T2. 引理 1.1.2(i)：一切有限盒集合有"共同细化"成两两不交的子盒（`BoundedInterval.partition :759`，`Box.partition :835`，`IsElementary.partition :873`）

*陈述*：任意 `Finset (Box d)` 都能拆成一组两两不交的盒子，使每个原始盒子都是其中一些新盒子的并。
*证明骨架*：一维先做。收集所有端点的集合 `endpoints = S.image a ∪ S.image b`，用 `orderIsoOfFin` 排成 a₀ < a₁ < … < a_{k−1}（`:764`），然后把细分切成"单点寄存器 `Icc aᵢ aᵢ` ∪ 相邻开区间 `Ioo aᵢ aᵢ₊₁`"（`:766`）。这些段两两不交：单点之间、开区间之间、单点与开区间之间全由顺序关系隔离。每个原始区间 I 的每个点要么落在某个单点（该点是端点）要么落在某个开段——由端点归属直接给出。d 维：各维独立细化后取**逐坐标笛卡尔积**（`Box.partition :843` 对 `Finset.univ.pi J` 取 image），不交性逐维传递。
*关键一步*：排序后的相邻段"不交"与"覆盖"都由顺序变量直接给出，机器在 `grind`/`omega` 层完成。
*Lean 位置*：`Section_1_1_1.lean:759-871`。

### T3. 引理 1.1.2(ii)：测度与分解无关（`Box.measure_uniq :1669`）

*陈述*：两个两两不交、并集相同的盒阵 T₁、T₂ 满足 ∑_{B∈T₁}|B|ᵥ = ∑_{B∈T₂}|B|ᵥ。
*证明骨架*：任取 N，用 N 级格点 (1/N)·ℤ^d 与并集 E 相交数点。因为 T₁、T₂ 各自两两不交，"数点"可以按盒分别数（`Box.sum_vol_eq :1634`：并的分点数 = 各盒分点数之和），所以"计数/N^d"对两个分解分别收敛到它们各自的体积和——同一个集合同一个极限，两边的体积和必须相等（`tendsto_nhds_unique`）。
*关键一步（机器难点）*：为什么计数/N^d 收敛到体积？一维归约：区间长度 = 格点计数极限（`BoundedInterval.length_eq :1493`，用 `tendsto_Icc_lattice_count :1308` + 开闭差 2 的 `lattice_count_diff_bound :1390`，配合 `tendsto_floor_div_atTop :1155` 的 ⌊Nx⌋/N → x）；格点计数按维拆成乘积（`Box.sample_congr :1598`），乘积的极限 = 极限的乘积（`Box.vol_eq :1622`）。于是"同一集合的两分解"收敛到同一个极限，体积和被迫相等。
*Lean 位置*：`Section_1_1_1.lean:1307-1395`（一维格点计数机制）、`:1621-1700`（多维与测度定义）。这是整个测度大厦的第一根承重柱：`IsElementary.measure :1679` 的"任取 partition"被证明不影响计算。

### T4. 练习 1.1.1：初等集的布尔封闭（并 / 交 / 差 / 对称差 / 平移）

- **并**：两个盒集合级联（`IsElementary.union :678`，finset 版 `union' :696`）。
- **交**：逐坐标区间交（`IsElementary.inter :712`，关键是 `BoundedInterval.inter :422`——区间交仍是区间，由 T1 的序连通刻画保证）；盒集合取笛卡尔积 `S_E ×ˢ S_F` 逐对交。
- **差** `E \ F`（`:886`）：先把 `S_E ∪ S_H` 共同细化成两两不交盒阵 T（T2），再按"来自 E 的盒"与"来自 H 的盒"过滤出 tE、tH（`:896-899`），证 `E \ (E∩F) = ⋃(tE \ tH)`。关键一步是 `h_sdiff_union`（`:957`）：两个不交盒阵的并之差的"点"必须整体落在某个盒里，否则用两两不交性产生矛盾。
- **对称差**（`:997`）= 两个差再并：一箭（`symmDiff_def`）。
- **平移**（`:1005`）：逐类型平移区间 `(a+c, b+c)` 等，集合等式 `(I + {c}) = I + {c}` 直接验证（`:1011-1068`）。关键一步是视角转换：**"y ∈ E + {x}" 永远等价于 "y − x ∈ E"**（`:1071` 起的 `hf` 证明）。
*Lean 位置*：`Section_1_1_1.lean:678-1124`。

### T5. 基本性质（非负 / 可加 / 单调 / 次可加 / 平移不变 / 证明无关）

| 性质 | 定理 | Lean 位置 |
|------|------|-----------|
| ∅ 测度 0 | `IsElementary.measure_of_empty` | `:1982` |
| 单盒测度 = 体积 | `measure_of_box` | `:1994` |
| 非负 | `measure_nonneg` | `:1719` |

### T6. 练习 1.1.3：唯一性——"凡是测度般的东西就是体积的倍数"（`IsElementary.measure_uniq :2618`）

*陈述*：设 m' 对初等集满足 (i) 非负、(ii) 不交并可加、(iii) 平移不变，则存在常数 c ≥ 0 使 `m' E = c · hE.measure` 对一切初等集成立。若还有 `m'(单位立方体) = 1`，则 c = 1（`measure_uniq' :2633`）——体积被唯一钉死。
*证明骨架*：
1. 令 c := m'((0,1]^d)（`Box.unit_cube :2305`）。为什么单位立方体选半开 (0,1]^d 而不是 [0,1]^d？因为第 2 步的"铺满"要求：半开格两两不交、合起来严丝合缝，每个点恰好落在唯一一格，N^d 个格才能无争议地铺满 (0,1]^d；换成闭盒，k/N 处的格线归谁要逐个裁断——格线测度 0，不值得为它弄脏铺砌。
2. **先收编"1/N 的小立方体"**：每个网格格 `Box.cell N k = ∏ᵢ (kᵢ/N, (kᵢ+1)/N]` 是 `(0,1/N]^d` 的平移（`cell_eq_translate :2329`），平移不变 ⇒ m'(cell) = m'((0,1/N]^d)；N^d 个格平移铺满 (0,1]^d（`gridCells_pairwiseDisjoint :2362` + `gridBox_eq_cells_union :2380`），可加性 ⇒ **m'((0,1/N]^d) = c/N^d**（`m'_cube_value :2485`）。
3. **再到小盒子 B**：把 B 里外夹在网格盒之间——外层 `gridBox (⌊Na⌋−1, ⌈Nb⌉) ⊇ B`、内层 `gridBox (⌈Na⌉, ⌈Nb⌉−1) ⊆ B`；每个网格盒的 m' = (#格数)·(c/N^d)（`m'_gridBox_count :2471`，格数 = ∏(qᵢ−pᵢ)）。记号：`gridBox N p q := ∏ᵢ (pᵢ/N, qᵢ/N]`（:2336），即"从 p/N 到 q/N 的半开网格盒"。两处 `−1` 的不对称正是半开格"左开"的账：**外层要包含闭盒 B 的左端点 a**——若 a 恰是格点 k/N，格 (k/N, ·] 不含自己的左端，必须退一格到 (k−1)/N，即 `⌊Na⌋−1`；右端 `⌈Nb⌉/N ≥ b` 保证 b 在格内。**内层要整个落在 [a,b] 内**——左端起在 `⌈Na⌉/N ≥ a` 处即可（左开，从 a 开始合法，故无 −1）；右端 `⌈Nb⌉−1` 恒满足 (⌈Nb⌉−1)/N < b（Nb 恰为整数时它比最大可行值 ⌊Nb⌋ 再多退一格，是保守无害的写法）。
4. **N→∞**：外/内层网格盒体积 → |B|（`tendsto_finset_prod` + floor/ceil 收敛），夹出 `m' B = c·|B|`（`m'_box_le :2509`、`m'_box_ge :2551` 一上一下；`ceil_floor_pos_eventually :1220` 保证格数非负）。
5. 对任意初等 E 用 partition 拆成盒的和，有限和把乘法因子出来。
*关键点*：**平移不变性不是点缀而是骨架**——它把任意 N 级网格单元统一折算成 c/N^d，从而把体积数轴上的每个有理标尺都校准过。这套机构就是 Lebesgue 测度的预演模板。
*Lean 位置*：几何脚手架 `:2318-2497`，夹逼 `:2509-2612`，最终 `:2618-2655`。

### T7. 练习 1.1.4：积集合的测度是乘积（`IsElementary.prod :2741`、`IsElementary.measure_of_prod :2818`）

*陈述*：E₁ ⊆ ℝ^d₁、E₂ ⊆ ℝ^d₂ 初等 ⇒ m(E₁ × E₂) = m(E₁)·m(E₂)。
*证明骨架*：盒层面先证体积乘积（`Box.volume_prod :2681`，用 `Fin d₁ ⊕ Fin d₂ ≃ Fin (d₁+d₂)` 的索引分裂）；再到盒阵层面：`T₁ × T₂` 的逐对积仍两两不交（某一坐标下标不同即可），并起来正是 E₁×E₂（`Box.prod_toSet :2699`）；最后 `Finset.sum_product`：ΣΣ x·y = (Σx)(Σy)。
*关键一步*："不交性"从"整体不交"退化为"某个坐标下标不交"，用 `Set.prod_inter_prod` 把另一维撇掉。
*Lean 位置*：`Section_1_1_1.lean:2658-2921`。

## 下一幕：Jordan 测度（1.1.2）——初等测度拿到"所有有界集合"身上的方式

初等测度只认识有限个盒子。1.1.2 节把资格放宽到一切有界集合：**从里用初等集从下逼近（内测度），从外用初等集从上逼近（外测度），两者相等就发"Jordan 可测"牌照。**

```
Jordan_inner_measure E := sSup { m | ∃ A, IsElementary A, A ⊆ E ∧ m = hA.measure }   （Section_1_1_2.lean:23）
Jordan_outer_measure E := sInf { m | ∃ A, IsElementary A, E ⊆ A ∧ m = hA.measure }   （:26）
JordanMeasurable E      := Bornology.IsBounded E ∧ Jordan_inner_measure E = Jordan_outer_measure E  （:30）
JordanMeasurable.measure := Jordan_inner_measure E  （:34，等于外测度见 eq_outer :41）
```

- 为什么要有界：无界集合可以装进任意大的盒子，内测度定义中的集合可能没上界、外测度集合可能为空——`contains_bounded :45`（每个有界集都含于某个初等集，用 `Metric.closedBall 0 M` 放大到盒子）保证外测度的 sup/inf 集合非空。
- 非负（`Jordan_inner_measure_nonneg :92`、`Jordan_outer_measure_nonneg :108`）、内 ≤ 外（`Jordan_inner_le_outer :124`，骨架：A ⊆ E ⊆ B 且 A、B 初等 ⇒ m(A) ≤ m(B)，sup 与 inf 一夹）。
- 记号解释（`sSup`/`sInf` 第一次出现）：它们是对**一个实数集合**（可能无限）取上/下确界——"比集合里每个数都大（小）的数中的最小（大）者"；`max`/`min` 只能比较两个数。内外测度的定义里，逼近集 {m | ∃ A 初等, A ⊆ E ∧ m = hA.measure } 通常是无穷集合，所以必须用 sSup/sInf。直观：内测度 = 所有下逼近能堆到的最高处；外测度 = 所有上逼近能压到的最低处。

### J1. 练习 1.1.5：Jordan 可测的等价刻画（`JordanMeasurable.equiv :261`）

以下三句等价（对固定有界 E）：
1. `JordanMeasurable E`（内外测度相等）；
2. ∀ε>0，存在初等 A ⊆ E ⊆ B 使 m(B \ A) ≤ ε；
3. ∀ε>0，存在初等 A 使外测度(symmDiff E A) ≤ ε。

*证明骨架*：用 `Jordan_inner_le :198`（比内测度小的数都能被某个初等子集超过）和 `le_Jordan_outer :222`（比外测度大的数都能被某个初等超集压住）把内外测度各用 ε/2 逼出来，得到 A、B；再证 (B\A) 测度控制对称差的外测度（`Jordan_outer_le :176` + `csInf_le_csInf` 单调性）。反方向：从对称差小推出 B \ A 小，再推出外测度 ≤ 内测度 + ε（对一切 ε），从而相等。
*关键一步*：测度相等的证明套路 `le_of_forall_pos_le_add`——"对任意 ε > 0 有 x ≤ y + ε"⇒ x ≤ y，这是实数的阿基米德性。

### J2. 练习 1.1.6：Jordan 测度的全套性质

## 常用技巧（本节发的"徽章"）

- **端点排序 → 细化**：凡是"区间的有限集合混乱交叠"的问题，先把所有端点排好序，切成"单点 + 相邻开区间"，交叠的世界在排序里消失（T2）。
- **格点计数 + 夹逼 1/N**：要证明"总数 = 某数"，让 N 越来越大，把待证量夹在上下两个格子计数之间（`lattice_count_diff_bound` 的 2/N 就是一个典型）。这是 T3、T6、J3 反复出现的节奏："先取 N → ∞，一步到位"。
- **证明无关（proof irrelevance）**：同一个集合 E 可以用两个不同方式认证为初等（h₁、h₂），测度必须不随之变（`measure_irrelevant :1836`）。这是"测度 = 纯集合函数"的形式化守卫。
- **平移是"减法视角"**：`E + {x}` 的成员 y 永远满足 y − x ∈ E。所有平移证明都从这条出发（`:1071` 一带）。
- **四分支穷举端点归属**：sInf/sSup 两个端点各"在/不在" X，正好四种组合对应 Icc/Ico/Ioc/Ioo（T1 的四分类）。
- **ε 劈成两半**：两个逼近（内、外）各花 ε/2，加起来恰好 ε——J1/J2 的并、交证明全靠这个。

## FAQ / 反直觉清单

1. **长度为什么是 `max(b−a, 0)` 而不是 `b−a`？**——因为 Lean 允许"倒置区间"（junk 值），`Ioo 2 1` 是空集，要卖 0；直接写 b−a 会给空集发 −1。这是"测量总是 ≥ 0"与"定义域允许越界"的交接处（反例 1）。
2. **空区间为什么是 `Ioo 0 0`？** 需要让 ∅ 能写作一个具体的 `BoundedInterval`，好让 `EmptyCollection` 有值（`:40` 保证作为集合就是 ∅）。b < a 的每个倒置区间都是它的替身。
3. **为什么定义 m 之前先拼命证明 partition（引理 1.1.2）？** `IsElementary.measure`（`:1679`）抽取了一个"任意的" partition——如果两个 partition 给出不同值，这个"任取"就使测度不可定义。所以"分解与分解无关"（T3）是定义 m 的资格声明，不是可选项。
4. **(0,1] 和 [0,1) 只差一个端点，但测度相同——测度是"瞎"的吗？** 不是瞎，是"对边界不敏感"被设计成性质：例 3 显示单端点差异在 2/N 量级，N→∞ 归零。1.1.2 节把"边界差可忽略"合法化为"内外测度相等"（`JordanMeasurable.equiv :261`）。
5. **为什么练习 1.1.3（唯一性）值得一个定理？** 它回答"体积的国标"源自哪里：三公理（非负、有限可加、平移不变）只有一个自由度（倍数 c），规范 c=1 就完全确定。如果有人给你一个"测度"且与体积不同，必是违反三公理之一——这是测度论的"等号公理"。
6. **为什么"单个点"算初等且测 0，但可数并却禁？** 单点是盒子 `Icc x x`（长度 0）；但 D = {0}∪{1/n} 有可数无限个连通支，任何有限盒并都不可能恰好拼出 D（初等集只有有限个连通支），所以 D 不是初等集。**但注意**：D 在 Jordan 层完全合法，m(D) = 0（尾段被一个盒吞掉，见反例 3）——"无穷个点"不自动是障碍。真正的裂口是**稠密**的可数集：ℚ∩[0,1] 的 Jordan 内测度 0、外测度 1，不可测（反例 4）。这也解释了为什么 Jordan 测度**没有可数可加性**——可数可加（countable additivity）指"互不相交的一列可测集 Aₙ 满足 m(⋃ₙAₙ) = Σₙ m(Aₙ)"：ℚ∩[0,1] 是**可数个单点**（各测 0）之并，若可数可加成立就该得 0，但它连可测都不是。这就是 Jordan → Lebesgue 的裂口：可测性对可数并不封闭。

## 反例（Jordan 层）——为什么还要往 Lebesgue 走

### 反例 4：ℚ∩[0,1] 不是 Jordan 可测（标准反例，机器未形式化）

- **内测度 = 0**：任意初等 A ⊆ ℚ∩[0,1]。A 是有限个盒子的并；任何一个"非退化"盒子（某边 a < b）都含无理点，不可能 ⊆ ℚ，所以所有盒子都退化、体积 0。sup 只能给 **0**。
- **外测度 ≥ 1**：任意初等 B ⊇ ℚ∩[0,1]。三步走：
  1. **闭包不改变体积**：B 是有限个区间之并，闭包与有限并可交换，每个区间的闭包仍是闭区间且长度不变，故 m(closure B) = m(B)——这是"从闭包回到体积"的桥，缺了它推不动。
  2. **稠密 ⇒ 闭包吞下整个 [0,1]**：ℚ 在 [0,1] 稠密，故 closure(B) ⊇ closure(ℚ∩[0,1]) = [0,1]。
  3. **有限个闭区间覆盖 [0,1] 则总长 ≥ 1**（标准归纳，写全）：取覆盖 0 的那个区间 [c₁,d₁]，它含 0 故长度 = d₁−c₁ ≥ d₁；其余区间必须覆盖 [d₁,1]——否则 (d₁,1] 里有点既不在第一个区间、也不在其余区间，整个就漏了；由归纳假设其余区间总长 ≥ 1 − d₁。合计 ≥ d₁ + (1−d₁) = 1。
  于是 m(B) = m(closure B) ≥ m([0,1]) = 1，inf 给 ≥ 1；又 m([0,1]) = 1 是可行覆盖，外测度恰 = **1**。
- 结论：0 ≠ 1，ℚ∩[0,1] 不可测。（直观上成立的标准结论，此反例本身未在 Lean 中形式化；机器已形式化的是其近亲"零测集"概念 `JordanMeasurable.null :4149`、`null_iff :4152`。）

这个集合有个致命特征：**它同时是"可数个点之并"**。每个点测 0，但整体测不出 0——因为 Jordan 测度只有有限可加（`mes_of_disjUnion :712`），可数可加性在这一层完全缺失。这就是下一章 Lebesgue 测度要补的洞。

### 反例 5：图可测性必须闭盒——f(x) = 1/x 在开盒上（Lean 记录在案）

`Section_1_1_2.lean:870-879` 的注释明确记载：如果把练习 1.1.7 的错误版本（任意盒子 + ContinuousOn）当真，f(x) = 1/x 在开盒 (0,1) 上连续但**无界**，其图无界，因而不满足 JordanMeasurable 的有界性条件。Lean 把这个错误陈述保留成注释掉的代码（`:1160-1164`），并给修正版补上假设"每条边都是 `Icc`"（`:1149`）。教训：**连续性 + 紧集 才给你有界性（一致连续性）；换到开集，条件立刻崩。**

### 为什么差异重要

不同教材对"先给什么、先信什么"的选择不同：Tao 把有限盒测度建立所需的全部工作（细化、良定义、唯一性）逐一道破，读者明白了"测度单位怎么发下来的"；Folland/S&S 的读者则走捷径跳到**外测度 = 从覆盖出发的 inf**，用半开盒子把端点问题直接扔掉（代价是不会意识到"同一集合不同拼法会给出不同值"这种危险）；Halmos/Rudin 甚至完全不经历"初等"货架（测度公理直接是对象）——但对这样起家的读者，Lebesgue 测度"为什么存在"反而更神秘。顺序即世界观，差异不在对错，而在新手接受的路径。

注：Halmos / Rudin / Royden 各书仅引用到章级位置，具体定理编号待核（各版本编号不同，此处不引用具体条目）。
