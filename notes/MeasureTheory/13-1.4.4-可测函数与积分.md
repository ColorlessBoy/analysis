# 13 · 1.4.4 可测函数与积分：一次证明，处处生效

> 一句话纲领：**1.3 的整个积分机器（简单函数 → 无符号积分 → 绝对可积 → 三大收敛定理）当初只在 ℝᵈ + Lebesgue 测度上开过机，但逐条检查它的证明，依赖的从来不是 ℝᵈ 的几何，而是两样东西——"可测集族对可数交并可数并封闭"（1.4.2 的 σ-代数公理）和"测度可数可加"（1.4.3 的测度公理）。这两样已经抽象好了，所以本节不需要任何新想法：把 1.3 的剧本在 (X, 𝒜, μ) 上原样重演一遍——可测函数、简单函数、无符号积分、绝对可积——终点是单调收敛、Fatou、支配收敛三个定理在任意测度空间上的正式形态。一次证明，处处生效：计数测度上积分变成级数，Dirac 测度上积分变成函数取值，三大定理分别退化为级数的逐项极限、数列的 liminf 不等式、Weierstrass M-检验。**诚实声明：仓库 `analysis/MeasureTheory/Section_1_4_4.lean` 是空壳（只有 import 与标题注释，无任何定理）——本节无仓库机验可引，机器实现见 Mathlib MeasureTheory（对照表在 §6）。**

## 1 这一幕要解决什么

1.4.3 用一整节把 (X, 𝒜, μ) 立了起来：σ-代数给户口，可数可加给账目。但直到现在，这个抽象空间上还没有一个积分号——∫ 只存在于 ℝᵈ 上，写在 Lebesgue 测度 m 旁边。于是局面有点尴尬：我们花了三节（1.2.1–1.2.3）在 ℝᵈ 上造 m，又花了一节半（1.3.1–1.3.4）在 ℝᵈ 上造积分，现在抽象出了 (X, 𝒜, μ)，却不知道它能不能积分。1.3.3 那个著名的换序悖论（尖峰 fₙ = n·1_{(0,1/n)}：∫fₙ = n·(1/n) = 1 对一切 n，所以 lim ∫fₙ = 1 ≠ 0 = ∫(lim fₙ)）当时在 ℝᵈ 上宣判：换序需要条件。可"换序什么时候合法"不该取决于舞台——一个论断如果在 ℝᵈ 上成立是因为 ℝᵈ 有特殊几何，那它就不是分析的真理，只是 ℝᵈ 的偶然。本节就是来回答：**把 1.3 全部重演一遍，哪些论断活下来？**

先做最朴素的实验：把 1.3 的每个句子抄一遍，把"ℝᵈ"换成 X、"Lebesgue 测度 m"换成 μ、"Borel 集"换成 𝒜 里的集。抄之前先问：1.3 的证明到底用了几样 ℝᵈ 特有的东西？逐条清点下来只有两样：可测集族对可数交并可数并封闭（否则 ⋃ₙEₙ 不可测，积分的水平集构造当场瘫痪），以及测度可数可加（否则"把面积切成可数片"的求和不合法）。而这两样，1.4.2 的 σ-代数公理和 1.4.3 的可数可加公理已经一字不差地抽象好了——连集合版的单调收敛（1.4.3 习题 1.4.23(ii)，仓库机验为 `Measure.upwards_mono`，`Section_1_4_3.lean:959`）都是 1.4.3 的定理，不依赖任何 ℝᵈ 几何。所以答案是：抄一遍，不崩。这就是概念套概念的回报——1.4.2/1.4.3 的抽象不是为抽象而抽象，它把 1.3 的全部证明压缩成了"可数可加"这一条公理的推论，于是本节的重演是免费的，而三大收敛定理从此在一切测度空间上合法。

## 2 定义重演：可测函数、简单函数、无符号积分

先重演"函数"。1.3.2 的可测函数是从"逐点极限闭包"长出来的：先用区间/开集定义最简函数类，再取逐点极限闭包。这个剧本的台词全是 ℝᵈ 的（区间、开球、坐标），在 (X, 𝒜) 上念不出来——X 上根本没有"开区间"。朴素替代：要求 f⁻¹(单个点) 可测？从两个方向同时崩。第一，抽象空间里单点集未必有户口：取 X = {a, b}、𝒜 = {∅, X}（最小 σ-代数），id : X → X 满足不了 f⁻¹({a}) = {a} ∉ 𝒜——条件在错误的对象上提要求，把一堆本可分级的函数直接判死。第二，就算单点集都可测（比如 ℝᵈ 上），条件也太弱：任何单射 f 的每个单点原像都至多一个点、自动通过，函数形状完全不受约束。再试：要求 f⁻¹(所有 Borel 集) 可测？这版本确实可行，但检验清单是无穷的——好在修补的关键观察把它收回来：𝒜 对可数并可数交封闭，所以只要能检验"骨架"（开集、或闭集、或半开区间——任何生成 Borel σ-代数的集合族），全部 Borel 原像的可测性就自动到手：开集原像可测 ⟹ 对生成族成立 ⟹ 用可数并/可数交逐层盖住每个 Borel 集。于是定义被逼出来：**f : X → ℝ 可测 ⟺ 对每个 Borel 集 B ⊆ ℝ，f⁻¹(B) ∈ 𝒜**（Tao §1.4.4，定义编号待核）。形式上它要求无穷次检验，但同段的骨架观察就是它的使用手册：实际操作只验开集（或闭集、或区间），定义与操作之间的等价性由 σ-代数公理免费提供。立即检验两个例子：E ∈ 𝒜 时示性函数 1_E 可测（1_E⁻¹({1}) = E，其余原像是 ∅ 或 X）；常函数可测（原像只有 ∅ 和 X）。闭包性质整批照搬——但注意，在逆像口径下它们不再是定义的一部分，而是真定理，证明的关键一步是把函数运算翻译成水平集运算：{supₙ fₙ ≥ t} = ∪ₙ{fₙ ≥ t}（可数并，σ-代数公理接管）、{infₙ fₙ ≥ t} = ∩ₙ{fₙ ≥ t}、{limsupₙ fₙ ≥ t} = ∩ₖ ∪_{n≥k} {fₙ ≥ t}——于是 f + g、fg、|f|、max(f,g) 可测，可测函数列的 sup、inf、limsup、liminf、逐点极限都可测（Tao §1.4.4 引理，编号待核）。1.3.2 的机器在抽象层上原样运行，而且下面 Fatou 的证明恰好踩在"liminf 可测"这条性质上。

再重演"积分"本身。1.3.1 的简单函数 Σᵢ cᵢ1_{Eᵢ}（Eᵢ ∈ 𝒜 不交且并满 X）直接照抄，积分配上 μ：∫(Σᵢ cᵢ1_{Eᵢ}) dμ = Σᵢ cᵢ μ(Eᵢ)。这一步的合法性只用了一件事：μ 可数可加，所以"把 X 切成有限片、逐片称重求和"的账目规则与切法无关。无符号积分同样照抄 1.3.3 的定义 1.3.13：∫f dμ = sup{∫g dμ : g 简单, 0 ≤ g ≤ f}（Tao §1.4.4，编号待核）。为什么这里能抄？因为 1.3.3 证明"下积分是对的"用的全部武器——单调性、可数可加性、集合版单调收敛——在 (X, 𝒜, μ) 上都现成。

定义一落地就检验两个抽象空间的例子，它们让积分现出原形。**例 1（计数测度）**：X = ℕ，μ = 计数测度（μ(E) = |E|，可数可加，因为可数并的元素数就是各片之和）。此时 ∫f dμ = Σₙ f(n)：简单函数 g = Σᵢ cᵢ1_{Eᵢ} 的积分 Σcᵢ|Eᵢ| 本来就是按点求和，sup 后亦然。取 f(n) = 2⁻ⁿ（n 从 0 起）：部分和 Σ_{n=0}^{N} 2⁻ⁿ = (1−2⁻⁽ᴺ⁺¹⁾)/(1−1/2) = 2(1−2⁻⁽ᴺ⁺¹⁾) → 2，所以 ∫f dc = 2——"积分是面积"的直觉在计数测度上变成了"积分是级数"，Σₙ₌₀^∞ 2⁻ⁿ = 2。**例 2（Dirac 测度）**：X 任意，δₓ(E) = 1 若 x ∈ E，否则 0。简单函数积分 Σcᵢδₓ(Eᵢ) 只把包含 x 的那一片算进来，恰好等于 g(x)；对 g ≤ f 取 sup，得 ∫f dδₓ = f(x)。取 X = ℝ（配 Borel σ-代数）、x = 3，考虑函数 φ(t) = t²（连续，故可测）：∫φ dδ₃ = φ(3) = 3² = 9——积分变成了"在 x 处取值"。这两个例子在 Mathlib 里就是两条定理：`lintegral_count`（`Mathlib/MeasureTheory/Integral/Lebesgue/Countable.lean:90`，断言 ∫⁻ f ∂count = ∑' f）与 `lintegral_dirac'`（同文件 :63，断言 ∫⁻ f ∂dirac a = f a）。

最后重演"带符号"这一层：绝对可积牌照 ∫|f| dμ < ∞，∫f dμ = ∫f⁺ dμ − ∫f⁻ dμ（Tao §1.4.4，同 1.3.4 的公式 (1.12) 抽象版）。牌照的来历与 1.3.4 完全相同：∫f⁺、∫f⁻ 都在 [0,∞] 里取值，减法要落在 ℝ 上就必须两个都有限，而 |f| = f⁺ + f⁻ 把两个条件合并成一个数 ∫|f|。在计数测度上检验：f(n) = (−1)ⁿ2⁻ⁿ，则 ∫|f| = Σₙ 2⁻ⁿ = 2 < ∞，牌照通过；∫f = Σₙ (−1)ⁿ2⁻ⁿ = Σₙ (−1/2)ⁿ = 1/(1+1/2) = 2/3（公比 −1/2 的几何级数）。这个例子同时预告了 §3 的一个主题：计数测度上的绝对可积 = 级数绝对收敛，绝对可积函数 = 绝对收敛级数——1.3.4 的"绝对可和 ⟺ 绝对可积"（习题 1.3.21）在抽象层就是同一句话。

## 3 三个收敛定理：换序的正式裁决，全体测度空间通用

重演的定义没有新意，重演的终点才有：三大收敛定理。它们是 1.3.3 那场换序悖论审判的正式判决书，现在在任意 (X, 𝒜, μ) 上生效。三兄弟的职能分工一句话：**单调就换序（MCT），被控制就换序（DCT），什么都不给就只剩下不等式（Fatou）**——而 Fatou 恰好是 DCT 的引擎。

### 3.1 单调收敛定理（MCT，Tao 定理 1.4.43）

先问为什么可信：fₙ 逐点上升到 f，那么"∫f 的面积"就是"∫fₙ 的面积"的极限——因为每一层 fₙ 都贴着 f 的下沿长，谁也不许掉队，面积只能一层层逼近。这与 1.4.3 的集合版（μ(∪Eₙ) = lim μ(Eₙ)，上升集列；习题 1.4.23(ii)，机验 `Measure.upwards_mono`，`Section_1_4_3.lean:959`）是同一件事的积分版：函数单调 ⟹ 水平集单调，水平集的面积逼近就是函数的积分逼近。

**陈述**：设 0 ≤ f₁ ≤ f₂ ≤ ⋯ 是无符号可测函数列，逐点收敛到 f，则 ∫fₙ dμ 单调上升到 ∫f dμ，即 limₙ ∫fₙ dμ = ∫(limₙ fₙ) dμ（两边都允许 ∞）。

**证明骨架**（与 1.3.3 完全同构，只是 m 换成 μ）：① ∫fₙ ≤ ∫f 逐项成立（fₙ ≤ f + 积分单调性），所以 lim ∫fₙ ≤ ∫f。② 反方向：固定简单 g ≤ f 与 0 < ε < 1，看水平集 Eₙ = {x : fₙ(x) ≥ (1−ε)g(x)}——它可测，因为 fₙ − (1−ε)g 可测（§2 闭包性质）且水平集 {≥ 0} 是 Borel 集的原像。fₙ 逐点上升 ⟹ Eₙ 上升；在 g(x) > 0 的点，(1−ε)g(x) < g(x) ≤ f(x) = lim fₙ(x)，所以从某个 n 起 fₙ(x) ≥ (1−ε)g(x)，即 ∪ₙEₙ ⊇ {g > 0}。写 g = Σᵢ cᵢ1_{Fᵢ}，逐点不等式 fₙ ≥ (1−ε)g·1_{Eₙ} 处处成立（Eₙᶜ 上右边是 0），于是 ∫fₙ ≥ (1−ε)∫(g·1_{Eₙ}) = (1−ε)Σᵢ cᵢ μ(Fᵢ ∩ Eₙ)。**关键一步**：对每个 cᵢ > 0 的 i，Fᵢ ∩ Eₙ 是上升可测集列，由集合版单调收敛（1.4.3 习题 1.4.23(ii)，机验 `Measure.upwards_mono`，`Section_1_4_3.lean:959`），μ(Fᵢ ∩ Eₙ) ↑ μ(Fᵢ ∩ ∪ₙEₙ) = μ(Fᵢ)。于是 ∫fₙ ≥ (1−ε)Σᵢcᵢμ(Fᵢ) = (1−ε)∫g，让 ε → 0、对 g 取 sup，得 lim ∫fₙ ≥ ∫f。合起来即等式。

**数字检验**（计数测度上）：fₙ(k) = 2⁻ᵏ·1_{k≤n}。∫fₙ = Σ_{k=0}^{n} 2⁻ᵏ = 2(1−2⁻⁽ⁿ⁺¹⁾)：n = 0 时 1，n = 1 时 1.5，n = 2 时 1.75，单调上升到 2 = ∫(lim fₙ)。在计数测度上 MCT 就是正项级数的逐项极限定理：非负项的逐点极限与求和可以交换。**这意味着什么**：MCT 的本质是**积分的可数可加性**——Tao 在 1.3.3 推论 1.3.14 之后明说，"这个性质也叫单调收敛定理（定理 1.4.43）"。把 ∫f 想成"把 f 的图切成一叠可数片再求和"，单调上升保证切片不重叠、不打架，求和顺序自由。1.3.3 的笔记里仓库机验的是它在 ℝᵈ 上的两个截断特例（`LowerUnsignedLebesgueIntegral.eq_lim_vert_trunc`，`Section_1_3_3.lean:976`；`eq_lim_horiz_trunc`，`Section_1_3_3.lean:1249`）；一般陈述即本定理，仓库未形式化，Mathlib 的形态是 `lintegral_iSup`（`Mathlib/MeasureTheory/Integral/Lebesgue/Add.lean:34`）。

### 3.2 Fatou 引理（Tao 定理 1.4.46）

MCT 要单调，太贵：现实里遇到的列往往不单调，比如 1.3.3 的尖峰。问题变成：**不假设任何单调性，积分与极限之间还剩下什么关系？** 答案是 Fatou：无条件成立，但只是不等式。

**陈述**：设 fₙ 是无符号可测函数列，则 ∫(liminfₙ fₙ) dμ ≤ liminfₙ ∫fₙ dμ。

**证明骨架**：**关键一步是把"下极限"翻译成"单调上升"**——gₙ = inf_{k≥n} fₖ 逐点上升，且 limₙ gₙ = liminfₙ fₙ；每个 gₙ 可测（可测函数的 inf 可测，§2 的闭包性质）。对 gₙ 用 MCT：∫(liminf fₙ) = lim ∫gₙ。而 gₙ ≤ fₙ 逐点，故 ∫gₙ ≤ ∫fₙ，取 liminf 得 lim ∫gₙ = liminf ∫gₙ ≤ liminf ∫fₙ。证明总共两行，唯一的知识点是"liminf 是单调列的极限"这个恒等式。

**严格不等号的例子**（Lebesgue 测度，1.3.3 的尖峰）：fₙ = n·1_{(0,1/n)}。∫fₙ = n·(1/n) = 1 对一切 n，liminf ∫fₙ = 1；而每个固定 x，从 n > 1/x 起 fₙ(x) = 0，liminf fₙ = 0，∫0 dμ = 0。于是 0 = ∫(liminf fₙ) < liminf ∫fₙ = 1——Fatou 的缺口恰好就是尖峰那块面积：面积在每一层都存在，极限函数把它们全部抹掉。**这意味着什么**：Fatou 是免费的（无任何条件），所以它是理想的"引擎"——下面 DCT 的证明就是找个合适的列把 Fatou 当杠杆用。它也是"宁可多算也不能少算"的数学化身：极限先于积分的面积，永远不会超过各层面积的下极限。

### 3.3 支配收敛定理（DCT，Tao 定理 1.4.48）

换序的第二个充分条件，也是整个分析里用得最多的一个。直觉：fₙ 逐点趋向 f，如果有一件"大衣" g 把每个 fₙ 都罩住，且大衣本身可积（面积有限），那么 fₙ 无论如何乱动，面积都逃不出大衣的料子，于是 ∫fₙ 只能乖乖趋向 ∫f。

**陈述**：设 fₙ 是可测函数列，逐点收敛到 f（几乎处处即可），且存在可积的 g 使 |fₙ| ≤ g 处处成立（a.e. 即可），则 f 绝对可积，且 limₙ ∫fₙ dμ = ∫(limₙ fₙ) dμ。

**证明骨架**（Fatou 用在 |fₙ − f| 上）。分两步。① 先证 L¹ 收敛 ∫|fₙ − f| dμ → 0（比积分收敛更强）。把 Fatou 用在 hₙ = 2g − |fₙ − f| 上：hₙ 非负，因为 |fₙ − f| ≤ |fₙ| + |f| ≤ 2g（支配条件对 fₙ 与极限 f 同时生效）；逐点 |fₙ − f| → 0 给出 liminf hₙ = 2g（"liminf 吞掉收敛量"）。Fatou：∫2g ≤ liminf ∫hₙ = liminf(2∫g − ∫|fₙ−f|) = 2∫g − limsup ∫|fₙ−f|（∫g 有限才能拆）。移项得 limsup ∫|fₙ−f| ≤ 0，非负量取 limsup 非负，故 ∫|fₙ−f| → 0。② 三角不等式收官：|∫fₙ − ∫f| = |∫(fₙ−f)| ≤ ∫|fₙ−f| → 0；f 的可积性来自 |f| ≤ g ⟹ ∫|f| ≤ ∫g < ∞。**关键一步是为什么偏偏构造 hₙ = 2g − |fₙ − f|**：Fatou 只接受非负列，而 |fₙ − f| 本身非负却给出"错的"方向（Fatou 对它是 ∫0 ≤ liminf ∫|fₙ−f|，无信息量）——需要把收敛"翻个面"：2g 减去一个趋向 0 的量，liminf 恰好回到 2g，Fatou 的不等式于是反转成 limsup ≤ 0。这是"Fatou 当引擎"的标准打法：想证极限存在，就造一个极限已知的非负列去套 Fatou。（一个常见的等价写法是把 Fatou 分别用在 g + fₙ 与 g − fₙ 上，上下夹出同一个结论；对无符号列则直接套在 g − fₙ 上。）

**数字检验**（Dirac 测度上 DCT 退化为普通函数极限）：∫fₙ dδ₃ = fₙ(3) → f(3) = ∫f dδ₃。取 fₙ(x) = (1+1/n)^{−x}、g ≡ 1：逐点支配 |fₙ| ≤ g 其实只在 x = 3 成立（x < 0 时 (1+1/n)^{−x} > 1），但这**恰好够了**——DCT 陈述里"a.e. 即可"在 Dirac 测度上的含义就是"只在 3 处检验"，δ₃ 忽略一切不含 3 的点，而 |fₙ(3)| = (1+1/n)⁻³ ≤ 1 = g(3)。于是 ∫fₙ dδ₃ = (1+1/n)⁻³ → 1 = ∫1 dδ₃，与"控制函数 g ≡ 1 可积（∫1 dδ₃ = 1 < ∞）"的检验完全吻合。**这意味着什么**：DCT 把"积分与极限换序"归结为一个可检验的条件——找一件可积大衣。级数版（计数测度上）：若 |aₙₖ| ≤ bₙ 且 Σₙ bₙ < ∞，且每列 aₙₖ → aₙ（k → ∞），则 Σₙ aₙₖ → Σₙ aₙ——这就是 Weierstrass M-检验的逐项极限形态，也是 1.3.3 换序悖论的最终裁决：尖峰列（fₙ = n·1_{(0,1/n)}）没有大衣——任何支配函数 g 必须满足 g(x) ≥ fₙ(x) = n 对每个 n > 1/x 都成立，而 n 可以任意大，所以 g 在 (0,1) 上处处取值 ∞（或者用积分口径：g ≥ supₙ n·1_{(0,1/n)} ≥ 1/x 于 (0,1)，∫g ≥ ∫₀¹ dx/x = ∞），不存在实值可积的支配——所以 DCT 不适用，悖论不构成攻击；换上单调上升的条件 MCT 接管，换上大衣 DCT 接管，两件武器把"什么时候能换序"回答完了。

## 4 反直觉清单 / FAQ

- **DCT 的支配条件为什么不能换成"逐点有界"？** 计数测度上的尖峰 fₙ(k) = n·1_{k=n} 就是判决例。对每个固定的 k，fₙ(k) 只在 n = k 那一项非零（其余全是 0），所以逐点上确界 supₙ fₙ(k) = k < ∞——逐点有界**成立**；可这个逐点界 C(k) = k 不可积：∫C dc = Σₖ k = ∞。与此同时 fₙ 逐点收敛到 0（固定 k，n > k 时 fₙ(k) = 0），而 ∫fₙ dc = n → ∞ ≠ 0 = ∫0。逐点有界救不了换序，因为每一点的界可以"各自为政"地随 n 越放越大，合起来无限重；支配函数必须是一整件**可积**的大衣：g(n) ≥ n 对一切 n 才罩得住尖峰，∫g ≥ Σₙ n = ∞，∫g < ∞ 是条件不是装饰。
- **MCT 的单调为什么不能省？** 尖峰列不单调，MCT 直接无权使用；换成"单调下降"也不行——1.4.3 的 `Measure.downwards_mono_counter`（`Section_1_4_3.lean:977`）给出了集合版的精确反例：ℕ 上计数测度，Eₙ = {n, n+1, …} 单调下降，μ(Eₙ) = ∞ 但 μ(⋂ₙEₙ) = μ(∅) = 0，lim μ(Eₙ) = ∞ ≠ 0——向下需要有限测度（某一片有限）的额外条件，函数版同理（fₙ = 1_{Eₙ}：∫fₙ = ∞，fₙ ↓ 0，∫0 = 0 ≠ lim ∫fₙ）。这就是为什么 MCT 只承诺上升方向。
- **"积分 = 面积"在抽象空间还成立吗？** 算账方式变了：计数测度上面积变成柱状图高度之和（级数），Dirac 上面积塌缩成一个点（函数值）。"面积"不是抽象积分的定义，而是 ℝᵈ 上的一个解释；抽象积分只有一条规矩：简单函数按 μ 称重，其余用 sup 逼近。
- **换序悖论的正式裁决（完整版）**：lim ∫fₙ = ∫lim fₙ 在以下情形合法——(i) fₙ 无符号且单调上升（MCT）；(ii) fₙ 被可积函数支配（DCT）；不合法时仍有无条件的不等式 ∫liminf fₙ ≤ liminf ∫fₙ（Fatou）。三个条件都是 sharp 的：尖峰列同时击穿 (i)(ii)，Fatou 对它给出严格不等号 0 < 1。
- **三大定理的级数形态**：在计数测度上，MCT = 正项级数逐项极限（Σₙ aₙₖ ↑ Σₙ aₙ，若每列 0 ≤ aₙₖ ↑ aₙ）；DCT = M-检验逐项极限；Fatou = 非负数列的 liminf 不等式。数字例子：aₙₖ = 2⁻ⁿ·k/(k+n)，|aₙₖ| ≤ 2⁻ⁿ 且 Σ2⁻ⁿ = 2，所以 limₖ Σₙ aₙₖ = Σₙ limₖ aₙₖ = Σ2⁻ⁿ = 2；k = 10 时实际求和 ≈ 1 + 0.5·10/11 + 0.25·10/12 + 0.125·10/13 + ⋯ ≈ 1.84，随 k 增大趋向 2。
- **Fatou 的积分值允许 ∞ 吗？** 允许，且这正是它"免费"的一部分：两边都可以发散，不等式照成立。DCT 里 ∫g < ∞ 的假设正是为了把 Fatou 的输出从 ∞ 拉回有限。
- **本节的定理在仓库里机验了吗？** 没有。`Section_1_4_4.lean` 只有 import 和标题；三大定理的一般陈述在仓库内未形式化。最接近的机验物是 1.3.3 的 MCT 截断特例（`Section_1_3_3.lean:976, 1249`）与 1.4.3 的集合版上下单调收敛（`Section_1_4_3.lean:959, 964`）。真正完整的机器实现是 Mathlib 的 MeasureTheory 库，见 §6。
