# 03 · 1.2.2 Lebesgue 可测性：给集合发"可测"牌照

> Tao《An Introduction to Measure Theory》§1.2.2 讲稿式笔记 + Lean 形式化对照
> 一句话纲领：**外测度对一切集合都发数，却只肯签 ≤ 号；"可测"是它肯签 = 号的资格证。上节预告的这张证，本节发放：用"能被开集从外面逼近到任意小误差"验收集合（`LebesgueMeasurable`，`Section_1_2_0.lean:2291`），先普查好集合的户口（引理 1.2.13：开、闭、零测、空、补、可数并、可数交全可测），再宣布 m := m\* 在可测集上成为真测度——可数可加（引理 1.2.15）、单调收敛、Cantor 集"紧 + 不可数 + 零测"三合一，全部在这一节一次付清。**

## 1 这一幕要解决什么

先把镜头拉远，看一个贯穿数学三千年的病。

√2 不在有理数里，但 1.4, 1.41, 1.414, … 这一串有理数无限逼近它。历史上这不是"√2 的问题"，而是**有理数不封闭**：极限运算跑出了有理数的世界，数学的痊愈方式不是怪罪极限，而是**把数的世界扩大**——从 ℚ 到 ℝ，让极限住进来。实数的定义本身就是"用有理数序列逼近"。这是根号二 PTSD 的第一次发作。

上一节我们已经撞上第二次发作。每个单点 {qₙ} 都是 Jordan 可测的，测度 0；但可数并 ℚ∩[0,1] 不是 Jordan 可测的——**Jordan 可测集对"可数并"这个运算不封闭**。就像有理数对极限不封闭一样，Jordan 的世界留不住自己的极限。而数学的痊愈方式千年不变：**把集合的世界扩大**（Jordan → Lebesgue），让"可数并"住进来。测度论就是根号二故事的第三次重演，而本书 1.2.2 到 1.4 就是这场"封闭性补丁手术"的手术台。

那么手术怎么做？先看清病人。上一节我们造了一把对一切集合都发数的尺子 m\*，但它只肯签可数次可加：

```
m*(⋃ₙ Eₙ) ≤ Σₙ m*(Eₙ)
```

等号是奢侈品。什么时候能写等号？上节给出了第一个答案：两个集合**隔得够远**（距离 > 0，引理 1.2.5）。但"隔得够远"救不了最要命的局面——同一个集合对自己内部的拆分。把单位立方体拆成单点：每个单点零测，可数并的机器对不可数族直接熄火，m\*([0,1]ᵈ) = 1 无论如何不等于 Σ 0。这把尺子对"整个宇宙"（所有子集）只能做到次可加，这是一个铁的事实，不是技巧不够。

但注意：我们并不真的需要给**每一个**子集发等号。真正在分析里出场的集合——开集、闭集、零测集、它们的可数布尔组合——只占全体子集的很小一角。所以出路是反过来的：**给集合发牌照，把"等号持有者"从全体子集中挑出来**。这一节要做的正是这件事：设计一张验收标准（"可测"），证明它放行的集合足够多（引理 1.2.13 的户口普查），然后在持牌集合上把 m\* 改名为 m，宣布它满足可数可加——比外测度强得多的一整套律法。更准确地说：我们要造的 σ-代数（对可数并、可数交、补都封闭的集合族）就是"封闭性补丁"本身——补丁打上之后，可数并这个运算再也跑不出这个世界了。

还有一个影子敌人要提前亮相。为什么需要"验收"而不是"一切集合都发牌"？因为存在不可测集——§1.2.3 会用选择公理构造（Vitali 式，把 ℝ 按 ℚ 的陪集打散取代表元）。Solovay 定理说：若放弃选择公理，存在一切集合都可测的模型。所以"不可测"不是自然界的现象，是选择公理的产物——这决定了可测性只能是一张**过滤网**，而不是某种"构造性定义"能绕开的障碍。读者现在只需要知道：网眼的大小由 ε 决定，网的形状（用开集从外面包）由上一节的外正则性决定。

## 2 把"可测"逼出来：差集小，才是硬道理

先试最自然的方案：照抄 Jordan 的"内测度 = 外测度"。上节已经见过它的尸骸——开集 U(ε)（以每个有理数为中心、半径 ε/2ⁿ 的区间并，取 ε = 1/3）是开集，m\*U ≤ 2/3，而 Jordan 外测度 ≥ 1，内外读数对不上，Jordan 可测性当场破产（机验反例 `Section_1_2_1.lean:3914`）。如果我们把 Lebesgue 可测性定义成"Jordan 内测度 = Lebesgue 外测度"，那么**开集都可能不可测**——这不是我们想要的验收标准，开集是分析的基本建材，必须先放行。此路不通。

再想一层。上一节已经证明外正则性：对任意 E 和 ε > 0，存在开 U ⊇ E 使 m\*U ≤ m\*E + ε（`exists_open_superset_measure_le`，`Section_1_2_1.lean:6009`）。这听起来已经够好了——"测度差"可以压到 ε。但请算一笔细账：m\*U ≤ m\*E + ε 只说了 U 和 E **在秤上读数接近**，没说 U \ E（差集）本身小。外测度没有减法可加性：m\*(U\E) 不是 m\*U − m\*E。差集被两条不等式夹着：单调性给上界 m\*(U\E) ≤ m\*U；次可加给下界——把 U = (U\E) ∪ (U∩E) 代进 m\*U ≤ m\*(U\E) + m\*(U∩E)，再用单调性 m\*(U∩E) ≤ m\*E（m\*U、m\*E 有限时移项，本节使用场合均满足）：

```
m*U − m*(E) ≤ m*(U\E) ≤ m*(U)
```

上下界之间是一道真实的裂缝：m\*U 逼近 m\*E 只压小**下界**，差集本身可以贴着上界 m\*U 走，依然是巨大的。要的是更强的条件：**差集的外测度** m\*(U\E) 小。这才是"E 能被开集贴身包住"的正确表述——多出来的部分（U 比 E 多的那一圈）在秤上必须无足轻重。注意这正是"差集可加性"成立的场合：若 m\*(U) = m\*(U\E) + m\*(E)（对固定的 U 成立），则 m\*(U\E) ≤ ε 和 m\*U ≤ m\*E + ε 就是一回事。所以"差集小"这个条件不是挑了个等价表述，它直接指向可加性的根源——习题 1.2.17 的 Carathéodory 准则（下详）说"差集可加 ⟺ 可测"，形成漂亮的闭环。

于是验收标准被逼出来了：**E 可测，当且仅当对任意 ε > 0，存在开集 U ⊇ E 使 m\*(U \ E) ≤ ε**。Lean 的定义与之一字不差（`Section_1_2_0.lean:2291`）：

```lean
def LebesgueMeasurable {d:ℕ} (E: Set (EuclideanSpace' d)) : Prop :=
  ∀ ε > 0, ∃ U: Set (EuclideanSpace' d), IsOpen U ∧ E ⊆ U ∧ Lebesgue_outer_measure (U \ E) ≤ ε
```

定义落地，立刻验两笔账。第一笔：[0,1] 自己。取 ε = 0.01，令 U = (−0.005, 1.005)（左右各胀开 0.005），则 U \ [0,1] = (−0.005, 0) ∪ (1, 1.005)，是两个开区间，m\*(U\[0,1]) = 0.005 + 0.005 = 0.01 = ε。ε 任意小都可以照此办理，[0,1] 可测。第二笔：[0,1]\ℚ（[0,1] 里的无理数）。先算它的外测度：E ⊆ [0,1] 给 m\*E ≤ 1；反过来 1 = m\*[0,1] ≤ m\*E + m\*(ℚ∩[0,1]) = m\*E + 0（可数集零测，上节 T6），所以 m\*E = 1。它可测吗？取 U = (0,1)：注意 0 和 1 都是有理数，不在 E 里，所以 E ⊆ (0,1)；而 U \ E = (0,1)∩ℚ 是可数集，零测，≤ ε 对一切 ε 成立。所以 [0,1]\ℚ 可测，且差集是零测集——"从外面包"包住了它，多出来的一圈是干干净净的零测有理数。这个例子同时预告了习题 1.2.19：可测集 = Gδ 集挖掉零测集（Gδ 指可数个开集的交，术语在习题 1.2.19 前有正式定义；这里 (0,1) 是开集，更甚，是 Gδ）。

一个细节提醒：d = 0 时这套定义照常工作（单点空间里空集和全空间都是开集），但证明零测集可测时要特判——Lean 在 `IsNull.measurable` 的证明里花了整整一个 0 维分支（`Section_1_2_2.lean:364`），因为 0 维空间没有零体积盒可用。读者不必细究，知道"0 维有坑"即可。

## 3 户口普查：引理 1.2.13 七连

标准立起来之后，第一个问题是：有多少集合拿得到牌照？Tao 的引理 1.2.13 一口气报了七种：开、闭、零测、空、补、可数并、可数交。逐个过。

**(i) 开集可测**：开集 E 自己就是自己的证人——取定义里的 U 为 E，差集 E \ E = ∅，m\*(∅) = 0 ≤ ε。证明是三行的事（`IsOpen.measurable`，`Section_1_2_2.lean:11`），但这句话的分量重：上一节死于 Jordan 可测性的开集 U(ε)，在这里直接复活。

**(ii) 闭集可测**（`IsClosed.measurable`，`Section_1_2_2.lean:285`）。先化到有界：E = ⋃ₙ (E ∩ B(0,n))（闭球族覆盖全空间），若每个有界闭块可测，可数并（等 (vi) 到手）就收工。对有界闭集 E（Heine–Borel 下即紧集）：用外正则性取开 U ⊇ E 使 m\*U ≤ m\*E + ε/2（ε/2 预算）；然后差集 U\E 是开集，按引理 1.2.11 拆成可数并**几乎不交的二进立方体** Qₙ，引理 1.2.9（几乎不交盒族的可数并：外测度 = 体积和）给出 m\*(U\E) = Σₙ|Qₙ|。对任意有限指标集 t，F_t = ⋃_{i∈t} Qᵢ 是紧集，与紧集 E 不相交，于是（习题 1.2.4，反证 + 紧致抓子列）set_dist E F_t > 0，引理 1.2.5 的分离可加性生效：

```
m*(E) + m*(F_t) = m*(E ∪ F_t) ≤ m*U ≤ m*E + ε/2
```

m\*E 有限（紧集，`finite_of_compact`，`Section_1_2_1.lean:6065`），两边消去 m\*E：m\*(F_t) ≤ ε/2。有限部分和全部受控，级数 Σₙ|Qₙ| ≤ ε/2 ≤ ε，于是 m\*(U\E) ≤ ε。这是全书第一次把"紧致 + 分离"组合拳用在可测性上，之后会反复出现。Lean 的证明链：`dist_of_disj_compact_pos`（`Section_1_2_1.lean:2515`）→ `union_of_separated`（:2268）→ `sum_of_almost_disjoint_finset`（`Section_1_2_2.lean:33`）。

**(iii) 零测集可测**（`IsNull.measurable`，`Section_1_2_2.lean:359`）。这里用上一节预留的 ε 性格：m\*E = 0 时，对 ε' > 0 存在盒覆盖总长 ≤ ε'/2（`exists_cover_close`，`Section_1_2_1.lean:2146`）。但盒子不是开集——差集逼近要开证人。修补：把每个盒 Bₙ 胀开一小圈，第 n 个盒胀 δₙ = ε'/2^(n+2)，胀开后的盒子取内部（开盒），并成 U。算账：胀开总共多花 Σₙ δₙ = ε'·(1/4 + 1/8 + …) = ε'/2，所以 m\*U ≤ ε'/2 + ε'/2 = ε'。取 ε' = 0.01：盒覆盖 ≤ 0.005，胀开 ≤ 0.005，合计 ≤ 0.01，报账平。于是 ℚ∩[0,1] 这类"没有一片实心区域"的集合全部持牌——它们的外测度是 0，任何 ε 都满足，因为差集 U\E ⊆ U 且 m\*U ≤ ε'。

**(iv) 空集**：开集特例，或直接用定义（`LebesgueMeasurable.empty`，`Section_1_2_2.lean:522`，仓库给了两种证法 :522 和 :526）。

**(v) 补集可测**（`LebesgueMeasurable.complement`，`Section_1_2_2.lean:609`）。这是户口普查里最绕的一步。思路：对每个 n 取开 Uₙ ⊇ E 使 m\*(Uₙ\E) ≤ 1/(n+1)；令 Fₙ = Uₙᶜ（闭集），则 Fₙ ⊆ Eᶜ 且 Eᶜ \ Fₙ = Uₙ \ E。取 F = ⋃ₙ Fₙ（Fσ 集：可数个闭集的并，与"Gδ = 可数个开集的交"对偶，习题 1.2.19 前书上有正式定义），则 Eᶜ \ F ⊆ Uₙ \ E 对一切 n，所以 m\*(Eᶜ\F) = 0——补集 = 可数闭并 ∪ 零测集，由 (ii)(iii)(vi) 拼成。注意这里 1/(n+1) → 0 的预算设计：不需要"任意 ε"，只要误差趋于 0，因为最终要把误差**压成零测集**而不是压到 ε。这是和 (vi) 的 ε/2ⁿ 策略不同的第二种预算哲学。

**(vi) 可数并**（`LebesgueMeasurable.countable_union`，`Section_1_2_2.lean:540`）。ε/2ⁿ 技巧的标准出场：对每个 Eₙ 用定义拿开 Uₙ ⊇ Eₙ 使 m\*(Uₙ\Eₙ) ≤ ε/2^(n+1)；⋃Uₙ 是开集且 ⋃Uₙ \ ⋃Eₙ ⊆ ⋃(Uₙ\Eₙ)；次可加加上几何级数：

```
m*((⋃Uₙ) \ (⋃Eₙ)) ≤ Σₙ m*(Uₙ\Eₙ) ≤ Σₙ ε/2^(n+1) = ε
```

预算为什么拨 ε/2^(n+1)？因为 Σₙ₌₀^∞ ε/2^(n+1) = ε(1/2 + 1/4 + …) = ε，总账正好等于 ε，分毫不差。有限并是免费附赠（尾部补 ∅ 当可数并用，`finite_union` :733、`union` :756）。

**(vii) 可数交**（`LebesgueMeasurable.countable_inter`，`Section_1_2_2.lean:773`）：de Morgan，⋂Eₙ = (⋃Eₙᶜ)ᶜ，由 (v)(vi) 各用两次，三行收工。

这七条合起来说的是一句话：**从开集出发，做任意可数次数的并、交、补，走不出可测集一族**——这就是 σ-代数的雏形（书上的 Remark 1.2.14 点破，§1.4 才正式抽象）。对照 Jordan 的体检报告（习题 1.1.6）：Jordan 可测只对**有限**布尔运算关门，可数并一步就散架（1.2.1 节的反例）。"可数"这两个字，就是 Lebesgue 体系对 Jordan 体系的全部分界线。Lean 仓库还把七条之外的日常用品一并备好：`inter` :811、`finset_inter` :827、`finset_union` :852、`closedBall` :900（闭球可测，定理 (ii) 的白送）、`of_ae_eq` :879——**几乎处处相等的集合同生共死**：A 与可测集 B 只差一个零测集 N（A∩Nᶜ = B∩Nᶜ），则 A 也可测，拆成 A = (B∩Nᶜ) ∪ (A∩N)，前者是 B 挖掉零测集，后者是零测子集。"几乎处处"这个懒人修辞从此有了合法的立足点。

## 4 六种说法一回事：可测性的 TFAE

户口普查证明可测集**很多**，但"多"不等于"好认"。习题 1.2.7（仓库：`LebesgueMeasurable.TFAE`，`Section_1_2_2.lean:905`）给出六条等价判据，把"可测"的各个侧面一次打通：

| # | 判据 | 直觉 |
|---|------|------|
| (i) | E 可测（定义） | 从外面用开集包，误差 ≤ ε |
| (ii) | 外逼近：∃开 U ⊇ E，m\*(U\E) ≤ ε | 定义本身（恒等） |
| (iii) | 几乎开：∃开 U，m\*(U Δ E) ≤ ε | 对称差小：E 和开集只差 ε 厚的一层 |
| (iv) | 内逼近：∃闭 F ⊆ E，m\*(E\F) ≤ ε | 从里面用闭集填 |
| (v) | 几乎闭：∃闭 F，m\*(F Δ E) ≤ ε | 对称差小版 |
| (vi) | 几乎可测：∃可测 E'，m\*(E' Δ E) ≤ ε | 已经可测的东西差 ε 以内 |

证明骨架是循环链 0→1→2→3→4→5→0。0→1 是定义恒等。1→2：E ⊆ U 时对称差 UΔE = U\E，免费。2→3 是最有技术含量的一步：对称差只能保证 m\*(U\E) ≤ ε 和 m\*(E\U) ≤ ε 各一个 ε，但 (iii) 要的是**同一个**开集的对称差小。修补：把 ε 预算分成三份 ε/3——取开 U 使 m\*(U\E) ≤ ε/3；对 E\U 用外正则性拿开 W ⊇ E\U 使 m\*W ≤ m\*(E\U) + ε/3 ≤ 2ε/3；令 V = U ∪ W，则 V\E ⊆ (U\E) ∪ W，m\*(V\E) ≤ ε/3 + 2ε/3 = ε'，且 E ⊆ V。算账干净：ε/3 + 2ε/3 = ε，一分不多。3→4 用补集（开集的补是闭集，对称差技术性翻折）；4→5、5→0 各是定义级操作（5→0 需要 ε/2ⁿ 可数并，等 (vi) 再用一次）。

这条 TFAE 意味着什么？**可测性不依赖"外面"和"里面"的偏好**：能用开集从外逼近 ⟺ 能用闭集从里逼近。上一节的外正则性只给了"外"的方向，这里"内"的方向也打通了——为习题 1.2.15 的内正则性（m(E) = sup 紧子集测度）铺路。顺带的推论：**Jordan 可测 ⟹ Lebesgue 可测**（习题 1.2.8，`Jordan_measurable.lebesgue`，`Section_1_2_2.lean:1160`）。骨架一句话：Jordan 可测 ⟺ 边界零测（1.1 节的判定），于是 E = interior E ∪ (E \ interior E)，前者开集可测，后者是边界子集、零测可测。Lebesgue 体系完整收编了 Jordan 体系，且在可测集上两种读数一致（`Jordan_measurable.Lebesgue_measure`，`Section_1_2_2.lean:1993`：m\*(E) = Jordan 测度）——尺子换了，数值没换。

## 5 旗舰例子：Cantor 集，以及一节教科书级的验尸

习题 1.2.9 的主角是三分 Cantor 集，它是本节所有概念的试金石。构造（`CantorInterval`、`CantorSet`，`Section_1_2_2.lean:1209`/`:1211`）：从 [0,1] 出发，每一步挖掉每段中间的三分之一开区间。第 n 步由 2ⁿ 段闭区间组成，第 n 步的每一段是

```
[ Σᵢ aᵢ/3^(i+1) , Σᵢ aᵢ/3^(i+1) + 1/3ⁿ ]，aᵢ ∈ {0,2}
```

（三元小数第 i 位是 0 或 2 的所有长度为 n 的前缀，每段长 1/3ⁿ）。比如 n = 1：两个区间 [0,1/3] 和 [2/3,1]，总长 2·(1/3) = 2/3；n = 2：四个区间 [0,1/9]、[2/9,1/3]、[2/3,7/9]、[8/9,1]，总长 4·(1/9) = 4/9。Cantor 集 C = ⋂ₙ CantorInterval n。

三笔账，全部可算。**紧**：每层都是有限个闭区间的并（闭），可数交保闭；有界（含于 [0,1]）；Heine–Borel 收工（`CantorSet.compact` :1214）。**不可数**：映射 b ↦ Σₙ (2·bₙ)/3^(n+1)（bₙ ∈ {0,1}，即三元小数只许写 0/2）是从 ℕ→{0,1} 到 C 的**单射**——三元展开唯一（值域里没有 1 这个数字，不存在两种展开打架的歧义），而 2^ℕ 不可数（`cantorEmbedding` :1259、`cantorEmbedding_injective` :1419、`CantorSet.uncountable` :1513）。**零测**：C ⊆ CantorInterval n 对一切 n，而

```
m*(CantorInterval n) = 2ⁿ · 1/3ⁿ = (2/3)ⁿ
```

当 n = 10 时 (2/3)¹⁰ = 1024/59049 ≈ 0.0173——层层收紧，趋于 0（`CantorSet.null` :1526）。换一种算法对账：挖掉的总长 = 1/3 + 2/9 + 4/27 + … = (1/3)·(1 + 2/3 + (2/3)² + …) = (1/3)/(1−2/3) = 1，[0,1] 全长 1 被挖得干干净净，剩下的 C 自然是 0。

这三笔账放在一起就是一个著名的悖论式组合：**紧、不可数、零测**。上一节只告诉我们"可数 ⟹ 零测"，Cantor 集是反方向的教材：零测不欠可数任何东西——它比 ℚ 多得多（不可数），却和 ℚ 一样在秤上归零。"几乎所有点都在 C 之外"，而 C 的势和 [0,1] 一样大；这一句话同时震动了测度直觉（零测集可以很胖）和基数直觉（不可数集可以很瘦）。它还是 §1.2.3 不可测集构造的参照物：Cantor 集是"紧 + 零测"的好集合，而 Vitali 集将证明"有界 + 正外测度"仍可能连牌照都拿不到。

同节的习题 1.2.10 是另一个病理展示（机验反例 `Section_1_2_2.lean:1771`）：[0,1) **不能**写成可数个两两不交闭区间的并。骨架：每个闭区间只能是 [aₙ,bₙ]，若并成 [0,1)，用紧性/连通性推矛盾——有限个显然不够（端点泄漏），可数个则总有一个区间碰到另一个的端点，破坏了"两两不交"。这个反例的意义：Cantor 集的"可数交"结构和 [0,1) 的"可数并"结构是两种不同的存在方式，开与闭的边界行为不对称，可测性理论必须同时容纳两者。

## 6 测度公理：把 ≤ 升级成 = 的那一天

现在给持牌集合改名。**Lebesgue 测度** m(E) := m\*(E)，只对可测集发言（`Lebesgue_measure`，`Section_1_2_0.lean:2295`）。引理 1.2.15 宣布两条公理，第一条免费：

**(i) m(∅) = 0**（`Lebesgue_measure.empty`，`Section_1_2_2.lean:2086`）。

**(ii) 可数可加**：两两不交的可测集族 {Eₙ}，m(⋃ₙEₙ) = Σₙ m(Eₙ)（`Lebesgue_measure.countable_union`，`Section_1_2_2.lean:2398`）。≤ 方向免费（次可加）。≥ 方向按"紧 → 有界 → 一般"三段爬（`countable_union_compact` :2093、`countable_union_bounded` :2202）：

- **紧段**：两两不交的紧集两两正分离（习题 1.2.4），引理 1.2.5 逐对相加：m(⋃_{n<N} Eₙ) = Σ_{n<N} m(Eₙ)，单调性给出 ≥ Σ_{n<N} m(Eₙ)，N → ∞。
- **有界段**：ε/2ⁿ 技巧——每个有界可测 Eₙ 是紧集 Kₙ 并一个外测度 ≤ ε/2ⁿ 的零头（TFAE (iv)），Σ m(Eₙ) ≤ Σ m(Kₙ) + ε ≤ m(⋃Eₙ) + ε，ε → 0。
- **一般段**：环带分解 ℝᵈ = ⋃ₘ Aₘ，Aₘ = {x : m ≤ ‖x‖ < m+1}（两两不交、有界可测），每个 Eₙ = ⋃ₘ (Eₙ∩Aₘ) 是"有界可测集的可数不交并"，把前两段的结果套到双重和上。

这是全节的最高潮：**m 在可测集上满足了外测度拒绝签的一切 = 号**。立刻核算两笔：m([0,1]) = 1（[0,1] 是初等集，读数没变）；m([0,1]\ℚ) = 1（§2 已算外测度 = 1，现在升级为测度）。可数可加顺带把有限可加（`Lebesgue_measure.finite_union` :2659、`union` :2748）和习题 1.2.12 的推论（单调性 + 次可加自动成立，`exercise_1_2_12_monotonicity` :3358，及两个 example :3442、:3447）全部签出——空集公理 + 可数可加这两条，就足以让 m 成为一个行为良好的测度，这是 §1.4 抽象测度公理化的预告。

## 7 单调收敛：测度与极限的第一次握手

可数可加是"静态"的律，单调收敛定理（习题 1.2.11）是"动态"的律：测度与极限可以交换，在恰当的方向上。**上行版本**（`Lebesgue_measure.upward_monotone_convergence`，`Section_1_2_2.lean:2778`）：E₁ ⊆ E₂ ⊆ … 可测递增，则 m(⋃ₙEₙ) = limₙ m(Eₙ)。骨架：把递增并拆成**空隙**（lacunae）F₀ = E₀，Fₙ = Eₙ\E_{n−1}——两两不交、可测（补集 + 交封闭），⋃Fₙ = ⋃Eₙ，且 m(E_N) = Σ_{k≤N} m(Fₖ)（有限可加），于是 m(⋃Eₙ) = Σₙ m(Fₙ) = lim_N Σ_{k≤N} m(Fₖ) = lim m(E_N)。数字验证：Eₙ = [0, 1−1/(n+1)] 递增趋于 [0,1)，m(Eₙ) = 1 − 1/(n+1) → 1 = m([0,1))。✓ 这个定理不需要任何有限性假设：等号两边同时允许 ∞。

**下行版本**（`Lebesgue_measure.downward_monotone_convergence`，:2942）：E₁ ⊇ E₂ ⊇ … 递减，则 m(⋂ₙEₙ) = limₙ m(Eₙ)——**但要求至少一个 m(Eₙ) 有限**。为什么？骨架：m(E₁) = m(Eₙ) + m(E₁\Eₙ)（可加性），E₁\Eₙ 递增，上行版本 + 消去有限数 m(E₁)。消去一步要求 m(E₁) ≠ ⊤——这正是**反例**的裂缝：

```
Eₙ = { x ∈ ℝ : ‖x‖ ≥ n }      （ℝ 的"尾巴"）
```

每个 Eₙ 都闭（{‖x‖ ≥ n} 是连续函数的闭原像），可测；递减（n 越大尾巴越短）；但 m(Eₙ) = ⊤：Eₙ 含有区间 [n, n+M] 对任意 M，m(Eₙ) ≥ M 对一切 M，只能 = ∞。而 ⋂ₙ Eₙ = ∅（任何 x 的模长小于 ⌈‖x‖⌉+1，够不着那条尾巴），m(∅) = 0。于是 lim m(Eₙ) = ⊤ ≠ 0 = m(⋂Eₙ)。机验反例 `Section_1_2_2.lean:3207`。这就是 ∞ − ∞ 陷阱的集合版本：m(E₁) = m(Eₙ) + m(E₁\Eₙ) 在 m(E₁) = ⊤ 时不能用来消去，极限和测度拒绝交换。对比有限例子：Eₙ = (0, 1/n) 递减到 ∅，m(Eₙ) = 1/n → 0 = m(∅)，下行定理适用（m(E₁) = 1 < ∞）。✓

习题 1.2.13 把同样的握手推广到**集合的逐点收敛**（指标函数点点收敛，`Section_1_2_2.lean:3560`）：若 1_{Eₙ}(x) → 1_{E₀}(x) 对每个 x 成立，则 E₀ 可测。骨架：x ∈ E₀ ⟺ 指标函数最终恒等于 1 ⟺ ∃N ∀n, x ∈ E_{N+n}，于是 E₀ = ⋃_N ⋂_n E_{N+n}（liminf 恒等式），可数交并各用一次。若再要求 Eₙ 都被某个有限测度集 F 包住，则 m(Eₙ) → m(E₀)（支配收敛的集合版，:3600；骨架：上下极限 A_k = ⋂_j E_{k+j}、B_k = ⋃_j E_{k+j} 夹住 E₀，上行下行定理各用一次）。有限性假设不是摆设：反例（:3760）就是上面那族尾巴 Eₙ = {‖x‖ ≥ n}——指标函数点点收敛到 0（每个 x 都够不着足够远的尾巴），但 m(Eₙ) = ⊤ 不收斂到 m(∅) = 0。F = ℝ 可测但 m(F) = ∞，"有限测度的伞"正是定理需要的伞。

## 8 正则性谱系与其余判据速览

引理 1.2.15 之后，本节剩下的内容是一串"可测性判据"，每一条都是习题，仓库全部机验。它们共享同一个主题：**可测集可以被更简单的对象（开、闭、紧、初等、二进方块）逼近到任意 ε**（书上的 Remark 1.2.17 称之为 tradeoff：误差形式越强，逼近对象的规格越具体）。

- **习题 1.2.14**（`Section_1_2_2.lean:3924`）：任意 E ⊆ 可测 F，m(F) = m\*E。骨架：外正则性给开 Uₙ ⊇ E 使 m\*Uₙ ≤ m\*E + 1/(n+1)，F = ⋂ₙ Uₙ 是 Gδ（可测，可数交），F ⊇ E 且 m\*F ≤ m\*E + 1/(n+1) 对一切 n ⟹ m\*F ≤ m\*E；另一方向单调性免费。数字：若 m\*E = 0.3，每层预算 1/(n+1) 把 F 的读数压到 0.3 封顶。
- **习题 1.2.15 内正则性**（`Lebesgue_measure.eq`，:4038）：E 可测 ⟹ m(E) = sSup { m(K) : K ⊆ E 紧 }。骨架：≥ 方向是紧子集单调免费；≤ 方向用 TFAE (iv) 拿闭 F ⊆ E 使 m\*(E\F) ≤ ε，再 F = ⋃ₙ (F∩B(0,n)) 拆成紧集递增并，上行单调收敛。
- **习题 1.2.16 有限测度判据**（`LebesgueMeasurable.finite_TFAE`，:6162）：九条等价——其中最后一条最漂亮：**像素化**——E 有限测度可测 ⟺ 对任意 ε，存在 n 和二进尺度 2⁻ⁿ 的有限个闭二进立方体之并 F，使 m\*(EΔF) ≤ ε（`finite_TFAE_8_implies_0` 等九个方向，:4996–:6069）。这就是"可测集在足够细的网格下看起来像像素画"的严格版本，为后面的 Lebesgue 微分定理埋伏笔。
- **习题 1.2.17 Carathéodory 判据**（`LebesgueMeasurable.caratheodory`，:6279）：可测 ⟺ 对一切初等集 A，m\*(A) = m\*(A∩E) + m\*(A\E) ⟺ 对一切盒 B 同样成立。注意书里只要一个方向（判据的必要性），**仓库把两个方向都证了**（双向 TFAE）——这正是 §2 说的闭环：差集可加 ⟺ 可测。0→1 方向用可数可加对 A = (A∩E) ∪ (A\E) 拆分；1→0 方向是硬活：盒版本 → 全集合版本（`caratheodory_inter_box` :6212）→ 用可数可加在可测集上重建。这是 Halmos/Folland 抽象路线（§1.7 Tao 的预告）的核心机制：**外测度 + Carathéodory 条件 ⟹ 真测度**，在 ℝᵈ 上这一节已经手工完成。
- **习题 1.2.18 内测度**（`inner_measure`，:4123；`inner_measure.eq` :4338；`inner_measure.le` :4566；`inner_measure.eq_iff` :6476）：对**有界** E，取任意初等 A ⊇ E，定义 m\*(E) = m(A) − m\*(A\E)（良定义：两个不同的 A 给出同一值，:4338）。数字核算：E = ℚ∩[0,1]，A = [0,1]：m\*₋(E) = 1 − m\*([0,1]\ℚ) = 1 − 1 = 0 = m\*E ✓（相等，因为 E 可测）；E = [0,1]\ℚ，A = [0,1]：1 − m\*(ℚ∩[0,1]) = 1 − 0 = 1 = m\*E ✓。定理：m\*₋(E) ≤ m\*(E) 恒成立，**相等 ⟺ E 可测**（:6476）。非可测集的"内 < 外"裂口要等 §1.2.3 的 Vitali 集来展示。
- **习题 1.2.19 Gδ/Fσ 判据**（`LebesgueMeasurable.TFAE'`，:6848）：可测 ⟺ Gδ 集挖掉零测集 ⟺ Fσ 集并上零测集。骨架：0→1 用 Uₙ 取 1/(n+1) 误差，F = ⋂Uₙ，F\E 零测；1→0 反过来用可数交；Gδ ↔ Fσ 用补集。§2 的 [0,1]\ℚ 就是现成例子：开集 (0,1) 挖掉零测有理数。
- **习题 1.2.20/21/22 运算不变性**：平移（`LebesgueMeasurable.translate` :7023、`Lebesgue_measure.translate` :7057：m(E+x) = m(E)，骨架：开集平移仍开、差集平移保测——外测度的平移不变性 `Lebesgue_outer_measure.translate` :6992）；线性变换（`LebesgueMeasurable.linear` :7230、`Lebesgue_measure.linear` :7281：m(T(E)) = |det T|·m(E)，骨架：先用 Jordan 外测度按 |det T|·|B| 控制盒子像，再外正则性；数字：T(x) = 2x，|det| = 2，m(T([0,1])) = m([0,2]) = 2 = 2·1 ✓）；乘积（`Lebesgue_outer_measure.prod` :7537：m\*(E₁×E₂) ≤ m\*E₁·m\*E₂；`LebesgueMeasurable.prod` :8057：可测集乘积可测且测度相乘，为 §1.5 的乘积测度定理开路）。

至此本节收官：**"可测"从一张过滤网变成了一个代数结构（σ-代数）、一个测度（可数可加）、一整套正则性（内外逼近）**。下一节（§1.2.3）将用选择公理证明网眼确实存在漏网之鱼——Vitali 集——从而宣告：这张网是必要的，不是多虑。

## 9 FAQ 与反直觉清单

1. **为什么用"开集外逼近"当验收标准，而不是"内测度 = 外测度"？** Jordan 式内 = 外对无界集合要先定义内测度，且把开集 U(ε)（m\* ≤ 2/3，Jordan 外测度 ≥ 1）挡在门外——开集是分析的基本建材，必须放行。"开集外逼近"由上一节的外正则性现成支撑，且内外逼近的等价性（TFAE）是**定理**，不必塞进定义。
2. **"测度逼近"和"差集逼近"有什么区别？** 外正则性只保证存在开 U ⊇ E 使 m\*U ≤ m\*E + ε（秤上读数接近）；可测性要求 m\*(U\E) ≤ ε（差集本身小）。次可加只给 m\*(U\E) ≥ m\*U − m\*E，反方向不免费——差集可加（m\*U = m\*(U\E) + m\*(E)）恰恰就是可测性本身（习题 1.2.17 的闭环）。§1.2.3 的 Vitali 集将是"测度逼近成立、差集逼近破产"的活标本。
3. **可数并为什么必须可数？不可数并能不能也发牌照？** 不能，而且不是技术问题：若 σ-代数对不可数并关门，[0,1] = ⋃{x} 单点族就要放进可测集，连同平移不变性一起，会与可数可加性矛盾（1.2.1 节反例的重演）。Vitali 构造（§1.2.3）正是把"不可数选择"变成具体矛盾。Solovay 定理提醒我们：这个矛盾需要选择公理才能引爆。
4. **下行单调收敛为什么需要"至少一个 m(Eₙ) 有限"？** 证明要消去 m(E₁)：m(E₁) = m(Eₙ) + m(E₁\Eₙ)。m(E₁) = ⊤ 时消不去，∞ − ∞ 没有定义。反例：Eₙ = {‖x‖ ≥ n}，全族测度 ⊤，交集 ∅，lim ⊤ = ⊤ ≠ 0。上行版本没有这个病：∞ 的极限算账 ∞ = ∞ 是合法的。
5. **可数集零测，反过来零测集可数吗？** 不。Cantor 集是零测但不可数（势 2^ℵ₀）。"可数 ⟹ 零测"是单向的；零测集可以比任何可数集都"胖"。零测的概念是纯尺子的，与基数无关。
6. **零测集能随便删吗？** 能，在"几乎处处"的意义上：`LebesgueMeasurable.of_ae_eq`（`Section_1_2_2.lean:879`）保证与可测集只差零测集的集合仍可测，且测度不变。这是 §1.3 积分理论里"几乎处处"修辞的许可证。
7. **为什么仓库把习题 1.2.17 证成了双向？** 书只要"可测 ⟹ Carathéodory 分裂"一个方向（必要性的练习），仓库把充分性也补上了（`caratheodory` :6279 是完整 TFAE）——因为只有双向才构成 §2 说的闭环，也才真正演示了 Halmos/Folland 抽象路线的核心机制：外测度 + 分裂条件 ⟹ 真测度。

**为什么这差异重要**：构造次序决定读者先看到什么、先信什么。Tao 的次序（近似 → 代数）让读者先获得"可测 = 边界可忽略、误差可压 ε"的操作直觉，代价是可数可加性必须手工打出来（引理 1.2.15 的三阶段证明是全书最长的计算之一）；Halmos/Folland/Rudin 的次序（代数 → 近似）让读者先获得"σ-代数 + Carathéodory 扩张"这台万能机器（同一台机器能造 Lebesgue 测度、Lebesgue–Stieltjes 测度、Haar 测度），代价是"为什么开集可测"要绕道抽象定义。仓库跟随 Tao 的次序，但把习题 1.2.17 升级成双向 TFAE——形式化上已经替读者预习了 §1.7 的抽象外测度理论。
