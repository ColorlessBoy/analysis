# 14 · 1.4.5 收敛定理：换序从"悖论"到"牌照"，第一章的加冕礼

> 一句话纲领：**第一章从头到尾只追问一个问题——极限与积分什么时候可以换序**？1.1–1.3 把"积分"从 Riemann 升级成 Lebesgue，换序却照样失败：书 p.87 的三个"移动肿块"（水平逃逸 1_{[n,n+1)}、宽度逃逸 (1/n)1_{[0,n]}、垂直逃逸 n·1_{[1/n,2/n]}）每个都有 ∫fₙ = 1 而 ∫(lim fₙ) = 0。1.4.5 给这场审判下正式判决：**单调上升就换序（MCT，定理 1.4.43）；被一个绝对可积函数支配就换序（DCT，定理 1.4.48）；什么都不给，就只剩一条无条件的不等式（Fatou，推论 1.4.46）**。三兄弟内部还能互相推出（Fatou ⟸ MCT，DCT ⟸ Fatou），合起来把"换序"从 1.3.3 的悖论升级成带牌照的合法运算——第三次根号二发作就此痊愈。**诚实声明：仓库 `analysis/MeasureTheory/Section_1_4_5.lean` 是空壳（仅 import 与标题注释，无任何定理）——本节无仓库机验可引，机器实现见 Mathlib MeasureTheory（对照表在 §10）。**

## 1 这一幕要解决什么

把 1.4.4 的收获摆上桌：抽象测度空间 (X, 𝒜, μ) 上有了可测函数、无符号积分和绝对可积牌照，三大收敛定理的"抽象版"已经就位。但 1.3.3 那个换序悖论还悬在读者心上：尖峰 fₙ = n·1_{(0,1/n)}（面积 ∫fₙ = n·(1/n) = 1 恒等，逐点极限是零函数）宣判过"逐点收敛推不出积分收敛"。上一节我们说过，这个审判的判决书就是本节的三条定理——现在轮到宣读正文了。书 p.86 开门见山地亮出本节要回答的问题：设 fₙ 逐点（或 a.e.）收敛到可测的 f，什么条件下

$$\lim_{n\to\infty}\int_X f_n\,d\mu = \int_X \lim_{n\to\infty} f_n\,d\mu ?$$

注意这个问题问得比 1.3.3 更狠：1.3.3 只问"ℝᵈ 上的下积分服不服收敛"，本节问的是**任意测度空间**。fₙ 可以是计数测度上的数列（积分 = 级数）、Dirac 测度上的点值（积分 = 取值）、Lebesgue 测度上的函数——定理必须一次生效。为什么会失败？书 p.87 给出三个经典反例，全是"移动肿块"型：质量没有消失，只是每次都以一种不同的方式逃走了。下面把三种逃逸逐个算清楚，因为**三个定理的假设恰好就是封死这三种逃逸的三道闸门**——这是本节全部内容的骨架。

## 2 三个逃逸：失败的具体形态

**逃逸一：水平逃逸（例 1.4.39）**。X = ℝ 配 Lebesgue 测度，fₙ = 1_{[n,n+1)}。半开区间 [n,n+1)（n ≥ 1）两两不交，每个固定的 x 至多落进一个，所以 fₙ 逐点收敛到 0；而 ∫fₙ = μ([n,n+1)) = 1 恒等（端点选开还是闭不影响积分，选半开纯粹为了"至多一个"字面成立）。于是 lim ∫fₙ = 1 ≠ 0 = ∫0。质量整体向右平移出一切有限范围——每个 fₙ 的面积都还在，但极限函数在每一个固定点都看不见它。为什么单调收敛救不了它？fₙ 与 fₙ₊₁ 的支集不相交，列不单调。为什么支配收敛救不了它？任何满足 g ≥ fₙ（一切 n）的 g 必须在 [n,n+1) 上 ≥ 1 对一切 n 成立，即 g ≥ 1 于 [1,∞)，∫g ≥ μ([1,∞)) = ∞——不存在绝对可积的支配函数。

**逃逸二：宽度逃逸（例 1.4.40）**。fₙ = (1/n)·1_{[0,n]}。这次连一致收敛都有了：sup_x |fₙ(x) − 0| = 1/n → 0。可 ∫fₙ = (1/n)·n = 1 ≠ 0。这比逃逸一更令人不安：**一致收敛都不够**——1.3.5 之前我们可能以为"好收敛"总能换序。书 p.87 立刻指出解法：习题 1.4.41 说"有限测度空间上一致收敛可换序"，这里 X = ℝ 不是有限测度空间，支持集越铺越宽，fₙ 的高度虽然降到 1/n，宽度却涨到 n，面积 1 守恒。支配函数同样不存在：supₙ fₙ(x) 在 x ∈ [0,1) 处是 1（n = 1 就够），在 x ∈ [k, k+1)（k ≥ 1）处是 1/(k+1)（需要 n ≥ x 即 n ≥ k+1，取最小者），于是 ∫(supₙ fₙ) dμ ≥ ∫₁^∞ (1/⌈x⌉) dx = Σ_{k=1}^∞ 1/(k+1) = ∞——调和级数，高度压不住，宽度的总和是发散的。

**逃逸三：垂直逃逸（例 1.4.41）**。X = [0,1]，fₙ = n·1_{[1/n, 2/n]}。对每个 x > 0，取 n > 2/x，则 2/n < x，x 落进 [1/n, 2/n] 之外，fₙ(x) = 0——逐点极限仍是 0；fₙ(0) = 0 恒成立。而 ∫fₙ = n·(2/n − 1/n) = n·(1/n) = 1。这就是 1.3.3 那根钉子的正式版本（1.3.3 用 (0, 1/n)，书用 [1/n, 2/n]，同一种逃逸：高度 n 与宽度 1/n 精确抵消）。有限测度、可测、逐点收敛——全都满足，只有高度无界。支配函数检查：任何 g ≥ fₙ 对一切 n 成立者，在 x ∈ (0,1) 处必须 g(x) ≥ ⌈1/x⌉（取 n = ⌈1/x⌉ 就落在 [1/x, 2/x] 内，因为 ⌈1/x⌉ ≤ 1/x + 1 ≤ 2/x 当 x ≤ 1），故 ∫g ≥ ∫₀¹ (1/x) dx = ∞。（编号插曲：书 p.87 此处"例 1.4.41"与同页"习题 1.4.41（有限测度空间上一致收敛）"重号，PDF 原文如此、疑为排印——同类重号还有注 1.4.44 与习题 1.4.44、推论 1.4.45 与习题 1.4.45；本笔记一律按 PDF 原文引用编号。）

三个逃逸并排看，模式就清楚了：**面积在每一层都存在（都是 1），极限函数把它们全部清零**——用书 p.91 注 1.4.47 的话说，"在取极限的过程中，质量可以被销毁，但不可以被创造"。换序失败 = 质量被销毁。那么换序合法化的两条路就是：让质量**无法逃跑**（单调性：fₙ 不许离开前面 f₁,…,fₙ₋₁ 已经占据的位置，书 p.88 原话），或者给质量**上保险绳**（存在绝对可积的支配函数 G，把每一层的质量都罩在 G 的有限面积里）。前者是 MCT，后者是 DCT；而什么都不给时，Fatou 告诉你残存的下界——质量被销毁得再狠，极限函数的积分也永远不会超过各层积分的地下极限。三句话对应三个定理，下面逐个给形式陈述。

## 3 单调收敛定理（MCT，定理 1.4.43）

**直觉铺垫**：fₙ 逐点上升到 f，每一层 fₙ 都贴着 f 的下沿生长、不许掉队，那么面积只能一层层逼近 f 的面积。这跟 1.4.3 的集合版（上升集列 μ(Eₙ) ↑ μ(∪Eₙ)，机验 `Measure.upwards_mono`，`analysis/MeasureTheory/Section_1_4_3.lean:959`）是同一件事：函数单调 ⟹ 水平集单调，水平集的测度逼近就是函数的积分逼近。单调性封死三种逃逸：水平逃逸不单调（支集不相交）；宽度逃逸不单调（f₁ = 1 于 [0,1]，f₂ = 1/2 于 [0,2]，在 [0,1) 上反而下降）；垂直逃逸不单调（在 x = 2/n 处 fₙ(2/n) = n > 0 = fₙ₊₁(2/n)，因为 2/n ∉ [1/(n+1), 2/(n+1)]）。

**陈述（定理 1.4.43，书 p.88）**：设 0 ≤ f₁ ≤ f₂ ≤ ⋯ 是 (X, 𝒜, μ) 上的无符号可测函数列，逐点收敛到 f，则 limₙ ∫fₙ dμ = ∫f dμ（两边都允许 ∞）。

**证明骨架**（书 p.88–89）。方向一免费：fₙ ≤ f ⟹ ∫fₙ ≤ ∫f（积分单调性），故 lim ∫fₙ ≤ ∫f。方向二反着来：由无符号积分的定义（∫f = sup 一切 ≤ f 的简单函数积分），只需对任意简单 g = Σᵢ cᵢ1_{Aᵢ} ≤ f 证明 ∫g ≤ lim ∫fₙ。取 0 < ε < 1，定义水平集 Aᵢ,n := {x ∈ Aᵢ : fₙ(x) > (1−ε)cᵢ}。fₙ 上升 ⟹ Aᵢ,n 上升；对 cᵢ > 0 的 i，Aᵢ 上 f(x) ≥ cᵢ（因为 g ≤ f），而 f = supₙ fₙ 逐点，故 (1−ε)cᵢ < cᵢ ≤ f(x) 保证从某个 n 起 fₙ(x) > (1−ε)cᵢ，即 ∪ₙAᵢ,n = Aᵢ（cᵢ = 0 的项对积分无贡献，可不管）。**关键一步在这里**：Aᵢ,n 是上升可测集列，由集合版单调收敛（1.4.3 习题 1.4.23(ii)，机验 `Measure.upwards_mono` 同上）得 μ(Aᵢ,n) ↑ μ(Aᵢ)。另一边，逐点不等式 fₙ ≥ Σᵢ (1−ε)cᵢ·1_{Aᵢ,n} 处处成立（Aᵢ,n 之外该项为 0），积分得 ∫fₙ ≥ (1−ε)Σᵢ cᵢ μ(Aᵢ,n)，取极限 n → ∞、再令 ε → 0，得 lim ∫fₙ ≥ (1−ε)∫g → ∫g。对 g 取 sup 即 ∫f ≤ lim ∫fₙ。两方向合拢。

**数字检验 1（水平逃逸的合法版本）**：fₙ = 1_{[0,n]} 于 ℝ。列单调上升：1_{[0,n]} ≤ 1_{[0,n+1]}；逐点极限是 1_{[0,∞)}（每个 x ≥ 0 从 n ≥ x 起进入支集）。∫fₙ = μ([0,n]) = n：n = 1, 2, 10 时是 1, 2, 10，趋于 ∞；∫1_{[0,∞)} = μ([0,∞)) = ∞。**∞ = ∞，MCT 照样工作**——水平逃逸的非法律版本里质量凭空消失，合法版本里质量实实在在地躺在极限函数里，只是总和无限。单调性让"逃逸"变成了"累积"。

**数字检验 2（x² 的 dyadic 楼梯）**：fₙ = Σ_{k=0}^{2ⁿ−1} (k/2ⁿ)²·1_{[k/2ⁿ, (k+1)/2ⁿ)} 于 [0,1]。每个小区间取左端点值，二分时左半不变、右半从 (k/2ⁿ)² 升到 ((2k+1)/2ⁿ⁺¹)² ≥ (k/2ⁿ)²，故列单调上升；逐点极限在 x ∈ [0,1) 处是 x²，在 x = 1 处是 0（最右区间 [(2ⁿ−1)/2ⁿ, 1) 半开，1 永远不在任何区间里）——与 x² 只差一个点，积分相同，所以 MCT 的结论 lim ∫fₙ = ∫(x² a.e.) = 1/3 不受影响。逐项算：∫fₙ = (1/2ⁿ)³·Σ_{k=0}^{2ⁿ−1} k² = (2ⁿ−1)·2ⁿ·(2ⁿ⁺¹−1)/(6·2³ⁿ)。代入：n = 1 时 Σk² = 0+1 = 1，∫f₁ = 1/8 = 0.125；n = 2 时 Σk² = 0+1+4+9 = 14，∫f₂ = 14/64 = 7/32 ≈ 0.21875；n = 3 时 Σk² = 140，∫f₃ = 140/512 = 35/128 ≈ 0.2734。三者递增，极限 (1−2⁻ⁿ)(2−2⁻ⁿ)/6 → 2/6 = **1/3**，与 ∫₀¹ x² dx = 1/3 精确吻合——这里积分直接可算，MCT 给出的是"先取极限再积分"的同一答案。

**这意味着什么**：MCT 的本质是**积分的可数可加性**——Tao 在 1.3.3 推论 1.3.14 之后明说，这个性质也叫单调收敛定理。把 ∫f 想成"把 f 的图横切成可数片再求和"，单调上升保证切片不打架，求和顺序自由。推论 1.4.45（Tonelli 求和版，书 p.89）：对无符号可测 fₙ，∫(Σₙ fₙ) = Σₙ ∫fₙ——对部分和 F_N := Σ_{n≤N} fₙ 用 MCT 即得，这行证明总共一句话。无符号假设不是装饰：§8 的 FAQ 会给出带符号版本的翻车例。另外注 1.4.44 说单调性只需 a.e. 成立——1.4.4 的"a.e. 语言"在这里第一次真正派上用场。

## 4 Fatou 引理（推论 1.4.46）

**直觉铺垫**：MCT 要单调，太贵。现实里的列往往不单调（三个逃逸都是），问题是：**不假设任何单调性，积分与极限之间还剩下什么关系？** 答案是 Fatou：无条件成立，但只是不等式——"质量可以被销毁，但不可以被创造"（注 1.4.47）的精确化。

**陈述（推论 1.4.46，书 p.90）**：设 fₙ 是无符号可测函数列，则 ∫(liminfₙ fₙ) dμ ≤ liminfₙ ∫fₙ dμ。

**证明骨架**（书 p.90，两行）。令 F_N := inf_{n≥N} fₙ。**关键一步：liminf 本身就是一列单调上升函数的极限**——F_N 随 N 上升，lim_N F_N = liminfₙ fₙ（这是 liminf 的定义重写：尾端下确界再取上升极限）。每个 F_N 可测（1.4.4 的可测函数 inf 闭包性质）。对 F_N 用 MCT：∫(liminf fₙ) = lim_N ∫F_N = sup_N ∫F_N。而 F_N ≤ fₙ 对一切 n ≥ N 逐点成立，故 ∫F_N ≤ inf_{n≥N} ∫fₙ。于是 ∫(liminf fₙ) = sup_N ∫F_N ≤ sup_N inf_{n≥N} ∫fₙ = liminfₙ ∫fₙ。证毕。整个证明只有一个知识点："liminf = 单调列的极限"。

**严格不等号的例子（垂直逃逸，例 1.4.41）**：fₙ = n·1_{[1/n, 2/n]}。∫fₙ = 1 恒等，liminf ∫fₙ = 1；逐点 liminf fₙ = 0（§2 已算），∫0 = 0。于是 0 = ∫(liminf fₙ) ≤ liminf ∫fₙ = 1，**严格不等号，方向与 Fatou 一致**——注意这不是"Fatou 错了"，恰恰是"Fatou 只能给 ≤"的现场演示：面积在每一层都存在（1），极限函数把它们全部抹掉（0）。想从 Fatou 里榨出等式，必须外加条件——这正是下一节 DCT 干的事。

**这意味着什么**：Fatou 是免费的（零假设），所以它是理想的"引擎"：下面 DCT 的证明就是构造一列非负函数去套 Fatou，把不等式反过来变成等式。它是"宁可多算也不能少算"的数学化身——先取极限再积分的面积，永远不超过各层积分的下极限；三兄弟里它最弱，也最耐用。

## 5 支配收敛定理（DCT，定理 1.4.48）

**直觉铺垫**：换序的第二个充分条件，也是整个分析里用得最多的一个。fₙ 逐点趋向 f；如果有一件"大衣" G 把每个 |fₙ| 都罩住，且大衣本身绝对可积（面积有限），那么 fₙ 无论如何乱动，面积都逃不出大衣的料子——三个逃逸全被这件大衣挡下：水平逃逸的大衣必须在 [1,∞) 上 ≥ 1（∫ = ∞，料子不够）；宽度逃逸的大衣必须 ≥ supₙ fₙ = 1/⌈x⌉（∫₁^∞ 1/⌈x⌉ dx = Σ 1/(k+1) = ∞，调和级数）；垂直逃逸的大衣必须 ≥ 1/x 于 (0,1)（∫₀¹ dx/x = ∞）。没有一件现成，所以它们全翻车。

**陈述（定理 1.4.48，书 p.91）**：设 fₙ : X → ℂ 可测，逐点 μ-a.e. 收敛到可测极限 f；设 G : X → [0,∞] 无符号绝对可积（∫G dμ < ∞），且 |fₙ| ≤ G 对一切 n μ-a.e. 成立。则 limₙ ∫fₙ dμ = ∫f dμ。注意这是三兄弟里唯一允许复值、唯一全面采用 a.e. 语言的——它是 1.4.4 绝对可积牌照（∫|f| < ∞）的正式加冕。

**证明骨架**（书 p.91–92，实值情形；复值拆实部虚部）。先在零测集上改 fₙ、f、G，把"a.e."升级成"处处"（改完不改变任何积分——a.e. 相等的函数积分相同，1.4.4 的兼容性）。于是处处 −G ≤ fₙ ≤ G，且 −G ≤ f ≤ G。把 Fatou 用在 fₙ + G ≥ 0 上：∫(f + G) ≤ liminf ∫(fₙ + G) = ∫G + liminf ∫fₙ，两边减掉有限量 ∫G（**绝对可积牌照在这里被使用：∫G < ∞ 才能减**），得 ∫f ≤ liminf ∫fₙ。再把 Fatou 用在 G − fₙ ≥ 0 上：∫(G − f) ≤ liminf ∫(G − fₙ) = ∫G − limsup ∫fₙ，移项得 limsup ∫fₙ ≤ ∫f。夹逼：∫f ≤ liminf ∫fₙ ≤ limsup ∫fₙ ≤ ∫f，全部相等。**关键一步是"为什么偏偏把 Fatou 用在 fₙ + G 和 G − fₙ 上"**：Fatou 只接受非负列，而我们要证的量（∫fₙ）是带符号的；加上 G 把它顶到非负、减去它用 G − fₙ 再顶一次非负，两次 Fatou 分别给出 liminf 的下界和 limsup 的上界，一夹就出等式——这就是"Fatou 当引擎"的标准打法：想证极限存在，就造两个极限已知的非负列去套 Fatou。（无符号列的常见等价写法是直接把 Fatou 用在 G − fₙ 上；习题 1.4.45 要的 L¹ 收敛 ‖fₙ − f‖_{L¹} → 0 则用 2G − |fₙ − f| ≥ 0：|fₙ − f| ≤ |fₙ| + |f| ≤ 2G，liminf(2G − |fₙ−f|) = 2G，Fatou 给出 ∫2G ≤ liminf(2∫G − ∫|fₙ−f|) = 2∫G − limsup∫|fₙ−f|，移项得 limsup∫|fₙ−f| ≤ 0，即 ∫|fₙ−f| → 0——比"积分收敛"更强的 L¹ 收敛。）

**数字检验（xⁿ 于 [0,1]）**：fₙ(x) = xⁿ。逐点极限：x ∈ [0,1) 时 xⁿ → 0，x = 1 时 1ⁿ = 1——极限函数是单点集 {1} 的指示函数 1_{{1}}，与零函数只差一个点。支配：|xⁿ| ≤ 1 =: G 处处成立，∫G = ∫₀¹ 1 dx = 1 < ∞，牌照通过。DCT 宣判 lim ∫fₙ = ∫1_{{1}} = 0。直接算验证：∫₀¹ xⁿ dx = 1/(n+1)：n = 1 时 1/2，n = 2 时 1/3，n = 10 时 1/11 ≈ 0.0909，n = 100 时 1/101 ≈ 0.0099，→ 0 ✓。注意那个 x = 1 的点：它让逐点极限在一点上偏离 0，却对积分毫无贡献——**这就是"a.e. 收敛足够"的活教材**：DCT 的结论是 ∫fₙ → ∫f，而 f 与零函数 a.e. 相等，积分相同。

**这意味着什么**：DCT 把"积分与极限换序"归结为一个可检验的条件——找一件可积大衣。1.3.3 换序悖论的正式裁决到此完成：尖峰列没有大衣（任何支配函数必须 ≥ 1/x 于 (0,1)，∫ = ∞），所以 DCT 无权适用，悖论不构成攻击；换上单调上升条件 MCT 接管，换上大衣 DCT 接管。级数版（计数测度上）：若 |aₙₖ| ≤ bₙ、Σₙ bₙ < ∞ 且每列 aₙₖ → aₙ，则 Σₙ aₙₖ → Σₙ aₙ——这就是 Weierstrass M-检验的逐项极限形态；数学分析里含参级数换序的大多数标准情形（存在可积支配者）都是 DCT 的特例。但注意 DCT 不是全部：Abel 型换序（比如交错级数 Σ(−1)ⁿ/n 的幂级数在 x → 1⁻ 处取极限）没有可积大衣（|aₙ|xⁿ 的逐项支配需要 Σ|aₙ| < ∞），靠的是求和法的专门技巧，超出本节射程。

## 6 三兄弟的内部关系：谁推出谁

三条定理不是三个孤立的招式，而是一条推导链：**MCT ⟹ Fatou ⟹ DCT**。Fatou 从 MCT 推出的骨架已在 §4 给出（F_N = inf_{n≥N} fₙ 上升，对 F_N 用 MCT，F_N ≤ fₙ 给出逐项控制）；DCT 从 Fatou 推出的骨架已在 §5 给出（两次 Fatou 夹 liminf/limsup）。书 p.92 注 1.4.49 专门点破：这个推导顺序不是唯一的——[StSk2005]（Stein–Shakarchi）走的是另一条路：先证更简单的**有界收敛定理**（BCT：一致有界 + 支集落在有限测度集上 ⟹ 换序），再用 BCT 证 Fatou，用 Fatou 证 MCT，最后用 1.3.3 的水平/垂直截断把 BCT 推广成 DCT。为什么这个事实值得知道？因为它说明三条定理共享同一个核心（都是"质量不能凭空消失"的变体），谁先谁后只是讲故事的次序；也因为它给了你一张查漏表——任何一本教材只要证明了三兄弟里的两个，第三个必然免费。Tao 的顺序（MCT → Fatou → DCT）好处是每步的证明都最短：MCT 的证明只用集合版单调收敛，Fatou 的证明只用 MCT，DCT 的证明只用 Fatou，链条上每个环节都是上一环的直接抄写。仓库里这套逻辑的机器对应物在 Mathlib 里同样可见：`lintegral_liminf_le`（`Mathlib/MeasureTheory/Integral/Lebesgue/Add.lean:214`）一行归结到 a.e. 版 `lintegral_liminf_le'`（:202），后者的证明 :205–211 先重写 liminf = ⨆ₙ ⨅_{i≥n}（正是 F_N 技巧，:205–206），再调用 `lintegral_iSup'`（:208）；`tendsto_lintegral_of_dominated_convergence` 的证明（`Mathlib/MeasureTheory/Integral/Lebesgue/DominatedConvergence.lean:50–58`）用 `tendsto_of_le_liminf_of_limsup_le` 把 `lintegral_liminf_le`（liminf 半边）与 `limsup_lintegral_le`（limsup 半边，:27）夹在一起——机器走的正是书上"两次 Fatou 夹逼"的同构路线。

## 7 收尾：一路走来，第三次发作痊愈

把第一章的地图摊开：1.1 量箱子（初等测度，Jordan 的前身）；1.2 量千疮百孔的集合（外测度、可测性、Vitali 不可测集）——这一程治好了第二次根号二发作（Jordan 可测集对可数并不封闭，痊愈方式是 σ-代数牌照）；1.3 量函数（简单函数 → 可测函数 → 无符号积分 → 绝对可积）——第三次发作登场：Riemann 积分切不动 Dirichlet 函数、切不动尖峰列，极限与积分换序成了悖论；1.4 把整个舞台抽象化（布尔代数 → σ-代数 → 测度空间 → 抽象积分），并在此刻落下终章：**单调、被支配，换序就合法；否则至少有不等的方向**。三兄弟合起来回答的就是 1.1 以来唯一的问题——积分运算对极限封闭到什么程度。答案是：**σ-代数牌照保证极限的可测性（liminf/limsup 可测，Fatou 才有意义），绝对可积牌照保证极限的积分是有限实数（DCT 里 ∫G < ∞ 才能移项），两条牌照合起来，把"先取极限再积分"和"先积分再取极限"焊成同一个数**。根号二的故事第一次发作时，治愈方式是扩大数的世界（ℚ → ℝ）；第二次是扩大集合的世界（Jordan → Lebesgue）；这一次是给运算本身发牌照——不是怪罪极限，而是把合法的换序条件全部写出来。第一章，到此封顶。

## 8 反直觉清单 / FAQ

- **尖峰列到底为什么三兄弟都不收？** fₙ = n·1_{[1/n,2/n]}：逐点极限 0、∫fₙ = 1。（i）不单调：x = 2/n 处 fₙ(2/n) = n 而 fₙ₊₁(2/n) = 0（2/n ∉ [1/(n+1), 2/(n+1)]），MCT 无权使用。（ii）无支配：g ≥ fₙ 一切 n ⟹ g(x) ≥ ⌈1/x⌉ ≥ 1/x 于 (0,1)，∫₀¹ dx/x = ∞，DCT 无权使用。（iii）Fatou 对它是严格的 0 < 1——不是定理失效，是"≤"本来就允许严格。
- **宽度逃逸的可怕之处：一致收敛都不够，那"好收敛"还有什么用？** 习题 1.4.41：有限测度空间上的一致收敛确实可以换序。宽度逃逸 fₙ = (1/n)·1_{[0,n]} 是"一致收敛却失败"的标准例，因为 X = ℝ 是无限测度空间——一致收敛只控制"每个点上的偏差"，控制不了"偏差发生的范围有多大"。DCT 的条件（存在可积支配）才是无限测度空间上的正确答案：它同时控制高度（|fₙ| ≤ G 逐点）和宽度（∫G < ∞ 总量）。
- **推论 1.4.45（∫Σfₙ = Σ∫fₙ）为什么要求 fₙ 无符号？** 习题 1.4.42 的反例（水平逃逸改装的电报序列）：fₙ = 1_{[n,n+1)} − 1_{[n+1,n+2)}，n ≥ 1。每个 fₙ 绝对可积（∫|fₙ| = 2），逐点求和绝对收敛（每点至多两项非零，x ∈ [k,k+1) 处只有 f_k 与 f_{k−1} 贡献，总和 1_{[1,2)}：x ∈ [1,2) 时 f₁(x) = 1，x ∈ [k,k+1)（k ≥ 2）时 f_k(x) + f_{k−1}(x) = 1 − 1 = 0）。于是 ∫(Σₙ fₙ) = ∫1_{[1,2)} = 1，而 Σₙ ∫fₙ = Σₙ (1 − 1) = 0——1 ≠ 0。带符号时"先和再积"与"先积再和"可以差一个整数；无符号假设让部分和单调上升，MCT 接管。
- **Borel-Cantelli（习题 1.4.43）是本节定理的直接应用？** 是的：Σₙ μ(Eₙ) < ∞ ⟹ a.e. x 只落在有限多个 Eₙ 里。证明就是推论 1.4.45 配指示函数：∫(Σₙ 1_{Eₙ}) dμ = Σₙ μ(Eₙ) < ∞，故被积函数 a.e. 有限（否则在正测度集上取 ∞ 会让积分为 ∞；这就是 Mathlib 的 `ae_lt_top`，`Mathlib/MeasureTheory/Integral/Lebesgue/Markov.lean:153`），即 Σₙ 1_{Eₙ}(x) < ∞ 对 a.e. x。数字检验：Eₙ = [0, 1/n²] 于 ℝ，Σμ(Eₙ) = Σ 1/n² = π²/6 ≈ 1.645 < ∞；每个 x > 0 只被有限多个 Eₙ 覆盖（x < 1/n² ⟺ n < 1/√x，有限个），只有 x = 0 落在全部 Eₙ 里，故 limsup Eₙ = {0}，μ({0}) = 0 ✓——与定理的结论（μ(limsup Eₙ) = 0）精确吻合。注意习题 1.4.44(i) 说这也能不用收敛定理、直接靠测度的次可加性证；条件放宽成 lim μ(Eₙ) = 0 则失败（习题 1.4.44(ii) 的反例：在 [0,1] 上按块铺游走区间——块 k（n = 2ᵏ, …, 2ᵏ⁺¹−1）把 [0,1) 分成 2ᵏ 个半开区间 [j/2ᵏ, (j+1)/2ᵏ)（j = n − 2ᵏ）。每个 Eₙ 的测度 2⁻ᵏ → 0，满足放宽后的假设；可每个 x ∈ [0,1) 在每一块里恰好被覆盖一次，落在无穷多个 Eₙ 里，limsup Eₙ = [0,1)，μ = 1 ≠ 0——结论失效）。
- **Fatou 什么时候取等号？** 无条件只有 ≤；取等号的情形就是 MCT（单调）与 DCT（被支配）的结论本身。所以 Fatou 的正确用法不是"希望它取等"，而是"用它作为夹逼的一边"——DCT 的证明就是样板。
- **MCT 为什么只承诺上升方向？** 下降方向的函数版会崩：1.4.3 的 `Measure.downwards_mono_counter`（`analysis/MeasureTheory/Section_1_4_3.lean:977`）给出集合版反例——ℕ 上计数测度，Eₙ = {n, n+1, …} 单调下降，μ(Eₙ) = ∞ 而 μ(⋂Eₙ) = μ(∅) = 0；fₙ = 1_{Eₙ} 给出 ∫fₙ = ∞ ≠ 0 = ∫0。下降需要"某一片测度有限"的额外条件（这就是 `lintegral_iInf` 类定理要带有限性假设的原因）。上升方向的 fₙ 有下界 0 兜底，下降方向没有上界兜底。
