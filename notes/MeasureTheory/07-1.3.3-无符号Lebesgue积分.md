# 07 · 1.3.3 无符号 Lebesgue 积分：换序悖论的正式裁决

> Tao《An Introduction to Measure Theory》§1.3.3 讲稿式笔记 + Lean 形式化对照
> 一句话纲领：**1.3.1 把简单函数（有限层）积完了，1.3.2 把"函数 = 简单函数列的逐点极限"定下来了——现在轮到最后一步：对任意无符号可测函数定义 ∫f。最朴素的做法是上下双管齐下：下积分 L(f) = sup{∫g : g 简单, g ≤ f}，上积分 U(f) = inf{∫h : h 简单, h ≥ f}（定义 1.3.12）。但三个反例函数把这条路炸开：1/√x（无界、有限支撑）满足 L = 2 < ∞ = U；尾巴尖峰列 2⁻ᵏ（有界、无限支撑）满足 L = 2 < ∞ = U；尖峰列 2ᵏ（无界）同样 L = 2 < ∞ = U。更致命的是，上积分沿"截断逼近"取极限是病态的——对 1/√x，lim U(min(f,n)) = 2，而 U(f) 本身 = ∞：用逼近列定义积分，对上积分不是良定的。下积分却对两条单调截断列都成立极限交换（习题 1.3.10(viii)(ix)，机器验证）。于是定义 1.3.13 别无选择：∫f := L(f)。这一选择直接裁决了动画里的换序悖论（fₙ = n·1_{(0,1/n)}：lim ∫fₙ = 1 ≠ 0 = ∫lim fₙ）：换序合法的充分条件是序列单调上升（单调收敛定理 MCT，Tao 定理 1.4.43；§1.3.3 仓库内机验的是它的两个截断特例）——尖峰列不单调，MCT 不适用，悖论不构成攻击。**
> 形式化：`analysis/MeasureTheory/Section_1_3_3.lean`（7633 行，本节核心）；定义 1.3.12/1.3.13、习题 1.3.10(i)–(x)、习题 1.3.11（含两个"假设不可删"反例 `isFalse`）、推论 1.3.14、习题 1.3.12–1.3.18、引理 1.3.15 全部机验；三个反例函数 `f_inv_sqrt`、`f_horiz`、`f_tail` 逐一构造并验证 L ≠ U。

## 1 这一幕要解决什么

动画系列里最扎眼的那个画面：取 fₙ = n·1_{(0,1/n)}——一根"越变越尖的钉子"。每根钉子下的面积都是 ∫fₙ = n·(1/n) = 1（高 n、底长 1/n 的矩形），可对每个固定的 x，只要 n > 1/x，x 就落在 (0,1/n) 外面，fₙ(x) = 0——逐点极限是零函数。于是 lim ∫fₙ = 1，而 ∫(lim fₙ) = ∫0 = 0。**积分与极限的换序失败了**，差出整整 1 个单位的面积。这 1 个单位去哪儿了？哪儿也没去：尖钉的面积在每一层都存在，但极限函数把它们全部抹掉了。这个悖论不是动画效果，它是这一节要正面回答的问题：**什么时候 lim ∫fₙ = ∫lim fₙ 合法？**

铺垫已经把问题逼到这里：1.3.1 定义好了简单函数（有限层）的积分（`UnsignedSimpleFunction.integ`，`Section_1_3_1.lean:172`）；1.3.2 把可测函数定义为简单函数列的逐点极限（`UnsignedMeasurable`，`Section_1_3_2.lean:21`）。两层台阶都齐了，自然的一步是：对任意无符号可测 f，取逼近列 gₙ → f，定义 ∫f := lim ∫gₙ。但上一段的反例已经把这扇门炸开了一个更深的洞：**这个极限依赖你选哪条逼近列**。两条完全合法的简单函数列都逐点收敛到零函数，却给出不同的极限——列 1 就是尖钉本身 gₙ = n·1_{(0,1/n)}（每个 gₙ 都是简单函数：只在两个值 n 和 0 之间切换），lim ∫gₙ = 1；列 2 取 gₙ = (1/n)·1_[0,1]，也逐点收敛到零函数（对每个 x，gₙ(x) = 1/n → 0），而 ∫gₙ = 1/n → 0。**同一个极限函数（零函数）被算出两个积分：1 和 0。** 于是"∫f := lim ∫gₙ"连良定义都谈不上。注意这不是说零函数的积分"应该"是 1——积分理论的答案就是 0；这里要说的是：朴素定义（挑一条列取极限）**没有能力**给出答案，它同时给出 1 和 0。于是本节先退一步，问一个更老实的问题：**不经过任何"列"，能不能直接给每个函数一个积分？** 能：把"所有简单函数逼近"这个集合整体拿在手里，而不是挑一条列。这就是下积分的来历。

## 2 朴素方案：把"尺子"接到每个函数上——上、下积分

先不讨论"哪条列"，讨论"所有列的下方与上方"。对任意无符号函数 f : ℝᵈ → [0,∞]（注意：**不需要可测**），把"所有不高于 f 的简单函数的积分"放在一起取上确界，同时把"所有不低于 f 的简单函数的积分"取下确界：

L(f) = sup { ∫g : g 简单, 0 ≤ g ≤ f }，　U(f) = inf { ∫h : h 简单, h ≥ f }。

这就是 Tao 定义 1.3.12 的下、上无符号 Lebesgue 积分（书 p.52–53）。Lean 里一字不差：`LowerUnsignedLebesgueIntegral`（`Section_1_3_3.lean:17`）定义为 sSup {R | ∃ g, g 简单 ∧ ∀ x, g x ≤ f x ∧ R = ∫g}；`UpperUnsignedLebesgueIntegral`（:21）把 ≤ 换成 ≥、sSup 换成 sInf。定义只要求"简单函数"这台机器（1.3.1）能开出来，对 f 本身零要求；值域是扩展实数 [0,∞]（1.3.1 的约定），∞ 是合法答案。顺带交代 1.3.1 留下的乘法约定（后文"在正测集上取 ∞"要用）：简单函数的积分是 Σ cᵢ·m(Eᵢ)，其中 cᵢ ∈ [0,∞]，按 ENNReal 同款约定，∞·m(E) 在 m(E) > 0 时为 ∞，0·∞ = 0（仓库 `EReal.top_mul_of_pos` 的使用见 `Section_1_3_1.lean:1237`，约定来源 `Notation.lean:62` 一带）。

定义立即自检（都是习题 1.3.10 的条目，机器全证）：

- **与简单积分兼容**：f 自己就是简单函数时，上确界被 g = f 取到，L(f) = ∫f（`eq_simpleIntegral` :132，习题 1.3.10(i)）。上、下积分是 1.3.1 积分的扩张，不是新东西。
- **单调性**：f ≤ g（几乎处处）⟹ L(f) ≤ L(g)（`mono` :146，(ii)）。骨架：f 的每个逼近 g′ ≤ f 也满足 g′ ≤ g（a.e.），于是 L(f) 的每个成员都是 L(g) 的成员，sup 不增。一行。（书上的版本允许 f、g 是任意无符号函数；机器版额外要求 `UnsignedMeasurable`——它是用 a.e. 版下积分（`.eq` :24）证明的，见 Lean 表。）
- **齐性**：L(c·f) = c·L(f)，c ≥ 0（`hom` :189，(iii)）。注意书上补了一句："该命题对 c = +∞ 不幸失败（这有点难证）"——Lean 的 `hom` 因此只接受 c : ℝ，这正是书说的边界。
- **超可加**：L(f+g) ≥ L(f) + L(g)（`superadditive` :383，(v)）。骨架：f 的逼近 g₁ 与 g 的逼近 g₂ 相加仍是简单函数且 ≤ f+g，所以 ∫g₁ + ∫g₂ ≤ L(f+g)；取上确界。**等号不是自动的**——这是下一幕的病根。

**定义→立即检验**：f = 1_ℚ∩[0,1]。L 方向：任何简单 g ≤ 1_ℚ∩[0,1] 在无理点上必须 ≤ 0，而无符号函数取值 ≥ 0，所以 g = 0 于所有无理点，即 g 的支撑 ⊆ ℚ，零测集——∫g = 0。故 L(1_ℚ∩[0,1]) = 0。U 方向：h = 1_ℚ∩[0,1] 本身是合法支配函数（h ≥ f 逐点，等号成立），∫h = 1·m(ℚ∩[0,1]) = 0；而任何 h ≥ f ≥ 0 满足 ∫h ≥ 0，所以下确界 = 0。上下都是 0：**1_ℚ∩[0,1] 的积分是 0**，与零函数在测度意义下不可区分（这正是习题 1.3.10(iv)，a.e. 相等 ⟹ 积分相等，`integral_eq_integral_of_aeEqual` :315）。注意别踩坑：这个例子上下一致，**没有**暴露 L 与 U 的分裂——分裂需要更坏的材料，下一节登场。

## 3 失败诊断：上积分的三处崩坏

三个机器验证的反例。前两个分别抽掉习题 1.3.11 的两个假设（有界、有限支撑），第三个是本节真正的转折点。

**反例 1：无界 + 有限支撑。** `f_inv_sqrt`（`Section_1_3_3.lean:2060`）：f(x) = 1/√x 于 (0,1)，其余为 0。下积分：答案是经典瑕积分 ∫₀¹ x⁻¹ᐟ² dx = 2√x |₀¹ = 2——注意这不来自某一条固定剖分的积分和（例如把 (0,1) 剖成 [1/(n+1), 1/n]、取每段下端值得到的简单函数，其积分 Σ√n/(n(n+1)) ≈ 1.856 < 2，是一条合法但不取到上确界的逼近），而是"所有从下方逼近的简单函数"的上确界恰为 2；机器只验证了 L < ⊤（`f_inv_sqrt_L_lt_top` :2847），精确值 2 是手工计算（严格论证要等习题 1.3.13 的面积解释 `eq_area` :5302 或截断技巧，本节按经典瑕积分引用）。上积分：把"逐点支配"四个字拆开——h 简单意味着它只有有限多个值 c₁ < … < c_m；若这些值全有限，令 M = max cⱼ，则在 (0, 1/M²) 上 1/√x > M ≥ h(x)，与 h ≥ f 逐点矛盾；所以 h 必须在某个**正测度**的片上取 ∞（在零测集上取 ∞ 救不了它：正测度的 (0,1/M²) 上处处要求 h > M，有限值片盖不住）。于是 ∫h = ∞。U(f) = ∞（`f_inv_sqrt_upper` :2157）。**L = 2 ≠ ∞ = U**，`eq_upperIntegral_unbounded_isFalse`（:2887）宣告：习题 1.3.11 的"有界"假设不能删。

**反例 2：有界 + 无限支撑。** `f_tail`（:2918）：f(x) = 2⁻ᵏ 于 (k, k+1)，k = 0,1,2,…。有界（≤ 1，`f_tail_le_one` :3077），但支撑 [0,∞) 测度无限。下积分：部分和 g_n = Σ_{k<n} 2⁻ᵏ·1_{(k,k+1)} 是简单函数且 ≤ f，∫g_n = Σ_{k<n} 2⁻ᵏ = 2(1 − 2⁻ⁿ) → 2，所以 L ≥ 2；机器验证 L ≤ 2（`f_tail_L_le_two` :3228），L = 2。上积分：任何简单 h ≥ f_tail 都满足 ∫h = ∞。论证用"有限片"这一条：h 只有有限多个片 E₁,…,E_m，值 c₁,…,c_m。零值片盖不住任何 (k,k+1)（那里 f = 2⁻ᵏ > 0，逐点支配要求 h > 0），所以正值片们的并 ⊇ (0,∞)；而有限多个集合之并测度为 ∞ 当且仅当其中某一片测度为 ∞（有限并的测度不超过各片之和……反过来：有限个有限测度集合的并是有限测度）——故存在正值片 E_j，m(E_j) = ∞，贡献 c_j·∞ = ∞。U(f) = ∞（`f_tail_upper_aux` :3554）。**L = 2 ≠ ∞ = U**，`eq_upperIntegral_infinite_supp_isFalse`（:3605）宣告："有限支撑"假设也不能删。

**反例 3：截断极限的崩坏（真正的转折点）。** 上面两个反例说明 L ≠ U，但积分到底取哪个？直觉会说"取小的那个、取 L"。可是还有一个更隐蔽、更本质的判据：**逼近列的极限交换**。回忆 1.3.2 的两个截断：min(f(x), n) 随 n 逐点上升到 f（值域封顶）；f·1_{|x|≤n} 也逐点上升到 f（支撑截断）。若积分尊重"函数单调上升"，就应当有 lim ∫min(f,n) = ∫f 与 lim ∫(f·1_{|x|≤n}) = ∫f——这正是单调收敛定理的雏形（习题 1.3.10(viii)(ix)，书 p.53）。

下积分：**两条都对**。`eq_lim_vert_trunc`（:976）：limₙ L(min(f,n)) = L(f)；`eq_lim_horiz_trunc`（:1249）：limₙ L(f·1_{B(0,n)}) = L(f)，对任意无符号可测 f。（简单函数版先行：`integral_limit` :939，文件注释直接写着 "simple MCT"。）

为什么下积分稳、上积分脆？机制在"从下方逼近的简单函数自动有界"：任何简单 g ≤ f 都只取有限多个值，设其上界 M，则对一切 n ≥ M，g ≤ min(f,n)（在 f ≤ n 处 g ≤ f = min(f,n)，在 f > n 处 g ≤ M ≤ n = min(f,n)）。于是每个从下方逼近的 g 都被竖直截断列"吃掉"：∫g ≤ L(min(f,n)) 对所有充分大的 n 成立，取上确界得 L(f) ≤ limₙ L(min(f,n))；反方向 L(min(f,n)) ≤ L(f) 由单调性白送。**sup 方向被"有界"保护**：截断列捕捉了全部下逼近。上积分没有对应的保护：min(h,n) 在 f > n 处掉到 f 下面，不再是合法支配函数——**上逼近类不被截断稳定**，inf 方向没有自动有界的帮手，这就是 U 脆的根源。

上积分：**两条都错**。对 f = 1/√x：min(f,n) 有界（≤ n）且有限支撑（⊆ (0,1)）⟹ 习题 1.3.11 的结论适用，U(min(f,n)) = L(min(f,n))；而 L(min(f,n)) ↑ L(f) = 2（`eq_lim_vert_trunc` 对 L 成立）。于是 limₙ U(min(f,n)) = 2，但 U(f) = ∞——**"先截断、取上积分、再取极限"给出 2，"直接取上积分"给出 ∞**。水平截断的同款事故发生在 `f_horiz`（:1557）：尖峰列，第 k 根尖峰在 (2ᵏ, 2ᵏ + 2⁻²ᵏ) 上取值 2ᵏ；每根面积 2ᵏ·2⁻²ᵏ = 2⁻ᵏ，总面积 Σ_{k≥0} 2⁻ᵏ = 2，支撑总测度 Σ_{k≥0} 2⁻²ᵏ = 1 + 1/4 + 1/16 + … = 4/3；无界（高度 2ᵏ → ∞）⟹ U = ∞（`f_horiz_upper` :1734）。机器把两个失败证成了否定定理：`eq_lim_vert_trunc_upper_isFalse`（:2526）、`eq_lim_horiz_trunc_upper_isFalse`（:2014）。

**这意味着什么**：如果"∫f"被定义为"沿逼近列取积分极限"，这个极限**依赖你喂给谁**——喂给下积分，得到 2（正确的答案，∫₀¹ x⁻¹ᐟ² dx = 2）；喂给上积分，先截断得到 2、不截断得到 ∞。逼近列不能定义上积分的值；上积分不尊重单调收敛。反过来，下积分对两条单调截断列都给出正确的极限——**单调收敛是下积分的固有性质，不是上积分的**。这就是选择 ∫ := L 的全部理由，下一节把这一选择立成定义。

## 4 概念的必然出场：∫ := 下积分

于是唯一的出路是：积分就是下积分。**定义 1.3.13（无符号 Lebesgue 积分，书 p.54）**：对无符号**可测** f，定义 ∫f := L(f)（下积分）。上积分被放弃——书 p.53 原话：上积分 "we will use this integral much more rarely"。Lean 里的定义一行：`UnsignedLebesgueIntegral`（`Section_1_3_3.lean:1338`）:= `LowerUnsignedLebesgueIntegral`，没有任何选择余地；对不可测函数，Lean 给一个"垃圾值"（docstring :1337 明说，`UnsignedMeasurable.integ` :1340 才是有意义的入口），书上则干脆不定义。

为什么是"可测"而不是"任意函数"？因为可测性正是让 L 拥有好性质的入场券：

- **习题 1.3.11**（`eq_upperIntegral` :2595）：f 可测 + 有界 + 支撑在有限测度集内 ⟹ L(f) = U(f)。骨架：L ≤ U 恒成立（任意 g ≤ f ≤ h 给出 ∫g ≤ ∫h，sup ≤ inf）；反方向用习题 1.3.4 的一致逼近（有界可测函数 = 简单函数的一致极限，`Section_1_3_2.lean:2200`）：对任意 ε > 0，找简单 g ≤ f 与简单 h ≥ f 满足 ∫h − ∫g < ε，夹出 L = U。细节：h 只在支撑 S（有限测度）上有义务 ≥ f，在 S 之外 f = 0，可以就把 h 置 0——所以 h 的积分不会因为无穷远处的补集而炸掉；一致逼近则保证 h − g 在 S 上的"盈余"可以压到 ε 内。**关键一步**：一致逼近把"支配函数的积分盈余"压到 ε——这正是有界性 + 有限支撑换来的。仓库在 :2887 与 :3605 用两个反例回答了书 p.54 的追问"如果 f 无界，或支撑不在有限测度集内，会怎样"：两个假设各缺一个，L = U 立刻崩。
- **推论 1.3.14（有限可加性，`add` :3857）**：f、g 可测 ⟹ ∫(f+g) = ∫f + ∫g。骨架（书 p.54 原证）：先用水平截断 + 极限过渡，可假设 f、g 有界；再用垂直截断 + 极限，可假设支撑有界（有限测度）；于是习题 1.3.11 对 f、g、f+g 都适用，L = U 三处成立；超可加（习题 1.3.10(v)）给 L(f+g) ≥ Lf + Lg，次可加（(vi)，`subadditive` :519）给 U(f+g) ≤ Uf + Ug，夹出等式。被跳过的过渡不等式只有一条：min(f+g, n) ≤ min(f,n) + min(g,n)（a+b ≤ n 时两边都是 a+b；a+b > n 时左边 = n ≤ min(a,n)+min(b,n)），以及每个截断在有界有限支撑类上的加性——两者把"可测"从截断函数传回一般 f、g。**关键一步**：两个截断极限各用一次，把一般可测函数压回"有界 + 有限支撑"这个 L = U 的舒适区。
- **没有可测性，加性直接崩**：`LowerUnsignedLebesgueIntegral.not_additive`（:4476）——取 V 为 Vitali 集（1.2.3 节，`VitaliSet`/`VitaliSet.nonmeasurable`，`Section_1_2_3.lean:66/:145`），C = [0,1]：1_V + 1_{C\V} = 1_C，但 L(1_V) = 0（Vitali 集的内测度为 0：每个简单函数 g ≤ 1_V 的支撑只能落在 V 的零测可测子集里——机器把这一条证成 `vitali_inner_measure_zero`，`Section_1_3_3.lean:4148`；`not_additive` 的证明 :4476 直接调用它）、L(1_{C\V}) < 1（`complement_lower_lt_one` :4179；数学上其实也是 0——同样的内测度论证对 C\V 成立——但机器只验证了 < 1 这半，已经足够）、L(1_C) = m(C) = 1：**0 + 0 ≠ 1**。习题 1.3.12（`eq_outer_measure_integral` :3911）给出更刺眼的版本：U(1_E) = m*(E)——上积分把不可测集的**外测度**当成了积分；对 V：L(1_V) = 0 < 1 = U(1_V)。积分与测度一样，只在"干净"（可测）的对象上才言行一致。

**这意味着什么**：定义 1.3.13 不是"挑了一个顺眼的公式"，而是被三个反例逼到墙角后的唯一活路——L 是单调收敛的好孩子，U 是坏孩子，"有界 + 有限支撑"的可测类则是两者握手言和的地方。从这一行起，积分号 ∫ 正式启用，默认指下积分。

## 5 单调收敛定理：换序的判决书

现在回到开头的悖论。判决书内容：

**定理（单调收敛定理 MCT）**：设 0 ≤ f₁ ≤ f₂ ≤ … 是无符号可测函数列，逐点收敛到 f，则 ∫fₙ 单调上升到 ∫f，即 lim ∫fₙ = ∫lim fₙ（两边都允许 ∞）。

Tao 把一般陈述放在抽象测度论部分作为**定理 1.4.43**（§1.4.6），并在推论 1.3.14 之后明说："在下一节我们会把无符号积分的有限可加性提升为可数可加性；这个性质也叫单调收敛定理（定理 1.4.43）"（书 p.54）——**MCT 的本质是积分的可数可加性**。仓库在 §1.3.3 内机器验证的是它的两个截断特例：`eq_lim_vert_trunc`（:976）、`eq_lim_horiz_trunc`（:1249）与简单函数版 `integral_limit`（:939）；一般陈述对应 `Section_1_4_6.lean`，该文件尚不存在，未形式化——待证。

证明骨架（定理 1.4.43 的标准证法）：

1. ∫fₙ 单调上升（习题 1.3.10(ii) 的 `mono`），收敛到 I = lim ∫fₙ（允许 ∞）。
2. I ≤ ∫f：fₙ ≤ f 逐点 ⟹ ∫fₙ ≤ ∫f，取极限。
3. I ≥ ∫f（技术核心）：固定简单 g ≤ f 与 0 < ε < 1，看水平集 Eₙ = {x : fₙ(x) ≥ (1−ε)g(x)}。fₙ 逐点上升 ⟹ Eₙ 上升；在 g(x) > 0 的点，(1−ε)g(x) < g(x) ≤ f(x) = lim fₙ(x)，所以最终 fₙ(x) ≥ (1−ε)g(x)，即 ∪ₙ Eₙ ⊇ {g > 0}。于是 ∫fₙ ≥ ∫((1−ε)g·1_{Eₙ}) = (1−ε)Σᵢ cᵢ·m(Fᵢ ∩ Eₙ)，其中 g = Σᵢ cᵢ·1_{Fᵢ}；对每个 cᵢ > 0 的 i，Fᵢ ⊆ {g > 0} ⊆ ∪ₙEₙ，且 Fᵢ ∩ Eₙ 是上升的可测集列，由集合版单调收敛（习题 1.2.11，`Lebesgue_measure.upward_monotone_convergence`，`Section_1_2_2.lean:2778`），m(Fᵢ ∩ Eₙ) → m(Fᵢ ∩ ∪ₙEₙ) = m(Fᵢ)（cᵢ = 0 的片贡献恒为 0，无所谓盖不盖得住）。所以 I ≥ (1−ε)∫g；ε → 0，再对 g 取 sup，得 I ≥ L(f) = ∫f。
4. 夹逼：I = ∫f。

**关键一步是第 3 步的翻译**："函数列逐点上升"被翻译成"水平集列 Eₙ = {fₙ ≥ t} 上升"，于是积分的极限变成**集合测度的单调收敛**——1.2.2 已机验的习题 1.2.11 直接接管。仓库里这步翻译的机器形态现成地躺在 `eq_lim_vert_trunc` 的证明中（:1088 调用 `Lebesgue_measure.upward_monotone_convergence`）。

**这意味着什么——换序裁决**：

- **尖峰列 fₙ = n·1_{(0,1/n)} 不满足 MCT 的假设**：它不单调。检查：在 (1/(n+1), 1/n) 上，fₙ = n 而 fₙ₊₁ = 0，fₙ₊₁ < fₙ——函数值在下降。MCT 要求对每个 x、每个 n：fₙ(x) ≤ fₙ₊₁(x)。所以 lim ∫ = 1 ≠ 0 = ∫lim 不与 MCT 矛盾：MCT 只说"单调 ⟹ 合法"，没说"非单调 ⟹ 非法"（非单调可能合法也可能非法，Fatou 引理处理一半，见 FAQ）。
- **单调的例子真的合法**：fₙ = 1_[0,n] 于 ℝ。fₙ ↑ 1_[0,∞) 逐点（单调！）。∫fₙ = m([0,n]) = n → ∞，∫1_[0,∞) = m([0,∞)) = ∞。lim ∫ = ∫lim = ∞，换序成功——两边都是 ∞，而 ∞ 是合法积分值。
- **非平凡的例子：x² 的二分阶梯**。gₙ(x) = (⌊min(2ⁿx, 2ⁿ−1)⌋/2ⁿ)²（x ∈ [0,1]：前半段是"取 2ⁿx 的下取整"，x = 1 处被钳到 (2ⁿ−1)/2ⁿ，避免掉出格子）。gₙ 是简单函数（只有 2ⁿ 个值），且 gₙ ↑ x² **逐点**：⌊min(2ⁿx, 2ⁿ−1)⌋/2ⁿ ↑ x 对每个 x ∈ [0,1]（含 x = 1：gₙ(1) = ((2ⁿ−1)/2ⁿ)² ↑ 1 = x²(1)），平方保持单调。∫gₙ = Σ_{k=0}^{2ⁿ−1} (k/2ⁿ)²·(1/2ⁿ) = (1/2³ⁿ)·Σ_{k<2ⁿ} k² = (1/2³ⁿ)·(2ⁿ−1)(2ⁿ)(2^{n+1}−1)/6。验算：n = 1，∫g₁ = (1/4)·(1/2) = 1/8（公式 (2−1)(2)(4−1)/(6·8) = 6/48 = 1/8 ✓）；n = 2，∫g₂ = (0 + 1 + 4 + 9)/16·(1/4) = 14/64 = 7/32 ≈ 0.21875（公式 (4−1)(4)(8−1)/(6·64) = 84/384 = 7/32 ✓）。极限：(1 − 2⁻ⁿ)(2 − 2⁻ⁿ)/6 → 2/6 = 1/3，而 ∫₀¹ x² dx = x³/3 |₀¹ = 1/3 − 0 = 1/3 ✓。换序合法，且确实算出"曲线下的面积"——积分与面积在此汇合。

所以动画悖论的完整裁决：lim ∫fₙ = 1 与 ∫lim fₙ = 0 两个数都不是"算错"——它们如实存在，就像 1 和 0 一样都是事实。**换序合法 ⇐（充分条件）序列单调上升**（MCT）；尖峰列不单调，于是 MCT 不发言，两个数可以不相等——1 与 0 之差就是"非单调换序"的代价，没有任何定理欠你一个 lim ∫ = ∫lim。这不是和稀泥：正是"单调"这个条件让水平集列 Eₙ 上升（证明第 3 步），从而把问题交给已经立起来的集合单调收敛——**单调性不是技术上的锦上添花，它是"逼近极限与函数极限可交换"的判决条件**。

## 6 积分的延伸性质：Markov、唯一性、零积分

积分立起来之后，一连串性质几乎免费：

**引理 1.3.15（Markov 不等式，`markov_inequality` :7169）**：f 可测、t > 0 ⟹ m({x : f(x) ≥ t}) ≤ ∫f / t。证明：g = t·1_{f ≥ t} 是简单函数且 g ≤ f（在 {f ≥ t} 上 t ≤ f，别处 g = 0 ≤ f），所以 ∫f ≥ ∫g = t·m({f ≥ t})，移项。一行证明。验算：f = 1/√x 于 (0,1)（∫f = 2），t = 4：{f ≥ 4} = (0, 1/16]，m = 1/16 ≤ 2/4 = 1/2 ✓。**这意味着什么**：积分控制"高处的分布"——概率论"第一矩方法"的全部内容（书注记 1.3.16）。

**习题 1.3.14（唯一性，`unique` :5719）**：设 integ 是任何把可测函数映到 EReal 的函数，只要它 (a) 在简单函数上等于简单积分，(b) 可加，(c) 满足垂直截断极限，(d) 满足水平截断极限，(e) 非负——则 integ ≡ 无符号 Lebesgue 积分。骨架：min(f,n) 有界，再乘 1_{B(0,m)} 得有限支撑，落入"有界 + 有限支撑"类，那里 (a)+(b) 强制 integ = L（`integ_eq_L_bounded` :5655）；两次截断极限（(c)(d)）把一般 f 拉回该类。**关键一步**：有界有限支撑类上"一致 + 可加 ⟹ 等于 L"，再靠截断极限把一般函数挤回该类。**这意味着什么**：这是"良定义性"的终极裁决——任何"合理"的积分构造，只要满足这五条，都只能是 L。不存在"另一个积分定义"。

**习题 1.3.18**：

- (i) ∫f < ∞ ⟹ f 几乎处处有限（`ae_finite` :7228；仓库 docstring 标为 1.3.18(ii)，编号漂移见 Lean 表）。骨架：反证 + Markov——{f = ∞} ⊆ {f ≥ t} 对每个 t，若它有正测度，Markov 给 ∫f ≥ t·m({f ≥ t}) 对任意大 t，矛盾。
- **逆命题不成立**：f = 1/x² 于 (0,1)（`f_inv_sq` :7338）处处有限（每一点都是有限数），但 ∫f = ∞（`f_inv_sq_integral` :7476；机器版本 `ae_finite_no_converse` :7582）。有限 a.e. 远弱于可积。
- (ii) ∫f = 0 ⟺ f = 0 几乎处处（`eq_zero_aeZero` :7588）。⟸ 方向：习题 1.3.10(iv)（a.e. 相等 ⟹ 积分相等）。⟹ 方向：Markov 于 t = 1/(n+1)：m({f ≥ 1/(n+1)}) = 0 对每个 n；而 {f > 0} = ∪ₙ {f ≥ 1/(n+1)} 是零测集的可数并，零测。**关键一步**：把"积分零"逐层榨成"每个正高度层零测"，再用可数可加性。

以及习题 1.3.17（与 Riemann 积分兼容）：Riemann 可积的 f : [a,b] → [0,∞)（外部延拓为 0）满足新积分 = Riemann 积分（`riemann_eq_L` :6985，`RiemannIntegral.eq_UnsignedLebesgueIntegral` :7145）——1.1 节的整条线在此收编。1.3.4 节将在其上定义"绝对可积"（∫|f| < ∞）与 L¹。

## 7 FAQ 与反直觉清单

- **为什么积分取下积分而不是上积分？** 因为上积分不尊重单调收敛：对 f = 1/√x，limₙ U(min(f,n)) = 2（每个 min(f,n) 有界有限支撑，U = L；L(min(f,n)) ↑ L(f) = 2），但 U(f) = ∞（`eq_lim_vert_trunc_upper_isFalse` :2526）。"逼近列的积分极限"对上积分不是良定的；下积分两条截断极限都成立（:976、:1249）。
- **"∫f = lim ∫gₙ（gₙ 简单逼近 f）"会依赖逼近列吗？** 对 L 不会：L 是"所有逼近的积分"这个集合的上确界，天然唯一、与列无关。对 U 会：2 vs ∞（见上）。对非单调列，lim ∫gₙ 甚至给出互相矛盾的值——§1 的两条列 gₙ = n·1_{(0,1/n)} 与 gₙ = (1/n)·1_[0,1] 都逐点收敛到零函数，极限分别是 1 和 0。
- **书上的"水平/垂直截断"与仓库命名相反？** 是。书 p.53 习题 1.3.10(viii) 把 min(f(x),n) 叫 horizontal truncation（横着切一刀：值域封顶），(ix) 把 f·1_{|x|≤n} 叫 vertical truncation（竖着切一刀：支撑截断）；仓库 `Section_1_3_3.lean:975` 与 :1248 的名称恰好对调（条目编号相同，名字互换）。读代码以仓库为准，读书记住书上的名字。
- **尖峰列为什么不算 MCT 的反例？** MCT 要求 fₙ(x) ≤ fₙ₊₁(x) 对每个 x 成立。尖峰列在 (1/(n+1), 1/n) 上从 n 掉到 0，不单调。MCT 的逆命题也不成立：非单调序列换序也可能成功——例如 fₙ = (1 + (−1)ⁿ/n)·1_[0,1]：它交替高于、低于 1（f₁ = 0、f₂ = 3/2、f₃ = 2/3…），完全不单调，但逐点收敛到 1_[0,1]，∫fₙ = 1 + (−1)ⁿ/n → 1 = ∫1_[0,1]，换序照样合法——MCT 是充分条件不是必要条件。
- **Fatou 引理在哪里？** Tao 推论 1.4.46（§1.4.6，与 MCT 同节）：0 ≤ fₙ 任意（不单调）⟹ ∫liminf fₙ ≤ liminf ∫fₙ——"换序只丢不赚"的单向不等式。仓库未形式化（同 MCT，属 §1.4.6 内容，`Section_1_4_6.lean` 不存在）。
- **∞ 是合法的积分值吗？** 是：∫1_ℝ = ∞、∫(1/x² 于 (0,1)) = ∞ 都是正确结论。"可积"（1.3.4 的 absolutely integrable）才要求 < ∞。
- **1_ℚ∩[0,1] 的积分？** 0：与零函数 a.e. 相等（§2 已算：L 和 U 都是 0）。积分看不见零测集。
- **为什么定义 1.3.13 只收可测函数？** 不可测的 1_V（V 为 Vitali 集）：L(1_V) = 0 < 1 = U(1_V)（习题 1.3.12，:3911），且加性崩溃：L(1_V) + L(1_{C\V}) = 0 ≠ 1 = L(1_C)（:4476）。可测性是把 L、U、加性粘在一起的条件。
- **齐性为什么只对 c ≥ 0 的实数？** 习题 1.3.10(iii) 书明说 c = +∞ 时失败（"somewhat tricky"）；Lean 的 `hom`（:189）因此只收 c : ℝ。
- **截断极限需要 f 可测吗？** 需要：`eq_lim_vert_trunc` 与 `eq_lim_horiz_trunc` 都假设 `UnsignedMeasurable f`。这正是 1.3.2 的意义：可测类对逐点极限封闭，min(f,n) 与 f·1_{B(0,n)} 仍可测，积分才有意义。
