# 04 · 1.2.3 Vitali 不可测集：选择公理的影子

> Tao《An Introduction to Measure Theory》§1.2.3 讲稿式笔记 + Lean 形式化对照
> 一句话纲领：**上节预告的影子敌人今天登场。我们先把"一切集合都可测"这个朴素愿望写下来，看它怎么被四条底线（平移不变、可数可加、m([0,1])=1、全体子集可测）炸掉；然后顺着 ℝ/ℚ 商群把爆炸现场搭出来——Vitali 集 V，每陪集挑一个代表元，它的 ℚ 平移族既是 [0,1] 的覆盖又装得进 [−1,2]，于是 m(V) 被夹在"必须 = 0"和"必须 > 0"之间，无处安身。最后诊断病因：不是测度论的错，是选择公理的影子——Solovay 1970 说，不要 AC，一切集合都可测。**
> 形式化：`analysis/MeasureTheory/Section_1_2_3.lean`（688 行，本节核心）；书上的命题 1.2.18 与习题 1.2.26、1.2.27 全部机验。

## 1 这一幕要解决什么

还记得根号二的病吗？有理数不封闭极限，数学的痊愈方式是扩大数的世界——这是第一次发作。上一节开头我们看到第二次发作：Jordan 可测集不封闭"可数并"，痊愈方式是扩大集合的世界，把可数并请进来——这就是 1.2.2 整节干的事：设计"可测"牌照，宣布 σ-代数，让 m 在持牌集合上满足可数可加。当时我们留下了一个影子敌人：**为什么不能把牌照发给一切集合？** 为什么 σ-代数是一张过滤网，而不是整个幂集？

这一节要把这个影子敌人逼到台前，让它现出真身。我们的计划是这样：先替读者把那个朴素愿望说全——"一切集合都可测"听起来是美好的，但如果它和另外三条底线同时成立，数学就自爆了。那三条底线是：**平移不变**（把集合挪个位置，测度不变）、**可数可加**（不交的可数族并起来，测度相加）、**单位立方体测度 1**。这四条是任何"长度"概念的物理直觉：挪动不改变长度、拆分不改变总长、单位长度是 1。§1.2.3 的全部内容，就是证明这四条放一起必炸——而且爆炸的方式极其干净：造一个集合，它被拆成可数多个**全等的复制品**（平移拷贝），这些复制品拼起来至少是 [0,1]、至多是 [−1,2]，于是总长被夹在 1 和 3 之间；而每个复制品都和原集合一样长 t，可数可加说总长 = ∞ 个 t 之和。t = 0 时总长 0，装不下 [0,1]；t > 0 时总长 ∞，装不进 [−1,2]。**t 在 [0,∞] 里没有任何可去的地方。** 这就是"不可测集"的完整出场理由：不是我们造不出测度，是要求本身互相矛盾，必须牺牲一条——而牺牲的只能是"一切集合都可测"。

## 2 把炸药搭起来：ℝ/ℚ 商群与 Vitali 集

先动手做那个"拆不烂的集合"。直觉上，我们要找一族平移拷贝：互不相交、数量可数、覆盖 [0,1]、并集还有界。互不相交的平移拷贝意味着原集合的"平移周期"必须避开某些值：如果 A 和 A+q 相交，q 就不能作为平移量。什么集合的平移族能互不相交？答案是：**每个等价类只取一个代表**。

把 ℝ 按"差一个有理数"分家：x ~ y ⟺ x − y ∈ ℚ。这是个等价关系——传递性靠 ℚ 封闭减法：x − y ∈ ℚ 且 y − z ∈ ℚ 推出 x − z ∈ ℚ。每个等价类长什么样？看两个具体的。√2 的陪集是 √2 + ℚ = {√2 + q : q ∈ ℚ}，它包含 √2 − 1 ≈ 0.4142（取 q = −1，注意这里"平移 −1"），也包含 √2 − 2 ≈ −0.5858、√2 + 0.5 ≈ 1.9142——散落在整个实数轴上，可数多个点。3.7 的陪集是 3.7 + ℚ，包含 0.7（q = −3）、1.7、−0.3。每个陪集都可数（ℚ 可数，平移保持可数），而 ℝ 是不可数集——若只有可数个陪集，可数个可数集之并还是可数的，装不下 ℝ。所以陪集个数**不可数**；事实上它和 ℝ 一样多（每个陪集 ℵ₀ 个点，总点数 2^ℵ₀，所以 2^ℵ₀ = ℵ₀ × 陪集数 ⟹ 陪集数 = 2^ℵ₀）——**不可数多个陪集**，每个都是可数的点云。顺便注意一个呼应：上面那句"可数个可数集的并仍可数"本身用了一点弱选择（可数选择），这正是 Solovay 模型里 DC（依赖选择）恰好保住的部分——AC 的影子从论证的最底层就已经开始渗入。

现在关键的一步：每个陪集都要和 [0,1] 打交道。给定一个陪集的任意代表 r，我们要找一个有理数 q 使 r − q ∈ [0,1]，等价于 q ∈ [r − 1, r]（闭区间）。有理数在实数里稠密——而稠密性的力量比这更强：连**开**区间 (r − 1, r)（长度 1，夹着 r − 1/2）里也含有理数 q，于是 r − q ∈ (0,1) ⊆ [0,1]，比需要的还强一点。取开区间还是闭区间对这个论证无所谓（稠密性两者都保证），机器里用的是开区间版本：`coset_intersects_unit_interval` 的证明抓出的 q 落在 (r−1, r)，报出 r − q ∈ (0,1)。算一笔：r = √2 时，[√2 − 1, √2] ≈ [0.4142, 1.4142]，里面有理数 1 躺着，于是 √2 − 1 ∈ [0,1] 是 √2 那个陪集在单位区间里的代表；r = 3.7 时，[2.7, 3.7] 里有 3，代表是 0.7。这是仓库里的引理 `coset_intersects_unit_interval`（`Section_1_2_3.lean:34`），证明骨架：取陪集代表 r，用稠密性在开区间 (r−1, r) 里抓一个有理数 q，然后 r − q ∈ (0,1) ⊆ [0,1] 且 r − q 与 r 在同一陪集（差为 q ∈ ℚ）——机器里这一步落在 `Rat.isDenseEmbedding_coe_real.dense` 上。**这意味着什么**：每一个陪集都往 [0,1] 里伸进一只手，于是"每陪集挑一个落在 [0,1] 的代表"这件事有得挑——而"怎么挑"正是下一段的难题。

于是 Vitali 集的定义被逼出来了：**从每个陪集选一个落在 [0,1] 里的代表，收集起来**。但这正是问题的开始：要同时做**不可数多个**选择，而任何"统一规则"都行不通——最自然的候选（"取陪集在 [0,1] 里最小的代表"）直接失效：每个 [0,1]∩(r+ℚ) 都是稠密点集（陪集可数，而 r + ℚ 里差一个小数就变一个点，任何小区间都挤着它的点），没有最小元素、没有孤立点；更深刻的是，第 3 节末的定理将证明**任何可测的横截都不存在**——所以"规则"连"给出一个可测集"都做不到，必须调用选择公理。机器里一字不差：

```lean
noncomputable def VitaliSet : Set ℝ :=
  Set.range (fun c : RealModRat => (coset_intersects_unit_interval c).choose)
```

注意 `noncomputable` 这个词——这是 Lean 在说"这个定义绕不过选择公理"：`RealModRat` 就是商群 ℝ ⧸ ℚ（`Section_1_2_3.lean:31`），而 `(coset_intersects_unit_interval c).choose` 的 `.choose` 调用的正是 Hilbert 选择。选择公理在机器里的落点，和它在纸面证明里的落点，是同一个位置：**每个陪集恰好一个代表**。这一行定义同时保证了 V 的两条命根子：V ⊆ [0,1]（代表都落在单位区间里，`VitaliSet_subset_unit_interval`，`Section_1_2_3.lean:70`），以及**不同陪集的代表互不相同、同一陪集的代表只有一个**——后一条是整个论证的轴心，马上会用到。

## 3 三块积木与两把钳子：命题 1.2.18

V 造好了，现在让它承受四条底线。先立三块积木，全部是纯构造性的（不用 AC）。

**积木一（覆盖）**：每个 y ∈ [0,1] 都落在某个平移 V+q 里，且 q 只需取 ℚ∩[−1,1]。为什么？y 有自己的陪集，那个陪集在 V 里有代表 x ∈ [0,1]，同一陪集意味着 y − x ∈ ℚ，记 q = y − x。而 x, y ∈ [0,1] 把 q 夹在 [−1,1]：q ≥ −1 因为 y ≥ 0 且 x ≤ 1（0 减去 1 得 −1），q ≤ 1 因为 y ≤ 1 且 x ≥ 0（1 减去 0 得 1）。两个端点都能真的取到：若 y = 0 且它的陪集代表恰好是 x = 1（0 和 1 差 1 ∈ ℚ，同陪集，选谁都有可能），q = −1；若 y = 1、代表 x = 0，q = 1。所以平移幅度必须覆盖整个 [−1,1]，一个都不能省——这是 `unit_interval_covered_by_translates`（`Section_1_2_3.lean:76`）的骨架：找代表、同陪集、算界。**这意味着什么**：V 的 ℚ∩[−1,1] 个平移拷贝，可数多个，合起来吞掉了整个 [0,1]。而 ℚ∩[−1,1] 确实可数（`rat_Icc_countable`，`Section_1_2_3.lean:121`）且无限（−1, −3/4, −1/2, 0, 1/4, 1/2, 3/4, 1, …无穷下去，机器用单射枚举 `exists_injective_rat_enum_Icc` 把它排成 f : ℕ → ℚ，`Section_1_2_3.lean:357`）——可数性不是白来的：只有可数族，可数可加才有资格出场。

**积木二（不交）**：q₁ ≠ q₂ 时 (V+q₁) ∩ (V+q₂) = ∅。反证：公共点 z = v₁+q₁ = v₂+q₂，v₁, v₂ ∈ V。移项得 v₁ − v₂ = q₂ − q₁ ∈ ℚ——v₁ 和 v₂ 落在同一个陪集里！但 V 每个陪集只选一个代表，所以 v₁ = v₂，于是 q₁ = q₂，与假设矛盾。关键一步就是"每陪集一个代表"这条定义性质（`VitaliSet.translates_pairwise_disjoint`，`Section_1_2_3.lean:372`；机器里最后靠 `Rat.cast_injective` 从实数值等式抽回有理数等式）。**这意味着什么**：这族拷贝既是覆盖又是拼图——可数可加的条件（不交 + 可测）全齐了，只差"可测"。

**积木三（可测与读数）**：假设 V 可测（我们要证这是错的，先假设）。先把逻辑结构说清：矛盾的完整形式是"V 可测 ⟹ 爆炸"，即 V 不可测；四条底线里的第四条（一切集合可测）承诺了 V 可测，于是四条同时成立 ⟹ 爆炸。证明本身只用一、二、三推矛盾，第四条负责把 V 送进矛盾现场。于是每个平移 V+q 也可测（`LebesgueMeasurable.translate`，`Section_1_2_2.lean:7023`），且 m(V+q) = m(V)（平移不变性，`Lebesgue_measure.translate`，`Section_1_2_2.lean:7057`）。可数可加（`Lebesgue_measure.countable_union`，`Section_1_2_2.lean:2398`）把两块积木焊在一起：

```
m(⋃ₙ (V+qₙ)) = Σₙ m(V+qₙ) = Σₙ m(V)
```

现在两把钳子夹这个等式。**上钳**：每个 V+q ⊆ [−1,2]（V ⊆ [0,1] 加上 q ∈ [−1,1]，两点相加：0 + (−1) = −1 到 1 + 1 = 2），所以 ⋃ₙ (V+qₙ) ⊆ [−1,2]，单调性（`Lebesgue_outer_measure.mono`，`Section_1_2_1.lean:74`）给出 m(⋃) ≤ m([−1,2])。而闭区间测度 = 长度，m([−1,2]) = 2 − (−1) = 3——注意这个 3 **不是新假设**：m([−1,2]) = m([−1,0]) + m([0,1]) + m([1,2])，三段各长 1 且两两平移全等，有限可加（可数可加的特例）加底线三 m([0,1]) = 1 就够了。机器里由引理 `Lebesgue_measure.Icc_eq`（`Section_1_2_3.lean:125`）在 :334 处代入 a = −1, b = 2 报出 3（它的依据是"盒体积 = 边积"这一初等测度的定义性质，同一个事实）。**下钳**：⋃ₙ (V+qₙ) ⊇ [0,1]（积木一），单调性反向给出 m(⋃) ≥ m([0,1]) = 1 − 0 = 1（:282 代入 a = 0, b = 1 报出 1）——这正是底线第三条本身。合起来：

```
1 ≤ Σₙ m(V) ≤ 3
```

设 t = m(V)。测度非负（`Lebesgue_outer_measure.nonneg`，`Section_1_2_1.lean:85`），t 只有两种可能。t = 0：Σₙ 0 = 0，而 0 ≥ 1，矛盾（机器里这个分支在 :240–:291，`tsum_zero` 求和，`1 ≤ 0` 当场被 `norm_num` 毙掉）。t > 0：可数个相等的正数相加在扩展实数里发散到 ⊤（`EReal.tsum_const_eq_top_of_pos`，:300–:303），而 ⊤ ≤ 3 不可能。扩展实数 [0,∞] 就是把 +∞ 收编成正式成员（记作 ⊤）：加法部分定义（t + ⊤ = ⊤），序关系里 ⊤ 是最大元，级数 Σₙ aₙ 定义为部分和的递增上确界——正项发散时这个上确界就是 ⊤，所以"Σₙ t = ⊤"不是粗略说法，是扩展实数里的**精确等式**。机器里的收尾很漂亮：`(3 : EReal) ≠ ⊤` 且 3 ≤ ⊤，由反对称性若 ⊤ ≤ 3 则 3 = ⊤，矛盾（:343–:344）。想完全避开 ⊤ 也可以：t > 0 时有限可加给出 m(⋃) ≥ n·t 对一切 n，取 n 使 n·t > 3（阿基米德性质），与 m(⋃) ≤ 3 矛盾——这正是习题 1.2.26 的算法，机器只是把同一件事写成了 ⊤ 的语言。这就是定理 `VitaliSet.nonmeasurable`（`Section_1_2_3.lean:145`），书上命题 1.2.18 的核心；把"V 不可测"包装成"存在 [0,1] 里的不可测子集"就是 `LebesgueMeasurable.nonmeasurable`（`Section_1_2_3.lean:347`，`∃ E ⊆ [0,1]，¬ LebesgueMeasurable E`）。

**这意味着什么**——三件事。第一，四底线不可兼得是**定理**，不是感觉：任何翻译成公理的"长度"都必须牺牲"一切集合可测"。第二，注意矛盾发生在"可数可加"这一条上：V 的拷贝族是**可数**不交族，它的可数可加性直接撞上"装不下也盖不满"——若把可数可加砍成有限可加（回到 Jordan 的有限并世界），Σₙ m(V) 根本写不出来，矛盾消失；但那个世界连 ℚ∩[0,1] 都量不了（1.2.1 节），没有回头路。所以不可测集正是"为什么可数"的活证据：可数可加、可数并、不可测集是同一块拼图的碎片。第三，也是最需要消化的：**m(V) 不是"某个未知的正数"**，它连被安置成任何数字的可能性都没有——t 在 [0,∞] 里走投无路。这就是"不可测"的精确含义：不是量不出来，是**任何读数都会引爆矛盾**。

## 4 诊断：是选择公理的影子，不是测度论的错

现在做尸检：矛盾从哪一步渗进来的？把 §2–§3 的证明拆成四块。陪集分解 ℝ = ⊔ (r+ℚ)——加群商分解，不用 AC；每陪集与 [0,1] 相交——有理数稠密，不用 AC；ℚ∩[−1,1] 可数枚举——ℚ 可数，不用 AC；不交性、覆盖、夹逼——纯集合论与可数可加，不用 AC。**唯一不可替代的一步是"每陪集选一个代表"**——那是选择公理。Lean 把这一诊断写在了脸上：`VitaliSet` 是 `noncomputable def`，`.choose` 就是 AC；而它之前的三块积木全部是普普通通的 lemma。

这个诊断有元数学上的判决，先把术语交代清楚再下结论。ZF 是"**没有选择公理的那部分集合论**"（策梅洛–弗兰克尔公理系统）；ZFC 是 ZF + AC；DC（依赖选择）是介于两者之间的弱选择公理——它允许沿一条链做可数步的连续选择，测度论里日常用到的选择（可数并、可数覆盖的"每处取一个"）大多是这个量级。Solovay 1970 证明了：**在 ZF + DC 的某个模型（一个满足这些公理的数学宇宙）中，实数的一切子集都是 Lebesgue 可测的**——不可测集在那个宇宙里根本不存在。技术上这件事不是免费的：证明那个模型的一致性需要大基数假设（ZFC 与"存在不可达基数"一致；"一致" = 不会推出矛盾，"不可达基数"是一种大到无法从通常公理构造出来的无穷基数）。读者只需记住判决本身：**不可测集的存在要以超过 DC 的选择公理为代价——ZF + DC 推不出"存在不可测集"**。Tao 在命题 1.2.18 之后正是这么总结的（上一节笔记开头引的 Solovay 预告在这里兑现）。换句话说：不可测集不是实数空间的属性，不是"长度"概念的缺陷，而是**选择公理的副产品**——AC 承诺从不可数多个非空集合里"凭空"各取一物，Vitali 集就是这份承诺的账单。这也解释了为什么"可测"只能是一张过滤网：网眼要拦住的不只是"坏集合"，是 AC 塞进来的幽灵。σ-代数不是官僚主义的保守，是唯一能同时保住平移不变、可数可加和 m([0,1]) = 1 的结构。顺带一提，8.4 节预告的 Banach–Tarski 悖论（§7.3）和这里同根同源——同一个 AC，同一份账单，只是金额更大。

## 5 两道余震：外测度不可加、投影不可测

不可测集的存在不是终点，它立刻震出两个习题级的后果，仓库全部机验。

**余震一（习题 1.2.26）：外测度不能有限可加。**（记号速查，接下来三种尺子要分清：m\* = Lebesgue 外测度，对**一切**集合有定义（1.2.1 节）；m = Lebesgue 测度，即外测度在可测集上的名字（1.2.2 节）；m\*₋ = 内测度，仅对有界集合定义（习题 1.2.18，上节笔记 §8）。）先看 V 的户口：V ⊆ [0,1]，所以有界（机器证明 V 装在以 0 为心、半径 3 的闭球里），外测度有限（≤ m\*([0,1]) = 1），且 > 0——若 m\*V = 0，零测集可测（`IsNull.measurable`，`Section_1_2_2.lean:359`），V 就拿到牌照了，与 §3 矛盾。这就是 `vitali_bounded_pos_finite`（`Section_1_2_3.lean:414`）：**有界、正外测度、有限外测度**——三条"看起来很好量"的特征集于一身，仍然不可测。这与 1.2.2 节的 Cantor 集形成完美的对偶：Cantor 集紧、不可数、零测，可测；Vitali 集有界、正外测度、有限，不可测——"不可数"不杀死可测性，"有界"也不拯救可测性。现在假设外测度对一切有界不交对有限可加（反证）：记 r = m\*V > 0，对平移族 Tₙ = V + qₙ 归纳地拆 ⋃_{k<n} Tₖ（每一块都有界、与前块不交——这两条正是假设的适用条件），得到 m\*(⋃_{k<n} Tₖ) = n·r（`Section_1_2_3.lean:533`–:599，机器用归纳 + `ring` 结算）。但 ⋃_{k<n} Tₖ ⊆ [−1,2]，所以 n·r ≤ 3 对**一切** n（:600–:622）。取 N > 3/r（阿基米德性质）：算两笔，若 r = 0.1，则 3/r = 30，N = 31 就够，31 × 0.1 = 3.1 > 3，矛盾；若 r = 0.001，N = 3001，3001 × 0.001 = 3.001 > 3，照样爆。注意这个证明的怪脾气：它从头到尾**不点名 E、F 是谁**——纯存在性反证（`by_contra` 一口气推到底），这是数学里少见的"反例存在但拒绝给出显式构造"，因为任何显式构造都得先解决"每陪集选代表"这个 AC 问题。**这意味着什么**：外测度的 ≤ 号不是技巧欠缺，是铁律——可数可加是持牌集合的专利，无牌集合连有限可加都不配。

**余震二（习题 1.2.27）：可测集的投影不必可测。** 上二维空间 ℝ²，把 V 平放在 x 轴上：E = V × {0}。E 是可测的——它甚至零测：E ⊆ [0,1]×[0,0]，而 [0,1]×[0,0] 是长宽各 1 和 0 的盒子，体积 1 × 0 = 0（`vitali_line_isNull`，`Section_1_2_3.lean:635` 机验这条线零测），零测集可测。但把 E 投影到 x 轴，投影就是 V 本身——不可测（`Section_1_2_3.lean:656`，投影等式 :676 一行 `ext` 配平）。**这意味着什么**：投影丢失了第二坐标的全部信息，把零测的好集合"洗"成了不可测集。这就是为什么 σ-代数公理只对**原像**、可数并、可数交换门，却绝不能对连续像关门——投影就是连续映射，若可测集对连续像封闭，V 就拿到牌照了，§3 的爆炸会隔着投影再炸一次。内测度判据（`inner_measure.eq_iff`，`Section_1_2_2.lean:6476`）给这道裂口定标：判据说 m\*₋(E) = m\*(E) ⟺ E 可测；V 有界所以内测度有定义，且恒有 m\*₋(E) ≤ m\*(E)（`inner_measure.le`，:4566），于是 V 不可测 ⟹ 严格小于——"内 < 外"第一次有了活标本（具体数值依赖代表元的选择，没有确定值）。

## 6 FAQ 与反直觉清单

1. **为什么平移量偏偏选 ℚ，不选别的群？** 三个性质缺一不可：ℚ 是群（平移构成置换）、ℚ 可数（可数可加才有资格出场）、ℚ 稠密（每陪集伸进 [0,1]）。换成 2ℤ 也可数但稠密性没了，每陪集不一定碰到 [0,1]；换成 ℝ 稠密但不可数，可数可加用不上，Σ 无从谈起。
2. **为什么陪集个数不可数？** 每个陪集 r+ℚ 可数，而 ℝ 是它们的无交并；可数个陪集只能装下可数多个点，装不满 ℝ，所以陪集个数是 2^ℵ₀。V 每陪集取一个代表，所以 |V| = |ℝ|——V 和 [0,1] 一样"多"，只是被拆得七零八落。
3. **m(V) 为什么不能是某个正数 a？** 代入钳子：Σₙ a = ⊤（可数个相等的正数发散），而 ⊤ ≤ 3 不成立。为什么不能是 0？1 ≤ Σₙ 0 = 0 不成立。非负性把 t 的所有可能值分进这两类，于是 t 无处可去——"不可测"不是说"测度未知"，是说"任何读数都爆炸"。
4. **这个构造是不是太"不诚实"了（noncomputable）？** 是——而这正是重点。`VitaliSet` 的 `noncomputable` 是本质属性不是偷懒：定理本身证明了任何可测的横截（每陪集取一代表且可测）不存在，所以不可能有可计算的构造。AC 的账单必须用 AC 的货币支付。
5. **那测度论是不是废了？** 不是。可测集已经足够丰富（1.2.2 的户口普查：开、闭、零测、可数并交补全持牌，加上内外正则性），而且 Solovay 定理说明不可测只是 AC 的影子——在 DC 的世界里根本没有这回事。σ-代数的存在意义恰恰是：**用最小的牺牲（放弃部分子集）换最大的保全（平移不变 + 可数可加 + 单位立方体）**。
6. **为什么 Lean 能证"存在不可测集"，Solovay 却说可以一切可测？** 不矛盾：Lean 的根基是经典逻辑 + 选择公理（mathlib 的 `Classical.choice` 是公理），它形式化的是 ZFC 下的定理"∃ E ⊆ [0,1]，不可测"。Solovay 是元数学结论：存在**没有（全）AC 的模型**（ZF + DC）里一切集合可测。用第 4 节的术语说：同一个句子"∃ E ⊆ [0,1]，不可测"在 ZFC 的模型里为真、在 Solovay 模型里为假——定理的真值随公理系统而变，这正是"不可测集是选择公理的影子"的精确含义。
