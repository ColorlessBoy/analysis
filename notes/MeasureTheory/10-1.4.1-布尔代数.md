# 10 · 1.4.1 布尔代数：把"封闭性"从 ℝᵈ 里抽象出来

> Tao《An Introduction to Measure Theory》§1.4.1 讲稿式笔记 + Lean 形式化对照

## 1 这一幕要解决什么

把这个故事再讲一遍，因为它是全书的呼吸节奏。有理数 ℚ 对加减乘除封闭，却对极限不封闭：√2 = 1.4, 1.41, 1.414, … 这一串有理数无限逼近它，极限却不在 ℚ 里。数学的痊愈方式不是怪罪极限，而是把数的世界扩大成 ℝ，让极限住进来。这是"根号二 PTSD"第一次发作。

1.2.2 是第二次发作的现场：每个单点 {qₙ} 都是 Jordan 可测的、测度 0，但它们的可数并 ℚ∩[0,1] 不是 Jordan 可测的——**Jordan 可测集对"可数并"不封闭**。痊愈方式同前：把集合的世界从 Jordan 扩大成 Lebesgue，让可数并住进来。1.2.2 的户口普查（引理 1.2.13 七连）就是这场手术的缝合线：开、闭、零测、空、补、可数并、可数交，全部留在可测集的世界里。

现在到 1.4.1，我们退后一步，问一个更狠的问题。户口普查的七条结论里，哪些是**结构性的**——只依赖"集合族的组合封闭性"，不依赖 ε、开集、外测度这些 ℝᵈ 的具体血肉？逐条审视：开集可测用了"开集 U ⊇ E 使 m*(U\E) ≤ ε"，这是分析；闭集可测用了紧致 + 分离可加性，这是分析；零测集可测用了盒覆盖，这是分析。但"空集可测""补集可测""**有限**并可测"这三条，却是纯组合的——它们不需要任何实数，只需要集合运算本身。1.2.2 的证明（`LebesgueMeasurable.boolean_algebra`，`Section_1_4_1.lean:130`）用到 `LebesgueMeasurable.empty/complement/union`，全是机械的集合运算。

而分析的全部工作（开集逼近、ε/2ⁿ 预算），最后都浓缩成一个词：**可数**。可数并是分析砸钱砸出来的；有限并是结构白送的。

于是本章 1.4 的纲领出现了：把"结构"和"分析"分开，先研究纯结构的那个骨架。这就是布尔代数——它是 1.4.1 的全部内容。下一节 1.4.2 在这个骨架上再加一条"可数并封闭"，得到 σ-代数，分析的血肉重新灌注回来。本节先把骨架立稳：它有多大（能装下我们造过的所有集合族）、它有多小（有限并而已，可数并会跑出去）、它怎么被生成（从一盒盒盒出发能走多远）。

## 2 精确定义：三条条款是被逼出来的

先走一遍"重新发明"。你要给"集合族"立规矩，让它能承载测度。最自然的朴素方案是**全幂集 2^X**：一切集合都可测，还要什么封闭性？这个方案死在 1.2.3：Vitali 构造（在 ℝ 上按 ℚ 的陪集打散取代表元）证明平移不变的可数可加测度在 2^ℝ 上不存在——幂集太大，装不下一个诚实的测度。此路不通。

那换个方案：只要**有限可加**（finite additive）总行了吧？也不行——有限可加测度确实存在（构造需要选择公理，细节超出本节），但它撑不起单调收敛定理（积分版的，笔记 07），撑不起积分理论。测度论要的是可数可加，而可数可加在一个族上成立，首先要求这个族本身对可数并可测有交代。所以正确的问法不是"让所有集合都可测"，而是"找出一个足够大的族，使可测的运算封闭性成立"，再在这个族上定义测度。

那族的最小骨架是什么？回看 1.2.2 户口普查里那三条纯组合的结论，逐条变成公理：空集可测（iv）、补集可测（v）、有限并可测（vi 的免费附赠，`LebesgueMeasurable.finite_union`，`Section_1_2_2.lean:733`）。就这三条，一个不多。这就是 Tao 的定义 1.4.1，Lean 里一字不差（`Section_1_4_1.lean:13`）：

```lean
class ConcreteBooleanAlgebra (X : Type*) where
  measurable : Set X → Prop
  empty_mem : measurable (∅ : Set X)
  compl_mem : ∀ E, measurable E → measurable Eᶜ
  union_mem : ∀ E F, measurable E → measurable F → measurable (E ∪ F)
```

注意第三条是**有限**并：两两并加归纳（`finset_union_mem`，`Section_1_4_1.lean:848`，习题 1.4.7 的零件）就给出任意有限并。为什么不肯多给一条"可数并"？因为那是分析砸钱买的，不是结构白送的——本节先把结构立住，下一节 1.4.2 再加码。这个"少一条"的克制，正是 1.2.1 的教训：Jordan 可测集对可数并不封闭（ℚ∩[0,1]），所以"有限"这个台阶必须单独存在，不能假装它够用。

定义落地，立刻验两笔账（书的例 1.4.3）。取 X = {1,2,3}。最大族 2^X：8 个集合，全部可测——`instOrderTop`（`Section_1_4_1.lean:48`），它是偏序下的顶。最小族 {∅, X}：只有 2 个集合，空集是公理给的，X = ∅ᶜ 由补封闭补出来——`instOrderBot`（`Section_1_4_1.lean:60`），底。两个都是布尔代数：最大那个每条公理平凡成立；最小那个，∅ ∪ X = X ∈ 族、∅ᶜ = X、Xᶜ = ∅，验证完毕。数字：8 = 2³，2 = 2¹——之后会看到这不是巧合。

三条公理自动发酵出第四条：**有限交**。E ∩ F = (Eᶜ ∪ Fᶜ)ᶜ，De Morgan 两次应用补封闭和并封闭——`inter_mem`（`Section_1_4_1.lean:189`）。证明骨架就这一行等式；关键一步是"用补把交翻译成并"，这正是布尔代数与命题逻辑的同构：∩ ↔ ∧、∪ ↔ ∨、ᶜ ↔ ¬。由交和补再白送差集 E\F = E ∩ Fᶜ 和对称差 E△F = (E\F) ∪ (F\E)。Tao 的 Remark 1.4.2 说：∅、X 都在族里，且族对有限交、差、对称差封闭。Lean 把这条 remark 做成更硬的东西：`toBooleanAlgebra`（`Section_1_4_1.lean:235`）把每个 `ConcreteBooleanAlgebra`（一个集合族）升格成 Mathlib 序理论里的 `BooleanAlgebra`（一个格）。"格"（lattice）若没见过：这是"任意两元都有最小上界 sup 与最大下界 inf"的偏序结构；集合族按包含 ⊆ 排序时，sup = 并、inf = 交，所以这里 `toBooleanAlgebra` 只是把 ∪、∩、ᶜ 重新命名为格运算并逐条验证格公理（分配律 `le_sup_inf` 是其中唯一需要动手的，其余靠集合包含的传递性）。这意味着：**集合族意义上的布尔代数与格论意义上的布尔代数是同一个对象的两副面孔**——这也是"布尔"二字的出处，见 FAQ。

还有一条免费的自相似性质：布尔代数限制到子集上仍是布尔代数。`restrict`（`Section_1_4_1.lean:195`，习题 1.4.2）：把 B 限制到 A ⊆ X，可测集取"B 可测集在 A 上的原像"——这里"原像"指包含映射 ι : A ↪ X（Lean 的 `Subtype.val`）下的原像，即 E = ι⁻¹(E') = E' ∩ A，其中 E' ∈ B；补封闭靠 `Set.preimage_compl`，并封闭靠 `Set.preimage_union`，都是集合运算的机械搬运。`restrict_iff`（`Section_1_4_1.lean:214`）补充说：若 A 本身可测，则限制后的可测集恰好是"B 可测的 A 子集"。这意味着抽象测度论里"测度可以随便限制到子空间"不是奇迹，是结构自带的。

## 3 原生例子：我们一路造出的集合族全是布尔代数

定义的意义要用它覆盖我们已经认识的世界来检验。1.1.1 到 1.2.2 我们造了四条集合族，这一节把它们全部重新命名为"布尔代数"，并且按包含排成一条链（`Section_1_4_1.lean` 的 79–186 行就是这条链的出生证明）：

```
初等代数 ⊆ Jordan 代数 ⊆ Lebesgue 代数 ⊇ 零测代数
```

逐个看。**初等代数**（习题 1.4.1，`elementary_boolean_algebra`，`Section_1_4_1.lean:79`）：`measurable E := IsElementary E ∨ IsElementary Eᶜ`。注意这个"∨ Eᶜ"的条款不是装饰——初等集是有界的（`IsElementary.isBounded`，`Section_1_1_2.lean:244`），而有界集的补无界，永远不可能是初等集；没有这条"或"，补封闭当场破产。这正是抽象化逼出来的细节：书的例子里一句"初等集对补封闭"带过，Lean 必须把有界性造成的裂缝补上。数字检验，d = 1：E = [0,1) ∪ [2,3] 是两个盒的有限并，初等，直接过关；它的补 ℝ∖([0,1)∪[2,3]) = (−∞,0) ∪ [1,2) ∪ (3,∞) 无界，不是初等集，但 E 本身初等，∨ 条款放行。`union_mem` 的证明骨架：四个 case（E、Eᶜ 各两种可能）分别用初等集的并、差、交封闭（`IsElementary.union/sdiff/inter`，`Section_1_1_1.lean:678/886/712`）。

**Jordan 代数**（例 1.4.4，`JordanMeasurable.boolean_algebra`，`Section_1_4_1.lean:101`）：同样的 ∨ 条款，因为仓库的 Jordan 可测定义里含有界性（`JordanMeasurable := Bornology.IsBounded E ∧ Jordan_inner_measure E = Jordan_outer_measure E`，`Section_1_1_2.lean:30`）。数字例：[0,1] 有界且内外测度都等于 1，Jordan 可测；[0,1]ᶜ 无界，靠 ∨ 条款进入代数。包含关系 `JordanMeasurable.gt_elementary_boolean_algebra`（`Section_1_4_1.lean:121`）：初等 ⇒ Jordan（1.1.2 的成果，`IsElementary.jordanMeasurable`）。

**Lebesgue 代数**（例 1.4.5，`LebesgueMeasurable.boolean_algebra`，`Section_1_4_1.lean:130`）：不需要 ∨ 条款——Lebesgue 可测集没有有界性限制（定义在 `Section_1_2_0.lean:2291`），补封闭直接成立。`gt_jordan_boolean_algebra`（`Section_1_4_1.lean:138`）：Jordan ⇒ Lebesgue（1.2.2 的户口普查）。这条链到这里就是 1.2.2 引理 1.2.13 的浓缩版。

**零测代数**（例 1.4.6，`IsNull.boolean_algebra`，`Section_1_4_1.lean:161`）：`measurable E := IsNull E ∨ IsNull Eᶜ`，其中 `IsNull E := Lebesgue_outer_measure E = 0`（`Section_1_2_2.lean:356`）。这个代数有意思：它同时装零测集（ℚ∩[0,1]，m* = 0）和余零测集（[0,1]∖ℚ，补集零测）。并封闭需要新定理 `IsNull.union`（`Section_1_4_1.lean:146`）：E、F 都零测 ⇒ E∪F 零测。证明骨架：m*(E∪F) ≤ m*E + m*F = 0 + 0（外测度次可加，`Lebesgue_outer_measure.finite_union_le`，`Section_1_2_1.lean:442`）与 m*(E∪F) ≥ 0（非负）夹逼。关键一步：**可加性是奢侈品，次可加 + 非负足够**——0 ≤ m*(E∪F) ≤ 0。零测代数 ⊆ Lebesgue 代数（`lt_lebesgue_boolean_algebra`，`Section_1_4_1.lean:181`，用 1.2.2 的"零测 ⇒ 可测"）。这意味着什么：**零测世界在布尔运算下自给自足**——"几乎处处"这种语言（1.3.5 一直在用）不需要离开零测代数就能闭门造车。

## 4 反例一：可数并跑出初等代数（ℚ∩[0,1] 三度出场）

链建好了，现在检验它的边界。ℚ∩[0,1] 在初等代数里吗？逐项排查：它是单点的可数并 ℚ∩[0,1] = ⋃_{q∈ℚ∩[0,1]} {q}，而**每个单点是初等集**——退化盒，`singleton_isElementary`（`Section_1_4_1.lean:1271`，机验：把 {x} 写成每边都是 [xᵢ, xᵢ] 的盒）。可数并的每个成员都在初等代数里，但并本身不在：

- ℚ∩[0,1] 不是初等集。论证一（连通分支）：d = 1 时每个盒是一个区间，有限盒并是有限个区间的并，至多有有限个连通分支。而 ℚ∩[0,1] 的连通分支全是单点：任取两点 a < b，中间夹一个无理数 r ∈ (a,b)（ℝ∖ℚ 稠密）；因为 C ⊆ ℚ 而 r ∉ ℚ，所以 r ∉ C，于是 C = (C∩{x<r}) ∪ (C∩{x>r}) 是两个不相交的非空相对开集之并——任何含 a、b 两点的连通子集都会被这样切开，分支只能是单点。分支**无限多个**（可数多个），不可能是有限个区间的并。论证二（更省）：若 ℚ∩[0,1] 是有限个盒的并，每个盒 ⊆ ℚ∩[0,1] 且含两个以上点必含无理数（无理数稠密），故每个盒只能是空集或单点，有限并是有限集，矛盾于 ℚ∩[0,1] 无穷。
- ℚ∩[0,1]ᶜ 也不是初等集：它是无界的（(−∞,0) ∪ (1,∞) ⊆ 补集），而初等集有界（`IsElementary.isBounded`）。

两条路都堵死，所以 ℚ∩[0,1] 不可测于初等代数——**初等代数不封闭于可数并**。而 ℚ∩[0,1] 是 Lebesgue 可测的（零测，1.2.2 户口普查 (iii)）。于是完整的失败画面：可数并的每个零件（单点）都在初等代数里，可数并的产物（ℚ∩[0,1]）却跑到 Lebesgue 代数里去了。这就是 1.2.1 教训的抽象版本：Jordan 的失败不是 Jordan 特有的，是**所有布尔代数共有的**——只要你的世界只对有限并封闭，稠密的可数并就能逃出去。下一节 1.4.2 的 σ-代数，就是把这个洞补上。诚实标注：这个反例的结论（"ℚ∩[0,1] ∉ 初等代数"）在 Lean 里没有直接形式化的定理（待证），但它的两个零件——单点初等（:1271）与初等集有界（`Section_1_1_2.lean:244`）——都是机器验证过的。

## 5 核心定理：有限布尔代数 = 原子代数，可测集数 = 2ⁿ

布尔代数可以任意大（幂集），也可以很瘦（{∅, X}）。有限情形下能说什么？答案是一整串漂亮的定理：**有限布尔代数的可测集数必是 2 的幂，而且每个可测集都是"原子"的并**。这是本节的心脏。

先造"原子"这个概念。固定有限布尔代数 B（可测集族有限，`(B.measurableSets).Finite`）。对每个点 x ∈ X，定义它的原子为"所有含 x 的可测集的交"（`atom`，`Section_1_4_1.lean:883`）。为什么这个构造在有限情形才能落地？因为"所有含 x 的可测集"可能无穷多个，无穷交不保证留在族里；有限性（`atom_set`，:873）保证它是**有限交**，而有限交可测（`finset_inter_mem`，:887）——这正是"有限"条款的又一次出力。三个立即的引理：原子可测且含 x（`atom_measurable` :899、`mem_atom_self` :906）；原子是最小的含 x 可测集（`atom_subset` :915）；z ∈ atom(x) ⇒ atom(z) = atom(x)（`atom_eq_of_mem` :921）。最后这个要两边夹：半边 atom(z) ⊆ atom(x) 直接由 `atom_subset`（z ∈ atom(x)，取 E = atom(x)）；另半边先证 x ∈ atom(z)——反证：若 x ∉ atom(z)，则 (atom z)ᶜ 是含 x 的可测集（补封闭），`atom_subset` 给 atom(x) ⊆ (atom z)ᶜ，而 z ∈ atom(x)，于是 z ∈ (atom z)ᶜ，与 z ∈ atom(z) 矛盾；于是 `atom_subset` 再给 atom(x) ⊆ atom(z)。关键一步是补集的使用：**含 z 的可测集未必含 x，但含 x 的可测集必须含 z 的"对偶"陈述用补集强制出来**。

于是不同原子互不相交、覆盖全空间（`atom_partition`，`Section_1_4_1.lean:987`），并且**可测集 ⟺ 原子的并**（`measurable_iff_union_atoms`，:1020）。前一个方向的骨架：E 可测时，E = ⋃{atom(x) | x ∈ E}，每个 atom(x) ⊆ E（`atom_subset`），反向包含靠 `mem_atom_self`。后一个方向靠"原子子集的任意并只有有限多个（原子族有限，`Atoms_finite` :948），有限并可测"。把这两条拼起来就是结构定理（`atomic_of_finite`，`Section_1_4_1.lean:1070`）：

> **定理（有限布尔代数是原子的）**：若 (B.measurableSets) 有限，则 B 由某个划分（partition）生成：∃ 划分 parts，B = parts.to_ConcreteBooleanAlgebra。

证明骨架：取 AtomType = 全体不同原子（:983），`atom_partition` 给划分，`measurable_iff_union_atoms` 给相等。关键一步正是"有限交的原子定义"。

推论（`card_of_finite`，`Section_1_4_1.lean:1079`）：**可测集数 = 2^(原子数)**。证明骨架：映射 S ↦ ⋃_{A∈S} A 在"原子子集"与"可测集"之间建立双射（单射性用原子互不相交：并相等 ⇒ 对每个原子，它含的点落入同一个并 ⇒ 原子本身属于 S，`card_of_finite` 的证明花了 70 行做这件事）；于是 ncard = 2^(A.ncard)，`Set.ncard_powerset`。

数字检验。X = {1,2,3}，B = {∅, {1}, {2,3}, X}（"由 {{1}} 生成"——"生成"的正式定义在第 7 节，这里先给手算验证：任何含 {1} 的代数必须含 {1}ᶜ = {2,3}，以及 ∅ 与 X = ∅ᶜ，所以这四者是下界；而这四个集合恰好封闭：补集分别是 X、{2,3}、{1}、∅，都在；并的配对里唯一要动手的是 {1}∪{2,3} = X，其余配对含 ∅ 或 X，立即封闭。故它是最小含 {1} 的代数）。原子：点 1 的原子 = 所有含 1 的可测集之交 = {1}∩X = {1}；点 2 的原子 = 所有含 2 的可测集之交 = {2,3}∩X = {2,3}；点 3 同 {2,3}。原子数 2，可测集数 4 = 2²。✓ 再看 {∅, X}：点 1 的原子 = 所有含 1 的可测集之交 = X（只有 X 一个可测集含 1），整个 X 是一个原子，可测集数 2 = 2¹。✓ 再看 X = {1,2,3} 的幂集：原子 {1},{2},{3}，可测集数 8 = 2³。✓ 三个数字例覆盖 n = 1, 2, 3。

这个定理意味着什么：**有限情形的测度论就是计数**——你数清原子，测度不过是给每个原子一个非负权重，全体可测集的测度由原子的权重相加得到（这正是 1.4.3 会在有限情形建立的"测度 = 原子的权重函数"的图像，届时 premeasure 登场）。有限的布尔代数世界是离散的、可数的、完全透明的。

配套的还有原子与划分的词典。`IsPartition`（`Section_1_4_1.lean:301`）= 两两不交 + 并成全空间；每个划分生成一个布尔代数（`IsPartition.to_ConcreteBooleanAlgebra`，:305，例 1.4.7）：可测集 = 划分件的并。两个极端：单点划分生成幂集（`top_atomic`，:364），平凡划分生成 {∅, X}（`bot_atomic`，:382）。`IsAtom`（:1162）= "非空可测且无非空真可测子集"——划分件恰好是 IsAtom（`part_is_atom`，:1165），两个 IsAtom 相交非空则相等（`atom_eq_of_inter`，:1180），所以一个划分的"真正的原子"就是那些非空的划分件。习题 1.4.3 的 `boolean_algebra_eq_iff`（:800）说：两个原子代数的相等 ⟺ 去掉空件后划分件逐一对上（relabel）。这意味着"原子代数的结构 = 一个集合族 (I, parts)，不计指标重命名"——这是把"测度空间"理解成"带权原子的集合"的第一步。

## 6 原子代数与非原子性：连续世界的布尔代数

离散世界的结构定理（§5）说：有限代数 = 原子代数。现在要问：连续世界（ℝᵈ 上的大代数）还有原子吗？为了问这个问题，得先把"原子代数"本身造出来——书的例 1.4.7。

给定 X 的一个划分 parts : I → Set X（两两不交且并成全空间，`IsPartition`，`Section_1_4_1.lean:301`），定义它的原子代数为 `measurable E := ∃ J : Set I, E = ⋃ i ∈ J, parts i`——**划分件的任意并**，指标集 J 不限于有限（`IsPartition.to_ConcreteBooleanAlgebra`，:305）。请务必盯住这个"任意"：(i) 它自动含全空间 X：取 J = 全指标集（若只允许有限并，ℝᵈ 是无穷多个有界立方体之并，自己都进不了族——所以"任意并"条款不是装饰，是设计）；(ii) 自动补封闭：E = ⋃_{i∈J} parts i 的补是 ⋃_{i∉J} parts i（划分件拼满全空间）；(iii) 自动并封闭：J₁ ∪ J₂。三条款全部白送，原子代数事实上对**任意并**都封闭——闭得不能再闭，它自动是 σ-代数级别的对象。这与 §2 的"有限并可测"公理是两回事：公理是最低要求，原子代数自带的是最高能力。

数字例，d = 1，取尺度 1 的划分件 [k/2, (k+1)/2)，k ∈ ℤ。成员检查：[0,1) = [0,1/2) ∪ [1/2,1)，J = {0,1}，可测；[0, 5/2) = [0,1/2) ∪ [1/2,1) ∪ [1,3/2) ∪ [3/2,2) ∪ [2,5/2)，J = {0,1,2,3,4}，可测；ℝ = 全部件之并，可测；而单点 {3/2} 不可测——3/2 落在件 [3/2, 2) 的内部（半开件 [k/2,(k+1)/2) 把端点 1, 2, … 分给了右件，把 3/2 留给 [3/2,2)），任何含 3/2 的件之并都含 [3/2, 2) 的整段，所以 {3/2} 拼不出来。这个代数的成员是"端点对齐 k/2 的区间之并"，不多不少。尺度 n 的版本（`DyadicCube'.partition`，:553；关键一步：每个实数 xᵢ 落在唯一一个二进区间里，`dyadic_one_dim`，:521，用 floor(x·2ⁿ) 抓唯一的 aᵢ）给出例 1.4.8 的二进代数 𝓑ₙ（`DyadicCube'.boolean_algebra`，:585）。尺度越大代数越大：m ≤ n 时 𝓑ₘ ⊆ 𝓑ₙ（`boolean_algebra_mono`，`Section_1_4_1.lean:637`；每个粗立方体是细立方体的并，`dyadic_cube_subset`，:589），于是有一条递增链 𝓑₀ ⊆ 𝓑₁ ⊆ 𝓑₂ ⊆ ⋯。

口径警示：原子代数（任意并）不是唯一的合法口径。"有限布尔组合"是另一个更细的世界——生成代数（§7）只收有限组合。两个口径在有限划分上重合（有限个件，任意并 = 有限并），在无穷划分上分道扬镳：原子代数闭得不能再闭，生成代数只收每层有限步的产物。下面 §7 的 [0, 2/3) 反例在两个口径里都成立，但论证不同——那里细说。

连续世界的明星代数——初等、Jordan、Lebesgue、零测——都不是原子的（`*_not_atomic`，`Section_1_4_1.lean:1659/:1678/:1697/:1711`）。以 Lebesgue 代数为代表（`LebesgueMeasurable.boolean_algebra_not_atomic`，:1697），推理链如下。`isAtomic` 的定义（:844）说：B 由某个划分 (parts_i) 生成。若所有单点都可测，则每个划分件只能是单点：件本身可测非空，若件含两点 x ≠ y，单点 {x} 可测就把件切开——严谨版是 `isAtomic_imp_discrete_of_singleton`（:1192），其关键一步正是**任意并条款**：每个 E = ⋃_{x∈E} {x} 是单点们的一个（可能不可数的）任意并，原子代数允许它，于是 B = 幂集。若只允许有限并（§2 公理口径），只能推出有限集 ∪ 余有限集，到不了幂集，矛盾推不出来——所以"任意并"条款在这里不是可选，而是整个非原子性论证的承重墙，机器正是这样写的（:307）。于是 B = 幂集；但 Vitali 柱不可测（`not_lebesgue_measurable_cylinder`，:1540），矛盾。Vitali 柱（`vitaliCylinder`，:1392）是 1.2.3 的 Vitali 构造的柱面版：第一坐标 ∈ VitaliSet，其余坐标 ∈ [0,1]。不可测证明的骨架：按第一坐标平移有理数 q 得一族两两不交的平移柱（`vitaliCylinder_translates_disjoint`，:1495），它们覆盖单位立方体 [0,1]ᵈ（测度 1，`closedUnitCube_measure`，:1513）且全部装在 [-1,2]×[0,1]ᵈ⁻¹ 里（测度 3，`lebesgueBigBox_volume`，:1519）；平移不变性（`Lebesgue_measure.translate`）给每个平移柱同样的测度 c；若 c = 0 则并测度为 0，矛盾于 1 ≤ m(并)；若 c > 0 则可数求和得 ∞，矛盾于 m(并) ≤ 3。这四行里用到的全是 1.2.2/1.2.3 的机器——可数可加、平移不变、单调性。**这意味着**：Lebesgue 世界没有原子可言——"原子"这个概念在有限代数上成立（§5），在 Lebesgue 代数上必然崩盘，因为崩盘点正是幂集与 Vitali 的正面冲突。初等、Jordan、零测代数同样非原子（:1659/:1678/:1711），用的是同一把钥匙（单点可测 + 半空间/柱不可测）。

## 7 生成：最小包含的布尔代数

最后一个构造：给定任意集合族 F（比如"所有盒"），造出**包含 F 的最小布尔代数**——Tao 的定义 1.4.10（`generated_by`，`Section_1_4_1.lean:1762`）。

先看朴素方案会撞上什么。直接定义"F 的有限布尔组合全体"？首先要证明它真是代数（并、补的嵌套组合还是组合——对，但证明要递归地做，这就是习题 1.4.9 的工作，见下），其次"最小"的证明很绕。更干净的路是反向的：先证明**任意一族布尔代数的交仍是布尔代数**（习题 1.4.6，`instInfSet`，`Section_1_4_1.lean:1744`）——证明骨架：三条公理逐条验证，每条都"对每个 B ∈ S 成立则对交成立"，是纯逻辑搬运；然后令

```
generated_by F := ⋂ { B | ∀ E ∈ F, B.measurable E }
```

所有含 F 的代数之交——由刚才的引理它是代数，含 F（`generated_by_contains`，:1765），且被一切含 F 的代数包含（`generated_by_le`，:1770），所以是最小。这个"取所有候选之交"的手法与 1.4.2 的 σ-代数生成、以及抽象代数里的"生成子群"完全同构——**生成 = 交**。配套地，全体布尔代数按包含构成一个完备格（`instCompleteLattice`，`Section_1_4_1.lean:1781`）：下确界 = 交，上确界 = 生成（`instSupSet`，:1776）。这意味着布尔代数本身的世界也带着代数的结构——之后 1.4.2 会要同样的完备格换成 σ-代数。

例 1.4.11（`eq_generated_by_iff`，`Section_1_4_1.lean:1851`）：F 本身是代数 ⟺ generated_by F = F。平凡但有用：生成运算是不动点检验。

初等代数正是"盒生成"的（`elementary_boolean_algebra_generated_by_boxes`，`Section_1_4_1.lean:1870`）：初等集 = 有限盒并（`IsElementary` 的定义，`Section_1_1_1.lean:670`），加上补封闭（初等集补也是有限盒并的补——这是习题 1.4.1 的 ∨ 条款的另一种写法）。证明骨架：⊇ 方向用 `generated_by_le` 逐盒验证；⊆ 方向把"有限盒并"和"其补"分别用 `finset_union_mem`（:848）打进生成代数。这意味着：**1.1.1 的整个初等测度理论，在抽象框架下就是"盒 → 生成"四个字**——抽象的生成概念把具体的构造（有限并、补）打包成一个操作。

最后，习题 1.4.9 给出生成代数的**递归刻画**（`generated_by_eq`，`Section_1_4_1.lean:1971`）：设 F₀ = F，Fₙ₊₁ = {上一层的有限并} ∪ {上一层的有限并的补}，则 generated_by F 的可测集 = ⋃ₙ Fₙ。证明骨架：(⊇) 归纳证明每个 Fₙ 里的集合可测——并方向用 `finset_union_mem`，补方向用 `compl_mem`；(⊆) 证明 U := ⋃ₙ Fₙ 本身是代数——并封闭靠"两集合各在第 n、m 层，取 N = max(n,m)，并落在第 N+1 层"（`iterate_mono_le` :1920 + `iterate_union` :1931），补封闭靠 `iterate_compl` :1938，其机制是两步走：E ∈ Fₙ 时，E = ⋃{E} 是单元素有限并，故 E 先进 Fₙ₊₁；再由"有限并的补"条款，Eᶜ = (⋃{E})ᶜ 进 Fₙ₊₂——补运算两步之内封闭；U 含 F 且是代数，故 generated_by F ⊆ U。关键一步：**把"可数多步"装进 ⋃ₙ，而每一步只做有限运算**——层数可以任意大，但每一层内永远是有限组合。这意味着：生成代数里的每个集合都是某个有限层的产物，即"有限布尔组合"——只是步数无界。这解释了 §4 的 ℚ∩[0,1]：它是单点的可数并，需要无限多步，任何一层都只有有限多步，所以进不来。

这个层列刻画立刻给出一个真实的数字标本——**可数并跑出生成代数**。取 F = 全部二进区间（一切尺度），𝓐 = generated_by F。2/3 的二进制展开是 0.101010…₂（无限循环、不终止）；部分和 Sₙ = 1/2 + 1/8 + ⋯ + 1/2^(2n−1) 是几何级数，有闭式

```
Sₙ = (1/2)(1 − 1/4ⁿ)/(1 − 1/4) = (2/3)(1 − 1/4ⁿ) = 2/3 − 2/(3·4ⁿ) = (2²ⁿ−1)/(3·2²ⁿ⁻¹)
```

数字：S₁ = 1/2 = 0.5；S₂ = 1/2 + 1/8 = 5/8 = 0.625（2/3 − 5/8 = 1/24 ≈ 0.0417）；S₃ = 5/8 + 1/32 = 21/32 = 0.65625（2/3 − 21/32 = (64−63)/96 = 1/96 ≈ 0.0104）；S₄ = 21/32 + 1/128 = 85/128 = 0.6640625（差 1/384）。每个 Sₙ 的二进制展开在第 2n−1 位截断（0.1010…10，n 个 1），所以 Sₙ = (2²ⁿ−1)/3 / 2^(2n−1) 是二进有理数（分子整除 3：2²ⁿ = 4ⁿ ≡ 1 (mod 3)），并且 [0, Sₙ) = [0,1/2) ∪ [1/2,5/8) ∪ [5/8,21/32) ∪ ⋯ 是 n 个二进区间的有限并——所以 Sₙ ∈ 𝓐 对一切 n；更精确地，[0, Sₙ) 在尺度 2n−1 的二进代数里是一个单块，且不在尺度 2n−2 里（S₂ = 5/8 需要尺度 3 的块 [4/8, 5/8)，尺度 2 的块 [1/2, 3/4) 会越界——重算确认：任何含 5/8 的尺度 2 块是 [1/2, 3/4)，它的点 11/16 = 0.6875 > 5/8 跑出 [0, 5/8)）。

极限 [0, 2/3) 呢？在原子代数口径（§6）下：2/3 不是任何尺度的块边界（2/3·2ⁿ = 2ⁿ⁺¹/3 永非整数），含 2/3 的块 [⌊2ⁿ⁺¹/3⌋/2ⁿ, (⌊2ⁿ⁺¹/3⌋+1)/2ⁿ) 右端超出 2/3，任何含 2/3 的块之并都越界——所以 [0, 2/3) 不在任何 𝓑ₙ 里；尺度 n 的最佳内逼近是 [0, rₙ)，rₙ = ⌊2ⁿ⁺¹/3⌋/2ⁿ（r₁ = r₂ = 1/2，r₃ = r₄ = 5/8，r₅ = r₆ = 21/32——成对出现，因为 2/3 非二进）。在生成代数口径下：𝓐 里任何集合都是有限个二进区间的布尔组合，把它们共同细分到同一尺度 N（每个二进区间是若干 [k/2ᴺ, (k+1)/2ᴺ) 块的并），有限布尔组合变成有限个尺度 N 块的并——端点全是 k/2ᴺ 型二进有理数；若它等于 [0, 2/3)，右端点 2/3 必须是某个 k/2ᴺ，但 2/3 的二进制展开不终止，矛盾。两个口径殊途同归：[0, 2/3) 都进不来——原子代数口径下它不在任何 𝓑ₙ，生成代数口径下它不在 𝓐。而 [0, 2/3) = ⋃ₙ Sₙ（部分和单调趋于 2/3）是一个**可数并**——每个 Sₙ 都在 𝓑₂ₙ₋₁ 里（单块，进而在 𝓐 里），极限却逃出每一层；它却 Lebesgue 可测（测度 2/3 ≈ 0.6667）。与 §4 的 ℚ∩[0,1] 完全同构：零件在族里，可数并跑掉，只是把"单点"换成了"越来越细的区间"。这预先宣告了 1.4.2 的 σ-代数：只有把可数并请进族里，极限才有着落。（诚实标注：机器形式化了层列本身（:1971）、二进划分与单调链（:553/:637），但"[0, 2/3) 不在任何 𝓑ₙ 里 / ∉ 𝓐"这两句没有直接定理，待证——它们的零件（部分和公式、块边界论证）是手工验证的。）

## 8 反直觉清单 / FAQ

- **布尔代数为什么叫"布尔"？** 因为集合运算 ∪、∩、ᶜ 满足与命题逻辑 ∧、∨、¬ 完全相同的律（De Morgan、分配律、双重否定），inter_mem 的证明（`Section_1_4_1.lean:189`）就是 De Morgan 的集合版。数学上这是同一个代数结构的两副面孔，`toBooleanAlgebra`（:235）在 Lean 里把这个同构焊死。
- **为什么不直接要求可数并？** 因为"有限"和"可数"在 1.2 的经验里是两笔不同的账：有限并是集合运算白送的，可数并是 ε/2ⁿ 预算砸钱买的（1.2.2 户口普查 (vi)）。布尔代数只立前者；后者留给 1.4.2 的 σ-代数。而 §4 的 ℚ∩[0,1] 证明"有限"确实不够——两个台阶都必须存在。
- **premeasure（有限可加测度）在哪？** 本仓库尚未形式化——`Section_1_4_1.lean` 里没有任何测度概念。Tao 在 §1.4.3（"测度"，在布尔代数上定义有限可加测度）与 §1.7（Carathéodory 扩展定理：把布尔代数上的测度延拓到它生成的 σ-代数上）才让测度登场。本节只立结构。标注：待证/未形式化。
- **atom 和 IsAtom 什么区别？** atom（:883）是点的等价类构造（所有含 x 的可测集之有限交），需要"可测集族有限"；IsAtom（:1162）是"无非空真可测子集"的性质。有限情形两者一致（划分件 ↔ 原子，`part_is_atom` :1165 与 `measurable_iff_union_atoms` :1020 共同给出）；非有限情形 atom 无定义，IsAtom 仍可讨论（但连续世界的 IsAtom 是空集——Lebesgue 代数非原子，§6）。
- **为什么 ConcreteBooleanAlgebra 不直接用 Mathlib 的 BooleanAlgebra？** 因为 Mathlib 的 `BooleanAlgebra` 是序结构（任意格，不必来自集合），而我们要的语义是"集合族"。用 `Set X → Prop` 的谓词 + 三条集合公理最直接，`toBooleanAlgebra`（:235）在需要格论工具时桥接。名字里的 "Concrete" 就是提醒：这是"具体集合实现"的布尔代数。
- **幂集、{∅,X} 这类平凡例子为什么值得列？** 它们是格的顶与底（:48/:60），也是 §5 定理的极端检验：2^X 原子数是 |X|，{∅,X} 原子数是 1，可测集数分别是 2^|X| 与 2¹，公式全覆盖。
- **零测代数里 [0,1]∖ℚ 可测，但它的测度是 1 不是 0，为什么还在"零测代数"里？** 因为代数的成员判定是 "E 零测 ∨ Eᶜ 零测"（:163）——[0,1]∖ℚ 的补集 ℚ∩[0,1] 零测，所以它凭 ∨ 的右支进入。这个代数里"小"集合和"几乎全部"的集合和平共处，这正是"几乎处处"语言的温床。
- **"有限并可测"（公理）和"任意并可测"（原子代数）不矛盾吗？** 不矛盾，是两个不同层级的话：公理 §2 只要求有限并（最低门槛）；例 1.4.7 的原子代数在划分件上闭得更多——件之并连任意多都行（`to_ConcreteBooleanAlgebra` 的 `∃ J : Set I`，:307）。差别只在划分件上：普通代数成员之间只能做有限布尔组合（§7 层列），原子代数的成员本身就是"件的任意并"。§6 的非原子性证明（`isAtomic_imp_discrete_of_singleton` :1192）必须借助任意并条款才能从"单点可测"推到"幂集"——若只用有限并，只能到有限 ∪ 余有限，证明断掉。
