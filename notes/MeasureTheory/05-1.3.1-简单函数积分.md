# 05 · 1.3.1 简单函数的积分：把刀转九十度

> Tao《An Introduction to Measure Theory》§1.3.1 讲稿式笔记 + Lean 形式化对照
> 一句话纲领：**测度给集合配了把尺子，现在要给函数配一杆秤。Riemann 沿 x 轴切（竖切），死于 Dirichlet 函数——每一刀下去都切不开有理数与无理数；Lebesgue 把刀转九十度，沿 y 轴切（横切）：每个水平层 {x : f(x) = y} 都是一块可测集合，积分 = 各层高度 y 乘层底测度 m(f⁻¹({y})) 的加权和。但"横切公式"是有限和，只对有限多层有意义——于是"简单函数"这个概念不是被宣布的，是被这场切层实验逼出来的；而"同一个函数有无数种写法"带来的良定性问题（引理 1.3.4），由原子/Venn 图论证一网打尽。**
> 形式化：`analysis/MeasureTheory/Section_1_3_1.lean`（2803 行，本节核心）；书上的定义 1.3.2、引理 1.3.4、定义 1.3.5、定义 1.3.6 与习题 1.3.1、习题 1.3.2 全部机验。

## 1 这一幕要解决什么

前三节我们把"长度"这个词从区间推广到了集合：可测集有了测度 m，零测集被定义为测度 0 的集合，Vitali 集证明"一切集合都可测"是个妄想。但测度论的主角从来不是集合本身——是函数。你手里有一个"质量分布"（把质量铺在空间上的函数 f），你想问：它一共多重？更精确地说：测度给了集合一个数，**怎么给函数一个数**？这个数就是积分。

上一幕的病还记得吗？根号二第一次发作：有理数不封闭极限，数学的痊愈是扩大数的世界。Jordan 测度第二次发作：可测集不封闭可数并，痊愈是 σ-代数。现在是第三次发作，病人是 Riemann 积分。Riemann 的做法是沿 x 轴下刀：把定义域切成小区间 [xᵢ, xᵢ₊₁]，在每个小区间上取一个函数值 f(xᵢ)，用矩形 f(xᵢ)·(xᵢ₊₁ − xᵢ) 之和逼近面积，切得越细越准。这把刀切不动 Dirichlet 函数：f = 1 在有理数、0 在无理数（1.1.3 节的经典反例，那个曾经让"可积"这个词颜面扫地的函数）。任意小区间里既有有理数又有无理数——两者都稠密——所以每个小区间上 f 的上确界恒为 1、下确界恒为 0：上达布和永远是 1，下达布和永远是 0，切多细都不收敛。Riemann 积分对 f 不存在。

这一节回答：那把切不动 Dirichlet 的刀，怎么改？

## 2 竖着切：朴素公式第一次试用

Riemann 的刀是竖着切的——沿 x 轴把定义域切成薄片。把刀转九十度：沿 y 轴切。函数 f 把 x 轴上的点搬到 y 轴；我们反过来问：y 轴上的每一层高度 y，它的"层底" f⁻¹({y}) = {x : f(x) = y} 是多大的集合？如果函数只取有限个值 y₁, …, yₖ，最自然的候选公式是

∫f = Σᵢ yᵢ · m(f⁻¹({yᵢ}))

高度乘以层底的测度，逐层加权求和。对阶梯函数这显然就是面积：f 在 [0,1/2) 上恒 1、在 [1/2,3/4) 上恒 2、在 [3/4,1] 上恒 3，则层底分别是 [0,1/2)、[1/2,3/4)、[3/4,1]，测度分别为 1/2 − 0 = 1/2、3/4 − 1/2 = 1/4、1 − 3/4 = 1/4，于是 ∫f = 1·(1/2) + 2·(1/4) + 3·(1/4) = 1/2 + 1/2 + 3/4 = 7/4 = 1.75，与 Riemann 矩形和算出的面积一致——阶梯函数 Riemann 可积，两种切法给同一个数。

把公式试到杀死 Riemann 的 Dirichlet 函数上（限定在 [0,1] 上）：f = 1_{ℚ∩[0,1]} 只取两个值，层底是 ℚ∩[0,1]（y = 1）与 [0,1]∖ℚ（y = 0）。有理数可数，可数集零测（1.2.1 节），所以 m(ℚ∩[0,1]) = 0；而 m([0,1]∖ℚ) = m([0,1]) − m(ℚ∩[0,1]) = 1 − 0 = 1（[0,1] 的测度是 1，减掉零测集，有限可加）。代入公式：∫f = 1·0 + 0·1 = 0。Riemann 说"不存在"，横切公式报出一个明确的数 0——这把刀能切开 Dirichlet 了。

## 3 有限层：简单函数被逼出场

先别高兴。公式 ∫f = Σ_y y·m(f⁻¹({y})) 里那个 Σ 是**有限和**——它只对"有限个 y 值"有意义。拿 f(x) = x 在 [0,1] 上试：每一层 y ∈ [0,1] 的层底是单点集 {y}，m({y}) = 0，而层有**不可数**多个。把公式硬写成"Σ_{y∈[0,1]} y·0"是越界使用：**对不可数族根本没有求和这个操作**——1.2.1 节已经见过同一教训：单位立方体拆成不可数多个单点，每个单点测度 0，立方体的测度却是 1，可数可加性一到不可数就失效（`Section_1_2_1.lean:3497` 的反例）。所以这个横切和既不算出 0 也不算 1/2——它**根本没有被定义**（即便借用 Lean 里"有限部分和的上确界"那种最宽的求和概念硬算：每项 y·0 都是 0，上确界只得 0，照样不是 1/2；两种读法下公式都死），"Σ_y y·0 = 0"只是拿有限和的记号骗自己。真正的面积是 ∫₀¹ x dx = x²/2 |₀¹ = 1/2 − 0 = 1/2，横切公式碰不到它。问题不在公式的方向，在"层"的数目：**只有把层数限制成有限个，加权和才有意义**。注意这里的讽刺：Riemann 的竖切算得动 x（= 1/2）却死于 1_ℚ；横切算得动 1_ℚ（= 0）却死于 x。两种切法各有一个盲区——这是本节的张力所在，也是下一节 1.3.2 逼近机制存在的理由。

所以唯一的出路是：**先把公式限定在"只有有限多层"的函数上**，把有限层的理论做扎实，再用它去逼近一般函数。这就是简单函数（simple function）必须出场的方式——它不是什么高深概念，它就是"横切公式恰好有意义的那类函数"。

**定义（Tao 定义 1.3.2）**。非负简单函数 f : ℝᵈ → [0,∞] 是形如

f = Σᵢ₌₁ᵏ cᵢ · 1_{Eᵢ}

的函数，其中 k 有限，cᵢ ∈ [0,∞]，Eᵢ 皆 Lebesgue 可测。注意三个放行条款：系数可以取 ∞；Eᵢ 之间**不要求不交**；系数也不要求互异（可以重复、可以为 0）。Lean 里的定义一字不差：`UnsignedSimpleFunction`（`Section_1_3_1.lean:33`）是谓词 ∃ k c E，满足"每个 Eᵢ 可测 ∧ 每个 cᵢ ≥ 0 ∧ f = Σ cᵢ•1_{Eᵢ}"；实数版 `RealSimpleFunction`（:36）、复数版 `ComplexSimpleFunction`（:39）只是把系数换成 ℝ/ℂ 并删去非负条款。指示函数 1_E 本身定义在 :22（`EReal.indicator`：x ∈ E 取 1、否则取 0，求值规则由 :24/:27 两条定理给出）。

立刻检验定义。上面那个三层阶梯函数当然是简单函数（k = 3 的表示写在脸上）；Dirichlet 1_{ℚ∩[0,1]} 是简单函数（k = 2）。下面这个例子检验放行条款，顺便把两个符号约定摆上台面。先交代记号：**⊤ 是扩展实数 EReal = [0,∞] 里的"正无穷"，即 +∞**——测度值 m(E) 允许等于 ⊤（ℝ 本身的 Lebesgue 测度就是无穷：它包含任意长的区间），所以积分也将住在 [0,∞] 而不是 [0,∞)。配套的乘法约定两条：**0·⊤ = 0**（测度论的显式约定，Folland 在简单积分定义处声明：零测层不贡献质量）与 **c > 0 时 c·⊤ = ⊤**（`EReal.mul_top_of_pos`，`Section_1_3_1.lean:1267`）——Lean 的 EReal 把这两条内置进环律 zero_mul/mul_zero，对一切 x 含 ⊤ 成立。现在看例子：f = 1_ℤ（整数点上取 1，其余取 0）在整个 ℝ 上——取 E₁ = ℤ、c₁ = 1，E₂ = ℝ∖ℤ、c₂ = 0，两层都可测（ℤ 可数故可测，余集可测）。m(ℤ) = 0（可数），m(ℝ∖ℤ) = ⊤（抠掉零测集 ℤ 不变）。横切公式：∫f = 1·m(ℤ) + 0·m(ℝ∖ℤ) = 1·0 + 0·⊤ = 0 + 0 = 0。这一行里两个约定同时出力：积分结果允许住在扩展实数 [0,∞] 里（m(ℝ∖ℤ) = ⊤ 是合法项）；0·⊤ = 0 让"高度为 0 的层"即使层底无穷大也不贡献任何东西。于是得到一个值得停下来的结论：**一个在无穷多个点上等于 1 的函数，积分是 0**——因为它的支撑集（f ≠ 0 的地方，定义 1.3.5，`Section_1_3_1.lean:831`）是零测集。积分从这一刻起就看不见零测集，这是贯穿整个积分理论的第一个预言。

现在把横切公式正式立为定义。

**定义（Tao 定义 1.3.3，简单函数积分）**。设 f = Σᵢ₌₁ᵏ cᵢ·1_{Eᵢ} 是简单函数的一个表示（Eᵢ 可测、cᵢ ≥ 0）。定义

∫f := Σᵢ₌₁ᵏ cᵢ·m(Eᵢ)

——各层高度乘层底测度的加权和（系数、测度、和都允许取 ⊤，乘法按刚才那两条约定）。注意此刻它还是**候选定义**：它写在一个具体的表示 (k, c, E) 上。同一个函数换一种写法（§4 马上演示三种），右边的和会不会变？在证明"不会变"之前，∫f 只是"这个表示的名字"，不是"这个函数的名字"。Lean 里的积分定义正是按这个候选式写的：`UnsignedSimpleFunction.integ`（`Section_1_3_1.lean:172`）对 `choose` 抓出的既定表示直接求和。良定性的证明就是下一条引理。

## 4 良定性：同一个函数，无数种写法（引理 1.3.4）

定义 1.3.3 的候选公式 ∫f = Σᵢ cᵢ·m(Eᵢ) 现在有个尴尬：它写在一个"表示"上，而表示不唯一。同一个 f = 1_{[0,1]} 至少有三种写法：k = 1 的 (1, [0,1])；加幽灵项 1_{[0,1]} + 0·1_{[2,3]}（零系数配非空集）；拆分成 1_{[0,1/2)} + 1_{[1/2,1]}。三个写法的积分分别算：1·1 = 1；1·1 + 0·1 = 1；1·(1/2) + 1·(1/2) = 1。都对——但这不能靠"碰巧"：**换表示，积分不变**必须是一条定理，否则积分就不是函数的属性，而是写法的属性。

直觉铺垫：为什么这看上去可信？每一项 cᵢ·m(Eᵢ) 可以解读为"在 Eᵢ 上铺了 cᵢ 这么多质量"，而函数 f 决定的质量分布是唯一的——不同的写法只是把同一堆质量换了几种盒子来装。要证的正是"怎么装不影响总质量"。

**引理 1.3.4（良定性）**：定义 1.3.3 的候选值不依赖表示——若 f 是简单函数，f = Σᵢ cᵢ1_{Eᵢ}（Eᵢ 可测、cᵢ ≥ 0）是任意一个表示，则 ∫f = Σᵢ cᵢ·m(Eᵢ)。注意引理**不是在定义积分**：积分已由定义 1.3.3 定义（机器里就是对 `choose` 抓出的那个表示求和）；引理证明的是"任何表示代入公式都得同一个数"。Lean：`UnsignedSimpleFunction.integral_eq`（`Section_1_3_1.lean:796`）；它的引擎是 `weightedMeasureSum_eq_of_eq`（:471），两个表示 → 同一个加权和。

证明骨架（Venn 图论证，机器里叫 atom 论证）：两族集合 E₁..Eₖ 与 E'₁..E'ₖ' 把 ℝᵈ 划分成至多 2^(k+k') 个**原子**——每个原子是"对每个 Eᵢ、每个 E'ⱼ 都固定了在/不在"的最大区域（`atom`，:193；机器用二进制串 n ∈ Fin (2^(k+k')) 给原子编号，第 i 位比特记录 x ∈ Eᵢ 与否，`atomMembership` :187）。原子两两不交（`atom_pairwiseDisjoint` :198）、每个原子可测（`atom_measurable` :396）。然后在非空原子 Aₙ 上走四步：① 两个表示的函数相等，逐点求值，得 Σ_{i: x∈Eᵢ} cᵢ = Σ_{j: x∈E'ⱼ} c'ⱼ——x 在原子内时"x ∈ Eᵢ 与否"完全由编号 n 的比特决定，所以这是一个关于 n 的纯组合恒等式；② 每个 Eᵢ 是"第 i 位比特为 1 的那些原子"的并（`set_eq_biUnion_atoms` :349）；③ 原子两两不交且可测，有限可加性给出 m(Eᵢ) = Σ_{比特ᵢ=1} m(Aₙ)；④ 换序求和（三个小步，一步都不能省）：先用 ② 的原子分解把每个 m(Eᵢ) 替换成 Σ_{n: 比特ᵢ=1} m(Aₙ)；再在非负系数下把 cᵢ 乘进和里——乘法对和分配，`EReal.mul_finset_sum_of_nonneg`（机器在引理引擎里正是这样用的，:668）——得 cᵢ·(Σ_{n:比特ᵢ=1} m(Aₙ)) = Σ_{n:比特ᵢ=1} cᵢ·m(Aₙ)；最后对有限和换序、按 n 合并：

Σᵢ cᵢ·m(Eᵢ) = Σₙ m(Aₙ)·(Σ_{比特ᵢ=1} cᵢ) = Σₙ m(Aₙ)·(Σ_{比特ⱼ=1} c'ⱼ) = Σⱼ c'ⱼ·m(E'ⱼ)，

中间那个等式就是 ① 的纯组合恒等式。**关键一步是④的换序**：把"两个表示的差别"吸收进"同一套原子上的两个系数函数"，一切回到有限和的可交换性；整个论证里唯一出过力的分析是有限可加性（作用在原子族上），其余全是比特串的记账。注意空原子：它的 m = 0，而它的系数和可能是 ⊤——两边都是 ⊤·0 = 0（0·⊤ 约定在 §3 已声明，这里再上场），所以空原子不需要逐点求值（机器里 hbit_eq 只对 Nonempty 原子断言系数和相等，:538）。

**这意味着什么**。第一，∫f 是良定的函数：加幽灵项、拆分、调换顺序、甚至用重叠的 Eᵢ，都不改变积分——"定义 1.3.3 的求和公式"与"定义 1.3.2 的表示自由"之间的和解，良定性是付给自由的税。第二，按值域分层的标准形（层底两两不交）也是一种表示，所以朴素公式 ∫f = Σ_y y·m(f⁻¹({y})) 从"定义"降级为**定理**——横切直觉被数学兑现，且只在有限层时成立（§3 的 x 已经演示了越界）。第三，机器里实值版的标准形同样是定理不是定义：`RealSimpleFunction.disjoint_representation`（:1646）断言任何实值简单函数都有两两不交可测的表示 f = Σᵢ vᵢ·1_{Aᵢ}（构造：单家族原子 `singleAtom` :727，每个原子的值 = 落在其中的系数之和，`atomValue` :790）。第四，机器里积分定义（`UnsignedSimpleFunction.integ` :172）就是定义 1.3.3 的候选式，所以良定性不是可选项——`integral_eq` 不证，积分定义就没有数学意义。

## 5 运算律：正线性泛函与单调性（习题 1.3.1）

良定性到手，立刻问：这个积分像不像"积分"？要验的是线性与单调——习题 1.3.1(i)(iv)(v)(vi)，仓库全部机验。

**加法（习题 1.3.1(i)）**。直觉：质量分布当然可以叠加。但先看一个设计红利：因为定义不要求 Eᵢ 不交，**两个简单函数相加仍然是简单函数**，且表示就是拼接——f 用 (k₁, c₁, E₁)，g 用 (k₂, c₂, E₂)，f + g 用 k₁ + k₂ 项：前 k₁ 项抄 f，后 k₂ 项抄 g（机器里 `UnsignedSimpleFunction.add` :64 就是这个 if-then-else 拼接）。若定义强制不交，加法封闭性得先做一次原子细化——麻烦就大了。定理：∫(f+g) = ∫f + ∫g，`UnsignedSimpleFunction.integral_add`（:1031）。证明骨架：对拼接表示用引理 1.3.4，把三个积分都写成加权和，然后 `Fin.sum_univ_add` 把 (k₁+k₂) 的和拆成两段，逐项相加。**关键一步**：积分可加性被归约为有限和的可加性——本节定理全是这个套路，因为"积分"的定义本身就是有限和。数乘同理：∫(c·f) = c·∫f（c ≥ 0），`UnsignedSimpleFunction.integral_smul`（:1069），证明把系数整体换成 c·cᵢ，用 EReal 对非负和的分配律；**非负假设不是摆设**——EReal 里"乘法对和分配"只在非负系数时成立（机器 :1092 调 `EReal.mul_finset_sum_of_nonneg`），这就是 unsigned 理论坚持 c ≥ 0 的原因。**这意味着什么**：非负简单函数构成一个**锥**（对加法与非负数乘封闭的"半向量空间"），积分是这个锥上的**正线性泛函**——"正"和"线性"是整个 Lebesgue 积分理论的遗传密码，下一节单调收敛定理的两根柱子。

**单调性（习题 1.3.1(v)）**。先交代新记号（定义 1.3.5）。一个性质 P **几乎处处成立**（AlmostAlways，`Section_1_3_1.lean:823`），指例外集 {x : ¬P x} 是零测集（这个定义在机器里就一句话：`AlmostAlways P := IsNull {x | ¬P x}`）；f 与 g **几乎处处相等**（AlmostEverywhereEqual，:827）指 {x : f x ≠ g x} 零测；**支撑集** Support f = {x : f x ≠ 0}（:831）是同一族定义的第三个成员。直觉一句话：积分看不见零测集（§3 的 1_ℤ 积分是 0，§4 的空原子被赦免），所以只在零测集上失败的性质不影响积分。直觉：f 处处不比 g 大，f 的"质量"当然不比 g 多。定理是几乎处处版本：f ≤ g a.e. ⟹ ∫f ≤ ∫g，`UnsignedSimpleFunction.integral_le_integral_of_aeLe`（:1496）。证明骨架：把 f、g 同时重排到**联合原子族**上（两个表示共同细化的原子；函数在原子上的值 = `atomValueEReal`/`atomValueERealShift`，:1372/:1376，重排等式 :1434）。对每个原子 Aₙ 二选一：若 f 在 Aₙ 上的值 ≤ g 的值，乘以 m(Aₙ) ≥ 0 保持不等号（`mul_le_mul_of_nonneg_right`）；否则 Aₙ ⊆ {x : f x > g x}，而后者是零测集（几乎处处假设），于是 m(Aₙ) = 0，这一项两边都是 0。逐项求和（`Finset.sum_le_sum` :1559）。**关键一步**："坏原子全体零测"——几乎处处的不等式被原子化之后，坏原子被整个赦免（贡献 0 而不是被剔除），这是 "a.e." 信息第一次在证明里变成计算。**这意味着什么**：单调性是"积分"的底线之一——函数变小，面积不增。由它立刻得到习题 1.3.1(iv)：a.e. 相等的函数积分相等（`integral_eq_integral_of_aeEqual` :1564，用单调性两边夹，`le_antisymm`）——**积分对零测集失明**在这一节被彻底坐实：改写函数在零测集上的值，积分纹丝不动。这是 L¹ 空间"按 a.e. 相等取商"的第一块基石。

**与测度兼容（习题 1.3.1(vi)）**。最后验一验"新概念收编旧概念"：∫1_E = m(E)，`UnsignedSimpleFunction.integral_indicator`（:1584）。证明：k = 1、c = 1 的表示直接代入引理 1.3.4，1·m(E) = m(E)。顺带 ∫0 = 0（`zero_unsigned_integral` :2704，空表示 k = 0）。**这意味着什么**：集合 → 函数的桥（指示函数）把测度原样搬进积分——1_E 的积分就是 E 的测度。测度论攒下的所有财产（平移不变、可数可加、零测集理论）都从这个接口漏进积分理论，下一节每一步都会回头用这条等式。

## 6 两个判据与实值化：什么时候有限，什么时候为零

积分可以等于 ⊤（∫1_ℝ = ⊤），但读者会想知道：**什么时候有限？什么时候是 0？** 两个判据把"积分"与"函数本身"焊在一起。

**有限性判据**：∫f < ⊤ ⟺ f 几乎处处 < ⊤ 且 m(Support f) < ⊤，`UnsignedSimpleFunction.integral_finite_iff`（:1213）。证明骨架（⟹）：有限和 < ⊤ ⟹ 每项 cᵢ·m(Eᵢ) < ⊤（`EReal_sum_lt_top_iff_all` :1115）。于是 cᵢ = ⊤ 的项迫使 m(Eᵢ) = 0（否则 ⊤·m > 0 会把和撑爆，:1233–:1240），m(Eᵢ) = ⊤ 的项迫使 cᵢ = 0（否则 c·⊤ = ⊤，`EReal.mul_top_of_pos` :1267）——所以 {f = ⊤} ⊆ ⋃_{cᵢ=⊤} Eᵢ 是有限个零测集之并（`IsNull.finite_iUnion` :1163），零测；支撑 = 正系数集合并（`support_eq_iUnion_pos` :1172），是有限个有限测度集之并。⟸ 反向：设 f 几乎处处 < ⊤ 且 m(Support f) < ⊤，取任意表示，对每个系数三分支排除 ⊤（机器里就是这段三分支，:1278–:1315）：若 cᵢ = ⊤，则 Eᵢ 上 f 恒等于 ⊤（x ∈ Eᵢ 时表示至少贡献 cᵢ = ⊤，而 f ≤ ⊤ 永远成立），于是 Eᵢ ⊆ {x : f x = ⊤}——后者零测（"几乎处处 < ⊤"的补集），所以 m(Eᵢ) = 0，这一项 ⊤·0 = 0；若 cᵢ = 0，这一项 0·m(Eᵢ) = 0；若 0 < cᵢ < ⊤，则 Eᵢ ⊆ Support f（Eᵢ 上 f 恒为正数 cᵢ，故 f ≠ 0；这正是 `support_eq_iUnion_pos` 的断言），于是 m(Eᵢ) ≤ m(Support f) < ⊤，两个有限非负数的乘积仍 < ⊤（`EReal.mul_lt_top_of_nonneg` :1130）。每一项都 < ⊤，有限个之和也 < ⊤（`EReal_sum_lt_top_of_all` :1127）。**这意味着什么**：函数可以在零测集上"爆炸"到 ⊤ 而积分依然有限——∞·0 = 0 约定不是装饰，它让"几乎处处"成为积分的天然语言。注意两把锁互相卡死：cᵢ = ⊤ 只允许配零测 Eᵢ，m(Eᵢ) = ⊤ 只允许配零系数——这正是 EReal 里 ⊤ 与 0 的"婚姻法"。

拿两个极端试刀。**∫1_ℝ = ⊤**：1_ℝ 是简单函数（k = 1，c₁ = 1，E₁ = ℝ），直接代入定义：1·m(ℝ) = 1·⊤ = ⊤（c = 1 > 0，用 c·⊤ = ⊤）。判据对账：右端"f 几乎处处 < ⊤"成立（1 < ⊤ 处处为真），但 m(Support 1_ℝ) = m(ℝ) = ⊤——右端不成立；而 [0,∞] 里的值要么 < ⊤ 要么 = ⊤，所以 ∫1_ℝ = ⊤ 也是判据的推论，两条路对得上。**∫1_{[0,1]} = 1**：1·m([0,1]) = 1·1 = 1 < ⊤，判据放行（支撑 [0,1] 的测度是 1）。再看"零测集上爆炸"的例子：f = 1_{[0,1]} + ⊤·1_ℤ——在 [0,1] 上取 1，在整数点上额外爆到 ⊤，其余为 0。∫f = 1·m([0,1]) + ⊤·m(ℤ) = 1·1 + ⊤·0 = 1 + 0 = 1 < ⊤：函数在零测集 ℤ 上爆到无穷，积分照样有限。判据自动放行：f 几乎处处 < ⊤（爆炸只发生在零测集上），m(Support f) = m([0,1] ∪ ℤ) = 1 + 0 − 0 = 1 < ⊤。

**零性判据**：∫f = 0 ⟺ f 几乎处处等于 0，`UnsignedSimpleFunction.integral_eq_zero_iff`（:1332）。证明骨架：非负项之和为 0 ⟺ 每项为 0（`sum_eq_zero_of_nonneg`）；项 cᵢ·m(Eᵢ) = 0（两项都 ≥ 0）⟺ cᵢ = 0 或 m(Eᵢ) = 0（`mul_eq_zero_of_pos_left`）；于是正系数的 Eᵢ 全体零测，而支撑正是它们的并。实例对账：1_ℤ 在整个 ℝ 上——∫ = 1·0 + 0·⊤ = 0（§3 算过），判据说"积分 0 ⟺ f 几乎处处 0"，而 f 恰好在零测集 ℤ 上非零，两边都说是 0，对上了；反过来 1_{[0,1]}——∫ = 1 ≠ 0，而它在正测度集 [0,1] 上恒为 1，判据两边同时拒绝。**这意味着什么**：对非负简单函数，"积分等于 0"是关于函数形状的陈述，不是表示的偶然——函数在正测度集上的任何一处取正值，积分就大于 0。这一条是 L¹ 理论"∫f = 0 ⟹ f = 0 a.e."的种子。

**实值化（定义 1.3.6）**。有了 unsigned 理论，实值函数怎么办？朴素方案：直接 Σ cᵢ·m(Eᵢ)——但系数有正有负，表示自由立刻变成灾难：f = 1_{[0,1]} 可以合法地写成 1_{[0,1]} + 1_{[1,∞)} − 1_{[1,∞)}（三个可测集、系数 1, 1, −1，逐点求和确实等于 1_{[0,1]}），朴素求和 = 1·1 + 1·⊤ + (−1)·⊤ = ∞ − ∞，无意义。修补：**不碰系数，碰函数本身**——把 f 拆成正部 f⁺ = max(f, 0) 与负部 f⁻ = max(−f, 0)（机器 `EReal.pos_fun`/`neg_fun` :17–18，`RealSimpleFunction.pos` :1883、`.neg` :1941），f = f⁺ − f⁻，于是

∫f := ∫f⁺ − ∫f⁻

（`RealSimpleFunction.integ` :1948，实数值经 toReal 取出）。正部负部都是 unsigned 简单函数，积分良定且与表示无关——灾难解除。但还有一个暗礁：**toReal 把 ⊤ 兑成 0 是约定，不是定理**——`EReal.toReal : EReal → ℝ` 是全程函数（total function），⊤、⊥ 必须各配一个实数，mathlib 的定义文档写得很直白："把无穷送到 0 的映射"（`Mathlib/Data/EReal/Basic.lean:236`；`toReal_top : toReal ⊤ = 0` 就是定义直出，:242）。选 0 而不是别的数，理由有二：① 与 0·⊤ = 0 配对——⊤ 在积分里只通过乘积 c·⊤ 出场，而唯一能活着穿过良定性论证的乘积就是 0·⊤ = 0，兑成 0 恰好自洽（这与 ENNReal 的 ∞ ↦ 0 是同一个选择，`Mathlib/Data/ENNReal/Basic.lean:269`）；② 绝对可积牌照保证 f⁺、f⁻ 的积分都是有限扩展值，toReal 根本碰不到 ⊤——约定只影响不可积的坏函数，那里的答案本来就无意义。所以不加牌照地取差会静默出错：f = 1_ℝ 的正部积分 = ⊤，toReal 后是 0，"∫1_ℝ = 0 − 0 = 0"——荒谬（真值应是无穷，而实值积分无法表达无穷，理论干脆拒绝受理）。所以定义 1.3.6 加上**绝对可积**牌照：∫|f| < ⊤（`RealSimpleFunction.AbsolutelyIntegrable` :1876），线性性定理全部带这个假设：`RealSimpleFunction.integ_add`（:2177）、`integ_smul`（:2374）（其证明里 toReal 的加法只在有限值时成立，`toReal_add_fin` :2169——这就是假设存在的技术原因）。对实值简单函数，绝对可积 ⟺ m(Support f) < ⊤（`absolutelyIntegrable_iff` :1983）。⟹：把 unsigned 的有限性判据用在 |f| 上（|f| 是非负简单函数）：∫|f| < ⊤ 直接逼出 m(Support |f|) < ⊤——机器在 :1985 就是这么复用的；而 Support |f| = Support f（绝对值非零 ⟺ 自身非零），所以 m(Support f) < ⊤；判据的另一个结论"|f| 几乎处处 < ⊤"对实值函数自动成立（实数值恒 < ⊤，`EReal.coe_lt_top` :1995），不用出力。⟸：若 m(Support f) < ⊤，同一判据反方向给出 ∫|f| < ⊤。**这意味着什么**：实值简单函数天然有界（有限个有限系数，值域至多 2ᵏ 个值），所以"绝对可积"被化简成一个纯几何条件——积分是否有限完全由支撑集的测度说了算。复数版按实虚部分工：∫f = ∫Re f + i·∫Im f（`ComplexSimpleFunction.integ` :1980），共轭可进出积分（`integral_conj` :2509）。**这意味着什么**：1.3.1 的终点是把"只有有限种值"的函数完整积完——unsigned 允许 ∞（结果住在 [0,∞]），real/complex 用绝对可积保证结果永远是一个真数；实值版的兼容等式 ∫1_E = m(E)（`RealSimpleFunction.integral_indicator` :2731，要求 m(E) < ⊤）保证实值理论同样收编测度。下一节 1.3.2（`Section_1_3_2.lean` 已在仓库）将用这些简单积分逼近一般函数——f(x) = x 的死局在那里解开。

## 7 FAQ 与反直觉清单

1. **为什么定义 1.3.2 不要求 Eᵢ 两两不交、系数互异？** 两个原因。设计上：不交性会让"两个简单函数相加"必须先做原子细化，而拼接表示（`UnsignedSimpleFunction.add` :64）一行搞定；标准形作为定理存在（`disjoint_representation` :1646），需要时再取。账务上：不交性不是免费的——真问题是表示不唯一（幽灵项、拆分、乱序），标准形并不能消灭这个问题，只是把它藏进"化为标准形"这一步。Tao 的选择是明说 Eᵢ 不必不交，把税交给引理 1.3.4 统一支付。
2. **0·∞ = 0 是哪来的？为什么不是 0·∞ = ∞？** 这是测度论的显式约定（Folland 在简单积分定义处声明）。先澄清一个容易踩的坑：在 [0,1] 上算 Dirichlet 函数 1_ℚ 时，y = 0 那层的层底是 [0,1]∖ℚ，测度是 **1**——整个计算是 1·0 + 0·1 = 0，**根本用不到 0·∞**。要看到 0·∞ 的用场，得把战场换到整个 ℝ：f = 1_ℚ 的层底变成 ℚ（测度 0）与 ℝ∖ℚ（测度 ⊤）。若约定是 0·∞ = ∞，∫f = 1·0 + 0·⊤ = 0 + ∞ = ∞——一个可数集（有理数）被赋了无穷质量，荒谬；约定 0·∞ = 0 则 ∫f = 0，零测集彻底隐身。Lean 的 EReal 把约定内置进环律：0·x = 0（zero_mul）、x·0 = 0（mul_zero）对一切 x 包括 ⊤；c > 0 时 c·⊤ = ⊤（`EReal.mul_top_of_pos` :1267）。注意约定是**单向的**：⊤ 只在乘 0 时归零，乘任何正数都还是 ⊤——这就是 §6 里两把锁互相卡死的机制。
3. **unsigned 积分为什么允许 = ∞？** 因为非负函数可以真的有无穷质量：∫1_ℝ = ⊤（支撑测度无穷）。"有限"被单独做成判据（`integral_finite_iff` :1213）：几乎处处有限 + 支撑有限测度。real/complex 积分永远是有限的——绝对可积牌照保证。
4. **实值积分为什么不直接 Σ cᵢ·m(Eᵢ)？** 因为带符号系数的表示自由制造 ∞ − ∞（§6 的 1_{[0,1]} = 1_{[0,1]} + 1_{[1,∞)} − 1_{[1,∞)} 例子）。正部负部分解（pos − neg）是函数的性质、与表示无关，所以良定。而 toReal 把 ⊤ 兑成 0（mathlib 的约定，为什么选 0 见 §6 实值化），未加牌照的取差会静默出错——所以线性性定理全部要求 AbsolutelyIntegrable（:2177）。
5. **∫1_ℤ = 0，但函数在无穷多个点上是 1——积分"看不见"单点？** 对，而且不止单点：积分看不见一切零测集（§4 里空原子被赦免，§5 的 `integral_eq_integral_of_aeEqual` :1564 把它做成定理）。这正是"几乎处处"概念（定义 1.3.5，`AlmostAlways` :823、`AlmostEverywhereEqual` :827）存在的理由：积分理论从第一天起就是"商掉零测集"的理论。
6. **f(x) = x 的死局为什么必须等下一节？** 因为 x 不是简单函数：有限个指示函数的组合值域至多 2ᵏ 个值，而 x 的值域不可数。横切公式对它连"写出来"都做不到——"Σ_y y·0"那个不可数和根本没有定义（§3：即便按最宽泛的求和读法也只得 0 ≠ 1/2），这是公式越界的证据。解药在 1.3.2：把一般函数写成递增简单函数列的极限（上确界），积分取极限——单调收敛定理（MCT）的工作，`Section_1_3_2.lean` 已在仓库。
7. **为什么这一节叫"简单函数积分"却出现了 EReal 和 ℂ？** 因为本节要一次把三套系数铺好：unsigned（[0,∞]）是地基——0·∞ 约定、良定性、正线性泛函都在这里；real 是正负分解；complex 是实虚分解。下一节的逼近对三套各有一套，但三套共用的地基全部在本节。
