# 11 · 1.4.2 σ-代数与可测空间：把"有限"换成"可数"的那座房子

> Tao《An Introduction to Measure Theory》§1.4.2 讲稿式笔记 + Lean 形式化对照

## 1 这一幕要解决什么

把 1.4.1 的结尾再往前推一步。上一节我们立下了"集合族承载测度的最小骨架"：含空集、补封闭、**有限**并封闭，三条公理，一个不多（`ConcreteBooleanAlgebra`，`Section_1_4_1.lean:13`）。当时我们刻意把"可数并"拒之门外，理由写得很清楚：有限并是集合运算白送的，可数并是 1.2.1 用 ε/2ⁿ 预算砸钱买的。但这句话反过来读就是本节的全部起点——**既然可数并是我们真正需要的，那"不允许可数并"的家族就住不了我们真正要住的人**。

谁被赶出去了？回放 1.2.1 的现场：每个单点 {qₙ} 都是 Jordan 可测的、测度 0，但它们的可数并 ℚ∩[0,1] 不是 Jordan 可测的。当时的判决是"Jordan 的尺子不够长，换 Lebesgue 的尺子"。但 1.4.1 退后一步看清了问题的结构：这不是尺子的问题，是**集合族对可数运算的封闭性**问题。Jordan 可测集族是布尔代数（1.4.1 例 1.4.4），但它对可数并崩了。所以现在要问：**把"有限"换成"可数"，得到的那个新骨架是什么？它装得下我们一路造过的所有集合族吗？** 这一节就是给这个骨架一个名字、一套理论、以及一张"谁能住进来"的户口本。它是全章的总装车间：1.2.2 的 Lebesgue 可测集将在这里被抽象成 Lebesgue σ-代数，1.3.2 的"逆像可测"将在这里升级成结构保持映射的语言，下一节 1.4.3 的测度将直接住进 (X, 𝒜)。

## 2 定义被逼出来：σ-代数 = 布尔代数 + 一条公理

先做"重新发明"实验。你手里是 1.4.1 的布尔代数——空集、补、有限并。现在你想让"可数并"住进来。最自然的朴素方案：**把第三条公理原样放宽**，"有限并"改成"可数并"？但等等，得先确认一个事实：这个放宽到底放进来多少新集合？上一节的 ℚ∩[0,1] 是一个；本节要给出第二个、几何上更干净的：半空间。

取 d ≥ 1，令 H = {x ∈ ℝᵈ : x₁ ≥ 0}，即第一个坐标非负的半空间。把 H 写成可数并：H = ⋃ₙ [0,n] × [−n,n]ᵈ⁻¹。右端每个因子都是盒子，盒子是初等集（`IsElementary.box`，`Section_1_1_1.lean:670`），初等集是 Jordan 可测的（`IsElementary.jordanMeasurable`，`Section_1_1_2.lean:440`）——所以 H 是**可数多个 Jordan 可测集的并**。但 H 不是 Jordan 可测的：Jordan 可测要求有界（1.1.2），而 H 和它的补 Hᶜ = {x₁ < 0} 都是无界的（机器分别记为 `NotAtomic.halfspace_unbounded` :1320 与 `halfspace_compl_unbounded` :1341，`Section_1_4_1.lean`）。注意这个例子比 ℚ∩[0,1] 更狠：ℚ∩[0,1] 不可测是因为边界处处稠密这种"分析病"，而半空间是个**好得不能再好的几何物体**——它只是被可数并越过了 Jordan 的门槛。于是失败诊断成立：**布尔代数（有限并）装不下可数并的产物，哪怕产物是半空间**。

那修补方案呢？逐个打补丁？把 H 塞进可测族，然后可数并又产生新集合，无穷无尽——1.4.1 习题 1.4.9 的层列经验告诉我们补丁永远打不完。唯一的出路是**一次性把条款升级**：既然有限并的公理形式是"∀ E F, 可测 E → 可测 F → 可测 (E ∪ F)"，那就把它换成对整个 ℕ 指标族的版本。这就是 σ-代数，被这场实验逼出来的定义（文件注释即"Definition 1.4.12 (Sigma algebra)"，`Section_1_4_2.lean:11`）：

```lean
class ConcreteSigmaAlgebra (X : Type*) extends ConcreteBooleanAlgebra X where
  countable_union_mem : ∀ E : ℕ → Set X, (∀ n, measurable (E n)) → measurable (⋃ n, E n)
```

一个词都不用改，只把 `union_mem`（两个集合的并）换成 `countable_union_mem`（可数个集合的并）。补集公理原样保留——于是可数交自动免费：`(⋂ₙ Eₙ)ᶜ = ⋃ₙ Eₙᶜ`，De Morgan + 可数并 + 补封闭三行证完（`ConcreteSigmaAlgebra.iInter_mem` :368）。差集也自动可测：E \ F = (Eᶜ ∪ F)ᶜ（`sdiff_mem` :362）。**这意味着什么**：σ-代数就是"对可数布尔运算全部封闭"的集合族——1.2.2 户口普查的七条封闭性，现在全部由公理白送，一条分析都不需要。

定义之后的第一个检验，按规矩立即做：**我们一路造过的家族，哪些住得进来？**

- **Lebesgue 可测集**：住得进来。1.2.2 的户口普查 (vi) 就是可数并封闭（`LebesgueMeasurable.countable_union`，`Section_1_2_2.lean:540`），于是 `LebesgueMeasurable.boolean_algebra`（`Section_1_4_1.lean:130`）自动升级成 σ-代数，证明只有一行（习题 1.4.11，`LebesgueMeasurable.boolean_algebra.isSigmaAlgebra` :116，关键一步就是调用 :540）。这就是笔记 03 那个"LebesgueMeasurable"的抽象化：它从 ℝᵈ 上带 ε 的定义，升格为任意底空间上"可测集"这个词的标准含义。
- **零测集**：住得进来（`IsNull.sigmaAlgebra` :145，习题 1.4.11 的兄弟）。可数个零测集之并还是零测（`IsNull.countable_union'` :106）：m\*(⋃ₙ Eₙ) ≤ Σₙ m\*(Eₙ) = 0，关键一步是外测度的可数次可加性 `Lebesgue_outer_measure.union_le`。这个家族的意义是"几乎处处"的语言基地：可数多次"例外"不累积。
- **原子布尔代数**：自动住得进来（习题 1.4.10，`ConcreteBooleanAlgebra.isAtomic.isSigmaAlgebra` :77）。理由很妙：原子代数的成员 = 划分件的**任意**并（1.4.1 例 1.4.7 的 `∃ J : Set I` 口径），所以可数并只是又一次"任意并"，指标集 J = {i | ∃n, i ∈ Jₙ} 一步到位。有限结构和可数结构在原子代数里没有区别。
- **Jordan 可测集**：住不进来——这正是上面半空间反例的机器形态：`JordanMeasurable.boolean_algebra.not_isSigmaAlgebra`（:217）把 H 拆成可数并的盒子，若 Jordan 族是 σ-代数则 H 可测，再用无界性矛盾收尾。**这意味着什么**：四个家族，三个入住一个被拒。被拒的那个恰恰是 1.1 节花了大力气建的——不是它错，是它的条款（有界 + 边界零测）本质上"有限"，这是 Jordan 尺子的结构性天花板，Lebesgue 尺子之所以是终点站，就是因为它住进了 σ-代数。

最后补上术语与记号：**可测空间** = (X, 𝒜)，其中 𝒜 是 X 上的 σ-代数；𝒜 的成员叫**可测集**。文件里与 Mathlib 的双向桥（`toMeasurableSpace` :24 / `toConcreteSigmaAlgebra` :33）就是这件事的机器声明：Mathlib 的 `MeasurableSpace` 数据（`MeasurableSet'` + 空、补、可数并三条证明）与我们的 σ-代数逐字同构。两个极端成员立即命名：**平凡 σ-代数 {∅, X}** 是最小的（格的下界 `OrderBot` :290，判定 `E = ∅ ∨ E = univ`）——它只有 2 个可测集；**幂集 2^X** 是最大的（`OrderTop` :278，一切皆可测）——它有 2^|X| 个。"{∅, X} 最小"的论证只有一行：任何 σ-代数都含 ∅（公理第一条）且含 X = ∅ᶜ（补封闭），所以 {∅, X} ⊆ 𝒜 对**一切** σ-代数 𝒜 成立；而 {∅, X} 自身封闭（∅ 与 X 互为补集；可数个成员的可数并只能是 ∅——全空时——或 X——任一成员为 X 时，机器 `OrderBot` :290–316 正是这个 case 分析）。这两个成员之间，整个偏序还是个完备格：任意多个 σ-代数的交仍是 σ-代数（习题 1.4.13，`instInfSet` :327），上确界 = 生成（`instSupSet` :380——这句不是定理而是**定义直出**：:380 就把 sSup S 定义成由 ⋃ B.measurableSets 生成的 σ-代数；完备格公理验证在 :385）。"交还是 σ-代数"这句话马上要派大用场。

## 3 生成 σ-代数：最小性由"交封闭"保证

现在到了本节真正的转折：**可测集没法枚举，怎么指名一个 σ-代数？** 看 Borel 的需求：我们希望"所有开集可测"。开集有多少个？在 ℝ 上就有 2^ℵ₀ 个；从开集出发做可数并、可数交、补，能得到 2^ℵ₀ 个（§5 会算这个数）——没人能把这 2^ℵ₀ 个集合一条条写进定义。你只能写"**由开集生成的 σ-代数**"。所以问题变成：给一个集合族 𝒢（生成元），怎样定义一个"包含 𝒢 的最小 σ-代数"？

朴素方案：**枚举**。从 𝒢 出发，反复取可数并、可数交、补，直到封闭。这方案在 1.4.1 习题 1.4.9（布尔代数版）就做过一次，当时用 ℕ 层的层列就够；但 σ-代数版有个坏消息：**可数层列不够**——可数个层的并又产生新集合，需要递归到第一个不可数序数 ω₁ 才算完（§4 机器证明了这一点）。枚举法能工作，但作为**定义**太绕。

修补方案（也是标准定义）：**交**。所有包含 𝒢 的 σ-代数之交。这个方案能成立，全靠上面那句"σ-代数的交集仍是 σ-代数"（习题 1.4.13，`instInfSet` :327）——否则"交"出来的东西可能根本不是 σ-代数。把记号写干净再验证：设 𝒞 是**被交的那一族** σ-代数（将来取 𝒞 = {B | B 是 σ-代数且 𝒢 ⊆ B}），"E 属于交"的含义是 **∀ B ∈ 𝒞，B 里 E 可测**——注意交的判定是逐成员定义的，这本身不是定理而是 :327 的定义。验证可数并封闭：若对每个 B ∈ 𝒞 都有 Eₙ 在 B 里可测，则固定 B，用 B 自己的可数并公理得 ⋃ₙ Eₙ 在 B 里可测；这对每个 B ∈ 𝒞 都成立，故 ⋃ₙ Eₙ 属于交。空集、补集同理。**关键一步就是这个量词顺序：公理是"∀ B ∈ 𝒞，……"形式的全称句（还是逐成员的），所以交的成员资格"穿透"到每一个成员 B，而每个 B 自己负责自己的公理。**

于是概念的必然出场（Tao 定义 1.4.14，机器 `ConcreteSigmaAlgebra.generated_by` :348）：

```lean
def ConcreteSigmaAlgebra.generated_by {X : Type*} (F : Set (Set X)) : ConcreteSigmaAlgebra X :=
  sInf { B | ∀ E ∈ F, B.measurable E }
```

两个性质一步到位（这是"最小"的机器表述，:351 / :356）：**生成含生成元**（`generated_by_contains`：E ∈ 𝒢 ⟹ E 在 σ(𝒢) 里可测——因为它对每个"包含 𝒢 的 σ-代数"都可测）与**生成最小**（`generated_by_le'`：任何包含 𝒢 的 σ-代数 B 都满足 σ(𝒢) ≤ B）。唯一性由偏序的反称性给出（`ConcreteSigmaAlgebra.ext` :15 的用途）。**这意味着什么**：σ(𝒢) 是"交出来的"，不是"造出来的"——我们不需要会枚举可测集，只需要知道"所有候选之交"这个万无一失的操作。这是抽象测度论里第一个"存在性免费"的例子，后面 Carathéodory 扩展定理（1.7 节）还会再用一次同样的手法。

但交出来的定义有个代价：它不告诉你 σ(𝒢) 的成员**长什么样**。补救是归纳原理（Remark 1.4.15，`ConcreteSigmaAlgebra.induction` :551）：要证"σ(𝒢) 的所有成员都有性质 P"，只需检查四条——P(∅)、生成元有 P、P 对补封闭、P 对可数并封闭。机器在 :551 用一个"P 本身做成一个 σ-代数 U"的技巧把它证完（U 是 σ-代数且包含 𝒢 ⟹ σ(𝒢) ≤ U ⟹ 全部成员有 P）。这个原理是本节所有"对 Borel 集证明某事"的万能钥匙（§6 的乘积定理就是它的应用）。

生成与不生成之间的裂缝，机器用一个具体例子钉死（:515，作业式的 `example`）：取 X = ℕ，𝒢 = {{2n} : n ∈ ℕ}——所有偶数单点。**布尔代数版** σ_Boolean(𝒢) 的成员只有"有限多个偶数单点之并及其补集"（1.4.1 的层列）；而**σ-代数版**里，全体偶数 E = {0, 2, 4, 6, …} = ⋃ₙ {2n} 是可数并，直接是成员。E 为什么进不了布尔代数版？因为 E 无限、Eᶜ（全体奇数 {1, 3, 5, …}）也无限——有限并的层列造不出无限余无限的集合。机器用 `finOrCofin`（:460，"有限或余有限"代数，ℕ 上的经典例子）作证人：布尔生成 ⊆ finOrCofin，而 E ∉ finOrCofin（:509 的三个引理分别说偶数集不有限、奇数集不有限）。于是：**生成算子的"有限"版和"可数"版真的不同**，σ 不是锦上添花，是实实在在多放进来了一整层集合。

## 4 Borel σ-代数：六套生成元，殊途同归

现在把生成机器接到拓扑上（Tao 定义 1.4.16，`BorelSigmaAlgebra` :593）：

```lean
def BorelSigmaAlgebra (X : Type*) [TopologicalSpace X] : ConcreteSigmaAlgebra X :=
  ConcreteSigmaAlgebra.generated_by { U : Set X | IsOpen U }
```

**Borel σ-代数 = 开集生成的 σ-代数**；它的成员叫 **Borel 集**。定义一句话，`generated_by_open`（:597）甚至只是 `rfl`。但一个定义值不值钱，要看它"够不够大"。习题 1.4.14 的六个子题把这个问题问到底：闭集生成、紧集生成、开球生成、盒子生成、初等集生成，全都得到同一个 σ-代数。逐个看骨架（全部机器验证）：

- **闭集**（:600）：闭集是开集的补，而生成算子对补不变（若 E ∈ σ(𝒢) 则 Eᶜ ∈ σ(𝒢)）——两行 `le_antisymm`。
- **紧集**（:631）：ℝᵈ 上 Heine–Borel 的化身。方向一：每个闭集 F 是紧集的可数并——F = ⋃ₙ (F ∩ B̄(0, n))，闭球紧（`ProperSpace.isCompact_closedBall`，:666 用到），闭 ∩ 紧 = 紧。方向二：紧集 ⊆ 闭集（Hausdorff）⟹ 反过来也 ⊆。**关键一步**：闭集写成可数并的分解，正是"σ-代数可数并公理"的用武之地——这也是为什么紧集生成在一般拓扑空间上通常更小，在 ℝᵈ 上却刚好一样。
- **开球**（:803）：每个开集是可数多个开球的并。构造很具体：给定 x ∈ U，取 ε 球 B(x,ε) ⊆ U；用有理点逼近——取 q ∈ ℚᵈ 使 dist(x,q) < ε/4，再取有理半径 r 使 dist(x,q) < r < ε/4；则对 y ∈ B(q,r)，三角不等式给 dist(y,x) ≤ dist(y,q) + dist(q,x) < ε/4 + ε/4 = ε/2 < ε，故 B(q,r) ⊆ B(x,ε) ⊆ U。**这里的算术：ε/4 + ε/4 = ε/2，ε/2 < ε，缺口是 ε/2 不是 0——所以要求有理点距离严格小于 ε/4。这个"严格小于 ε/4"由引理 `exists_ratPoint_close`（:710）保证：给它预算 ε'，它逐坐标选有理点使每个坐标误差 < ε'/(d+1)，再用 L1 界 ‖x−q‖ ≤ Σᵢ|xᵢ−qᵢ| ≤ d·ε'/(d+1) < ε' 得到 ‖x−q‖ < ε'（:719–741）；调用时把预算设为 ε' = ε/4，就得到 dist(x,q) < ε/4。有理数稠密在这里是全部要点。** 而"有理"二字让生成元族变成**可数的**（`ratBall_countable` :747：ℚᵈ × ℚ 的像）——这是 §5 基数论证的伏笔。
- **盒子**（:1191）：先把每个盒子证明是 Borel 的（`Box.borel_measurable` :1181：任意盒子 = 可数个闭盒子的并，开边 (a,b) 用 [a + (n+2)⁻¹, b − (n+2)⁻¹] 逼近，(n+2)⁻¹ → 0；例如 n = 0 时收进 1/2，n = 2 时收进 1/4）；再把每个开集写成可数个**有理端点盒子**的并（`open_eq_union_ratBoxes` :902，同样的 ε/(4(d+1)) 预算）。
- **初等集**（:1257）：初等集 = 有限多个盒子的并，盒子 Borel ⟹ 初等集 ⊆ Borel；反过来开集是可数多个盒子（初等集）的并 ⟹ Borel ⊆ σ(初等集)。两方向各走一遍，就得到**初等代数生成 ⟹ Borel**——注意这等于说：1.1 节的盒子语言从头到尾都是够用的，Borel 集就是"从盒子出发做可数运算能到的一切"。

**这意味着什么**：Borel σ-代数不依赖"开集"这个具体选择。闭、紧、球、盒、初等——六个生成元系统殊途同归，机器把六条路全走了。对读者来说，这意味着你**挑顺手的生成元用**：证"某集合是 Borel 的"时可以选闭集（Cantor 集）、盒子（箱事件）、开球（连续性）……怎么方便怎么来。对一般拓扑空间这六者不一定重合（紧集生成更小），ℝᵈ 的特殊性全在 Heine–Borel。

## 5 Borel 有多大：基数论证与第一个非 Borel 集

Borel σ-代数含开集、闭集、Gδ、Fσ、……，看起来什么都有。（两个记号先交代：**Gδ 集** = 可数个开集之交，**Fσ 集** = 可数个闭集之并——G 来自德语 Gebiet"开域"，F 来自法语 fermé"闭"，δ 与 σ 分别指可数交与可数并。二者都在 Borel 里：可数交、可数并是 σ-代数的公理级性质。）**它到底有多少成员？** 这个问题值得算，因为答案直接给出第一个非 Borel 集的证明。

先建一般理论（习题 1.4.15/1.4.16 的机器内容）。这里要用超限递归，先给一个只够本节用的**序数速成**（只讲会用到的三层）：(i) 序数是"可以数到无穷之后"的计数工具——0, 1, 2, … 数完之后还有 ω₀（第一个无穷序数，就是 ℕ 本身），然后是 ω₀+1, ω₀+2, …，再往后还有 ω₀+ω₀、ω₀·ω₀、……；(ii) 每个序数 α 有**后继** α+1；不是任何序数的后继的序数叫**极限序数**（ω₀ 是第一个极限序数），在极限序数处超限递归"取并"来过渡——所以 stage_{α+1} 只对后继序数定义，极限序数处直接并上前面的层，不存在"α+1 在极限处怎么定义"的问题；(iii) **ω₁ = 第一个不可数序数**，即"所有可数序数的集合"——它是极限序数，而且满足**正则性**：可数多个小于 ω₁ 的序数的上确界仍小于 ω₁（等价于"可数个可数序数之并仍可数"）。这三条足够本节全部使用；形式化层面它们对应 Mathlib 的 `Ordinal` 与 `Cardinal.isSuccLimit_omega`（:1451、:1508 用到）。

σ(𝒢) 的成员是"从 𝒢 出发经可数运算到 ω₁ 为止"的一切：定义层列 stage₀ = 𝒢，stage_{α+1} = {可数并} ∪ {补} from stage_α，极限序数取并（`sigma_stage` :1335，`sigma_stage_zero` :1341，`sigma_stage_succ` :1344，`sigma_stage_limit` :1351）。然后关键定理（`generated_by_eq` :1600，习题 1.4.15）：

σ(𝒢) = ⋃_{α < ω₁} stage_α(𝒢)

证明骨架分两半。包含 ⊇：每个 stage 都在 σ(𝒢) 里（归纳，`sigma_stage_subset_generated` :1455）。包含 ⊆：令 U = 所有 stage 的并，验证 U 是 σ-代数——可数并这条**关键一步**是：可数多个指标 αₙ < ω₁ 的上确界仍 < ω₁（可数多个可数序数之并仍可数，`union_stages_countable_union` :1489 用 ω₁ 的正则性）；补集只需把指标 +1（`union_stages_compl` :1522）。U 含 𝒢 且是 σ-代数 ⟹ σ(𝒢) ⊆ U。**这意味着什么**：生成 σ-代数不是"可数层"能穷尽的——它本质上是超限构造，这正是枚举方案当定义会失败的原因。

基数估计随之而来（习题 1.4.16，`card_of_generated_by` :1761）：若 𝒢 无限，则

|σ(𝒢)| ≤ |𝒢|^ℵ₀

同样先给**基数算术速成**（四条，够本节用）：(i) |A|^|B| 定义为从 B 到 A 的函数个数（所以 2^κ = κ 个子集个数）；κ·μ 定义为 κ×μ 的基数；(ii) ℵ₀·ℵ₀ = ℵ₀，因为 ℕ×ℕ 可数（Cantor 配对 (m,n) ↦ (m+n)(m+n+1)/2 + n 是双射）；(iii) ℵ₁ = 第一个不可数基数，且有 ℵ₁ ≤ 2^ℵ₀（Cantor 定理的推论）；(iv) 对无穷基数 κ 有 κ·κ = κ（需要选择公理的标准事实）。前两条是"函数个数"这类定义层面的计算，后两条是标准定理——机器在用到它们的地方都标了出处（`Cardinal.mul_eq_self` :1619、`Cardinal.two_power_aleph0` :1731、`Cardinal.aleph_one_le_continuum` :1732）。

骨架：每层 stage_α 的成员来自"可数个旧成员的并或补"，而旧成员的**可数子族**至多有 max(|stage_α|, ℵ₀)^ℵ₀ 个（`stage_card_le` :1714 里用的是 ℵ₀ 级有界子集计数——"可数子族"就是"基数 ≤ ℵ₀ 的子集族"，而一个大小为 λ 的集合的子集个数是 2^λ，这里因 λ 的 ℵ₀ 次幂估计收紧）；叠 ℵ₁ 层，ℵ₁ · |𝒢|^ℵ₀ = |𝒢|^ℵ₀（用 (iii)(iv)）。关键一步是基数算术 κ^ℵ₀ 的幂等性：(κ^ℵ₀)^ℵ₀ = κ^ℵ₀（:1622–1624 的 `hκ_pow`，即 κ^(ℵ₀·ℵ₀) = κ^ℵ₀，再用 (ii)）。

现在代入 Borel（`BorelSigmaAlgebra.card` :1862）：ℝᵈ 的开球有理生成元族可数（ℵ₀ 个），故

|Borel(ℝᵈ)| ≤ ℵ₀^ℵ₀ = 2^ℵ₀

其中 ℵ₀^ℵ₀ = 2^ℵ₀ 的算术：反向 2^ℵ₀ ≤ ℵ₀^ℵ₀ 来自 2 ≤ ℵ₀（平凡），正向 ℵ₀^ℵ₀ ≤ (2^ℵ₀)^ℵ₀ = 2^(ℵ₀·ℵ₀) = 2^ℵ₀ 是机器在 :1887–1893 机验的链，两边夹住。（等号另一侧 |Borel| ≥ 2^ℵ₀ 来自单点 {x} 都是 Borel 的——标准事实，仓库只机验了 ≤。）**所以 Borel σ-代数有连续统那么多个成员。**

而 Cantor 集 C = ⋂ₙ Cₙ（`midThird` :1902；第 n 层 Cₙ = 2ⁿ 个长度 3⁻ⁿ 的闭区间，`CantorInterval` `Section_1_2_2.lean:1209`）是闭集（`cantor_isClosed` :1942，走 `CantorSet.compact` `Section_1_2_2.lean:1214`），所以 **C ∈ Borel**。C 的成员个数是连续统：|C| = 2^ℵ₀（`cantor_card` :1947，数字序列 ↔ 点的双射）。于是 C 的**子集**共有 2^(2^ℵ₀) 个，而 Borel 集只有 2^ℵ₀ 个——2^(2^ℵ₀) > 2^ℵ₀（Cantor 定理，`Cardinal.cantor`）。鸽笼原理：**C 的某个子集 N 不是 Borel 的**（`cantor_has_nonBorel_subset` :2053，证明就是上面这段基数比较，`Cardinal.mk_le_of_injective` 把它形式化）。

更有意思的是 N 的测度身份：N ⊆ C ⊆ ⋃(第 n 层的 2ⁿ 个盒子)，第 n 层盒子的总体积 = 2ⁿ · 3⁻ⁿ = (2/3)ⁿ——手算几个：n = 2 时 4 个盒子、每个 1/9，总共 4/9 = 0.444…；n = 3 时 8 个盒子、每个 1/27，总共 8/27 ≈ 0.296。随着 n → ∞，(2/3)ⁿ → 0（`cantorBox_sum_volume_le` :2018 机器算的就是这个上界，`cantor_jordan_outer_zero` :2039 把它取极限）。所以 N 的 Jordan 外测度 ≤ (2/3)ⁿ 对一切 n 成立 ⟹ = 0。**最后一格**（为什么这就推出 Jordan 可测）：Jordan 可测 = 有界 + 内外测度相等（1.1.2）；有界来自 N ⊆ C ⊆ 第 0 层盒子 [0,1]ᵈ（`isBounded_biUnion_box`，`Section_1_1_2.lean:923`）；内外相等来自夹逼——内测度 ≤ 外测度恒成立（`Jordan_inner_le_outer`，`Section_1_1_2.lean:124`），而内测度非负，于是 0 ≤ 内 ≤ 外 = 0，两边都是 0，相等。（另一条路：边界 ∂N ⊆ C（C 闭），而 C 的外测度 = 0。）**N 是 Jordan 可测的**！于是：

**存在 Jordan 可测（当然 Lebesgue 可测）但非 Borel 的集合**（`JordanMeasurable.not_borel` :2110）。

这句话值得停下来读两遍。1.2.3 的 Vitali 集不可测 ⟹ 非 Borel——但那只是"不可测 ⟹ 非 Borel"的单向通道；我们现在有了**反方向**的活标本：N 测度是 0，好得不能再好，却不是 Borel 的。"不可测"和"非 Borel"是两码事，差整整一个层级：**非 Borel 是家常便饭（Cantor 的子集几乎全都非 Borel），不可测才是稀罕物（需要选择公理级别的构造）**。1.3.2 注记 1.3.10 的 f(F) 例子是这件事的函数版（§6 回头讲）。

最后把 Borel 和 Lebesgue 的关系钉死：开集 Lebesgue 可测（`IsOpen.measurable`，`Section_1_2_2.lean:11`），Lebesgue 可测集是 σ-代数（§2），所以 **Borel ⊆ Lebesgue**（`BorelSigmaAlgebra.le_LebesgueSigmaAlgebra` :2319，一行 `generated_by_le'`）。而且反过来每个 Lebesgue 可测集都"几乎"是 Borel 的：E = B \ N，B 是 Borel 集、N 零测（`lebesgue_measurable_eq_borel_sdiff_null` :2327——取开集 Uₙ ⊇ E 使 m\*(Uₙ \ E) ≤ 1/(n+1)，令 B = ⋂ₙ Uₙ，用 1/(n+1) → 0 证 B \ E 零测）。等价地：**Lebesgue σ-代数 = σ(Borel ∪ 零测集)**（`LebesgueMeasurable.sigmaAlgebra_generated_by` :2399）。**这意味着什么**：Lebesgue 可测集 = Borel 集 + 一个零测补丁——"可测"这个概念的厚度全部来自"开集"这个生成元系统，零测补丁只是收尾。这也预告了 1.4.3 的完备化定理：Lebesgue 测度是 Borel 测度的完备化。

## 6 可测函数：结构保持映射，与切片反例

现在语言升级完成，回头重读 1.3.2 的"可测函数"。抽象语境下的定义顺理成章：f : (X, 𝒜) → (Y, ℬ) 可测 ⟺ 对每个 B ∈ ℬ，f⁻¹(B) ∈ 𝒜。**逆像把目标空间的 σ-代数拉回源空间**。这是范畴论意义的"结构保持映射"：σ-代数是结构，可测映射保持结构；可测空间是对象，可测映射是态射。1.3.2 的 TFAE（`UnsignedMeasurable.TFAE` :1686）在具体 ℝᵈ 情形下机验了"逆像条件"这一条（条件 (x)/(xi)：开集/闭集逆像可测），现在有了抽象定义，"f⁻¹(开集) 可测 ⟹ f⁻¹(Borel 集) 可测"是自动的：{B | f⁻¹B 可测} 含开集且是 σ-代数（这正是 §2 的机器成果 `LebesgueMeasurable.boolean_algebra.isSigmaAlgebra` :116 的用武之地）。**这意味着什么**：1.3.2 的保证条款在抽象语言里是**定义直出**，不再是定理——这就是 1.4.2 存在的意义之一。

两个机器定理展示这个语言的生产力：

**乘积可测（习题 1.4.17，`BorelSigmaAlgebra.prod` :2134）**：E ∈ Borel(ℝ^{d₁})、F ∈ Borel(ℝ^{d₂}) ⟹ 在等同映射 φ : ℝ^{d₁}×ℝ^{d₂} ≅ ℝ^{d₁+d₂}（坐标重排同胚 `EuclideanSpace'.prod_equiv` 的逆）下，φ(E × F) ∈ Borel(ℝ^{d₁+d₂})——机器陈述 :2137 写的正是 `prod_equiv.symm '' (E ×ˢ F)`，定理里两个空间的分歧由 φ 显式声明。证明骨架就是 §3 的归纳原理（`ConcreteSigmaAlgebra.induction` :551）：先对开集 U 证"φ(U × F)"可测——φ(U × F) = prod_equiv⁻¹(U × F)（:2125 的等式），而 prod_equiv⁻¹ 连续、开集的逆像是开集，所以 φ(U × F) 是开集、是生成元（`prod_equiv_symm_image_open` :2129）；然后对 E 做归纳：补集用差集公式 φ(Eᶜ × F) = φ(univ × F) \ φ(E × F)——这步需要 φ 单射（`Set.image_diff φ.injective`，:2159），可数并则用 φ(⋃ₙ Eₙ × F) = ⋃ₙ φ(Eₙ × F)（`Set.image_iUnion`）。**关键一步**是归纳原理把"从开集到任意 Borel 集"的证明分成四块机械检查——没有 :551，这个定理要另写一整页。

**切片可测（习题 1.4.18(i)，`slice_fst` :2214 / `slice_snd` :2242）**：E ∈ Borel(ℝ^{d₁+d₂}) ⟹ 每个切片 {x₁ | (x₁, x₂) ∈ E} ∈ Borel(ℝ^{d₁})。同样走归纳原理：开集的切片是开集（连续映射 `sliceMap` :2204 的逆像），补集、可数并各一行。

但**切片对 Lebesgue 可测集会断**（习题 1.4.18(ii)，:2277 的 example）：存在 E ⊆ ℝ²，E Lebesgue 可测，但切片 {x₁ | (x₁, 0) ∈ E} 不可测。构造：E = {(x₁, x₂) | x₁ ∈ VitaliSet, x₂ = 0}——Vitali 集躺在 x 轴上。E 装在盒子 [0,1] × [0,0] 里（VitaliSet ⊆ [0,1]，`VitaliSet_subset_unit_interval` `Section_1_2_3.lean:70`），这个盒子体积 = 1 · 0 = 0（:2293 机验：边长相乘，第二边长度为 0），故 E 零测 ⟹ Lebesgue 可测；但 x₂ = 0 的切片正是 VitaliSet（`NotAtomic.vitaliCylinder`，`Section_1_4_1.lean:1392`；`not_lebesgue_measurable_cylinder` :1540），不可测。**这意味着什么**：Borel 层切片免费、Lebesgue 层切片要钱——这是 Borel ⊊ Lebesgue 的第一笔账单。测度论里"切片定理"（Fubini 的前奏）必须在 Borel 层建，Lebesgue 层只能"几乎处处"补救，根子就在这个反例。

再把 1.3.2 注记 1.3.10 的 f(F) 例子翻译成新语言（`Section_1_3_2.lean:4219` 注释，机器 example :4224）：f 可测，F ⊆ [0,1] Vitali 不可测，E = f(F) ⊆ Cantor 集。E 零测（Cantor 集零测，`CantorSet.null` `Section_1_2_2.lean:1526`）⟹ Lebesgue 可测；但 f⁻¹(E) = F（f 在非二进有理点上单射）不可测。用本节的语言：**若 E 是 Borel 的，则 f⁻¹(E) 可测（结构保持），矛盾——所以 E 是"Lebesgue 可测但非 Borel"**。这与 §5 的 N 殊途同归：一个是基数论证（存在性），一个是函数构造（显式性）。两路都证明同一件事：**Borel 层不是封闭性的终点，Lebesgue 层才是；而"可测函数"的逆像保证精确地停在 Borel 层**。

## 7 FAQ 与反直觉清单

- **为什么"可数并"而不是"任意并"？** 任意并 = 幂集 = Vitali 死路：1.2.3 证明平移不变的可数可加测度在 2^ℝ 上不存在（`VitaliSet.nonmeasurable`，`Section_1_2_3.lean:145`）。可数并是"刚好够"：半空间、ℚ∩[0,1]、开集的可数覆盖全部入住（§2–§4），同时 Borel 层还只有 2^ℵ₀ 个成员——可数并既放进了所有我们需要的集合，又没放进来"太多"。
- **"可数-余可数 σ-代数"在哪？** ℕ 上的"有限-余有限"代数 `finOrCofin`（:460）在文件里（它只是布尔代数，偶数是它的叛逃者，§3 的 example :515）。ℝ 上的"可数-余可数"σ-代数 = 单点集生成的 σ-代数 σ({{x} : x ∈ ℝ})（可数并 = 可数集，补 = 余可数集，封闭性一步验证）。它**不是** Borel σ-代数——准确说是**严格更小**：单点 {x} 是闭集 ⟹ 可数集是 Fσ ⟹ 可数-余可数 ⊆ Borel(ℝ)；但 [0,1] 是 Borel 的（闭集），而 |[0,1]| = 2^ℵ₀ 既不是可数也不是余可数，所以 [0,1] 不在可数-余可数里，包含严格。这段推理手证即可，仓库未机验（标"待证"）。
- **Borel 和 Lebesgue 到底差多少？** 差"零测补丁"：每个 Lebesgue 可测集 = Borel 集 \ 零测集（:2327），且 Lebesgue σ-代数 = σ(Borel ∪ 零测)（:2399）。集合个数上：|Borel| = 2^ℵ₀，|Lebesgue| = 2^(2^ℵ₀)（后者标准事实，仓库未机验）。差得极多，但差的部分全是零测级的"灰尘"。
- **为什么生成 σ-代数要用"交"而不是"枚举"当定义？** 枚举要到 ω₁ 层才封闭（`generated_by_eq` :1600）——作为定义太绕；交的定义一句话，最小性免费（:351/:356），唯一性免费。枚举变成定理（习题 1.4.15），专门用来数基数。
- **为什么 Borel 集只有 2^ℵ₀ 个，却感觉"什么都有"？** 因为"什么都有"是就**可数运算**而言：开集、闭集、Gδ、Fσ、Cantor 集全在。但 ℝ 的子集有 2^(2^ℵ₀) 个，Borel 只是其中可数运算可达的那一层。Cantor 集的子集就有 2^(2^ℵ₀) 个，Borel 装不下（§5）——"几乎所有的 Cantor 子集非 Borel"。
- **"可测函数"在抽象语言里为什么是定义直出？** 1.3.2 的逆像条件是 TFAE 的成员（:1686）；本节之后，f⁻¹(开集) 可测 ⟹ f⁻¹(Borel 集) 可测是结构保持的一行推理。但 f⁻¹(Lebesgue 集) 不保证（注记 1.3.10 的 f(F)，`Section_1_3_2.lean:4219`；切片反例 :2277）。
- **ConcreteSigmaAlgebra 和 Mathlib 的 MeasurableSpace 什么关系？** 双向桥 :24/:33/:2426/:2434——Mathlib 的 `MeasurableSpace` 公理（`MeasurableSet'` + 空 + 补 + 可数并）逐字就是 σ-代数。仓库用 Concrete 版保持与 1.4.1 的叙事同构（"具体集合实现"），需要 Mathlib 生态（如 1.4.3 的 `Measure`）时桥接。

**为什么这些差异重要**：生成元的选择决定"Borel 集"的定义成本。开集生成最自然（拓扑自带），紧集生成是局部紧群/Haar 测度的传统（Halmos 的 σ-ring 双层结构正是为此），两者在 ℝᵈ 靠 Heine–Borel 重合——习题 1.4.14 的六路机验就是这个重合的完整证据。构造次序决定读者先见到什么：Tao 先建 Lebesgue 可测集（1.2.2）再抽象出 σ-代数（1.4.2），读者带着"开集可测、可数并封闭"的具体记忆走进抽象定义，半空间反例（§2）才不会显得突兀；Rudin 从 σ-代数直接开讲，最陡但最干净；Folland 居中（先具体 Lebesgue、后 Carathéodory）。本仓库跟随 Tao，`ConcreteSigmaAlgebra` 与 1.4.1 的 `ConcreteBooleanAlgebra` 一字之差地并排躺着——这个并排本身就是"有限 → 可数"这一课。
