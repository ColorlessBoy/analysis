# 02 · 1.2.1 Lebesgue 外测度：把"盖得住"当尺子

> Tao《An Introduction to Measure Theory》§1.2.1 讲稿式笔记 + Lean 形式化对照
> 一句话纲领：**外测度对每个集合都发一个数 m\*(E)，连最病态的集合也不例外；你为"来者不拒"付出的代价是只买得到可数次可加性（≤），买不到可数可加性（=）。等号要么靠"两个集合隔得够远"（引理 1.2.5），要么等下节把集合通过"可测"这道验收关（LebesgueMeasurable 的定义见 `Section_1_2_0.lean:2291`，§1.2.2 才展开）。**
> 形式化：`analysis/MeasureTheory/Section_1_2_0.lean`（定义与 Jordan 对照）、`analysis/MeasureTheory/Section_1_2_1.lean`（本节全部性质）。

## 1 这一幕要解决什么

上一节我们给自己造了一把尺子：Jordan 测度。它量区间极准——量 [0,1] 得 1，量 (0,1) 也得 1，端点不算钱；可它只认"初等集"，也就是有限个盒子的并。现在把这把尺子对准 ℚ∩[0,1]，问题来了：有理数千疮百孔，不含任何非空区间，可它的闭包是整个 [0,1]。于是 Jordan 内测度读出 0，外测度读出 1——同一堆点，内尺说"它什么也没有"，外尺说"它长满了一整段"。有理数在这个体系里既"没有长度"又"长满 [0,1]"，Jordan 可测性（要求内外读数相等）当场破产。Lean 把这一整出戏写成了 `exercise_1_2_1_union`（`Section_1_2_0.lean:15`）：可数个 Jordan 可测的有界集（每个单点 {qₙ} 都是，读数 0）的并，不再是 Jordan 可测的。

这还不是最要命的。要命的是"并"这个运算对**有限**个成员开门，对**可数**个成员关门——可黎曼积分理论里到处都是可数并：可数个开区间拼出一个开集，而开集正是逼近一切积分的砖块。目标函数（积分）被"有限并"卡死了。

所以这一节我们要做一件事：换一把对**一切集合**都发数的尺子，哪怕集合长得再怪。走法是教科书式的"先放开，再收紧"：先放开——允许用**可数**个盒子去盖，读数定义为"最省盖法的总长"；再收紧——接受这把新尺子只满足较弱的律（可数次可加，≤），并追问等号何时成立。读者即将亲手走一遍"量有理数失败 → 换盖法实验 → 概念被逼出场"的完整旅程。

## 2 盖盒实验：外测度被逼出场

先把最自然的想法试一遍。你有一把尺子，想量 ℚ∩[0,1]。最直接的做法是"一段一段量"——可 ℚ∩[0,1] 里没有任何一段完整区间，尺子落下去全是空，无从下手。

那就绕路：不直接量它，用几个盒子把它**盖**住，量盖子的总长，再找最省的那种盖法。这正是 Jordan 外测度的思路，可它限定只用**有限**个盒子，而这正是死穴：有限个正体积盒子的并必含一块实心区域（某个盒子的内部），要盖住只有"点"没有"块"的 ℚ∩[0,1]，除非用零体积盒子，否则总会盖多。事实上 Jordan 外测度量的是**闭包**——有理数在 [0,1] 里稠密，任何有限盖都顺带把 [0,1] 盖进去了，读数 = 1。直觉上"啥也不是"的一堆点被读出 1，这不是尺子精度不够，是"有限"这两个字把尺子焊死了。

那换一个改法：把"有限"放宽成"可数"。有理数可数，把它排成一列 q₀, q₁, q₂, …；给第 n 个有理数配一个半径 ε/2^(n+1) 的开区间。这个实验做起来是这样：第 n 个区间长度 = 2·ε/2^(n+1) = ε/2ⁿ，整个覆盖的总长是

```
Σₙ ε/2ⁿ = ε·(1 + 1/2 + 1/4 + …) = 2ε
```

取 ε = 1/2，总长恰好 = 2·(1/2) = **1**——和 Jordan 读数一样，没什么稀奇。可取 ε = 1/100，总长 = 2/100 = **1/50**：同样盖住全部有理数，开销缩了五十倍。ε 想取多小就多小，于是"最小盖长"被压到 0。注意这套覆盖允许越界——它从没被要求待在某段区间内部，盒子多盖出去不扣分，盖不住点才扣分。

实验到此，出路只剩一条：**允许可数个盒子，把"覆盖总长的下确界"定义为集合的读数**。这就是 Lebesgue 外测度：

```
m*(E) = sInf { V | ∃ 可数盒子族 {Bₙ}，E ⊆ ⋃ Bₙ ∧ V = Σₙ |Bₙ|ᵥ }     （Section_1_2_0.lean:1338）
```

m\* 的值域是扩展实数 EReal，允许 +∞——无界集合（比如 ℝ 自己）当然量不出有限数。定义刚落地，立刻验三笔账：单点 {x} 在 d > 0 时用一个零体积盒 [x,x] 就盖住，m\*({x}) = 0，和 Jordan 一致；空集用空覆盖，m\*(∅) = 0；区间 [0,1] 自己就是盒子，m\*([0,1]) = 1。最关键的对照是 ℚ∩[0,1]：上面的实验给出 m\*(ℚ∩[0,1]) ≤ 2ε 对一切 ε > 0 成立，所以读数 = **0**——同一堆点，Jordan 读出 1，Lebesgue 读出 0。这把尺子真的变细了：它不再量"闭包"，改量"点本身"。

这里有一个 0 维的坑要提前说破。盒子体积是边长乘积 ∏ᵢ(bᵢ − aᵢ)；d = 0 时这是**空乘积**，约定空乘积 = 1（乘法单位元，与"空和 = 0"的加法约定同构地自然）。于是 ℝ⁰ 是单点集，每个"盒子"都是全空间、体积 1，单点盒不再零体积，"可数集零测"直接失效（见 T6 的 d > 0 前提）。正因为 d = 0 时没有零体积盒可用来填充，Lean 的定义用 `Set ℕ` 指标的**可数族**而非 ℕ 序列（注释见 `Section_1_2_0.lean:1337`）；d > 0 时两者等价（`Lebesgue_outer_measure_eq_nat_indexed`，:1344）。1 维里"点长 0"的直觉搬到 0 维就翻车：那里点就是全空间。

还有一个下确界的空集陷阱，说破了免得后面慌：EReal 里 sInf ∅ = ⊤，但没有任何集合真会走进这个分支——任意 E ⊆ ℝᵈ 都有覆盖（连全空间都只需可数个大方盒 {[−N,N]ᵈ}），候选值集永不为空；Lean 证 m\* ≥ 0（`nonneg`，:85）时要覆盖"候选集为空"的一般情形，属定理证明的泛化处理，不是定义有洞。

新尺子最要紧的律是**可数次可加**：盖 Eₙ 的盒子叠在一起就是盖 ⋃Eₙ 的盒子，所以 m\*(⋃ₙEₙ) ≤ Σₙ m\*Eₙ（`union_le`，`Section_1_2_1.lean:159`）。不等式而不是等式，因为盖 E₁ 的盒子和盖 E₂ 的盒子可以重叠，叠起来时重叠部分被算了两遍——多算不亏，少算才亏。等号什么时候能写？两个答案。第一个是本节定理：两集合**隔得够远**（距离 > 0，T3）。第二个预告性地留到 §1.2.2：集合**可测**——`LebesgueMeasurable E := ∀ ε > 0, ∃ U 开, E ⊆ U ∧ m*(U \ E) ≤ ε`（`Section_1_2_0.lean:2291`），"能被开集从外面逼近到任意误差 ε"。这是本节所有铺垫指向的验收标准，读者现在只需要记住：**"可测"是外测度把 ≤ 升级成 = 的资格证**，下节发证。

在证明可数次可加之前，先认识下确界的**ε 性格**，因为它是预算分配的根据：c = sInf S 意味着对任意 ε > 0，存在候选值 s ≤ c + ε。反证：若所有候选值都 > c + ε，则 c + ε 是 S 的下界，比下确界还大，矛盾。翻译回我们的场景：**对任意 ε > 0，存在一个覆盖，总长 ≤ m\*(E) + ε**。这正是 Lean 的 `exists_cover_close`（:2146）。注意它要求 m\*E ≠ ⊤——若 E 的外测度本来就是 ∞，这句话没有内容，好在 ∞ 的情形不等式平凡。

## 3 把秤校准：核心定理

先验公理。**空集读数 0、单调、非负**（`of_empty` :52，`mono` :74，`nonneg` :85）——这三条的证明都是"下确界的定义战"，一边用具体覆盖夹住一边（空集：∅ ⊆ 空覆盖族，候选值含 0 而一切覆盖总长 ≥ 0，两边夹出 0；单调：F 的每个覆盖自动覆盖 E，候选值集合反向包含，下确界变小；非负：所有候选值 ≥ 0）。这套"下界靠具体覆盖（csInf_le）、上界靠普适论证（le_csInf）"的两头夹，是本节的招牌手法。它们意味着：外测度不挑食，但讲规矩——集合越大读数越大，读数从不为负。这条"秤"至少是一把正经秤。

接下来是本节分量最重的定理，可数次可加（`union_le` :159）。证明骨架：任取 ε > 0。对每个 Eₙ，用 ε 性格选一个覆盖 Sₙ，总长 ≤ m\*Eₙ + ε/2^(n+1)（误差预算逐项递减）；可数多个覆盖按 ℕ×ℕ 打包成一个覆盖（`Nat.pairEquiv.symm`，:230），其总长 ≤ Σₙ m\*Eₙ + Σₙ ε/2^(n+1) = Σₙ m\*Eₙ + ε（几何级数 `tsum_geometric_eps`，:149）；ε 任意小，用 `EReal.le_of_forall_pos_le_add'` 让 ε → 0，收工。注意预算为什么拨 ε/2^(n+1)：Σ ε/2^(n+1) = ε 精确等于 ε，是最干净的预算方案，但不是唯一方案——任何可和正序列都行（比如 ε/(n+1)²，总和 ε·π²/6，稍大同样随 ε → 0 消失），几何级数赢在总和对账最整齐。这个定理意味着：可数个集合拼起来，读数最多等于读数之和——多算可能，少算不可能。把有限族用 ∅ 补齐成可数族，就得有限次可加（`finite_union_le` :442），这也是后面所有"≤"方向论证的免费午餐。

但且慢——"可数次可加"说 ≤，那"不可数次可加"呢？连 ≤ 都救不回来，这是本节最重要的反例（`Section_1_2_1.lean:3499`）：把单位立方体拆成单点，[0,1]ᵈ = ⋃ {x}（x 跑遍整个立方体），每个单点 m\*({x}) = 0，可 m\*([0,1]ᵈ) = 1。若"不可数和"存在，则 1 ≤ Σ 0 = 0，荒谬。这不是规定而是事实：可数级数 Σₙ aₙ 的机器定义是部分和序列的极限，依赖"按 ℕ 排成一列"；对不可数族，数学里没有配套的求和运算（∑' 的指标必须是可数类型）——"把每个点的贡献 0 加起来"是自由联想，换成"每个点贡献 1"同样自洽却得到不同结果，说明这条路根本没定义。测度论里"单点零测 ⟹ 并零测"的合法桥梁只有可数次可加，它只对可数并开门；不可数并连桥都没有。这个反例同时预告了下节的主题：外测度在全体集合上只能保证 ≤，只有把集合收进"可测"一族，= 才肯现身。

既然 ≤ 是常态，什么时候能写成 =？T3 给出第一个充分条件。先定义**集合距离**：`set_dist E F := sInf { dist x y | x ∈ E, y ∈ F }`（:503）。引理 1.2.5：`set_dist E F > 0 ⟹ m*(E ∪ F) = m*(E) + m*(F)`（`union_of_separated`，:2268）。立刻用数字检验。取 E = [0,1]、F = [2,3]：距离 = 1（x = 1、y = 2 恰好取到 |1−2| = 1，且任何 x ∈ [0,1]、y ∈ [2,3] 都有 y − x ≥ 1），于是 m\*([0,1] ∪ [2,3]) = m\*([0,1]) + m\*([2,3]) = 1 + 1 = **2**。换非对称版：E = [0,1]、F = [2, 2.5]，距离仍是 1，m\* = 1 + 0.5 = **1.5**。这套"先量分块再相加"的算术，是后面勒贝格积分线性的最原始模型。证明骨架：≤ 方向是有限次可加，免费；≥ 方向是本节最硬的活，关键一步是**把覆盖盒子的直径压到比距离还小**——取 r 满足 0 < r < set_dist E F，把每个盒子反复二等分（`subdivide_iter`，:1410）直到直径 < r（`diameter_lt_of_iter_count`，:1789）；二等分不改变总体积（`volume_subdivide_iter`，:1556），细化免费。细分后每个盒子直径 < 距离，一个盒子不可能同时碰到 E 和 F（`not_intersects_both_of_diameter_lt`，:1207：若同时碰到，取 x ∈ B∩E、y ∈ B∩F，盒内两点距离 ≤ 直径（`dist_le_diameter`，:843），于是 set_dist E F ≤ dist x y ≤ 直径 < set_dist E F，严格小于自己，矛盾）。把盒子按"碰 E / 碰 F"分成两堆，两堆分别覆盖 E 和 F，于是 m\*E + m\*F ≤ 总开销 ≤ m\*(E∪F) + ε，ε → 0 收工。这套"先粗覆盖、再细分"的打法值得记住：它把"盒子碰两边"这个尴尬局面，用几何强制拆开。

"隔得够远"和"不相交"是两回事，这是本节最容易栽的直觉陷阱：**不相交集合的距离可以是 0**。E = [0,1)、F = [1,2] 不相交，但取 x = 1 − δ ∈ E、y = 1 ∈ F，距离 = δ 任意小，set_dist = 0（Lean 机验：`Section_1_2_1.lean:2463`）。所以引理 1.2.5 对这堆集合不适用——结论碰巧还对（m\*([0,2]) = 2 = 1 + 1，因为闭开区间都是初等集），但证明的脚手架（细分盒子分组）在距离 = 0 时整条断裂：一个盒子可以同时碰到两边，分不了家。假设是证明的脚手架，不能拆了脚手架说房子还站着。配套的习题 1.2.4 给出一个保底判据：**不交的紧集距离一定 > 0**（`dist_of_disj_compact_pos`，:2515）。骨架一句话点破：反证——若距离 = 0，取 xₙ ∈ E、yₙ ∈ F 距离 → 0，紧致性抓子列（E 紧 + F 闭），极限点同时属于 E 和 F，矛盾。这是"反证法 + 紧致抓子列"的教科书出场。

**T4：盒子的外测度 = 体积**（`Lebesgue_outer_measure.elementary`，:3471）：E 是初等集时 m\*(E) = hE.measure。≤：E 自己覆盖自己，sInf ≤ |E|。≥：任取覆盖 E 的盒子族，把初等集拆成有限盒并，用有限次可加把"覆盖体积总和"逐块压到 ≥ |E|——关键一步是把总和拆成"每个组成盒被覆盖的体积"之和，再用单调性逐个控制。推论：m\*([0,1]) = 1、m\*((0,1)) = 1、m\*([0,1]ᵈ) = 1。这个定理回答了上节遗留的问题：新尺子对旧尺子能量的一切集合，读数分毫不差——改的只是"量法"，不是"数值"。

**T5：Lebesgue 外测度 ≤ Jordan 外测度**（`Lebesgue_outer_measure_le_Jordan`，`Section_1_2_0.lean:1872`）。为什么可信：Jordan 外测度是"用**有限**个盒子的总长取下确界"（`Jordan_outer_eq`，:1173），Lebesgue 放宽成可数盒族——候选值集合更大，下确界只降不升。关键一步：**把有限覆盖当可数覆盖**（尾巴接零体积盒）。这是"放权给可数"第一次带来实打实的收益：秤变细了，读数只降不升。它意味着：Lebesgue 测度是 Jordan 测度的精化，不是另起炉灶。这里有个漂亮的副产品（Remark 1.2.8，机验 `Section_1_2_1.lean:3914`）：取 ε = 1/3 时的 U(1/3)（§2 那套有理数覆盖），它是**有界开集**却非 Jordan 可测——m\*(U(1/3)) ≤ 2/3（可数次可加，`U_lebesgue_le` :3869），而 Jordan 外测度 ≥ 1（有理数稠密 ⟹ 闭包 ⊇ [0,1]，单调性）；0.666… < 1 这一道不等式就把 Jordan 可测性判了死刑。开集——每个点都是内点的规规矩矩的集合——居然进不了 Jordan 体系，这就是"有限"和"可数"水火不容的铁证。

**T6：可数集零测**（`Countable.Lebesgue_measure`，`Section_1_2_0.lean:2189`）：d > 0 时，可数集的外测度 = 0。骨架：枚举 E = {xₙ}，用单点盒 {xₙ} = Icc xₙ xₙ 盖住，d > 0 时单点盒体积 0（`Box.volume_singleton`，引用处 :2215），总开销 = Σ 0 = 0，非负给出等号。关键一步：**零体积的盒子不贡献任何开销**。注意它依赖 d > 0——0 维空间里单点盒体积是 1，定理失效（这正是 §2 那个 0 维特判的原因）。推论实例（均已机验）：ℚ∩[−R,R] 的外测度 = 0（`Section_1_2_0.lean:2275`），全部 ℚ 也 = 0（:2285）；对照同一定义域上的 Jordan 读数 = 2R（:2065）。同一个对象，两把尺子差了一个"闭包"。

**T7：外正则性**（`Lebesgue_outer_measure.eq`，:5732）：m\*(E) = sInf { m\*(U) | E ⊆ U，U 开 }——外测度可以完全用**开集**从外面逼近。≤ 方向免费（单调性）；≥ 方向是把盒覆盖变成开集覆盖：对每个盒子 B 和 ε > 0，微胀成一个开盒子，体积至多多出 ε/2^(n+1)（几何级数第三次出场），得到开 U 使 m\*U ≤ m\*E + ε。ε 版本 `exists_open_superset_measure_le`（:6009）：对任意 ε > 0 存在开 U ⊇ E 且 m\*U ≤ m\*E + ε。这意味着 LebesgueMeasurable 定义（`Section_1_2_0.lean:2291`）里"从外面逼近"不是空头支票——本节已经证明了它永远可行。顺带：书上引理 1.2.11 用二进立方体算外测度，Lean 有整套对应机器（`DyadicCube`，`Section_1_2_1.lean:4792`；`IsOpen.exists_dyadic_cube_subset`，:5113），那是为 §1.2.2"开集 = 二进立方体可数并"的分解服务的。

**T8：紧集外测度有限**（`finite_of_compact`，:6065）。骨架：紧集有界，装进大方盒 [−M,M]ᵈ，方盒是初等集、外测度 = (2M)ᵈ < ∞，单调性收尾。关键一步：**先找一顶有限体积的"大伞"，让所有集合都在伞下**。这定理同时拆掉一个诱惑：别把"无界"和"外测度 = ∞"划等号。反例：以每个整数 n 为中心、半径 2^−|n| 的开区间，总长 Σₙ 2·2^−|n| = 2·(1 + 2·(1/2 + 1/4 + …)) = 2·3 = **6**——一个无界集合拥有总长 6 的覆盖！可它盖不满 ℝ：1.5 就不在任何区间里（n = 1 的区间 (0.5, 1.5) 是开的，1.5 不在其中；n = 2 的区间从 1.75 才开始）。"有总长有限的覆盖"和"覆盖住 ℝ"是两回事，后者不存在。m\*(ℝ) = ∞ 的严格证法走**单调性**而不是"无界所以盖不完"：ℝ ⊇ [0,N] 对一切 N，m\*(ℝ) ≥ m\*([0,N]) = N（T4），N 任意大，故 m\*(ℝ) = ⊤（`Lebesgue_outer_measure.univ`，:4546）。外测度为 ∞ 的集合在积分理论里对应"测度无限"的积分区域，常见，不病态。

## 4 FAQ 与反直觉清单

1. **为什么外测度只有 ≤ 可加，而不是 =？** 覆盖可以"重复计算"：盖 E 的盒子和盖 F 的盒子重叠，叠起来盖 E∪F 时重叠部分被算两遍。只有保证"不重叠"才还你等号——两个保底：集合隔得够远（T3），或集合可测（§1.2.2）。
2. **m\*(ℚ∩[0,1]) = 0，可它稠密，为什么"从外面包"包不住它？** 稠密只说明任何开集都含 ℚ 的点，不说明开集体积压不下去——§2 的实验用总长 1/50 的开区间并就盖住了全部有理数。Jordan 秤量"闭包"（1），Lebesgue 秤量"点本身"（0）。
3. **不交集合的外测度之和一定等于并的外测度吗？** 不一定。T3 需要 set_dist > 0；[0,1) 与 [1,2] 距离 = 0（:2463），结论碰巧对是初等集的运气，不是定理。可测集才把"不交即可加"彻底买断。
4. **m\* 会等于 ∞ 吗？** 会，ℝ 就是（`univ`，:4546）。但别推广成"无界 ⟹ ∞"：整数中心、半径 2^−|n| 的区间族总长 6，并集无界。外测度 = ∞ 的严格判据要别的工具，紧集总是有限的（T8）。
5. **为什么用一般盒子而不用开盒子？** 等价。定义用一般盒子是"放宽"；外正则性（T7）证明开集覆盖已足够逼近；闭盒对 T4 直接给体积。各家教材选择差异见教材对照。
6. **0 维为什么特殊？** d = 0 时空间是单点集，盒子体积 = 空乘积 = 1，单点盒不零体积，可数集零测失效（T6 的 d > 0 前提），定义被迫用可数族而非 ℕ 序列（`Section_1_2_0.lean:1337`）。形式化为此付出了不小代码量（`Lebesgue_outer_measure.eq` 里整整一个 0 维分支）。
