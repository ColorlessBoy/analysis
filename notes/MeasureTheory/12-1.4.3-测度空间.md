# 12 · 1.4.3 可数可加测度与测度空间：舞台搭好了，演员登场

> Tao《An Introduction to Measure Theory》§1.4.3 讲稿式笔记 + Lean 形式化对照
> 一句话纲领：**1.4.1 与 1.4.2 建好了舞台 (X, 𝒜)——布尔代数、σ-代数、可测空间。但舞台是空的：还没有"量"什么东西。本节给舞台配上演员——测度 μ : 𝒜 → [0,∞]，一条非负、一条空集为零、一条**可数可加**（不交可数并的测度等于测度之和）。"可数可加"是全场的主角：它对全体集合不可实现（Vitali 反例），却正好在 σ-代数上可实现——1.4.2 的舞台尺寸是量着这个演员的身材造的。测度空间 (X, 𝒜, μ) 就是舞台 + 演员的打包，它是本章的总装线终点：1.2 的 Lebesgue 测度、1.3 的积分理论，此后都只是"某个测度空间上的事"。**

## 1 这一幕要解决什么

把 1.4.2 的结尾读一遍：我们有了可测空间 (X, 𝒜)——一个底空间，一份"哪些集合有户口"的花名册。花名册本身不产生任何数字。从 1.1 到 1.2 我们一直在干的事，是给 ℝᵈ 的子集**赋值**：初等集有体积，Jordan 可测集有 Jordan 测度，Lebesgue 可测集有 Lebesgue 测度。现在舞台换成了任意的 X，问题就变成：**"测度"这个词，在 (X, 𝒜) 上到底应该满足什么规则，才算是一个配得上这个名字的量具？**

把这个问题问具体一点。1.2.3 的 Vitali 反例告诉我们一个冷冰冰的事实：在 ℝ 上，**不存在**定义在全体子集（幂集）上的、平移不变且可数可加的量具——不然 [0,1] 会被拆成可数个彼此平移等价的碎块，量出既大于 1 又小于 3 的矛盾。所以"可数可加"不是我们想要就要得起的：**它对全空间不可实现，对 σ-代数（Lebesgue 可测集那个户口本）却正好实现**。这几乎是本节全部内容的预告：可数可加是唯一配得上"测度"之名的账目规则，而它存在的条件，正是 1.4.2 花了一整节打造的 σ-代数。这一节要做的，就是把这条规则连同它的全部推论（单调性、次可加性、上下连续性、零测集、完备性）一次性地、在任意 X 上立起来——（预告，不是回顾：）1.3 的积分是在 ℝᵈ + Lebesgue 测度上具体定义的，Tao 随后会把积分整个搬到抽象测度空间上，而那套积分只认 (X, 𝒜, μ) 这三件套——所以这三件套今天必须封顶。

## 2 有限可加测度：先立最基本的账目规则

先做"重新发明"实验。你有一把新尺子，想量 (X, 𝒜) 里的每个可测集。最朴素的想法：给每个可测集 E 配一个数 μ(E)，然后立三条谁也无法反对的账目规则——空集量出 0；任何集合量出非负数；**不交的两个集合，并起来的读数等于读数之和**。先试试最后这条只对"两个"集合要：这就是"有限可加"（Tao 定义 1.4.19，机器 `FinitelyAdditiveMeasure`，`Section_1_4_3.lean:15`）：

```lean
class FinitelyAdditiveMeasure {X : Type*} (B : ConcreteBooleanAlgebra X) where
  measure : Set X → EReal
  measure_pos : ∀ A : Set X, B.measurable A → 0 ≤ measure A
  measure_nonneg : ∀ A : Set X, 0 ≤ measure A
  measure_empty : measure ∅ = 0
  measure_finite_additive : ∀ E F : Set X, B.measurable E → B.measurable F →
    Disjoint E F → measure (E ∪ F) = measure E + measure F
```

注意两个设计细节，都是被逼出来的。第一，`measure` 定义在**全体子集**上（类型 `Set X → EReal`），但真正作数的账目规则——空集为零、有限可加、以及 `measure_pos`——只约束**可测集**；不可测集的读数是一个"不作数的影子值"。不过代码里还有第四条 `measure_nonneg : ∀ A, 0 ≤ measure A` 是**全局**的（对所有子集，包括影子值），它是证明时的便利公理：中间步骤（比如单调性证明里对 F\E 用非负性，:296）省去反复搬运可测性证据，而 `measure_pos` 才是"可测集上非负"这条账目规则的诚实形态——两条分工如此，前者管账目、后者管证明便利，并不冗余（这与 1.2 的外测度同构：m\* 定义在幂集上，账目规则也只对可测集最终成立）。第二，值域是 EReal（扩展实数）而不是 ℝ——因为 ∞ 必须住得进来，下面立即会看到为什么；至于为什么不用 [0,∞] 而用含 −∞ 的 EReal，这是 1.1/1.2 一路的延续（`Lebesgue_outer_measure` 就是 EReal 值的），且 EReal 有减法运算，`mes_union_add_mes_inter`（:332）里的 `abel` 代数操作畅通无阻，而 ENNReal 没有减法——−∞ 只是载体的形式成员，非负公理把实际读数永远钉在 [0,∞] 上，桥接时用 `toENNReal` 翻译（:896）。

定义之后立即检验。第一个演员：**Dirac 测度** δₓ₀（例 1.4.22，`FinitelyAdditiveMeasure.dirac`，`Section_1_4_3.lean:76`）——把所有质量压在一点 x₀ 上的量具：δₓ₀(E) = 1 若 x₀ ∈ E，否则 0。取 x₀ = 0，读几个数：δ₀([0,1]) = 1，δ₀((0,1)) = 0，δ₀({0}) = 1，δ₀(ℝ) = 1。注意端点：δ₀ 对"0 在不在集合里"敏感到端点级别，这与长度不同——长度量 (0,1) 和 [0,1] 都是 1，δ₀ 量出 1 和 0。检验有限可加：δ₀((0,1) ∪ (1,2)) = δ₀((0,2)\{1}) = 0 = 0 + 0 ✓；δ₀([0,1] ∪ (1,2]) = 1 = 1 + 0 ✓——0 只可能在一个不交族的一个成员里，所以"至多一项是 1"就是 Dirac 的一切（这个观察后面是可数可加的证明本身）。第二个演员：**计数测度**（例 1.4.26，`FinitelyAdditiveMeasure.counting`，`Section_1_4_3.lean:260`）——μ(E) = |E|（有限或 ∞，机器用 `ENat.card`）。读数：count({1,2,3}) = 3，count(∅) = 0，count(ℕ) = ∞。检验有限可加：count({1,2} ∪ {3,4}) = 4 = 2 + 2 ✓。第三个演员就是老熟人：**Lebesgue 测度**（例 1.4.21，`FinitelyAdditiveMeasure.lebesgue`，`Section_1_4_3.lean:25`），它通过 `restrict_alg`（:42）同时住进初等代数、Jordan 代数、Lebesgue σ-代数、零测集代数四个户口本（:59–71）——同一个函数，不同舞台，读数一致：m([0,1]²) = 1 在四个代数上都是 1。

舞台上的算术也立起来了：零测度 μ ≡ 0 是合法演员（例 1.4.23，:106），两个演员可以相加、乘非负系数（例 1.4.24，`instAdd` :126、`instSmul` :147），比如 μ = 2δ₀ + 3δ₁：μ({0,1}) = 2 + 3 = 5，μ({0}) = 2，μ({2}) = 0。测度可以限制到子集上（例 1.4.25，`restrict` :231）：m 限制到 [0,1] 上，量 (A 内的 [0,1/2]) 得 1/2。甚至在一个有限原子代数上，一个测度被它在原子上的取值完全决定（习题 1.4.21，`finite_atomic_eq` :478）：抛骰子 X = {1,…,6}、原子是单点、权重 cᵢ = 1/6，则 μ(E) = |E|/6——μ({1,2}) = 1/6 + 1/6 = 1/3。一切都很顺。

## 3 可数可加：第二次把"有限"换成"可数"

现在让上一节的尺子崩掉。**有限可加不够，而且失败点与 1.2.1 的教训一模一样。** 看 ℕ 上的这个量具：μ(E) = 0 若 E 有限，μ(E) = ∞ 若 E 无限。检查有限可加：E、F 不交——都有限则并有限，0 = 0 + 0 ✓；一有限一无限则并无限，∞ = 0 + ∞ ✓；都无限则并无限，∞ = ∞ + ∞ ✓。三条账目规则全部通过！但读者已经看见裂缝了：ℕ = ⋃ₙ {n} 是可数个单点的不交并，而 μ(ℕ) = ∞ ≠ ∑ₙ μ({n}) = ∑ₙ 0 = 0。**有限可加管不住可数并**——这正是 1.2.1 里 Jordan 测度量不了 ℚ∩[0,1] 的那个结构：单点都是零，可数并却是正质量（那里的答案是 ε/2ⁿ 预算，这里要的是公理升级）。另一个方向上的失败同样致命：1.3 的积分理论要"极限与测度换序"（单调收敛），而那只由可数可加提供——有限可加只给有限并的账目，给不了"lim μ(Eₙ) = μ(lim Eₙ)"。

修补方案是什么？把第三条公理从"两个集合"换成"可数个集合"：对不交可测族 (Eₙ)，要求 μ(⋃ₙ Eₙ) = ∑ₙ μ(Eₙ)。但这一换，两个配套问题同时爆炸。第一，**右端是无穷级数**——计数测度给出 ∑ₙ 1 = ∞，所以值域必须含 ∞，这就是 §2 里 EReal/ENNReal 的伏笔兑现（Jordan 测度只取有限值，于是无界集全部没户口；我们这次直接允许 ∞）。第二，**左端 ⋃ₙ Eₙ 必须可测**——这一步不是免费的，它正是 σ-代数公理（1.4.2 的 `countable_union_mem`）。于是 1.4.2 的舞台尺寸在这里被证明是"量着演员的身材造的"：**可数可加测度只能住在 σ-代数上**。这就是概念的必然出场（Tao 定义 1.4.27，机器 `CountablyAdditiveMeasure`，`Section_1_4_3.lean:521`）：

```lean
class CountablyAdditiveMeasure {X : Type*} (B : ConcreteSigmaAlgebra X)
    extends FinitelyAdditiveMeasure B.toConcreteBooleanAlgebra where
  measure_countable_additive : ∀ (E : ℕ → Set X), (∀ n, B.measurable (E n)) →
    Set.univ.PairwiseDisjoint E → measure (⋃ n, E n) = ∑' n, (measure (E n))
```

`extends` 一词说明它是 1.4.19 的纯升级：少一条都不是，多一条正好。公理里的 `∑'`（tsum）是"非负族的无穷和"的标准记号，第一次见面先交代清楚：对取值非负的数列，它等于**按任意顺序求和**的公共值——和有限时就是普通级数和，否则就是 ∞（所以计数测度给出 ∑ₙ 1 = ∞，合法）；EReal 上的 `∑'` 由 ENNReal 上的 `∑'` 经系数同态转移定义（`coe_tsum_ereal`，:544），而"顺序无关"正是本节后面一切换序论证（`tsum_comm_ereal` :593，Fubini 雏形）的根基。机器还给出了"升级的判定标准"——一个住在布尔代数上的有限可加测度，何时能升级成可数可加测度（`FinitelyAdditiveMeasure.isCountablyAdditive`，:525）：**舞台要升级成 σ-代数（B.isSigmaAlgebra），账目要升级成可数可加**，两件事打包成一个 Prop；`toCountablyAdditive`（:530）把这个证据机械地变成类实例。**测度空间 (X, 𝒜, μ) 就是这三件套**：自定义口径里它就是 `B : ConcreteSigmaAlgebra X` 与 `μ : CountablyAdditiveMeasure B` 的对（类本身就是数据结构）；Mathlib 口径里是 `[MeasurableSpace X]` 类型类与 `μ : Measure X`。

三个主角全部通过机器验收（例 1.4.28–29）：

- **Lebesgue 测度**（`lebesgue_isCountablyAdditive`，:647）：证明只有两行，关键一步是调用 1.2.2 的 `Lebesgue_measure.countable_union`（`Section_1_2_2.lean:2398`）——那是 1.2.2 用 ε 论证买来的可数可加性，现在被"升级"成抽象概念的一个实例。**这意味着什么**：1.2 那套具体构造没有白费，它生产的正是"抽象测度"这个词的一个模范住户。
- **Dirac 测度**（`dirac_isCountablyAdditive`，:669）：关键一步是引理 `dirac_tsum`（:620）——不交族里至多一个成员含 x₀，所以级数 ∑ₙ δₓ₀(Eₙ) 至多一项是 1，其余全 0，于是"若 x₀ 在并里则和为 1，否则为 0"，恰等于 δₓ₀(⋃Eₙ)。对任意 σ-代数都成立（前提 hB : B.isSigmaAlgebra）。
- **计数测度**（`counting_isCountablyAdditive`，:678）：对任意 X 的幂集成立。证明绕道 Mathlib 的 `Measure.count` 的 `m_iUnion`——"可数并的元素数等于元素数之和"（`ENat.card`）就是这条公理的诚实兑现。

此外可数可加测度继承全部舞台操作：限制到子代数（`restrict_alg` :660）、限制到子集（例 1.4.30，`CountablyAdditiveMeasure.restrict` :705）、加与数乘（习题 1.4.22，`instSmul` :792 与 `sum` :833——可数个测度逐点求和仍是测度，关键一步是双重级数的可换序 `tsum_comm_ereal`，:593，这是 Fubini 的雏形）。

## 4 标准推论：单调性、次可加性、上下连续性

一个定义值不值钱，看它能白送多少推论。这一节全部是习题 1.4.20–1.4.23，机器逐个验证，我们逐个看"为什么可信 + 骨架 + 关键一步"。

**单调性**（习题 1.4.20(i)，`FinitelyAdditiveMeasure.mono`，:277）：E ⊆ F 且都可测 ⟹ μ(E) ≤ μ(F)。为什么可信：大集合至少装下小集合的账。骨架：把 F 拆成不交的 E ⊔ (F\E)，有限可加得 μ(F) = μ(E) + μ(F\E)，再丢掉非负项。**关键一步**是 F\E 可测——σ-代数对差封闭（补与交的组合），这正是 1.4.2 白送的。数字检验：count({0,1}) = 2 ≤ count({0,1,2,3}) = 4。

**有限可加、有限族版**（习题 1.4.20(ii)，`finite_additivity`，:308）：不交的有限族，μ(⋃_{j∈I} Eⱼ) = ∑_{j∈I} μ(Eⱼ)。骨架：对 |I| 归纳，归纳步把新成员 Eⱼ 与已并的 ⋃_{i∈J} Eᵢ 分离。**关键一步**：用 pairwise disjoint 证明 Eⱼ ∩ (⋃_{i∈J} Eᵢ) = ∅，然后落在二元的 `measure_finite_additive` 上。它让"有限可加"从两个集合升级到任意有限多个——注意归纳只能到有限，到不了可数，这正是 §3 要补的洞。

**并 + 交的公式**（习题 1.4.20(iv)，`mes_union_add_mes_inter`，:332）：μ(E∪F) + μ(E∩F) = μ(E) + μ(F)。为什么可信：两边都把"重叠部分"算了两遍。骨架：E ∪ F = E ⊔ (F\E)、F = (E∩F) ⊔ (F\E)，两个不交分解各用一次有限可加，再 abel。数字检验：count：E = {1,2}，F = {2,3}：μ(E∪F) + μ(E∩F) = 3 + 1 = 4 = 2 + 2 ✓。

**有限次可加**（习题 1.4.20(iii)，`finite_subadditivity`，:383）：μ(⋃_{j∈I} Eⱼ) ≤ ∑ μ(Eⱼ)。**关键一步**：从上面的公式挤出 μ(E∪F) ≤ μ(E) + μ(F)（丢掉非负的 μ(E∩F)），再归纳。注意这是从"等号"退化出"不等号"——不交才有等号，重叠只给不等式，直觉完全对。

**可数次可加**（习题 1.4.23(i)，`Measure.countable_subadditivity`，:954）：μ(⋃ₙ Eₙ) ≤ ∑ₙ μ(Eₙ)。证明骨架（机器只调一行 mathlib 的 `measure_iUnion_le`，:956）：**不相交化**——令 Eₙ' = Eₙ \ ⋃_{m<n} Eₘ，则 (Eₙ') 不交、⋃ Eₙ' = ⋃ Eₙ、Eₙ' ⊆ Eₙ，于是可数可加 + 单调性夹出不等式。**这意味着什么**：这就是 1.2.1 的 ε/2ⁿ 预算的正式形态——"可数个来源的泄漏总和不超过预算"，外测度的灵魂就是它。测度从可数可加免费获得可数次可加，外测度却只有后者——这条区别贯穿全书。

**向上单调收敛（集合版 MCT）**（习题 1.4.23(ii)，`Measure.upwards_mono`，:959）：Eₙ 单调上升（Monotone E）⟹ μ(⋃ₙ Eₙ) = ⨆ₙ μ(Eₙ)。为什么可信：并是"逐点极限"，测度是"可数可加的"，两者应该换序。数字走一遍：ℝ 上取 Eₙ = [0, n/(n+1))，则 μ(E₁) = 1/2，μ(E₂) = 2/3，…，lim n/(n+1) = 1；而 ⋃ₙ Eₙ = [0,1)（对任何 x < 1，取 n > 1/(1−x) − 1 即得 x ∈ Eₙ），μ([0,1)) = 1 ✓。骨架：不相交化后，部分和 ∑_{n≤N} μ(Eₙ') 的极限就是上确界。**关键一步**：上确界 ⨆ 对 [0,∞] 值域**永远存在**（无需收敛性论证）——这是值域含 ∞ 的第二个红利。向上版**不需要任何有限性假设**：计数测度上 Eₙ = {0,…,n} 上升，count(Eₙ) = n+1 → ∞ = count(ℕ) ✓。**这意味着什么**：这就是 1.3 节积分单调收敛定理的集合版地基。

**向下单调收敛**（习题 1.4.23(iii)，`Measure.downwards_mono`，:964）：Eₙ 单调下降（Antitone E）且 **∃n，μ(Eₙ) < ∞** ⟹ μ(⋂ₙ Eₙ) = ⨅ₙ μ(Eₙ)。为什么可信 + 为什么要有有限性：直觉上"补集化"就能转成向上版——但补集的测度是 μ(E₁) − μ(Eₙ)，**只有 μ(E₁) 有限，"∞ − ∞"才不会出现**。骨架：E₁ \ Eₙ 单调上升，用向上版得 μ(E₁) − μ(⋂Eₙ) = lim (μ(E₁) − μ(Eₙ))，再减回去；机器实现是调 mathlib 的 `hmono.measure_iInter`（:975）。数字走一遍：ℝ 上 Eₙ = [0, 1/n]，则 μ(E₁) = 1 < ∞，μ(Eₙ) = 1/n → 0，⋂ₙ Eₙ = {0}，μ({0}) = 0 ✓。

**反例：没有有限性，向下版当场崩掉**（`Measure.downwards_mono_counter`，:977）——这是机器验证的反例，值得逐行读：取 X = ℕ、μ = 计数测度、Eₙ = {m : ℕ | n ≤ m}（即 [n,∞) ∩ ℕ）。每个 Eₙ 都无限，count(Eₙ) = ∞（机器把 Eₙ 写成 range (n + ·) 证明无限，:998–1016）；而 ⋂ₙ Eₙ = ∅——若 m ∈ ⋂ₙ Eₙ，则 m+1 ≤ m，矛盾（:986–994）；于是 μ(⋂Eₙ) = 0 ≠ ⨅ₙ count(Eₙ) = ∞（:1017–1021）。与 Lebesgue 测度在 [0,∞) 上取 Eₙ = [n,∞) 是同一个机制：每个读数 ∞，交为空，0 ≠ ∞。**这意味着什么**：有限性不是技术性假设而是本质条件——测度在 ∞ 处"失忆"，向下极限换序在无穷处不成立。向上永远免费、向下需要买票，这个不对称要刻进直觉。

## 5 测度的等级：有限、σ-有限、完全

有了测度，读者自然会问：一个测度"多大"？三个等级按强度排列，全部在本节登场。

**有限测度**：μ(X) < ∞。Dirac 测度是典范（δ₀(ℝ) = 1）；加权计数测度 μ(E) = ∑_{n∈E} 2⁻ⁿ⁻¹（权重 cₙ = 2⁻ⁿ⁻¹，习题 1.4.25 将系统研究这种形状）也是——μ(ℕ) = 1/2 + 1/4 + … = 1，它是概率论的骨架。习题 1.4.25（`Measure.on_countable`，:1303）把可数空间上的情况彻底说清：X 可数且 σ-代数离散 ⟹ 每个测度都是**加权计数测度** μ(E) = ∑'_{x∈E} cₓ，权重 cₓ = μ({x}) 且唯一。**关键一步**：E = ⋃_{x∈E} {x} 是**可数**并（X 可数），于是可数可加白送。数字检验：cₙ = 2⁻ⁿ⁻¹ 时 μ({0,1,2}) = 1/2 + 1/4 + 1/8 = 7/8；计数测度对应 cₙ ≡ 1（μ(ℕ) = ∞）；δ₀ 对应 c₀ = 1、其余 0。

**σ-有限测度**：X 可写成可数个有限测度集之并。Lebesgue 测度在 ℝᵈ 上：ℝᵈ = ⋃ₙ [−n,n]ᵈ，m([−n,n]ᵈ) = (2n)ᵈ < ∞ ✓。计数测度在 ℕ 上 σ-有限（ℕ = ⋃ₙ {0,…,n}）。**反例：计数测度在 ℝ 上不是 σ-有限的**（手工论证，本文件未形式化）：若 ℝ = ⋃ₙ Eₙ 且 count(Eₙ) < ∞，则每个 Eₙ 有限，可数个有限集之并仍可数，矛盾于 ℝ 不可数——需要**不可数**多个有限集才盖得满。为什么 σ-有限重要：下面的逼近定理假设它（`approx_sigma_finite` :2005 的 hσfin），后面的乘积测度与 Fubini 定理也要它——它是"测度论里的大多数定理"的入场券。

**完全测度空间**：零测集（μ(E) = 0 的可测集）的**每个子集都可测**。Lebesgue 测度是完备的——这不是事后补丁，而是 1.2.2 定义时就内建的：`IsNull.measurable`（`Section_1_2_2.lean:359`）说每个零测集都是 Lebesgue 可测的，于是它的子集（自动零测）也可测。Borel 测度不完备：标准论证（本文件未形式化，但每个教材都接受）——Cantor 集 C 测度 0（C 被 2ⁿ 个长 3⁻ⁿ 的区间盖住，m(C) ≤ (2/3)ⁿ → 0），而 Borel 集只有 2^ℵ₀ 个（归纳论证：开集经可数次运算生成的层只有可数个层次 ω₁ 层，每层至多 (2^ℵ₀)^ℵ₀ = 2^ℵ₀ 个成员，总数 ≤ ω₁ · 2^ℵ₀ = 2^ℵ₀，这里 ω₁ ≤ 2^ℵ₀ 是 ZFC 的标准基数事实）；C 却有多达 2^(2^ℵ₀) 个子集，故存在 C 的非 Borel 子集：零测但不可测。本文件把这条裂缝的**修补**机器化了：`borelNullMeasurable_iff_lebesgue`（:1538）说"Borel 测度的零可测集 ⟺ Lebesgue 可测集"，于是 `EuclideanSpace'.borel_completion_eq_lebesgue`（习题 1.4.27，:1651）——**Borel 测度的完备化恰好就是 Lebesgue 测度**，机器验证的等式（`Measure.equiv` :1440 的意义：两边的 σ-代数相等、可测集上取值相等）。这里"零可测集"（NullMeasurableSet）第一次登场，先交代定义：**存在可测集 t 使 E 与 t 只差一个零测集**（对称差零测，机器即 `E =ᶠ[ae μ] t`）；它等价于"存在可测超集 B ⊇ E 使 B\E 零测"（机器用的正是这个方向，`exists_measurable_superset_ae_eq`，:1360）——完备化就是把所有零可测集收进户口本。关键一步还在两处：夹逼刻画配合 `lebesgue_measurable_eq_borel_sdiff_null`（`Section_1_4_2.lean:2327`：每个 Lebesgue 可测集 = Borel 集 \ 零测集）把两边互相翻译。

完备化还满足**最小性**（习题 1.4.26，`Measure.completion_lt`，:1356）：任何完备的、在 𝒜 上与 μ 一致的扩张 μ'，都必须把 μ 的每个零可测集收进来且取值相同——即完备化是"最小的完备补丁"。证明骨架：对 μ-零可测集 E，取夹逼 B ⊇ E、B\E ⊆ N、μ(N) = 0（:1360）；μ' 的完备性把 N 变成 μ'-可测零集（:1384 用 `IsComplete` 的判定），于是 E = B △ D 可测，且 μ'(E) = μ'(B) = μ(B) = μ(E)（:1403–1434 的测度链）。**这意味着什么**：Lebesgue 测度不是"Borel 测度加了一点"，而是"Borel 测度的唯一最小完备扩张"——完备化把 1.4.2 的"两个户口本"（Borel ⊆ Lebesgue）解释成了"一个测度的两种完成度"。

## 6 与 Mathlib 的桥：toMeasure，以及 Carathéodory 扩展定理的位置

本文件结尾是一个双向翻译器，值得单独一段。`CountablyAdditiveMeasure.toMeasure`（:893）把自定义的可数可加测度变成 Mathlib 的 `Measure X`：用 `Measure.ofMeasurable` 构造，只需验证空集为零与可数并两条（:897–917），值域经 `EReal.toENNReal` 从 EReal 翻到 ENNReal。反方向 `Measure.toCountablyAdditiveMeasure`（:923）把 Mathlib 测度（外测度公理定义的那套）翻译回自定义口径——`measureOf`、`m_iUnion` 逐条对上。**这意味着什么**：两个口径是同一概念的两种包装，双向翻译无损——所以文件头注释说"之后的习题用 Mathlib 更省力"，不是换概念，是换语言。`EuclideanSpace'.lebesgueMeasure`（:1436）就是 1.2 的 Lebesgue 外测度穿上 Mathlib 制服的样子；`borelMeasure`（:1438）是它限制到 Borel 代数（经 `BorelSigmaAlgebra.le_LebesgueSigmaAlgebra`，`Section_1_4_2.lean:2319`）。

那 **Carathéodory 扩展定理**呢？诚实交代：**本文件没有它**。1.2.1/1.2.2 的那套"外测度 → 可测集 → 限制成测度"的抽象重演（在任意 X 上、任意"预测度"上重跑一遍），在 Tao 书中属于 §1.7（Carathéodory extension theorem，编号待核），Folland 则在 §1.2–1.3 以 Theorem 1.11（外测度的 Carathéodory 定理）与 Theorem 1.14（Hahn 扩展定理，编号待核）出现。本文件里它最近的两个邻居是：其一，上面的双向桥——它说明"可数可加测度"与 Mathlib 的"测度"概念互译，后者正是 Carathéodory 构造的产物；其二，习题 1.4.28 的**逼近定理**（`BooleanAlgebra.approx_finite` :1947、`approx_sigma_finite` :2005）——"σ(B) 里的每个可测集，都能被 B 里的集合在对称差意义下 ε-逼近"，这是扩展定理的密度/唯一性那一面。它证明的关键一步值得点破预算账：给第 n 个逼近项分配预算 δₙ = ε/2^(n+3)，几何级数求和得 ∑ₙ δₙ = ε/4（`geo_sum` :1809 算出首项 ε/8、公比 1/2、和为 ε/4，读者可验）；这一项**不直接花掉**，而是用来证"并的对称差误差 < ε/2"——逐项误差合计 ≤ ε/4，机器显式比较 ofReal(ε/4) < ofReal(ε/2)（:1886）；"并的尾部"（⋃Fₙ \ F'，有限并 F' 之前剩下的尾巴）由有限测度假设经 `tail_union_measure`（:1695，向上单调 + 向下极限换序）再控住 ε/2；最后两项相加：ε/2 + ε/2 = ε（:1931 用 `ring` 证明 ofReal 加法，:1942 收尾）——预算链是 ε/2 + ε/2，前一项由 ε/4 的几何预算**夹出**（留了 ε/4 的余量），不是 ε/4 + ε/2 + ε/4 三段平摊。σ-有限情形（:2005）则把每个有限测度片 Aₙ 分别逼近（restrict 后套有限情形）。**这意味着什么**：本节的抽象化不是终点——它还差"存在性"那一半（扩展定理）才算闭环，但那需要 1.7 节的篇幅，此处只是预告它逼近的一面。

顺带一提，习题 1.4.24 的"集合版控制收敛"（`measure_of_lim` :1186 及反例 `measure_of_lim_counter` :1263）把 §4 的上下连续性拧成一条：若集合序列 Eₙ **逐点收敛**到 E'（`SetConvergesTo` :1026 的定义：对每个 x，最终 x ∈ Eₙ ⟺ x ∈ E'——即指示函数 1_{Eₙ} 逐点收敛到 1_{E'}，两个方向都要；机器注释说 Sierpinski 拓扑下单向版本是偏的）且被有限测度集 F 控制，则 μ(Eₙ) → μ(E')；失去控制就崩——反例又是 Eₙ = {m ≥ n}：读数 μ(Eₙ) = ∞ 恒成立（注意是**读数**恒为 ∞，计数测度本身当然不是常值函数——count({0}) = 1），极限集空，∞ 不收敛到 0。同一家族的反例第三次出场，读者应当已经对它脱敏。

## 7 反直觉清单 / FAQ

- **为什么测度值域是 [0,∞] 而不是 ℝ？** 因为 ∞ 必须住得进来：count(ℕ) = ∞、m([0,∞)) = ∞。若限定有限值，无界集全部没户口——这是 Jordan 尺子的结构性天花板（1.1）。自定义口径用 EReal（`measure : Set X → EReal`，`Section_1_4_3.lean:16`），Mathlib 用 ENNReal；桥经 `toENNReal` 翻译（:896）。
- **为什么先定义"有限可加测度"这么弱的对象？** 它是脚手架：Jordan 测度正是这个等级（有限可加、可数可加崩在 ℚ∩[0,1] 上）；且 `CountablyAdditiveMeasure extends FinitelyAdditiveMeasure`（:521），验证一个对象可数可加 = 先建有限可加实例、再补一条级数等式（例 1.4.28–30 全是这个流程）。
- **测度与外测度什么关系？** 外测度：定义在幂集上、可数次可加（只有不等式）；测度：定义在 σ-代数上、可数可加（等式）。1.2 的外测度 m\* 限制到 Lebesgue σ-代数后就是测度——`lebesgue_isCountablyAdditive`（:647）验证的正是这件事。
- **为什么可数可加测度只能住在 σ-代数上？** 公理左端 ⋃ₙ Eₙ 必须可测；有限可加只要求二元并可测（布尔代数够用），可数并的可测性恰是 σ-代数公理（1.4.2）。`isCountablyAdditive`（:525）把"舞台是 σ-代数"写进了条件本身。
- **为什么向下单调收敛要 μ(E₁) < ∞？** 证明要借 μ(E₁) − μ(Eₙ) 做减法，∞ − ∞ 无意义；反例：count 在 ℕ 上，Eₙ = {m ≥ n}，读数全 ∞、交为空（`downwards_mono_counter` :977）。
- **Borel 测度为什么不完备、完备化是什么？** 完备 = 零测集子集都可测；Borel 不完备（Cantor 集有非 Borel 子集，基数论证），完备化 = 补上全部零测集子集；机器验证：Borel 的完备化恰是 Lebesgue（`borel_completion_eq_lebesgue` :1651），且完备化是最小的完备扩张（`completion_lt` :1356）。
- **计数测度在 ℝ 上为什么非 σ-有限？** σ-有限要求 X 是可数个有限测度集之并；计数测度下"有限测度"= 有限集，可数个有限集之并仍可数，盖不满不可数的 ℝ。
- **Dirac 测度为什么不是平移不变的？** δ₀([0,1]) = 1，而平移 1 后的 [1,2] 给出 δ₀([1,2]) = 0——平移不变会要求两者相等。对比：Lebesgue 测度平移不变（1.2 的核心性质），这就是为什么 Vitali 反例只杀平移不变的测度、不杀 Dirac。
- **为什么说这一节是整章的终点？** 1.3 的积分只认 (X, 𝒜, μ) 三件套；从此"Lebesgue 积分"只是"关于某个测度空间的积分"的特例，抽象化在此封顶。
