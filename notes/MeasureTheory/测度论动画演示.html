Cantor 三分集
每步删掉每段的中间 1/3。第 n 步剩下 2ⁿ 段，总长度 (2/3)ⁿ → 0。但段数是 2ⁿ 个——和实数的"多少"一样多。长度 ≠ 多少
n = 0 · 长度 1.000
黎曼竖切 vs Lebesgue 横切
同一堆"点"（有理点高度 1，无理点高度 0）。左：黎曼按 x 轴竖切，每根细条里既有 0 又有 1，上下积分永远差 1 → 不可积。右：Lebesgue 按 y 轴横切，只有两层——高层的底集合测度 0，积分 = 0。换把尺子，积分就出来了
黎曼上积分 = 1 · 下积分 = 0 → 不可积
换序悖论：搬山的尖峰
fₙ 是 (0, 1/n) 上的高度 n 的尖峰。每个 fₙ 的面积都是 n·(1/n) = 1（下面绿色填充面积恒定）。但每个点的极限都是 0（峰越收越窄）。lim∫ = 1，∫lim = 0——大学微积分里偷偷换序的地方，在黎曼框架下不成立。
n = 1 · 面积 = 1.000
单调收敛定理：楼梯逼近
f(x) = x²（灰线）。fₙ 取"左端点值"的阶梯函数（绿），单调上升逼向 f。楼梯的积分（绿色填充）从下往上爬，收敛到 ∫₀¹x² = 1/3。单调上升 ⟹ 极限与积分可以换序
n = 1 · ∫fₙ = 0.000
