## 1 这一幕要解决什么

上一节结束时，积分这台机器只会积一种函数：**无符号**可测函数 f : ℝᵈ → [0,∞]，值域允许 ∞，答案也允许 ∞。这对一半的世界是够用的——概率密度、面积、体积都是非负的。但积分之所以是积分，是因为它要线性：∫(f + g) = ∫f + ∫g。而"差"和"负号"要求函数能取负值。实值函数 f : ℝᵈ → ℝ 有正有负，怎么积？

最朴素的想法是：把无符号定义原样搬过去。f 是实值的，那把它写成一串简单函数的和 Σcᵢ·1_{Eᵢ}，系数有正有负，照算 ∫f := Σcᵢ·m(Eᵢ)。这条路有两个各自致命的洞。第一，**带符号系数的表示不唯一**：1.3.1 节放过这个事故的录像——f = 1_{[0,1]} 可以"合法地"写成 1_{[0,1]} + 1_{[1,∞)} − 1_{[1,∞)}（逐点求和确实处处等于 1_{[0,1]}），朴素求和 = 1·1 + 1·⊤ + (−1)·⊤ = ∞ − ∞，没有意义（记号 ⊤ 是扩展实数 [0,∞] 的顶元素，即 ∞ 的形式化名字，下文混用不另注）。第二，就算你规定"只许用互不相交的标准形"（此时表示确实唯一：系数就是 f 在每片上的值），求和 Σcᵢ·m(Eᵢ) 也只是一串普通级数——对条件收敛的系数列（如 cₙ = (−1)ⁿ/n），Riemann 重排定理说它可以按不同顺序收敛到任意值甚至发散，"按序求和"本身没有数学意义。∞ − ∞ 只是这种病最扎眼的症状，根子在求和顺序。

上一段的失败有一个干净的观察：灾难来自**表示**的自由。那么躲开表示，直接拆**函数本身**行不行？每个实值 f 都有一个完全确定的分解 f = f⁺ − f⁻，其中 f⁺ = max(f,0)（正部）、f⁻ = max(−f,0)（负部），两个都是无符号函数，且这个分解由 f 唯一决定，没有任何选择余地，更不涉及任何求和顺序。于是 ∫f := ∫f⁺ − ∫f⁻ 良定了……**只要减法有意义**。∫f⁺ 与 ∫f⁻ 都在 [0,∞] 里取值：两个都有限时差是实数，可行；但只要有一个是 ∞，差就落在扩展实数里（∞ − 5 = ∞、0 − ∞ = −∞ 在扩展实数中"有定义"），而积分理论要的是**实数**答案——线性性、三角不等式、L¹ 范数、收敛定理全部建立在 ℝ 上，±∞ 会在第一道加法 ∫(f+g) = ∫f + ∫g 处重新制造 ∞ − ∞。所以减法成立是有条件的：**∫f⁺ < ∞ 且 ∫f⁻ < ∞**（书公式 (1.12) 也只对这两个积分都有限的情形宣告定义）。这个条件长什么样？注意到 |f| = f⁺ + f⁻ 逐点成立（max(x,0) + max(−x,0) = |x|），而无符号积分对加法是可加的（1.3.3 节推论 1.3.14），所以 ∫|f| = ∫f⁺ + ∫f⁻，**"两个部分积分都有限"恰好就是"∫|f| < ∞"**。于是全部要求浓缩成一个可检验的数：∫|f|。这就是"绝对可积"（absolutely integrable）牌照的全部来历——它不是被宣布的，是被 ∞ − ∞ 逼出来的：想对实值/复值函数做减法，先交上 ∫|f| < ∞ 的保证金。

## 2 精确定义与第一个例子

**定义 1.3.17（绝对可积，书 p.56–57）**：可测函数 f 称为绝对可积，若无符号积分

‖f‖_{L¹(ℝᵈ)} := ∫_{ℝᵈ} |f(x)| dx

有限；这个量叫 f 的 L¹(ℝᵈ) 范数（严格说是**半**范数：‖f‖_{L¹} = 0 只推出 f 几乎处处为 0——书 p.57 在定义后立即说明 "The L¹ norm is then a seminorm"，商掉 a.e. 相等后才成真范数，见 §4 FAQ），全体绝对可积函数记作 L¹(ℝᵈ)。实值绝对可积 f 的积分定义为（书公式 (1.12)）

∫f := ∫f⁺ − ∫f⁻，

其中 f⁺ = max(f,0)、f⁻ = max(−f,0)；书上随即点破："右边的两个无符号积分都是有限的，因为 f⁺、f⁻ 被 |f| 逐点支配"。复值 f 则定义 ∫f := ∫Re f + i∫Im f，把复积分还原成两个实积分——这里的合法性先记一笔账（§3 比较判别还）：|Re f| ≤ |f| 逐点 ⟹ ∫|Re f| ≤ ∫|f| < ∞（机器 `ComplexAbsolutelyIntegrable.re` :79），Im 同理，所以 ∫|f| < ∞ 一张牌照同时为 Re、Im 两个实积分担保；反过来 |f| ≤ |Re f| + |Im f| 给出反方向（`ComplexAbsolutelyIntegrable.iff` :135，双向夹）。

Lean 里的三连定义一字不差：`UnsignedAbsolutelyIntegrable`（`Section_1_3_4.lean:18`）= 无符号可测 ∧ ∫f < ⊤；`RealAbsolutelyIntegrable`（:22）= 实可测 ∧ ∫|f| < ⊤；`ComplexAbsolutelyIntegrable`（:20）= 复可测 ∧ ∫|f| < ⊤。实积分的定义一行写完：`RealAbsolutelyIntegrable.integ`（:262）= `hf.pos.integ − hf.neg.integ`；复积分（:264）= `hf.re.integ + Complex.I * hf.im.integ`。注意这里 `EReal.abs_fun`（`Section_1_3_1.lean:13`，即 x ↦ ‖f x‖ 的嵌入）、`pos_fun`/`neg_fun`（:17–18，即 max(f,0)/max(−f,0)）都是 1.3.1 就备好的零件——整节没有发明任何新机器，只是把旧机器接上了减法。

"牌照 ⟺ 拆分安全"在机器里是两条方向。正方向：`RealAbsolutelyIntegrable.pos`（:230）与 `.neg`（:246）——由 hf 证 ∫f⁺ < ⊤ 与 ∫f⁻ < ⊤。骨架：f⁺(x) = max(f(x),0) ≤ |f(x)| 逐点（max(a,0) ≤ |a|，机器在 :234–238 用 `max_le_iff` 拆成 a ≤ |a| 与 0 ≤ |a| 两条），无符号积分的单调性（`LowerUnsignedLebesgueIntegral.mono`，`Section_1_3_3.lean:146`）给出 ∫f⁺ ≤ ∫|f| < ⊤。**关键一步**就是书上那句"点wise dominated by |f|"——支配关系 + 单调性，一行不等式换一张牌照。反方向（两个积分都有限 ⟹ 绝对可积）没有单独立定理，但它的原料在 `RealAbsolutelyIntegrable.abs_integ_le`（:3678）的证明里：那里把 ∫|f| = ∫f⁺ + ∫f⁻ 整条证了出来（`h_sum` :3693–3698，用逐点恒等式 max(x,0) + max(−x,0) = |x| 加上无符号积分加法性），于是两半都 < ⊤ 推出和 < ⊤，机械地成立。

**定义→立即检验**：f(x) = x 于 [0,1]（外部延拓为 0）。x ≥ 0 于 [0,1]，所以 f⁺ = f、f⁻ = 0，∫f = ∫₀¹ x dx − 0 = 1/2。这 1/2 不是新计算——f·1_{[0,1]} 是 Riemann 可积的，而机器定理 `RiemannIntegral.eq_integ`（:3018）宣告 Riemann 积分 = Lebesgue 积分（下一节细说），所以 1.1 节的全部微积分直接作数。牌照检查：∫|f| = ∫₀¹ x dx = 1/2 < ∞，通过。

再验一个真正有正有负的：f(x) = x − 1/2 于 [0,1]。正部 f⁺ = max(x−1/2, 0) 只在 [1/2,1] 上非零，∫f⁺ = ∫_{1/2}^1 (x−1/2) dx = [(x−1/2)²/2]_{1/2}^{1} = (1/4)/2 = 1/8；负部 f⁻ = max(1/2−x, 0) 只在 [0,1/2] 上非零，∫f⁻ = ∫₀^{1/2} (1/2−x) dx = [x/2 − x²/2]₀^{1/2} = 1/4 − 1/8 = 1/8。于是 ∫f = 1/8 − 1/8 = **0**，而 ∫|f| = 1/8 + 1/8 = 1/4。两个方向的核对都对得上：∫(x − 1/2) = ∫x − ∫(1/2·1_{[0,1]}) = 1/2 − 1/2 = 0（线性性，见下）；正负部面积严格抵消，这正是符号积分的意义——它量的是"净面积"，不是"总面积"。而 1/4 这个数提醒我们：∫|f| 永远 ≥ |∫f|（三角不等式，§3 定理），净面积永远小于等于总面积。

**失败诊断（牌照为什么必要）**：f(x) = x 于整个 ℝ。f⁺ = x·1_{x≥0}，∫f⁺ = ∫₀^∞ x dx = ∞；f⁻ = (−x)·1_{x<0}，∫f⁻ = ∫_{−∞}^0 (−x) dx = ∞。朴素公式 ∫f = ∞ − ∞，没有意义；∫|f| = ∫|x| dx = ∞，牌照被拒。这是本节最诚实的边界情形：**x 在 ℝ 上不存在 Lebesgue 积分**，不是"积分是某个数"，而是"积分这个操作对它没有定义"。Lean 的全局函数 `RealLebesgueIntegral`（:267）是 `if hf : RealAbsolutelyIntegrable f then hf.integ else 0`——不可积时给 0。这不是数学结论（数学上没有值），是编程约定（防呆的垃圾值），所有真定理都带 hf 假设，所以垃圾值永远不会被定理误用；mathlib 全局积分对非可积函数同样给 0。

第二个失败的例子更阴险，它直接枪毙一个貌似显然的命题。取 f(x) = −x·1_{x≥0} 与 g(x) = 1_{[0,1]}(x)。逐点比较：x < 0 时 f = 0 ≤ 0 = g；0 ≤ x ≤ 1 时 −x ≤ 1 = g；x > 1 时 −x ≤ 0 = g。**f ≤ g 处处成立，g 绝对可积（∫g = 1），但 f 不绝对可积**——∫|f| = ∫₀^∞ x dx = ∞，而按朴素拆分 ∫f = ∫f⁺ − ∫f⁻ = 0 − ∞ = −∞，照样不是实数。教训：**对带符号的函数，"f ≤ g 且 g 可积"推不出 f 可积**。比较判别必须写成无符号形式（0 ≤ f ≤ g），或者给带符号函数用 |f| ≤ g 的形式——因为 g 只在上方罩住 f 的"大小"，罩不住 f 的"负方向"（f 可以在负方向无限走远而依然 ≤ g）。这一条是本节 FAQ 的头号反直觉。

## 3 核心定理

**线性性（习题 1.3.19，书 p.58）**：积分 f ↦ ∫f 是从 L¹ 到 ℂ 的复线性映射，且 ∫f̄ = conj(∫f)（共轭线性，即 *-线性）。机器把这句话推到最满：`L1.integ : L1 d →ₗ[ℂ] ℂ`（:4069）是一个完整的线性映射——L¹ 空间（`PreL1` :610 与商空间 `L1` :940）上的线性泛函，加法和数乘都验过（`map_add'`/`map_smul'`）。

可积类的封闭性先于积分值：`RealAbsolutelyIntegrable.add`（:336）、`.smul`（:493）、`.sub`（:409）、`.of_neg`（:581）、`.conj`（:591，复共轭）。以加法为例，骨架：|f+g| ≤ |f| + |g| 逐点（范数的三角不等式 `norm_add_le`），无符号积分单调性 + 加法性给出 ∫|f+g| ≤ ∫|f| + ∫|g| < ⊤（:361–371）。**关键一步**：可积类对加法封闭靠的是"范数三角不等式"，不靠任何积分理论——L¹ 是向量空间，因为范数本身是次可加的。

积分值层面的加法 `RealAbsolutelyIntegrable.integ_add'`（:3833）才是真功夫，它的心脏是一个纯代数的逐点恒等式：

(f+g)⁺ + f⁻ + g⁻ = f⁺ + g⁺ + (f+g)⁻

（`Real.pos_neg_add_identity` :3724，逐实数的 case 分析；`EReal.pos_neg_add_identity` :3757 是函数层版本）。**关键一步**：这个恒等式把所有四个无符号积分收进同一个等式——两边都是无符号函数的和，无符号积分的加法性（推论 1.3.14）各管一边，然后约掉公共项 f⁻ + g⁻，得到 ∫(f+g)⁺ − ∫(f+g)⁻ = ∫f⁺ − ∫f⁻ + ∫g⁺ − ∫g⁻，即 ∫(f+g) = ∫f + ∫g。为什么必须这么绕？因为 (f+g)⁺ ≠ f⁺ + g⁺——取 f ≡ 1、g ≡ −1：左边 (f+g)⁺ = max(0,0) = 0，右边 f⁺ + g⁺ = max(1,0) + max(−1,0) = 1 + 0 = 1，差出 1 个单位的面积。正负部的和要互相补偿，恒等式就是补偿的记账本。数乘 `integ_smul'`（:3801）同理，但分成 c ≥ 0 与 c < 0 两半：c ≥ 0 时 (cf)⁺ = c·f⁺ 干净利落，c < 0 时正负部互换（`EReal.pos_fun_smul_neg` :3781）。复数的加法与数乘（`ComplexAbsolutelyIntegrable.integ_add` :3909、`integ_smul` :3947）不再有新内容：拆成实部虚部，套实数定理，最后 `ring`。**这意味着什么**：线性性是"积分"这个称谓的合法证书——∫(f + g) = ∫f + ∫g 是 1.1 节 Riemann 和就有的直觉，现在在 ∞ 面前被证明依然成立，且只在牌照（绝对可积）之下成立。

**三角不等式 |∫f| ≤ ∫|f|（引理 1.3.19，书 p.59）**：对 f ∈ L¹(ℝᵈ → ℂ)，|∫f| ≤ ∫|f|。

实值版 `RealAbsolutelyIntegrable.abs_integ_le`（:3678）几乎是一行：∫f = ∫f⁺ − ∫f⁻ 是两个非负数的差，|a − b| ≤ a + b（a,b ≥ 0），再代入 ∫f⁺ + ∫f⁻ = ∫|f|（`h_sum` :3693，就是 §2 那条恒等式）。**关键一步**：|f| = f⁺ + f⁻ 把"差的绝对值"变成"和"，而不等式 |a − b| ≤ a + b 在 a,b ≥ 0 时是平凡的。

复值版 `ComplexAbsolutelyIntegrable.abs_le`（:4248）是本节最有教学价值的一个证明。书上的警告先说在前面（书 p.59）：**"naively mimicking the real-valued argument would lose a factor of 2"**——若硬拆实部虚部，|∫f| ≤ |Re∫f| + |Im∫f| ≤ ∫|Re f| + ∫|Im f| ≤ 2∫|f|，只能得到系数 2 的劣质界。修补：**相位旋转**。先处理退化情形 ∫f = 0：|∫f| = 0 ≤ ∫|f| 由无符号积分的非负性白送（机器证明开头的 `by_cases h : hf.integ = 0` 分支，:4250–4253）。剩下 ∫f ≠ 0：令 u = conj(∫f) / ‖∫f‖，则 u 是单位复数且 u·∫f = ‖∫f‖ ∈ [0,∞)（把积分的复数值旋转到正实轴；分母 ‖∫f‖ ≠ 0 正是这一支的前提）。由线性性，∫(u·f) = u·∫f，于是

‖∫f‖ = Re∫(u·f) = ∫Re(u·f) ≤ ∫|Re(u·f)| ≤ ∫|u·f| = ∫|f|，

其中最后一个等号是 `abs_smul_unit`（:4232）：‖u‖ = 1 时 ∫|u·f| = ∫|f|（|u·f| = |u|·|f| = |f| 逐点）。**关键一步**是旋转把"复数的模"翻译成"逐点不等式 Re(u·f)(x) ≤ |u·f(x)|"——模的三角不等式被降级成每个点上都成立的一维事实，剩下全是无符号积分的单调性。**这意味着什么**：积分映射 L¹ → ℂ 是一个压缩（contraction）：‖∫f‖ ≤ ‖f‖_{L¹}。这条不等式是 L¹ 理论一切连续性结论的种子——DCT 的结论 ∫fₙ → ∫f 最终就是靠 |∫fₙ − ∫f| ≤ ∫|fₙ − f| 与支配条件一起压出来的（见 §3 末）。

**比较判别（无符号版）**：0 ≤ f ≤ g、g 绝对可积 ⟹ f 绝对可积。这不是文件里的单独立定理——它就是 `LowerUnsignedLebesgueIntegral.mono`（`Section_1_3_3.lean:146`）的一个直接转写：∫f ≤ ∫g < ⊤。机器里它被反复内联使用：`ComplexAbsolutelyIntegrable.re`（:79–105）证 |Re f| ≤ |f| 逐点（`Complex.abs_re_le_norm`）后走 mono 得 ∫|Re f| ≤ ∫|f| < ⊤；`RealAbsolutelyIntegrable.pos`（:239–244）同样；`mul_indicator`（:4128）证乘上指示函数不增积分。**注意上节 §2 的反例**：带符号版本 f ≤ g 是假的（−x·1_{x≥0} ≤ 1_{[0,1]} 而 f 不可积），比较判别的正确形态是 |f| ≤ g 或 0 ≤ f ≤ g。

判别法的第一场实战：**f(x) = 1/(1+x²) 在 ℝ 上绝对可积，且 ∫f = π**。可积性：对 |x| > 1，1/(1+x²) ≤ 1/x²，而 ∫₁^∞ x⁻² dx = [−x⁻¹]₁^∞ = 1，对称的一半同样 1，中间 [-1,1] 上 ≤ 1 给 2，所以 ∫|f| ≤ 2 + 1 + 1 = 4 < ∞——比较判别 + 三条单变量微积分，牌照到手。精确值：对每个 N，∫_{[-N,N]} f = 2 arctan N → π；f ≥ 0，无符号积分沿支撑球截断的极限定理（`eq_lim_horiz_trunc`，`Section_1_3_3.lean:1249`）把截断极限搬进积分，得 ∫_ℝ f = π。数值自洽：π ≈ 3.14159 < 4，与上面的粗界吻合。（此值机器未验——文件没有具体到 1/(1+x²) 的常数定理，截断机器（:1249）与 arctan 极限是手工拼的；"1/x² 在 [1,∞) 上积分 1"这类数是 1.3.1 简单函数机器的常规练习。）

**Riemann 兼容（书 p.59 的"绝对可积版习题 1.3.17"）**：Riemann 可积的 f : [a,b] → ℂ（零延拓）自动绝对可积，且 Riemann 积分 = Lebesgue 积分。机器两条定理：`RiemannIntegrableOn.realAbsolutelyIntegrable`（:2912）与 `RiemannIntegral.eq_integ`（:3018）。前者的骨架：Riemann 可积 ⟹ 有界（`RiemannIntegrable.bounded`），设 |f| ≤ M，则 |f·1_I| ≤ M·1_I，∫|f| ≤ M·m(I) = M(b−a) < ∞——又是比较判别。后者的骨架是"两侧同构"：f = f⁺ − f⁻，Riemann 侧用 `riemann_integral_add'`（:2896）与 `riemann_integral_smul'`（:2882）证明 Riemann 积分也线性，于是两侧都等于"正部积分减负部积分"（`hpos_int`/`hneg_int` 用 1.3.3 的 `RiemannIntegral.eq_UnsignedLebesgueIntegral` 把 Riemann 积分兑成无符号积分，:3046–3057）。**这意味着什么**：§2 的 1/2、1/8 全部合法落地——1.1 节 Riemann 积分的每一笔计算，在 Lebesgue 记号下原样有效。这也是本节工作例子的合法性来源：没有这条桥，例子里的 ∫₀¹ x dx 就要重新从简单函数开始算。

**平移与线性换元（习题 1.3.20，书 p.58）**：把 1.3.3 的三个无符号定理（习题 1.3.15 平移不变、1.3.16 线性换元、1.3.17 Riemann 兼容）搬给绝对可积函数。机器：`RealAbsolutelyIntegrable.trans`（:1071）+ `integ_trans`（:1078）：∫f(x+a) dx = ∫f(x) dx；`comp_linear`（:1212）+ `integ_comp_linear`（:1228）：对可逆线性 A，∫f(Ax) dx = |det A|⁻¹·∫f(x) dx。骨架：平移不变性直接来自测度的平移不变（无符号积分层已验，`UnsignedLebesgueIntegral.trans`）；线性换元的关键是测度因子——A 把单位体积拉伸 |det A| 倍，所以积分要除以 |det A|，机器在 pos 与 neg 上分别套 `UnsignedLebesgueIntegral.comp_linear`（含 |det A|⁻¹ 因子）再合并（:1230–1242）。复值版本（:1090/:1097/:1244/:1260）照例拆实部虚部。**这意味着什么**：这正是书 Remark 1.3.18（p.57）说的那件事——非绝对可积的推广（广义 Riemann 的 lim ∫₀^R、主值 p.v. ∫_{−R}^R）"tend to be poorly behaved with respect to change of variables or exchanging limits and integrals"。平移和换元公式是绝对可积理论独有的待遇；对条件收敛的 sin(x)/x 这类对象，平移、缩放、换序全都变得不可靠，所以书说这类"exotic integrals"只能 ad hoc 处理，不值得建立系统理论。

**绝对可和 ⟺ 绝对可积（习题 1.3.21，书 p.58）**：对双无限序列 (cₙ)_{n∈ℤ}，阶梯函数 f(x) = c_⌊x⌋（⌊x⌋ 为向下取整）绝对可积 ⟺ Σ|cₙ| < ∞；此时 ∫_ℝ f = Σcₙ。机器验了双向 iff：`AbsolutelySummable.realAbsolutelyIntegrable_iff`（:3631）与复版（:3653）。骨架：把 ℝ 切成单位格 cell n = [n, n+1)（每格测度 1，`cell_measure` :3120），f 在格 n 上恒为 cₙ，所以"积分"与"级数"是同一笔账的两个记法；机器用两个双向夹：`floor_integral_le_tsum_b`（:3506，∫|c∘⌊⌋| ≤ Σ|cₙ|，上界方向）与 `tsum_le_floor_integral_b`（:3611，反方向），合起来 Σ|cₙ| < ⊤ ⟺ ∫|f| < ⊤。**关键一步**是逐格拆分：每格上 f 是常数，积分的可加性（推论 1.3.14）把整条实数轴的积分拆成可数多份，每份 = cₙ·1，于是级数的收敛性直接搬运。**这意味着什么**：级数理论是积分理论的一维离散投影——"绝对可积是绝对可和的连续化"，习题的名字就是这句话。数值检验：cₙ = 2⁻ⁿ（n ≥ 0，n < 0 时 0），Σ|cₙ| = 1 + 1/2 + 1/4 + … = 2 < ∞，所以 f(x) = 2⁻⌊x⌋·1_{⌊x⌋≥0} 绝对可积且 ∫f = 2——每个单位格贡献 cₙ·1，可数可加性把几何级数原样抬进积分。（值等式 ∫f = Σcₙ 书上给出，仓库只形式化了 iff 那一半，值等式标"待证"。）

**粘接（习题 1.3.22，书 p.59）**：E、F 不交可测，f 在 E∪F 上绝对可积 ⟹ ∫_E f + ∫_F f = ∫_{E∪F} f。机器：`ComplexAbsolutelyIntegrableOn.glue`（:4169），其中"在 E 上可积"用局部化定义 `ComplexAbsolutelyIntegrableOn f E`（:4163）= f·1_E 绝对可积，∫_E := ∫(f·1_E)。骨架：1_{E∪F} = 1_E + 1_F（不交时，`Complex.indicator_union` :4108），于是 f·1_{E∪F} = f·1_E + f·1_F，两边取积分，线性性收工；`restrict`/`mono`（:4203/:4212）保证子集上仍可积。**这意味着什么**：积分是"局部量"——可以按可测集切开拼回，边界零测与否无所谓。这是 Fubini 定理（§1.7）的胚胎：先会切，才能会换序。

**DCT 前奏（书定理 1.4.48，仓库待证）**：如果 fₙ → f 逐点（a.e.）且 |fₙ| ≤ g 对某个 g ∈ L¹ 处处成立，则 ∫fₙ → ∫f。书在 §1.3.4 结尾预告："we will see that it also obeys a fundamentally important convergence theorem, the dominated convergence theorem (Theorem 1.4.48)"，正文在 §1.4.6 抽象测度部分（书 p.91），仓库同 MCT、Fatou 一道未形式化。但本节把 DCT 的全部零件备齐了：支配条件 |fₙ| ≤ g 与 |f| ≤ g 由比较判别给出 fₙ、f ∈ L¹（牌照）；差值的积分被三角不等式夹住，|∫fₙ − ∫f| ≤ ∫|fₙ − f|（引理 1.3.19）；至于 ∫|fₙ − f| → 0 这一步，书上的路线（p.91–92）是：先拆实部虚部，对 g + fₙ 与 g − fₙ 两个非负序列各用一次 Fatou 引理（∫liminf ≤ liminf ∫）。把中间的代数写全：由 fₙ → f 逐点，liminf(g + fₙ) = g + f、liminf(g − fₙ) = g − f；Fatou 给出 ∫(g + f) ≤ liminf ∫(g + fₙ)，再用线性性拆开右边、约掉 ∫g，得 ∫f ≤ liminf ∫fₙ；另一侧 liminf(∫g − ∫fₙ) = ∫g − limsup ∫fₙ（liminf 与 limsup 的镜像关系），约掉 ∫g 得 −∫f ≤ −limsup ∫fₙ，即 limsup ∫fₙ ≤ ∫f。两条一夹：limsup ∫fₙ ≤ ∫f ≤ liminf ∫fₙ，故 lim ∫fₙ = ∫f。**关键一步**：支配条件保证 g ± fₙ ≥ 0，这是 Fatou 的入场券；没有支配，尖峰列 n·1_{(0,1/n)} 的老事故（1.3.3 节 §1）立刻复活。这一节把车造好，§1.4 加油。

## 4 反直觉清单 / FAQ

- **sin(x)/x 有没有 Lebesgue 积分？没有。** ∫_ℝ |sin x/x| dx = ∞：对 k ≥ 1，在区间 I_k = [kπ+π/4, kπ+3π/4] 上 |sin x| ≥ √2/2 且 |x| ≤ kπ+3π/4 < (k+1)π，所以 ∫_{I_k} |sin x/x| ≥ (√2/2)·(π/2)·(1/((k+1)π)) = √2/(4(k+1))，对 k 求和是调和级数，发散。但经典 Riemann 广义积分 ∫₀^∞ sin x/x dx 条件收敛（Dirichlet 判别，值 π/2；sin(x)/x 是偶函数，全直线对称加倍得 ∫_{−∞}^∞ sin x/x dx = π）。**Lebesgue 可积 ≠ 广义 Riemann 可积**：Lebesgue 要 |f| 先过门槛，Riemann 广义积分可以靠正负振荡互相抵消。这正是书 Remark 1.3.18（p.57）的立场：这类"exotic"积分对换序、换元行为恶劣，只配 ad hoc 处理。Lean 里对它没有定理；若手贱调用 `RealLebesgueIntegral (fun x => sin x / x)`，得到 if-else 的 else 分支 0——那是垃圾值约定，不是数学。
- **为什么比较判别必须写成 |f| ≤ g（或 0 ≤ f ≤ g）而不是 f ≤ g？** 反例：f(x) = −x·1_{x≥0} ≤ 1_{[0,1]} = g 处处成立，g 可积（∫ = 1），f 不可积（∫|f| = ∞）。g 只罩得住 f 的上方，罩不住 f 在负方向的无底洞。无符号函数的比较 f ≤ g 之所以自动有效，是因为无符号函数没有负方向。
- **f(x) = x 在 ℝ 上，∫f 是多少？** 没有这个数。∫f⁺ = ∞、∫f⁻ = ∞，∞ − ∞ 无定义，牌照被拒。区分三种"失败"：积分有限（有牌照）、积分 = ∞（无符号语境合法）、积分无定义（符号语境，正负部之一或两者为 ∞）。Lean 的 `RealLebesgueIntegral` 对无定义情况机械地返回 0（:267 的 else 分支）。
- **为什么 ∫|f| < ∞ 就叫"绝对可积"？** 因为 ∫|f| = ∫f⁺ + ∫f⁻（机器 `h_sum` :3693），所以"绝对积分有限" ⟺ "正负部积分都有限" ⟺ "∫f⁺ − ∫f⁻ 是实数的减法"。牌照的完整名称是"可以安全地做正负拆分"。条件收敛（∫f 若定义则依赖正负抵消）被排除在外，这正是 sin(x)/x 的待遇。
- **L¹ 范数 ‖f‖_{L¹} 是范数吗？** 只是半范数：‖f‖_{L¹} = 0 ⟺ f = 0 几乎处处（1.3.3 习题 1.3.18(ii) 的搬运；机器 `L1.dist_eq_zero` :954：dist F G = 0 ⟺ AlmostEverywhereEqual F G）。两个 a.e. 相等的函数无法被范数区分，所以要商掉"几乎处处相等"（`L1` :940 = `SeparationQuotient (PreL1 d)`）才得到真赋范空间；商之后 Riesz–Fischer 完备性（书 p.58 预告）才有意义。
- **为什么书里同时有 Lemma 1.3.19 和 Exercise 1.3.19？** Tao 对定理/定义/引理与习题各用一条编号序列，两条序列平行，所以引理 1.3.19（三角不等式，书 p.59）与习题 1.3.19（线性性，书 p.58）同号不冲突。Lean docstring 沿用了这一习惯（:3675 与 :4068 各标一个 1.3.19）。
- **DCT 为什么不在这一节？** 书把它放在抽象测度框架（§1.4.6，定理 1.4.48），因为它的正确舞台是任意测度空间；欧氏情形只是特例。本节只备零件：比较判别（牌照）、三角不等式（差值的控制）、截断极限（`eq_lim_vert_trunc` :976、`eq_lim_horiz_trunc` :1249，1.3.3 已验）。
- **条件收敛级数对应什么函数？** 习题 1.3.21 说绝对可和 ⟺ 绝对可积，所以条件收敛级数对应的阶梯函数拿不到牌照。例如 cₙ = (−1)ⁿ/n（n ≥ 1）、cₙ = 0（n ≤ 0），f(x) = c_⌊x⌋：Σcₙ = −1 + 1/2 − 1/3 + … = −ln 2 条件收敛，但 Σ|cₙ| = Σ1/n = ∞，于是 f 不绝对可积——与 sin(x)/x 同病：级数版的条件收敛就是积分版的条件收敛的离散影子（注意 c₀ = 0 必须显式指定，否则 ⌊x⌋ = 0 的格子 [0,1) 上函数无定义）。
