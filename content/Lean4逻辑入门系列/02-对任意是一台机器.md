## 热身（复习旧词）

用第 1 课的词汇，证明"如果 P 且 Q 成立，则 Q 成立"：

<details>
<summary>答案：</summary>

```lean
example {P Q : Prop} : P → Q → Q := fun _hp hq => hq
```

</details>

记得三个要点：承诺写在 `:` 右边，交付写在 `:=` 右边，用不上的输入用 `_` 划掉。

## 课文 2.1（逐行注释版）

上一课证明的都是"固定的命题"。这一课的命题是：

> **每个自然数都不小于零。**（∀ n : ℕ, 0 ≤ n）

这不是一个命题，是**无穷多个命题**：0 ≤ 0、1 ≤ 0 的否定……你不能写无穷多个证明。那怎么办？

```lean
example : ∀ n : ℕ, 0 ≤ n := fun n => Nat.zero_le n
--   ①    ②     ③    ④     ⑤             ⑥
```

| 位置 | 代码 | 读法 | 含义 |
|------|------|------|------|
| ① | `example :` | "例题：" | 同上课 |
| ② | `∀ n : ℕ` | "对任意自然数 n" | 命题的前提：n 是任意的 |
| ③ | `,` | "逗号" | 分隔"任意"和"要证的" |
| ④ | `0 ≤ n` | "零小于等于 n" | 要证的结论 |
| ⑤ | `fun n =>` | "lambda" | **看这里：输入 n！** |
| ⑥ | `Nat.zero_le n` | "零小于等于 n 的已知定理" | 输出：n 对应的那个证明 |

**课文 2.1 的全部秘密在 ⑤**：`∀ n : ℕ, 0 ≤ n` 的证明，就是一个**函数**——输入任意一个自然数 n，输出"0 ≤ n"的证明。你不需要写无穷多个证明，你写一台机器：**任何 n 放进去，都能吐出证明出来。**

这不是比喻，也不是巧合——`fun` 和 `∀` 就是同一个东西的两副面孔：

```lean
-- 同一段代码：机器检查会告诉你，左边和右边是同一件事
#check (fun n : ℕ => Nat.zero_le n)
-- 输出：fun n ↦ Nat.zero_le n : ∀ (n : ℕ), 0 ≤ n
```

**机器自己把 `fun` 和 `∀` 打印在同一个冒号的两边。**"对任意"不是一个咒语，是一台流水线。

## 课文 2.2（tactic 模式：第二个写法）

同一个证明，还有另一种写法——用 `intro`（读作"引入"）：

```lean
example : ∀ n : ℕ, 0 ≤ n := by
  intro n
  exact Nat.zero_le n
```

`intro n` 的意思是"把输入 n 拿进来"——**它和 `fun n =>` 是同一个动作的别名**。`exact Nat.zero_le n` 的意思是"用这个表达式精确地完成交付"——**它就是 `fun n =>` 后面的部分**。

tactic 从来不是新知识，是你写的函数的语法糖。学 Lean 的头号误区就是背 tactic 名——本系列所有 tactic 都会在课文里出现一次"它其实就是你写的那个 λ"。

## 词汇表

| 符号 | 读法 | 含义 | 类比 |
|------|------|------|------|
| `∀ n : ℕ, ...` | "对任意 n" | 依赖函数：输入任意 n，输出对应证明 | 流水线机器 |
| `fun n => ...` | "lambda n" | 与 ∀ 同一件事的程序面孔 | 机器本体 |
| `intro n` | "引入 n" | 把输入拿进来（= `fun n =>`） | 说"拿 n 来" |
| `exact t` | "精确交付" | 用表达式 t 完成证明 | 说"就是它" |
| `Nat.zero_le` | "Nat 的零最小" | 定理：0 ≤ n 对一切 n | 字典里的现成词 |
| `ℕ` | "自然数" | 自然数类型 | 一门子语言 |
| `#check` | "检查" | 让机器打印一个表达式的类型 | 查字典 |

## 语法点：依赖函数（Π 规则）

回看课文 2.1 的 ⑥：`Nat.zero_le n` 的类型**取决于 n**。

- n = 0 时，它是"0 ≤ 0"的证明
- n = 5 时，它是"0 ≤ 5"的证明

**输出的类型随输入变化**——这样的函数叫**依赖函数**（dependent function）。"依赖"是这个名字的全部意义：整个类型论体系建立在"类型可以依赖值"之上，所以它叫**依赖类型论**。

普通函数 `ℕ → ℕ`：输入是数，输出是数，类型不依赖输入。
依赖函数 `∀ n : ℕ, 0 ≤ n`：输入是 n，输出的类型（那个不等式）**写着 n**。

如果你只听懂这一课的一句话，听这句：**∀ 就是函数，函数就是 ∀，它们的区别只有一个——输出的类型里有没有写着输入的名字。**

## 练习

**练习 1 · 翻译**：把数学句子"每个自然数加零等于它自己"写成 Lean 的证明（提示：定理 `Nat.add_zero` 现成，`#check Nat.add_zero` 可以先查）：

<details>
<summary>答案：</summary>

```lean
example : ∀ n : ℕ, n + 0 = n := fun n => Nat.add_zero n
```

</details>

**练习 2 · 仿写**：把课文 2.1 用 `intro` 写法重写一遍（不许看课文）：

<details>
<summary>答案：</summary>

```lean
example : ∀ n : ℕ, 0 ≤ n := by
  intro n
  exact Nat.zero_le n
```

</details>

**练习 3 · 改错**：下面这段想证明"每个自然数都大于零"，会报错。错在哪？

```lean
example : ∀ n : ℕ, 0 < n := fun n => by omega
```

<details>
<summary>答案：</summary>

命题是假的：n = 0 时 `0 < 0` 不成立。机器会在 `by omega`（算术计算器）那里报"无法证明"。
注意**这不是机器的问题**——是你挑了一个假命题。Lean 的最高美德：它宁可拒绝你，也不让你骗自己。
</details>

## 总结

- `∀ n, P n` = 一台机器：`fun n =>`（证明）
- `intro` 和 `exact` 是 `fun` 和表达式交付的别名（语法糖）
- 输出的类型里写着输入的名字 → 依赖函数 → 依赖类型论

**下一课预告**：∀ 是一台机器，那 ∃ 呢？——"存在一个大于 5 的自然数"在 Lean 里是一个**包裹**：见证者 + 证据，当场交付。而且，你会看到一个著名的"作弊证明"（√2 的√2 次方）如何在类型论面前现出原形。
