## 热身（复习旧词）

用第 2 课的词汇，证明"每个自然数加零等于它自己"：

<details>
<summary>答案：</summary>

```lean
example : ∀ n : ℕ, n + 0 = n := fun n => Nat.add_zero n
```

</details>

回顾：`∀` 是一台机器——输入 n，输出"n 的性质"的证明。

## 课文 3.1（逐行注释版）

新命题：

> **存在一个自然数大于 5。**

在 Lean 里，它长这样：

```lean
example : ∃ n : ℕ, n > 5 := ⟨6, by norm_num⟩
--   ①    ②     ③  ④   ⑤      ⑥        ⑦
```

| 位置 | 代码 | 读法 | 含义 |
|------|------|------|------|
| ① | `example :` | "例题：" | 同前课 |
| ② | `∃ n : ℕ,` | "存在 n" | 命题：某个 n 满足后面 |
| ③ | `n > 5` | "n 大于五" | 要求 n 满足的性质 |
| ④ | `:=` | "定义为" | 交付开始 |
| ⑤ | `⟨6, ...⟩` | "尖括号" | **打包**：见证者 + 证据，一个包裹 |
| ⑥ | `6` | "六" | **见证者**：具体是哪个 n（就是 6） |
| ⑦ | `by norm_num` | "算数计算" | **证据**：6 > 5 的证明 |

**∃ 的证明是一个包裹：先交出见证者（具体的数），再交出证据（它满足性质）。**不是"存在"，是"就在这，你验"。这就是"存在必须给出现场"。

注意 `⟨⟩` 尖括号——它是第 1 课 `fun` 之外的第二种"打包语法"。以后你还会遇到它几十次：凡是"一组数据"要交付，都用尖括号。

## 课文 3.2（拆包：从存在里取东西）

假设有人给了你一个包裹（`h : ∃ n : ℕ, n > 5`），你想把里面的见证者拿出来用：

```lean
example (h : ∃ n : ℕ, n > 5) : ∃ m : ℕ, m > 3 := by
  rcases h with ⟨n, hn⟩
  --      ①        ②
  exact ⟨n, by omega⟩
```

| 位置 | 代码 | 读法 | 含义 |
|------|------|------|------|
| ① | `rcases h with` | "拆包" | 把包裹 h 拆开 |
| ② | `⟨n, hn⟩` | "拆成 n 和 hn" | n 是见证者，hn 是"n > 5"的证据 |
| ③ | `exact ⟨n, by omega⟩` | "重新打包" | 用同一个 n 证明更强的性质 m > 3 |

拆包—打包，两个动作，一种思想：**存在 = 数据，数据就可以被拆开和重组。**

### 阅读框：一个"作弊"的证明（√2 的 √2 次方）

数学里有一个著名定理：**存在两个无理数 a、b，使得 a^b 是有理数。**证明只用三行：

> 考虑 √2^√2。如果它是有理数，取 a = √2，b = √2；如果它是无理数，取 a = √2^√2，b = √2，则 a^b = (√2^√2)^√2 = 2，是有理数。

两种情况必居其一，所以"存在"。**但这个证明从头到尾没告诉你 a、b 到底是什么**——它证明了存在，却交不出包裹。数学课本的裁决：合法。这个证明作为"非构造性证明"的经典，流传了一百多年。

在类型论里，这个"作弊"是**可见的**：真的要从它里面提取见证者，你必须调用选择公理，而且机器会强制你标注 `noncomputable`——"**不是算出来的，是赌出来的**"：

```lean
-- 非构造性提取：Classical.choose（选择公理）
noncomputable def getWitness (h : ∃ n : ℕ, n > 5) : ℕ := Classical.choose h
```

`noncomputable` 四个字，就是类型论给非构造性证明贴的标签：数学课本把它藏在"显然"，Lean 把它写在脸上。

## 词汇表

| 符号 | 读法 | 含义 | 类比 |
|------|------|------|------|
| `∃ n : ℕ, ...` | "存在 n" | 存在量词：n 的具体值要交出来 | 点名 |
| `⟨a, b⟩` | "尖括号对" | 打包两个数据成一个包裹 | 装箱 |
| `rcases h with ⟨n, hn⟩` | "拆包" | 把包裹拆成见证者和证据 | 开箱 |
| `norm_num` | "数值计算" | 自动验证 6 > 5 这类算术 | 计算器 |
| `omega` | "算术求解" | 自动验证不等式（本课用于 ≥ 6 的情形） | 更强的计算器 |
| `Classical.choose` | "选择" | 从"存在"里无中生有取见证者（需 noncomputable） | 开挂 |
| `noncomputable` | "不可计算" | 函数不是算出来而是赌出来的标记 | 免责声明 |

## 语法点：依赖对（Σ 规则）

∀ 的证明是"输出类型随输入变化"的函数；∃ 的证明是对偶结构——**"类型里写着值"的数据**：

- ∀（机器）：输入 n → 输出"写着 n 的证明"
- ∃（包裹）：值 6 → 证据"写着 6 的命题"

在类型论里，∃ 的包裹叫**依赖对**（dependent pair）：第二个数据的类型，写着第一个数据的值。`⟨6, by norm_num⟩` 里，证据的类型是 `6 > 5`——**证据的类型里写着见证者的名字**。

这就是 Σ 规则（Sigma 类型）：`∃ n : ℕ, n > 5` 读作"一个对：n 是某个自然数，且 n > 5"。**∀ 是机器，∃ 是包裹——Π 和 Σ，整个类型论的两根支柱，你已经都有了。**

## 练习

**练习 1 · 翻译**：把"存在一个自然数大于 100"写成 Lean 证明：

<details>
<summary>答案：</summary>

```lean
example : ∃ n : ℕ, n > 100 := ⟨101, by norm_num⟩
```

见证者：101。证据：101 > 100。
</details>

**练习 2 · 仿写**：把课文 3.2 改一版：从 `h : ∃ n : ℕ, n > 5` 出发，证明 `∃ k : ℕ, k > 4`（比课文更弱，更容易）：

<details>
<summary>答案：</summary>

```lean
example (h : ∃ n : ℕ, n > 5) : ∃ k : ℕ, k > 4 := by
  rcases h with ⟨n, hn⟩
  exact ⟨n, by omega⟩
```

</details>

**练习 3 · 改错**：下面这段会报错。为什么？

```lean
example : ∃ n : ℕ, n > 5 := ⟨3, by norm_num⟩
```

<details>
<summary>答案：</summary>

见证者 3 不合格：3 > 5 是假的。`by norm_num` 试图证明 3 > 5，机器报"无法证明"。
**机器拒绝签收不合格的包裹**——"存在"不是你说存在就存在的，见证者要合格，证据要成立，两个都过关才签收。
</details>

## 总结

- ∃ = 包裹：`⟨见证者, 证据⟩`，当场交付
- 拆包用 `rcases`，打包用 `⟨⟩`
- 非构造性证明 = 开挂（`Classical.choose` + `noncomputable` 标记）
- 两节课两支柱：∀ 是机器（Π），∃ 是包裹（Σ）

**下一课预告**：数学里最日常的两个字——"且"和"或"。在类型论里它们不是连接词，是两种数据结构：且 = **配对**（两个证据都交），或 = **选择**（二选一，并说明选了哪个）。然后你会发现一个藏了一百年的问题：**为什么证明"或"比证明"且"难？**
