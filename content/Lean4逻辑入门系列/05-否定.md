## 课文 5.1（否定不是什么）

先做一个实验。猜猜 `¬ P` 在 Lean 里是什么？

你可能会猜"一个表示否定的符号"。错了。在 Lean 里：

```lean
-- ¬ P 的完整定义：
-- ¬ P 就是 P → False（"P 蕴含假"）
```

**"不 P"不是一个词，是一个函数类型：从 P 的证据到 False。**证明 `¬ P`，就是证明"给我 P，我吐给你一个矛盾"。这就是反证法的本质——它不是一个技巧，是 `¬` 的定义本身。

来看看实际操作。命题："P 且 非P 不可能同时成立"——矛盾律：

```lean
example {P : Prop} : ¬ (P ∧ ¬ P) := by
  intro h
  -- h : P ∧ ¬ P —— 一个"既 P 又非P"的包裹，要拆
  rcases h with ⟨hp, hnp⟩
  -- hp : P，hnp : ¬ P（即 P → False）
  exact hnp hp
  --      ①     ②
```

| 位置 | 代码 | 含义 |
|------|------|------|
| ① | `hnp hp` | 把 hp（P 的证据）喂给 hnp（P → False 的函数） |
| ② | `exact` | 得到 False——完成！ |

**读最后一行**：`hnp hp`——"非P"这个函数吃掉 P 的证据，吐出矛盾。整段证明就是一个函数调用链。反证法不是魔法，是**类型匹配**：你手里有 P，而"非P"就是要 P，两者一碰，世界爆炸（False）。

## 课文 5.2（False：没有值的世界）

刚才证明了"矛盾"（False）。但 False 到底是个什么东西？

在类型论里，**False 是一个没有任何值的类型**——没有人能拿出 False 的证据（否则世界就矛盾了）。所以：

- 证明 `¬ P` = 构造一个"从 P 到空世界"的函数
- 如果这个函数被调用（真拿到了 P 的证据）→ 立刻爆炸 → 证明完成

这就是 `exact hnp hp` 的全部秘密：**你不是在"证明 False"，你是在证明"False 永远不可能被真正用到"。**

## 课文 5.3（你知道吗：经典逻辑是选项）

在纯类型论（构造性逻辑）里，`¬ ¬ P → P`（双重否定消去）是**证明不了的**——你没有"P 的证据"，只有"没有'没有 P'的证据"。看这个失败的尝试：

```lean
-- 这样写会报错：类型不匹配
example {P : Prop} : ¬ ¬ P → P := fun hnnp => hnnp
```

`hnnp` 的类型是 `¬ ¬ P`（即 `(P → False) → False`），不是 P——你手里没有 P 的证据。要想拿到 P，必须调用经典逻辑的反证法：

```lean
-- 这样写可以编译：但注意，它用了额外的公理
example {P : Prop} : ¬ ¬ P → P := by
  intro hnnp
  exact Classical.byContradiction hnnp
```

`Classical.byContradiction` 需要**排中律**（P 或 非P 必居其一）——排中律不是免费的午餐，是一个额外的公理。Lean 默认提供它（Mathlib 内置经典逻辑），但你要知道：**每用一次 `Classical`，你就是在选择"经典世界"而不是"构造性世界"。**

这和第 3 课 `noncomputable` 是一家人：**非构造性 = 开挂，机器让你知道你在开挂。**

## 词汇表

| 符号 | 读法 | 含义 | 类比 |
|------|------|------|------|
| `¬ P` | "非 P" | 定义：P → False | 空头支票 |
| `False` | "假" | 没有值的类型（矛盾） | 空房间 |
| `intro h` | "引入 h" | 把前提拿进来（= `fun h =>`） | 接招 |
| `hnp hp` | "喂给它" | 函数调用：非P 吃掉 P 的证据 | 引爆 |
| `Classical.byContradiction` | "反证法" | 经典逻辑：双重否定消去（需排中律） | 开挂 |
| `by_contra` | "反证" | 反证法的 tactic 语法糖 | 换路 |

## 语法点：空类型与函数调用

把否定放进整个体系看：

| 类型 | 有多少个值 | 数学含义 |
|------|-----------|---------|
| `True` | 1 个（trivial） | 恒真 |
| `False` | **0 个** | 恒假——没有人拿得到证据 |
| `P` | 若干 | 命题成立与否 = 类型里有没有值 |

`¬ P = P → False` 的含义就清楚了：**它是"到空房间的楼梯"——如果 P 真的成立（有人站在楼梯口），楼梯通向的却是空房间，于是世界矛盾。**证明 `¬P` 不是证明"P 不存在"（那太难了），是证明"P 的证据只能通向矛盾"。

这就是构造主义者和经典数学家吵了一百年的那件事：经典数学家说"不是非P，所以是P"（排中律）；构造主义者说"你手里什么都没有，凭什么说 P"。**Curry-Howard 的裁决：排中律是额外公理，不是免费真理。**

## 练习

**练习 1 · 翻译**：把"非P 推出 'P 且 Q 不成立'"写成 Lean 证明（提示：拆开配对，把 P 的证据喂给 ¬P）：

<details>
<summary>答案：</summary>

```lean
example {P Q : Prop} : ¬ P → ¬ (P ∧ Q) := by
  intro hnp h
  rcases h with ⟨hp, hq⟩
  exact hnp hp
```

`hnp` 是"P → False"的函数：把拆出来的 `hp` 喂给它，矛盾达成。
</details>

**练习 2 · 仿写**：用课文 5.1 的结构，证明"P 且 非P 推出 False"：

<details>
<summary>答案：</summary>

```lean
example {P : Prop} : (P ∧ ¬ P) → False := by
  intro h
  rcases h with ⟨hp, hnp⟩
  exact hnp hp
```

</details>

**练习 3 · 改错**：下面这段要证明双重否定消去，在构造性世界里会报错。为什么？

```lean
example {P : Prop} : ¬ ¬ P → P := fun hnnp => hnnp
```

<details>
<summary>答案：</summary>

`hnnp : ¬ ¬ P`，也就是 `¬P → False`，也就是 `(P → False) → False`。
把 `hnnp` 直接交上去，类型是 `(P → False) → False`，而要求的是 `P`——**类型不匹配**。
你手里只有"没有'没有 P'的证据"，没有 P 本身。要 P，就得开挂（`Classical.byContradiction`）。
</details>

## 总结

- `¬ P` 不是否定，是 **`P → False`**——反证法就是类型定义
- False = 空类型：证明"矛盾"= 证明"矛盾到不了你手里"
- 排中律 / 双重否定消去 = 额外公理（经典世界），Lean 让你选择世界观
- 构造性 vs 经典，是数学史上唯一让你自选逻辑的工具

**下一课预告**：把两课前的 ∧ 和今天的 ¬ 合起来——**"等价"（↔）**。它是"双向蕴含"，在类型论里是一个**双函数对**：去路一个函数，回路一个函数。你会第一次亲手证明一个"当且仅当"定理：`(P ∧ Q) ↔ (Q ∧ P)`——交换律。然后你会发现：证明 ↔ 最难的不是两个方向，是**别把两个方向搞混**。
