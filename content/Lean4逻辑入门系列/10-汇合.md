## 课文 10.1（你的第一个实分析定理）

准备好了吗？这是陶哲轩《实分析》第一章的核心定理之一，也是你凭十课词汇就能读懂的：

> **阿基米德性质：对任意实数 x，存在一个自然数 n，使得 x < n。**
>
> （任何实数都小于某个自然数——直观上"显然"，但它需要证明，而且正是 ∀ 和 ∃ 的完美合奏。）

在 Lean 里，陈述和证明长这样：

```lean
example : ∀ x : ℝ, ∃ n : ℕ, x < n := by
  intro x
  exact exists_nat_gt x
```

| 位置 | 代码 | 你认识的词汇 |
|------|------|-------------|
| ① | `∀ x : ℝ,` | 第 2 课：一台机器（输入任意实数 x） |
| ② | `∃ n : ℕ, x < n` | 第 3 课：一个包裹（见证者 n + 证据 x < n） |
| ③ | `intro x` | 第 2 课：`fun x =>` 的语法糖 |
| ④ | `exists_nat_gt x` | 标准库定理：x 的"见证者"（第 3 课的 `Classical.choose` 的近亲） |

**读一遍**："给我任意一个实数 x，我就能交出一个自然数 n，证明 x < n。"——第 2 课的机器和第 3 课的包裹，在这里结婚了。

## 课文 10.2（看一本真的教材）

陶哲轩《实分析》4.4 节有一道习题，现在你应该能读懂它的 Lean 陈述了（习题 4.4.1，整数夹逼）：

```lean
-- 每个有理数 x 都存在唯一的整数 n，使得 n ≤ x < n + 1
theorem Rat.between_int (x : ℚ) : ∃! n : ℤ, n ≤ x ∧ x < n + 1 := by
  -- 这个定理的完整证明有 153 行
  -- 但你注意：它的"陈述"只用到了你 10 课的词汇：
  --   ∃! （存在唯一）——第 3 课的包裹 + 唯一性
  --   ∧   （且）      ——第 4 课的配对
  --   n ≤ x、x < n+1 ——第 10 课之前的全部不等式直觉
  sorry
```

**153 行的证明，你还没学会——但陈述你全会读了。**这就是 10 课的意义：从"数学书是外语"到"数学书是母语，只是长句子多"。

（`∃!` 是"存在唯一"——第 3 课 `∃` 的加强版：见证者不但存在，而且唯一。它的证明用到唯一性的配对技巧，那是实分析系列的课。）

## 词汇表（毕业词汇表：十课总表）

| 结构 | 一课 | 一句话 |

## 练习（毕业题）

**练习 1 · 翻译**：把"每个实数 x 都有 x ≤ x + 1"写成 Lean 证明（提示：`linarith` 是处理实数不等式的计算器——第 2 课你见过它在 ℚ 上的用法）：

<details>
<summary>答案：</summary>

```lean
example : ∀ x : ℝ, x ≤ x + 1 := by
  intro x
  linarith
```

</details>

**练习 2 · 仿写**：证明"任意两个实数相加都满足交换律"——陈述先行：`∀ x y : ℝ, x + y = y + x`：

<details>
<summary>答案：</summary>

```lean
example : ∀ x y : ℝ, x + y = y + x := by
  intro x y
  ring
```

`ring` 是实数（环）的专用计算器——`omega` 管整数自然数，`ring` 管环运算，`linarith` 管不等式。工具越来越多，但结构还是那十课。
</details>

**练习 3 · 改错**：下面这段要证明阿基米德性质，会报错。为什么？

```lean
example : ∀ x : ℝ, ∃ n : ℕ, x < n := fun x => x
```

<details>
<summary>答案：</summary>

类型不匹配：`x : ℝ`，但要求交付的是一个包裹 `∃ n : ℕ, x < n`。
**你交了个实数，机器要的是一对数据（见证者 + 证据）**——第 3 课改错题的成年版。交付出错，机器照拒，不管你是第一个实分析定理。
</details>

## 毕业总结

十课，十一个结构，一个思想：

> **命题是类型，证明是程序，机器是裁判。**

你从 `fun hp => hp` 走到了阿基米德性质——第一课到第十课，没有跳过任何一步"显然"。
