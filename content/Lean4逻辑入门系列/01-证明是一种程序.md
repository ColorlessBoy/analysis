# 证明是一种程序：数学家的第一堂编程课

> 《证明也是程序》系列 第 1 篇 · 类型论第一课 · 机器验证版

---

## 开场

你写过这样的证明吗？

> "设 ε > 0，取 N = ...，则当 n ≥ N 时，|a_n - a| < ε。"

写到这里卡住，然后盯着白纸发呆半小时，最后把纸揉成一团。

你不是不会数学。你只是**写了一行程序，编译不过，而且没有编译器告诉你错在哪**。

这句话不是比喻。它是一个数学定理——一百多年前就被证明的那种。今天这篇，是让你"开窍"的第一课。

## 一个有点吓人的定理

1920-30 年代，两位数学家（Curry 和 Howard）独立发现了一件事，后来被称为 **Curry-Howard 对应**（也叫命题即类型）：

> **一个命题就是一个类型；一个证明就是一个程序。**

翻译成人话：

| 数学的世界 | 程序的世界 |
|-----------|-----------|
| 命题："若 P 则 Q" | 类型：函数 `P → Q` |
| 证明：由 P 推出 Q 的方法 | 程序：输入 P 输出 Q 的函数 |
| "P 为真" | "类型 P 里存在一个值" |
| 你证不出来 | 编译不过，且编译器给了错误信息 |

所以当你写"证明：设 x ∈ A，则..."，你其实是在写 `fun x => ...`——**在编程语言里，这段话就是字面意义的代码**。

## 第一道题：P → P

让我们做人生第一道"编程题"。命题：**P 蕴含 P**。也就是"如果 P 成立，那么 P 成立"。

在数学里你大概会写："显然。"然后结束。

在类型论里，它对应一个函数类型 `P → P`，你要给出一个**程序**：输入一个 P，输出一个 P。最懒也最正确的写法：

```lean
-- 命题 P → P 的证明：一个"原样返回"的函数
example {P : Prop} : P → P := fun hp => hp
```

`fun hp => hp` 读作："给我一个 P 的证据（hp），我把同一个证据原样还给你。"三秒钟的思考，零技巧，**但这是 20 世纪数学里最深的思想之一在 20 个字符里的样子**。

现在加一点戏：**P → Q → P**（如果 P 且 Q 成立，则 P 成立——高中数学里你叫它"同一律"或干脆"显然"）。

```lean
-- P → Q → P：给我 P 的证据和 Q 的证据，我退还 P 的证据
example {P Q : Prop} : P → Q → P := fun hp hq => hp
```

注意那个被忽略的 `hq`——它是 Q 的证据，用不上，所以程序里它被忽略。**你写的每一个忽略，都是数学里的一步"不必使用"**。证明的每一行，都对应程序里的一次操作，无处遁形。

## 为什么这改变一切

1900 年代初期，有一群数学家（构造主义者/直觉主义者）提出过一个"叛逆"的主张：**"存在"必须意味着"我能拿出来"**。你证明"存在一个 x 使 P(x)"，你就得给出具体的 x；你说"要么 P 要么 ¬P"，你就得说明到底是哪个。当时的数学界觉得这群人莫名其妙——你证明存在就好了，管我怎么证的？

Curry-Howard 让这场争论有了裁决者：**构造性证明 = 能编译的程序；非构造性证明 = 编译不过**。"存在"不是魔法咒语，是**交付**。数学和编程的边界从此融化。

对你的实际意义：

1. **"证明不会写"和"程序写不出来"是同一件事**。而程序员有一个你还没有的工具：**编译器的错误信息**。它不会说"你要再努力一点"，它说"第 3 行，类型不匹配，你需要的证据是 ε < δ 但你手里是 ε < δ/2"。
2. **"显然"在机器面前失效**。你写的每一步都必须成立——这很痛苦，但痛苦的方向是对的：它逼你发现你其实不会。
3. **以后你写的每个证明，都可以让机器检查**。这篇系列的所有内容都这样做。

## 机器验证是什么感觉

试着把下面这段扔进 [Lean Web](https://lean.math.hhu.de/)（不用装任何东西，浏览器打开就能跑）：

```lean
-- 一个故意写错的证明，看看编译器怎么骂你
example {P Q : Prop} : P → Q → P := fun hp hq => hq
```

你会得到一个错误：**"type mismatch"——你返回了 Q 的证据，但承诺的是 P 的证据**。它不会含糊地说"这样不对"，它精确地告诉你：**错在哪个符号上，差在哪个类型上**。

这就是我前面说的"编译器"的感觉。数学从此有了即时反馈——像游戏一样。这也是为什么这套系列的第一篇从编程讲起：**你学的不只是数学，是一个有错误信息的数学**。

## 结尾钩子

现在你知道：证明 = 程序。那么下一课的问题来了——

**∀ x，P(x) 对应什么程序？**（提示：它不是一个值，是一台机器。）

"对所有 x 成立"在类型论里是一个函数，输入任意 x，输出 P(x) 的证据。下一讲我们拆了它：**函数就是规则**。

先做道热身：在 Lean Web 里试试点开那两行代码，把它改成 `P → Q → Q`，然后试着写错一版，看看错误信息长什么样。评论区分享你的"编译器第一骂"。
