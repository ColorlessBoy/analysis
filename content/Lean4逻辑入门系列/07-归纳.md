## 课文 7.1（逐行注释版）

命题："每个自然数加零等于它自己"（∀ n : ℕ, n + 0 = n）。

这对 n = 0 是真的（0 + 0 = 0），对 n = 1 是真的（1 + 0 = 1），对 n = 2 是真的……但"对每个 n"是无穷多个命题，你不可能一个一个证。

你只需要两步：

```lean
example : ∀ n : ℕ, n + 0 = n := by
  intro n
  induction n with
  | zero => rfl
  | succ n ih =>
      calc
        (n + 1) + 0 = (n + 0) + 1 := by omega
        _ = n + 1 := by rw [ih]
```

| 位置 | 代码 | 含义 |
|------|------|------|
| ① | `induction n with` | 对 n 做归纳——多米诺骨牌的第一块 |
| ② | `\| zero => rfl` | **基例**：n = 0 时，0 + 0 = 0，一步到位 |
| ③ | `\| succ n ih =>` | **递推步**：假设 n 成立（ih），证明 n+1 成立 |
| ④ | `ih` | **归纳假设**：n + 0 = n（假设第 n 块骨牌倒了） |
| ⑤ | `by rw [ih]` | 用假设：把 (n+0)+1 里的 n+0 换成 n |

**`induction` 就是多米诺**：基例推倒第一块，递推步证明"第 n 块倒了，第 n+1 块必倒"。机器检查的正是这两件事——没有偷工减料，没有"显然推广到无穷"。

## 课文 7.2（如果机器有捷径）

诚实交代：这个命题用 `omega` 一句就能过（算术计算器直接算）。那为什么还要学归纳？

```lean
-- 捷径（机器会算）：
example : ∀ n : ℕ, n + 0 = n := by
  intro n
  omega
```

因为**捷径只能处理"算得出来"的命题**。数学里绝大多数命题不是算术——"每个偶数都能写成两个素数之和"（哥德巴赫猜想）、"不存在最大素数"——这些没有捷径，唯一的路就是归纳（或更深的递归结构）。**这一课学的是通行的能力，不是这一题的答案。**

而且，看课文 7.1 的 ⑤：`rw [ih]`——归纳假设被**亲手使用**的那一步。这一行的意义是：**你已经学会了数学里最硬核的一招——把"对无穷多个数成立"压缩成两个步骤。**

## 词汇表

| 符号 | 读法 | 含义 | 类比 |
|------|------|------|------|
| `induction n with` | "对 n 归纳" | 把命题拆成基例 + 递推步 | 排多米诺 |
| `\| zero =>` | "零的情况" | 基例：n = 0 直接证明 | 第一块骨牌 |
| `\| succ n ih =>` | "后继的情况" | 递推步：假设 n 成立，证 n+1 成立 | 连锁反应 |
| `ih` | "归纳假设" | 假设 n 的情况成立 | 上一块骨牌 |
| `rw [ih]` | "重写" | 用等式 ih 替换目标里的对应部分 | 替换 |
| `omega` | "算术" | 自动解决线性算术（含归纳假设） | 计算器 |
| `succ` | "后继" | n+1 的学名（successor） | 下一个 |

## 语法点：归纳类型与消除器

为什么归纳在自然数上合法？因为**自然数的定义本身就带开关**：

```lean
-- 自然数只有两种造法：
--   zero : ℕ          （0 是自然数）
--   succ : ℕ → ℕ      （n 是自然数 ⇒ n+1 是自然数）
```

每一个自然数，都是"从 zero 开始，succ 了若干次"造出来的。所以**要证明"所有自然数都有性质 P"——只需要证明 P 对 zero 成立（基例），且 P 对 succ n 成立（递推）**。没有第三种自然数，就没有第三种情况。

induction 的学名叫**消除器**（eliminator）：一个类型（自然数）造出来的规则，定义了它的一切推论规则。**类型的构造方式决定了你能对它证明什么**——这是依赖类型论最深的一句话，后面还会反复出现。

## 练习

**练习 1 · 翻译**：把"每个自然数 n 都有 n < n + 1"写成 Lean 证明（提示：`omega` 一步过——先自己写 `induction` 结构，再用 `omega` 填每一步）：

<details>
<summary>答案：</summary>

```lean
example : ∀ n : ℕ, n < n + 1 := by
  intro n
  induction n with
  | zero => omega
  | succ n ih => omega
```

</details>

**练习 2 · 仿写**：把课文 7.1 改成"每个自然数 n 都有 0 ≤ n"（归纳版；提示：zero 情况 `omega`，succ 情况用 ih + omega）：

<details>
<summary>答案：</summary>

```lean
example : ∀ n : ℕ, 0 ≤ n := by
  intro n
  induction n with
  | zero => omega
  | succ n ih => omega
```

</details>

**练习 3 · 改错**：下面这段会报错。为什么？

```lean
example : ∀ m n k : ℕ, (m + n) + k = m + (n + k) := by
  intro m n k
  induction m with
  | zero => omega
```

<details>
<summary>答案：</summary>

错误信息：**"Alternative `succ` has not been provided"**——"你没有提供递推步"。
你只倒了第一块骨牌（zero 情况），就宣布全倒。机器拒绝：**多米诺必须证明"第 n 块倒则第 n+1 块倒"，缺一步，整套作废。**
</details>

## 总结

- 归纳 = 基例 + 递推步，`induction` 一次给齐
- `ih` 是递推步的钥匙，`rw [ih]` 亲手使用它
- 自然数的构造（zero / succ）决定了归纳的合法性——类型定义一切
- 捷径（omega）存在，但归纳是通行证

**下一课预告**：归纳是"证明"，那**定义**呢？——"double（翻倍）"这种函数是怎么用同样的结构定义出来的？**递归**。你会第一次写出自己的函数，然后证明它的性质。归纳和递归，一对孪生兄弟，一个是证明的阶梯，一个是定义的阶梯。
