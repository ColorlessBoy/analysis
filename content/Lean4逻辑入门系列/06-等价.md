## 热身（复习旧词）

用第 4-5 课的词汇，证明"非P 推出 'P 且 Q' 不成立"：

<details>
<summary>答案：</summary>

```lean
example {P Q : Prop} : ¬ P → ¬ (P ∧ Q) := by
  intro hnp h
  rcases h with ⟨hp, hq⟩
  exact hnp hp
```

</details>

回顾：∧ 是配对，∨ 是选择，¬P 是 P → False——四种结构都齐了。

## 课文 6.1（最简等价）

数学里最庄严的符号：**"当且仅当"（↔）**。"P 当且仅当 Q"意思是 P 和 Q 同真同假。

在 Lean 里，它长什么样？先看最平凡的例子"P 当且仅当 P"：

```lean
example {P : Prop} : P ↔ P := ⟨fun hp => hp, fun hp => hp⟩
```

看尖括号里有什么：**两个函数**——去路（P → P）和回路（P → P）。

**↔ 的证据 = 一对函数：去路 + 回路。**它不是新结构，是配对的又一次出场：`P ↔ Q` 就是"（P → Q）∧（Q → P）"的简写——第 4 课你学会的配对，现在装的是一对函数。

## 课文 6.2（当且仅当定理：交换律）

现在证明一个真正的数学定理：

> **"P 且 Q"当且仅当"Q 且 P"**（合取的交换律）

```lean
example {P Q : Prop} : (P ∧ Q) ↔ (Q ∧ P) := by
  constructor
  -- ①：拆成两个方向
  · intro h
    rcases h with ⟨hp, hq⟩
    exact ⟨hq, hp⟩
  · intro h
    rcases h with ⟨hq, hp⟩
    exact ⟨hp, hq⟩
```

| 位置 | 代码 | 含义 |
|------|------|------|
| ① | `constructor` | 拆成两个子目标：去路、回路 |
| ② | 第一个 `·` | 去路：P∧Q → Q∧P（拆、换位、重装） |
| ③ | 第二个 `·` | 回路：Q∧P → P∧Q（同一个动作） |

**注意两个方向的关系：回路就是去路照镜子。**`⟨hp, hq⟩ → ⟨hq, hp⟩`，去路把证据换位，回路再换回来。这就是交换律的全部内容——**不是知识，是一个动作做了两遍。**

## 课文 6.3（使用等价：h.1 去路、h.2 回路）

假设你手里有一个等价的证据 `h : (P ∧ Q) ↔ (Q ∧ P)`，怎么用它？

```lean
-- h.1：去路（P∧Q → Q∧P）；h.2：回路（Q∧P → P∧Q）
example {P Q : Prop} (h : (P ∧ Q) ↔ (Q ∧ P)) : P ∧ Q → Q ∧ P := h.1
```

和第 4 课 `h.1`/`h.2` 完全一样——**配对的第一、第二分量**。等价不是一个神秘符号，是一个可以拆开的包裹，拆开就是两个函数。

## 词汇表

| 符号 | 读法 | 含义 | 类比 |
|------|------|------|------|
| `P ↔ Q` | "P 当且仅当 Q" | 双向蕴含：去路 + 回路 | 双向隧道 |
| `constructor` | "构造" | 拆出两个方向（↔ 的拆包） | 开双向门 |
| `h.1` / `h.2` | "去路/回路" | 取等价的两个方向 | 隧道两个口 |
| `Iff.intro` | "等价引入" | ⟨去路, 回路⟩ 的学名 | 命名双函数对 |

## 语法点：等价 = 双向函数对

把前六课的结构放进一张表，你会有种"全都见过"的感觉：

| 符号 | 类型论真身 | 证据 = |
|------|-----------|--------|
| `P → Q` | 函数类型 | 一个函数 |
| `P ∧ Q` | 积类型 | 一个配对 |
| `P ∨ Q` | 和类型 | 一个选择（带标记） |
| `P ↔ Q` | 双向函数对 | **一个双函数包**（= 积类型的又一次出场） |
| `¬ P` | `P → False` | 到空房间的函数 |
| `∀ n, P n` | 依赖函数 | 一台机器 |
| `∃ n, P n` | 依赖对 | 一个包裹 |

**类型论的恐怖与美丽在于：就这几种结构，反复出现。**学到这里，你已经握有逻辑的全部积木——下一课开始，我们离开"逻辑"本身，进入它真正的威力所在：**自然数**。

## 练习

**练习 1 · 翻译**：把"P 或 Q 当且仅当 Q 或 P"写成 Lean 证明（或的交换律——注意每个方向都要分两种情况）：

<details>
<summary>答案：</summary>

```lean
example {P Q : Prop} : (P ∨ Q) ↔ (Q ∨ P) := by
  constructor
  · intro h
    rcases h with hp | hq
    · exact Or.inr hp
    · exact Or.inl hq
  · intro h
    rcases h with hq | hp
    · exact Or.inr hq
    · exact Or.inl hp
```

每个方向都要分两种情况（或 = 选择），一共四条路，每条都要走通——这就是"或的交换律"比"且的交换律"长一倍的原因。
</details>

**练习 2 · 仿写**：课文 6.3 的镜像——用 `h.2` 走回路：

<details>
<summary>答案：</summary>

```lean
example {P Q : Prop} (h : (P ∧ Q) ↔ (Q ∧ P)) : Q ∧ P → P ∧ Q := h.2
```

</details>

**练习 3 · 改错**：下面这段要证明交换律，会报错。错在哪？

```lean
example {P Q : Prop} : (P ∧ Q) ↔ (Q ∧ P) := by
  constructor
  · intro h
    rcases h with ⟨hp, hq⟩
    exact ⟨hq, hp⟩
  · intro h
    rcases h with ⟨hq, hp⟩
    exact ⟨hq, hp⟩
```

<details>
<summary>答案：</summary>

第二方向错了：要求证明 `P ∧ Q`，但 `⟨hq, hp⟩` 给的是 `Q ∧ P`——证据放反了（`And.intro` 的第一个参数需要 P，却收到了 Q）。
**回路的正确写法是 `⟨hp, hq⟩`（换回来）。**交换律的两个方向不是重复，是彼此相反——写反一个，机器立刻报错。
</details>

## 总结

- `↔` = 双向函数对：`⟨去路, 回路⟩`，`constructor` 拆开，`h.1`/`h.2` 使用
- 等价不是新结构，是配对装了两个函数
- 逻辑七件套已齐：→ ∧ ∨ ↔ ¬ ∀ ∃——都是 2-3 种数据结构的变体
