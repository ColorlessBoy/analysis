## 热身（复习旧词）

用第 7 课的词汇，证明"每个自然数 n 都有 0 ≤ n"（归纳版）：

<details>
<summary>答案：</summary>

```lean
example : ∀ n : ℕ, 0 ≤ n := by
  intro n
  induction n with
  | zero => omega
  | succ n ih => omega
```

</details>

回顾：归纳是证明的阶梯（基例 + 递推）。今天看它的孪生兄弟。

## 课文 8.1（逐行注释版：定义翻倍）

第 7 课证明了"所有自然数满足性质 P"。这一课定义"对每个自然数都有定义"的函数——**double（翻倍）**：

```lean
def double (n : ℕ) : ℕ :=
  match n with
  | 0 => 0
  | k + 1 => double k + 2
--    ①      ②          ③
```

| 位置 | 代码 | 含义 |
|------|------|------|
| ① | `match n with` | 按 n 的形状分情况（和 induction 同款开关） |
| ② | `\| 0 => 0` | **基例**：double 0 = 0 |
| ③ | `\| k + 1 => double k + 2` | **递推**：double (k+1) = double k + 2 |

**和归纳一模一样的骨架**：先处理 zero，再处理 succ（这里叫 k+1）。区别只有一个：归纳**证明**性质，递归**定义**值。

机器怎么知道这个定义是合法的？——**因为它"变短了"**：`double k` 的参数 k 比 k+1 小。机器检查每一条递归都朝着 zero 递减，永远有终点。这叫声**终止性检查**（termination checking）——不允许你定义"double n = double n + 1"这种自噬的函数。

用一下：

```lean
-- double 3 = double 2 + 2 = double 1 + 4 = double 0 + 6 = 0 + 6 = 6
example : double 3 = 6 := rfl
```

`rfl`（定义等价）直接把 double 3 一步步算成 6——**递归函数是能算的，机器当场算给你看。**

## 课文 8.2（定义加法：你自己的 +）

第 7 课的 `n + 0 = n` 里的 `+`，其实是 Lean 标准库里**用同样的方式定义的**。现在我们自己造一个加号，看看它到底长什么样：

```lean
def myAdd (m n : ℕ) : ℕ :=
  match m with
  | 0 => n
  | k + 1 => myAdd k n + 1
```

读一下：myAdd 0 n = n（加零等于没加）；myAdd (k+1) n = (myAdd k n) + 1（多一个 k，结果多 1）。

```lean
example : myAdd 2 3 = 5 := rfl
-- myAdd 2 3 = myAdd 1 3 + 1 = (myAdd 0 3 + 1) + 1 = (3 + 1) + 1 = 5
```

**你在这一课里亲手造出了自然数加法**——陶哲轩《实分析》第 2 章做的事（定义加法、证明交换律），你现在已经能看懂了。这就是"从零开始"的真相：**不是记住 +，是造出 +。**

## 课文 8.3（证明自己定义的函数的性质）

定义完函数，数学家的职业病来了：证明它是对的。比如——**double 是加法意义上的翻倍**：double n = n + n。

```lean
example : ∀ n : ℕ, double n = n + n := by
  intro n
  induction n with
  | zero => rfl
  | succ n ih =>
      calc
        double (n + 1) = double n + 2 := rfl
        _ = (n + n) + 2 := by rw [ih]
        _ = (n + 1) + (n + 1) := by omega
```

| 位置 | 代码 | 含义 |
|------|------|------|
| ① | `double (n + 1) = double n + 2 := rfl` | 展开递归定义（机器算的） |
| ② | `rw [ih]` | 用归纳假设：double n = n + n |
| ③ | `omega` | 收尾算术 |

**归纳证明你的递归定义**——定义用递归（第 8 课的技能），证明用归纳（第 7 课的技能）。**递归和归纳是同一个结构的两个方向：向下造值，向上证性质。**这一对，就是数学构造论的全部发动机。

## 词汇表

| 符号 | 读法 | 含义 | 类比 |
|------|------|------|------|
| `def` | "定义" | 定义一个新函数 | 造词 |
| `match n with` | "按形状分情况" | 递归定义的开关 | 分类抽屉 |
| `\| k + 1 => ...` | "后继情况" | 递推分支（参数变短） | 下一级台阶 |
| `rfl` | "重写" | 定义等价：展开递归当场计算 | 展开计算 |
| 终止性检查 | — | 机器保证递归必然终止 | 楼梯有底 |

## 语法点：递归 = 归纳的对偶

| | 归纳（第 7 课） | 递归（第 8 课） |
|--|-----------------|----------------|
| 方向 | 向上：证明性质 | 向下：构造值 |
| 基例 | `\| zero => 证 P 0` | `\| 0 => 给出值` |
| 递推 | `\| succ n ih => 用 ih 证 P(n+1)` | `\| k+1 => 用 f k 算 f(k+1)` |
| 机器检查 | 两步都通过 | 每步参数变小（终止） |

**一个类型（自然数）的构造方式（zero / succ）同时决定了：**怎么证明关于它的事（归纳）、怎么定义作用在它上面的函数（递归）。这就是第 7 课"类型的构造方式定义了一切"的完整版——**构造 → 归纳 → 递归，三者一体。**

## 练习

**练习 1 · 翻译**：定义函数 `triple`（三倍）：基例 triple 0 = 0，递推 triple (k+1) = triple k + 3：

<details>
<summary>答案：</summary>

```lean
def triple (n : ℕ) : ℕ :=
  match n with
  | 0 => 0
  | k + 1 => triple k + 3
```

</details>

**练习 2 · 仿写**：定义自己的乘号 `myMul`（提示：用 myAdd——myMul 0 n = 0；myMul (k+1) n = myAdd (myMul k n) n）：

<details>
<summary>答案：</summary>

```lean
def myMul (m n : ℕ) : ℕ :=
  match m with
  | 0 => 0
  | k + 1 => myAdd (myMul k n) n
```

</details>

**练习 3 · 改错**：下面这个定义会报错。为什么？

```lean
def bad (n : ℕ) : ℕ :=
  match n with
  | 0 => 0
  | k + 1 => bad (k + 1) + 1
```

<details>
<summary>答案：</summary>

终止性检查失败：`bad (k+1)` 的参数是 k+1，**没有变小**——递归调用自己给自己加一，机器会无限循环。机器拒绝："这条路没有终点。"（错误信息里会有 termination / decreases 字样。）
</details>

## 总结

- 递归 = 归纳的对偶：`match` 分情况，参数变小保证终止
- `def` 造函数，`rfl` 当场展开计算
- 你可以自己造出 +、×——从零开始不是比喻
- 递归 + 归纳 = 定义与证明的完整闭环
