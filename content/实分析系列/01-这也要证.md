今天我们就来围观一道这样的题。它"显然"到像个笑话，但它让 90% 的人第一次都写错。它是陶哲轩《实分析》习题 4.4.1。

## 题目

> **Proposition 4.4.1（有理数中的整数夹逼）/ 习题 4.4.1**
> 对任意有理数 x，存在唯一的整数 n，使得
> $$n \le x < n+1$$

翻译成人话：**每个有理数都卡在两个相邻整数之间，而且夹它的那个整数是唯一的**。

比如 x = 3.7，n = 3（因为 3 ≤ 3.7 < 4）。x = -2.3，n = -3（因为 -3 ≤ -2.3 < -2——注意，这里就有人错了，四舍五入的直觉会说 n = -2，但 -2 ≤ -2.3 是假的）。

"这不就是取整吗？"你说。"小学生都会。"

对。但注意题目里那个词：**存在且唯一**。它要求你证明两件事：① 这样的 n 一定存在；② 只有一个。

## 思路：为什么这道题坑人

大部分人第一次做这道题，会写："取 n = ⌊x⌋。"然后结束。

问题是：**⌊x⌋ 是什么？**在严格数学里，你不能用一个没定义的东西去证明另一个东西的存在。取整函数本身依赖"每个数都有唯一的整数夹逼"——你正在证明的东西。这就是循环论证，而且是那种一眼看不出来的循环。

正确思路分两步，每一步都朴素得让人生气：

1. **存在性**：把 x 写成最简分数 p/q（q > 0）。做带余除法 p = q·n + r，其中 0 ≤ r < q。于是 x = n + r/q，且 0 ≤ r/q < 1，所以 n ≤ x < n+1。**存在性来自除法**，不是来自直觉。
2. **唯一性**：假设 m 和 n 都满足条件，那么 n ≤ x < n+1 且 m ≤ x < m+1，两个整数都在一个长度为 1 的半开区间里，所以 |n - m| < 1，整数之间距离小于 1 只能是 0，故 m = n。

就这两步。没有任何技巧。难的地方在于：**你愿不愿意承认"显然"不是证明**。

## 完整证明

> 证明（文字版）：

设 x = p/q 为最简分数，q > 0。由带余除法，存在唯一的整数 n 与余数 r 使
p = qn + r，0 ≤ r < q。

于是 x = p/q = n + r/q。因为 0 ≤ r/q < 1，所以 n ≤ x < n+1，存在性得证。

若 m 也满足 m ≤ x < m+1，则 n ≤ x < n+1 与 m ≤ x < m+1 同时成立，故
n - m ≤ x - m < 1 且 m - n ≤ x - n < 1，于是 |n - m| < 1。两个整数之差的绝对值小于 1，只能是 0，故 m = n。唯一性得证。∎

## 「机器验证」是什么意思

这不是修辞。这段证明不是"我检查过了"或"我觉着对"——它被一个**检查器**（Lean 的内核）逐行验证：每一个推理步骤都必须精确匹配逻辑规则，任何一步错了，整个证明被拒绝。你可以把 Lean 内核理解成一个**永远不会累、永远不会不耐烦、永远不会相信你"显然"的助教**。
