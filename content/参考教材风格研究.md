## 一、陶哲轩《实分析》的五个教学动作（逐字证据）

### 1. 以问题轰炸开篇，不以定义开篇（Ch 1.1）

陶哲轩开篇不给定义，给一串"你会吗？"的问题：

> What is a function? What does it mean for a function to be continuous? … If a function f(x) takes the value 3 when x = 0 and 5 when x = 1, does it have to take every intermediate value? **Why?**

**模式：先用一连串"你以为会但其实不会"的问题，让读者承认"我不会"——然后教材才值得开始。**

### 2. 反例轰炸建立必要性（Ch 1.2 "Why Do Analysis?"）

陶哲轩先自问"why bother?"，然后连发四个灾难反例：

- 除以零：`1×0 = 2×0` 盲目约分 → 1 = 2
- 无穷级数：`1+2+4+8+…` 用几何级数同一招 → `S = -1`
- 摇摆级数：`1-1+1-1+…` 三种合法括号 → ½、0、1 三个答案
- 极限：变量代换推出 `sin x → 0`、`cos x → 0`，平方相加 → **1 = 0**

每个反例的收尾都是同一句话的变体：**"哪里错了？（见习题 X）"——悬念留给读者。**

**模式：先让读者亲眼看"盲目信任规则"的灾难，再讲严谨的必要性。论证"为什么需要"，用的是反例，不是口号。**

### 3. "遗忘已知"宣言（Ch 2 开篇）

进入自然数之前，陶哲轩有一段著名的"弃权声明"：

> try to set aside, for the moment, everything you know about the natural numbers; forget that you know how to count, to add, to multiply… This may seem like an **irritating constraint**, especially as we will spend a lot of time proving statements which are **"obvious"**, but it is necessary to do this suspension of known facts **to avoid circularity**.

**模式：作者主动承认"这样学很烦、很慢、要证明显然的东西"，然后给出正当性（防循环论证）。**这段"道歉+辩护"是全书最有效的段落之一——读者被事先告知"接下来会难受，但难受是有原因的"。

### 4. "显然"要证是设计原则（Preface）

> I would strongly recommend that one do as many of these exercises as possible—and this includes those exercises proving "obvious" statements—if one wishes to use this text to learn real analysis.

**模式：教材作者亲自为"证明显然"背书——这正是我们《实分析精讲》系列和 Lean 系列的共同论题。**

### 5. 第一人称 + 承认过程代价（贯穿）

> I will have to ask you to perform a rather difficult task…

**模式：作者直接对读者说话、承认任务艰难、把自己放在读者一边。不是裁判腔，是领队腔。**

## 二、类型论教材的风格（MIL / HoTT，PDF 已下载并逐字提取）

### Mathematics in Lean（Avigad & Massot）——五条可借鉴

1. **第一句就是目标宣言**："The goal of this book is to teach you to formalize mathematics… It assumes that you know some mathematics, but it does not require much."
2. **三级别框架（全书 1.2 节的开篇教学法）**：用 #check 一口气展示三层——数学对象（`2+2 : ℕ`）、数学陈述（`2+2=4 : Prop`）、证明（`rfl : 2+2=4`，即"类型为 P 且 P : Prop 的表达式"）——最后用费马大定理做压轴："如果你能构造出类型为 FermatLastTheorem 的表达式…你做了件非常了不起的事。"
3. **游戏宣言**："(Using sorry is cheating, and Lean knows it.) So now you know the game. All that is left to learn is the rules."——**把学 Lean 定义为"知道规则前先知道游戏"**。
4. **sorry 幽默**："Using sorry is cheating, and Lean knows it."——严肃中的幽默，人感来源之一。
5. **洗碗机类比**（说 TPIL 适合"喜欢先读完整本说明书再用洗碗机的人"；MIL 适合"喜欢直接按启动按钮的人"）。

### HoTT Book（Univalent Foundations Program）——三条可借鉴

1. **术语精确**：明确区分 `a : A`（term 有类型 A）与命题的证明——并特意声明**尽量不用"proof of A"而用 witness/evidence**，避免混淆。"When A is a type representing a proposition, then a may be called a witness… (or even a proof of A, but we will try to avoid this confusing terminology)."——**验证了我们全程使用"证据"而非"证明"的术语选择。**
2. **判断与命题的区分**：`a : A`（判断，元层）vs `A`（命题，理论内部）——第一性逻辑只有"命题有证明"一种判断；类型论在此基础上加了"定义相等"（`a ≡ b : A`）。
3. **定义相等的直觉例子**：`32 = 9` 的证据 p 自动也是 `f(3) = 9` 的证据（因为 f(3) 按定义就是 3²）——**这解释了 `rfl` 为什么有用**（第 8 课素材）。

## 三、综合出的 7 条写作规则（应用于本系列）

| # | 规则 | 陶哲轩的证据 | 应用到哪 |
|---|------|-------------|---------|
| 1 | **以问题开篇**：一串"你以为会但其实不会"的问题，让读者承认"我不会" | Ch 1.1 问题轰炸 | 每课开场钩子升级为"问题轰炸" |
| 2 | **反例轰炸建立必要性**：先看灾难，再讲严谨 | Ch 1.2 四个反例 | 第 1 课开场（1=2、S=-1、1=0 三连） |
| 3 | **"遗忘已知"宣言**：事先道歉"接下来很烦很慢"，并给正当性 | Ch 2 开篇 | 第 1 课（"请暂时忘掉'显然'"） |
| 4 | **悬念留给读者**：反例收尾"哪里错了？"不代答 | Ch 1.2 各例 | 练习设计（我们已符合，需加强"不代答"） |
| 5 | **作者领队腔**：第一人称、承认任务艰难、站在读者一边 | "I will have to ask you…" | 作者注升级：对读者说话，不对读者说教 |
| 6 | **为"慢"辩护**：证明显然的东西值得，作者背书 | Preface | 全系列基调（"这也要证"正是陶哲轩自己说的） |
| 7 | **篇幅 = 耐心的可见形式**：一个概念愿意写两页解释"为什么慢值得" | Ch 2 开篇整段 | 每课 200-300 行（含作者注与阅读框） |
