# 双系列内容企划：《证明的机器》

> 状态：创作中（全部完稿后统一发布，不逐篇发布）
> 主阵地：知乎（SEO：标题带题号）+ 公众号/小红书图文节选
> 节奏：每周 2 篇（两系列交错），全部 22 篇完稿后开始发布

## 核心定位（一句话）

**所有答案被机器验证过的数学学习内容**——别人做不到的正确性背书。

## 价值优先原则（2026-08 定调）

**不追求变现，先提供价值。** 商业化设计（定价、会员、徽章）全部降级为"如果做成了再想"；产品的北极星是：让更多人体验"原来如此"的瞬间、让每个答案经得起检查、让数学对大众成为真实的情绪价值。**价值本身会找到它的回报**——这句话不是逃避商业，是把优先级摆正：内容先真实，回报后自然。

## 北极星：类型思维（愿景层，不改变近期执行）

段永平讲"做对的事情，把事情做对"；胖东来把"爱"变成制度。用类型论的语言翻译，它们是一回事：

| 正道词汇 | 类型论翻译 | 在内容里的体现 |
|---------|-----------|---------------|
| 做对的事情 | 命题选择（spec 对不对） | 每篇只讲真正重要的题，不追热点 |
| 把事情做对 | 证明（每一步可验证） | 机器验证答案 |
| 本分 | 不写"显然"，承认边界 | Mathlib 墙篇、从零地图篇 |
| 品质/真诚 | 把"好"变成可检查的规格 | 文章可复制、可自己跑、可证伪 |

**长期愿景**：让"类型思维"（说清楚、可验证、不糊弄）成为社会化的实用指导——各行各业的读者用它把工作做好：产品经理把需求写成可验证的规格，销售不承诺验证不了的事，管理者把"好"定义成可检查的标准。

**诚实的边界（形式化的能力边界，不越界承诺）**：形式化管的是**规则层**的正确性——证明、规格、协议、软件逻辑、合同条款；管不了**物理层**的经验性——材料、工艺、复杂环境中的涌现行为。光刻机、火箭、GPU 的难在后者：物理极限 + 几十年试错积累的经验知识，不是可证明的逻辑。如果形式化能建模复杂系统，AI 早就能自己造光刻机了。所以《类型思维》系列只承诺规则层：**帮你把"说话、承诺、需求、流程"这些信息层的工作做对**，不碰物理工程层。诚实的边界比夸大的承诺更可信——这也是"本分"。

**这不是营销话术，是内容必须亲证的价值观**：不骗点击（钩子来自真诚的场景，不来自夸大）、答案可验证、诚实面对缺陷。情绪价值 = 开场的真实故事，不是标题党的引诱——这是与"正道"唯一不冲突的钩子设计。

**内容分层**：
- 现在：系列 1（逻辑入门）+ 系列 2（实分析精讲）——数学学习者
- 中期：每日一题——开窍人群
- 远期：《类型思维》系列——把类型论的精确翻译到产品/销售/管理（"如果你的交付能被机器检查，你会怎么说话"）

## 单篇文章模板（统一格式）

```
标题: 《实分析》习题 X.Y.Z：一句话思路 + 机器验证证明
├─ 开场（情绪钩子：场景/故事/数据，1-2 段）
├─ 题目（原书陈述 + 为什么它坑人）
├─ 一句话提示（折叠）
├─ 思路：为什么这么做（折叠）
├─ 完整证明：文字数学证明 + Lean 代码块（可复制）
├─ 「机器验证」说明（这一步怎么被检查的 + 读者如何自己跑）
└─ 结尾钩子（下篇预告 + 互动问题："你在这本书哪题崩溃过？"）
```

## 情绪价值设计原则

1. **开场必是场景**：崩溃瞬间/顿悟瞬间/名人故事（素材库：B站 1273 赞评论、菲尔兹奖得主推翻自己证明、豆瓣 9.4 分、知乎 14.3 万浏览"自学难度"）
2. **每个"震撼点"一句话能说完**（如上表）
3. **结尾必有互动问题**——每篇文章 = 一道题的讨论串，这是"公开课病"的解药
4. **诚实是情绪的一部分**：Mathlib 墙篇、从零地图篇不回避问题，反而建立信任

## 第三层受众：开窍人群（每日一题形态）

逻辑题本身能吸引"开窍"的人——像数独、每日一题那样自带传播性。这类人不一定要学实分析，他们要的是**顿悟瞬间**（"哦——原来是这样！"）。

| 受众层 | 内容 | 规模 | 转化路径 |
|--------|------|------|---------|
| 开窍人群 | Lean 逻辑题（每日一题） | 大（数独人群） | 上瘾 → 好奇"证明" → 学 Lean 入门 |
| 新手池 | 系列 1（逻辑入门） | 中 | 学完 → 进入实分析 |
| 学习者 | 系列 2（实分析精讲） | 小但精准 | 留存 + 付费 |

**每日一题格式**：每天一道小逻辑题（如 `P → P → P` 变体、短路合取、`¬¬P` 系列），答案明天揭晓 + 机器验证。平台：知乎专栏/公众号/小红书日更，数据好的周更精讲。

## 运维策略：为什么它不会变成垃圾场（关键决策）

**"缺运维 → 题目垃圾场"是每日一题模式的经典死法。对策：把运维做成自动化，把治理做成规则。**

1. **内容供给自动化**：题目从仓库自动提取（124+ 习题 + 游戏关卡 + Mathlib 事实），AI 生成题目变体 → 人周审。日更的边际成本趋近于零——这是传统每日一题站做不到的
2. **判题自动化**：答案提交用 Lean 内核自动检查（LeetCode judge 模式）——运维里最贵的人力环节消失
3. **难度自动标定**：隐藏资产——`/Users/penglingwei/Documents/lean/analysis/.agents/experience/db.json` 记录了每道题形式化时的失败次数，**这就是机器测量的难度数据**（别的站只能用人工主观评级）。每日一题按难度桶自动排期
4. **垃圾场治理规则**：只保留三种内容形态（每日一题 / 每周精讲 / 每季企划），**不聚合、不转载、不投稿**——内容少而可控，宁缺毋滥。超出形态的一律不发布
5. **社区运维半自动**：自动化打卡/连击（streak）机制 + 每周一次直播答疑（人只做这一件重事）

## 情绪价值分类学（核心洞察：数学对大众是情绪产品）

**面向非专业化数学爱好者：数学对大部分人来说，应该是一种提供情绪价值的产品**——像音乐、游戏、美食一样。不是"学习工具"，是"体验"。受众是数学的**观众**（乐迷、影迷），不是**演员**（从业者）。你不需要会拉小提琴才能爱音乐；不需要做数学研究才能爱数学。

| 情绪价值 | 数学里的样子 | 内容体现 |
|---------|-------------|---------|
| 顿悟感 | "原来是这样！"开窍瞬间 | 每篇的震撼点（上确界为什么"漏"） |
| 审美感 | 优雅证明、意外联系（数学之美） | 精讲里"这个证明漂亮在哪" |
| 征服感 | 刷完裴礼文、证出难题 | 每日一题 + 连击/成就 |
| 共鸣感 | "艹，这也要证？"（1273 赞） | 崩溃瞬间内容、评论区互诉 |
| 秩序感 | 精确思维的平静（数学如禅） | 类型思维系列的调性 |
| 身份感 | "我是喜欢数学的人" | 社区、粉丝群、徽章 |
| 仪式感 | 每日一题、打卡、连击 | Wordle 式日常仪式 |

**情绪的诚实分级（核心原则：两种情绪价值，只卖一种）**：

> 没有人会在意你学会了某本老数学书里的经典题目——它们不是世界级未解难题；即使是，解出来对世界也未必有什么正向作用。"以为很了不起"本质上是错觉。所以：

| 类型 | 情绪 | 特征 | 判例 |
|------|------|------|------|
| **脆弱的情绪**（错觉，不卖） | 征服/优越/身份：解出题 = 我很了不起 | 依赖他人认可，经不起追问（"然后呢？"），会塌 | "学数学让你更聪明""超越同龄人""数学精英" |
| **稳健的情绪**（真实，只卖这个） | 顿悟/审美/共鸣/秩序/仪式 | 自足：不需要观众，不需要"了不起"的背书 | "原来如此"的瞬间、证明的美、共享的崩溃与开窍 |

**话术原则**：征服感重新定义为"战胜自己的困惑"（自足），不是"超越别人"（依赖比较）；身份感重新定义为"我是一个享受思考的人"，不是"我是一个聪明的人"。**每条内容过审时问一句：这个钩子卖的是哪种情绪？脆弱的，删。**

**拉布布原则（情绪价值的自尊）**：情绪价值有它自己的意义，不需要功利背书。拉布布如果是个 U 盘就完蛋了——套上"有用"的外壳，情绪产品就死了。同理：**永远不用"学这个有用"给内容找理由**（功利框架一出现，"这有什么用"的追问就出现，浪费感随之而来）。内容就是体验本身：顿悟、美感、共鸣、仪式——它们不需要 justify，就像盲盒不需要 justify。

**反浪费设计（"浪费"是一种负面情绪价值，必须从产品里驱逐）**：

| 浪费感的来源 | 反浪费设计 |
|-------------|-----------|
| 看 2 小时视频什么也没记住 | 文字优先（可检索、可定位），单篇 5-10 分钟读完 |
| 买了本书看 20 页弃了 | 免费内容为主，付费只卖仪式（低单价高频，盲盒式） |
| 学了没用的知识（功利愧疚） | 不承诺"有用"，只承诺体验（拉布布原则） |
| 白学错了（最贵的浪费） | 机器验证：学到的每一步都是对的 |
| 追更追到一半坑了（"更新到第 7 章"） | **全部完稿再发布**——系列完整性是反浪费承诺 |
| 收藏夹吃灰 | 每日一题 = 5 分钟完整闭环，单次交付完整情绪 |

**定价启示**：情绪产品按情绪定价（低单价、高频、仪式感——盲盒 ¥59 一个），不按效用定价（高价课程）。会员/徽章/连击 = 情绪定价的产品化。

**机器的意义在这里第三次升维**：卖假顿悟 = 卖假货。机器验证 = 情绪产品的**保真承诺**——胖东来质检他的货，我们质检我们的顿悟：每一份"原来如此"都经得起检查。这是情绪价值能被诚实交付的基础设施。

**内容设计随之改变**：每篇不再只是"讲题"，而是设计一条**情绪弧线**——悬念（这题怎么坑人）→ 紧张（你自己先想）→ 顿悟（展开提示）→ 奖赏（机器验证的完整证明）→ 共鸣（评论区分享崩溃/开窍瞬间）。题目是关卡，情绪弧线才是产品。

**正道的边界（情绪价值必须被真实内容挣得）**：
- 伪顿悟 = 情绪欺诈——靠"听起来对"的直觉骗你爽一下，细看是错的
- 机器验证的意义在这里升维：**它是情绪的诚实保障**。我们的顿悟经得起检查，别人的可能经不起
- 不贩卖焦虑（"别人都在学，你呢"）、不制造伪顿悟、不情绪剥削——胖东来式的体验：情绪是真的，服务是真的

## AI 层：永不撒谎的教练（产品规划的核心）

**架构红线（从第一天起）：AI 永远不判对错，内核判。** AI 幻觉 = 品牌自杀。市面上 AI 助教靠"听起来对"取信于人；我们的 AI 靠"被验证过"取信于人——这是唯一可防御的定位，也是"本分"在 AI 时代的翻译：不吹牛、承认边界、永远可以被检查。

**分工**：AI 负责共情、表达、个性化；Lean 内核负责真相；产品负责不撒谎。

**三阶段 AI 产品线**：

| 阶段 | 形态 | 用户价值 |
|------|------|---------|
| 现在（内容期） | AI = 制作引擎（初稿、素材、每日一题变体）；每篇 Lean 代码块可在线运行 | 第一次体验"有错误信息的数学" |
| 内容跑通后（互动期） | **AI 陪练**：读者提交证明草稿 → AI 引导思路 → Lean 内核判题 → AI 讲解错误。闭环："提交 → 内核检查 → AI 解释" | 直击调研第一大痛点："不再以为自己做对了" |
| 远期（大众期） | **类型思维教练**：AI 帮用户把工作语言规格化（需求、承诺、标准），"你的承诺能被检查吗"成为日常习惯 | 胖东来模式 × AI：小老板也能把自己的"爱"变成制度 |

**为什么这带来"极大的人生价值"**：内容是一次性消费，教练改变行为数年。人生价值的本质是**行为改变**——从"以为自己做对了"到"每一步都被检查"；从"凭感觉做事"到"把话说清楚再做事"。这是从内容产品升维到服务。

**素材积累**：每篇文章的互动问题 + 评论区 = 陪练的训练数据与需求样本——内容期就在为互动期铺路。

**顺序纪律**：不在受众出现前建教练。内容先验证需求，陪练在评论区有真实提问后上线（每篇的互动问题就是需求探测器）。
