# 每日一题盲盒 · 第一周（原型）

> 机制：每天 8:00 发正面题卡（悬念），20:00 发揭晓卡（机器验证答案）。
> 稀有度：普通 = 共鸣类（"这也要证？"）；稀有 = 一个关键技巧；传说 = 世界观级震撼。
> 一周 7 张 = 一套，收藏册进度随揭晓更新。全套完更 = 反浪费承诺。

## 发布规则

1. 每天 2 条笔记：早 8:00 题卡（悬念），晚 20:00 揭晓卡
2. 揭晓卡末尾带收藏册进度（1/7、2/7…）+ 明天预告
3. 每题都附 Lean Web 链接（零安装可验证）——"我们的盲盒不会开出假货"
4. 互动钩子固定在题卡末尾：你猜答案是什么？/ 你第一次写对了吗？
5. 周日下午发"本周合集"（7 张一屏），完成一个收藏册周期
